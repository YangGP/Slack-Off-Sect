# 后期研究与供能：待测事项及未实施方案

更新：2026-10-14。本文只维护仍待评估的事项与未实施方案。当前分组、前置及运行规则见 [RESEARCH.md](RESEARCH.md)、[DESIGN.md](DESIGN.md)；现行费用与效果见 [TABLES.md](TABLES.md)，世界观见 [SPIRIT-ENERGY.md](SPIRIT-ENERGY.md)。

## 变更 2–4：待测清单

修真应用、后期研究调整和建筑三态供能已实施，后续需要：

- 核对四座原理建筑与精研的重复收益，再决定是否设置叠加上限。
- 现有粒子研究与供能已做首轮校准；后续继续比较不同建设规模、祭炼等级、加工负荷与上线频率，避免只用固定夹具判断平衡。实际配置以 TABLES 为准。
- 评估大乘心经多产业增益和心印独立收费的价值。
- 复查因果池研究的灵机仓容承接路径，以及因果前置对重置收益和首飞节奏的影响。
- 如新增独立湮灭启动费用，需重新验证首启和恢复；当前控制用能从毛输出扣减，不另收启动费用。
- 评估缺供分配、自动备用，以及飞升预览中因果池有效收益的显示。
- 对比建筑扩建、灵能枢、加工驱动、灵能引采和飞升阵印之间的灵能竞争。
- 完整产线的零库存首启、断供恢复、停用、容量保留与在线／离线一致性已有回归；继续扩展长时经营、重修和不同旧档的组合场景。

住房名额、实体仓储与已锚定的洞天空间在停用或断供时保留；主动收益按运行模式与实际供给缩放。四座原理建筑保留早期启动职责，不自动增加灵能维护。完整运行规则以 DESIGN 为准。

## 变更 5：仙灵力（方向已定，未实施）

**已定定位**：炼虚后即可发现，作为飞升前最后一种基础材料参与后期发展。它属于本世可积累、可消耗的物资；形成稳定结构、不逸散。具体获取方式、费用与数量尚待设计。

仙灵力不能只作为渡劫前才开放的一项筹备材料。它应连接研究、建筑、法宝与加工，再进入飞升准备；各用途分阶段引入，不要求所有后期条目都消耗它。

**设定**：灵气分子吸收灵能，聚合为稳定的高阶结构。灵能既是输入之力，也有一部分被固结在产物中；具体催化、供能与物料消耗需分别记账。能源产业与仙灵材料产业是两条相连的分支，不用单条“形态阶梯”代替全部关系。

| 阶段 | 建议发展节奏 | 状态 |
| --- | --- | --- |
| 炼虚 | 发现、研究并建立有限的初期获取途径，接入首批后期用途 | 发现阶段已定；首次获取方式待定 |
| 合体 | 利用受控湮灭的灵能建立稳定仙灵力产线，支持后期设施与材料加工 | 量产阶段与配方为建议，待校准 |
| 大乘 | 扩大仙灵材料应用，发展高阶建筑、法宝及飞升工程 | 具体条目待设计 |
| 渡劫 | 将已有仙灵产业用于突破、护道与成道准备 | 具体费用待设计 |

**与飞升阵印的分工**：仙灵力是可用于多种工程与修行的基础投入；飞升阵印是构建飞升通道的专用加工品。是否把仙灵力加入阵印配方、替换哪些现有用料，需单独设计，不直接叠加全部新旧费用。

**获取与自举约束**：

- 当前湮灭炉从合体开始提供游戏库存灵能。若仙灵力在炼虚即可实际获取，初期来源须在炼虚可达，不能以尚未开放的湮灭炉为唯一来源。发现与稳定量产可采用不同途径。
- 首个来源、必要研究和首座产出设施不得消耗只能由自身提供的仙灵力；所有费用应由已开放材料与仓容承接。
- 每项强制用途必须晚于其可持续供给。冲炼虚不得要求炼虚之后才发现的材料；冲合体是否采用仙灵力，取决于炼虚初期来源的可达性与产能，尚未定案。
- 量产方案可考虑新增聚仙阵／仙灵池，以分子和灵能连续生产；设施的基础运行也必须支付必要的灵能投入，不能用灵气档绕过固结所需能量。

**待确定**：首次发现与获取方式、量产阶段、资源 id、容量与整数规则、产速和用料；首批研究／建设／加工用途；阵印与突破费用的替换关系；旧档的发现、解锁与自动加工兼容。新增资源不能预先断言无需迁移，应按最终接入方式验证。

## 变更 6：灵能反应堆（全局增产方向已定，未实施）

**已定定位**：参考猫国核反应堆，持续消耗灵能，为宗门增加一层额外的全局生产倍率。反应堆可重复建设、可启停，收益随有效运行数量叠加；它与工位加速、特定资源增益分别记账。

“增加一层”指新的生产倍率来源，不是只结算一次的奖励。多座反应堆的加成先相加，再作为这一层倍率参与生产；例如每座 +5% 的试调方案中，两座满供为 ×1.10，具体百分比待测。

**收益与消耗边界**：

- 加成面向宗门的持续资源生产，包含后续仙灵力产线；不限定为少数采集或加工设施。
- 反应堆直接消耗的灵能产出不受其自身增产倍率影响，避免燃料直接自增。其他来源的灵能增益继续按各自规则生效，不把灵能排除于全部全局成长。
- 每份手动或自动制作收益、点击、事件奖励、仙缘与道果结算不自动套用这一倍率；如果后续希望扩大范围，须另定义规则和成本。
- 上游分子与灵子增产能间接改善燃料供给，这属于产业反馈；仍需按实际吞吐、燃料、维护与余能测量净收益。
- 停用或断供时减少对应费用与收益；灵能在反应堆、工位驱动、建筑、仙灵力产线和阵印之间的分配应形成经营取舍。

**建筑候选**：独立奇观“灵能反应堆”，id 可沿用草案 spiritReactor。具体解锁境界、研究前置、造价、每座增产及耗能尚待校准，不把先前的大乘门槛和占位数值视作已定规则。指数造价限制扩建速度，不是硬上限；运行规模还须由净供能承接。

**工程建议**：使用可独立展示和排除燃料的反应堆增产字段，或给现有全局增益增加来源级过滤。不要为这一建筑把所有 ratioAll 对灵能一律关闭。实现时同步全局倍率展示、资源来源、费用预览、缺供缩放、启停与审计策略；验证满供、断供、祭炼或其他倍率组合、在线／离线及与仙灵产业争能的表现。

**待确定**：解锁阶段与造价、额外全局倍率、持续耗能、缺供分配；与现有供能及仙灵力产业的投资回报和阶段节奏。全局增产方向保留，具体数值以对照测量决定。

# 破境概率对游戏时间的影响

后续专项评估：[合体前护道准备与失败恢复](BREAKTHROUGH-FOCUS.md)，包含14个控制情景及调参记录。本页保留此前炼虚失败身死率10%的整局随机样本和数学结果；当前炼虚身死率已恢复为10%，但金丹、元婴、化神的失败后身死率新增为1%、2%、3%，历史结果不代表当前完整规则的概率。

评估日期：2026-10-11。对应调整前金丹70%／90%，合体20%／70%，大乘15%／65%，渡劫10%／60%的规则；完整费用见[设计文档](DESIGN.md)。

## 结论

当前设计将护道材料变成后期推进的核心投入。满配可将时间控制在产业发展与少量重试范围内；一直裸冲的退境、身死风险会造成很长的尾部，不能按一次失败损失多少材料简单估算。

固定策略数学模型中，裸冲一世内完成飞升的概率仅2.85%，金丹起满配为73.80%。完成飞升前平均身死次数分别为34.09与0.355。这些是概率与尝试次数的结果，不是小时数；仙缘会加快后续生产，但不直接提高这些策略的突破概率。

## 实际引擎时间样本

从零仙缘、零道果开局，关闭事件，每5秒决策，每60秒主动分配劳动力，优先加工下一境材料。使用真实仓储、制作、支付、减产、退境、身死与仙缘结算；模拟时钟按秒推进。时间为累计游戏运行时长，不是玩家操作时长。

三个模式使用同一产业策略：

- baseline：只在模拟中保证突破成功，支付正常基础费用。
- naked：所有境界不用可选护道材料。
- aided：金丹起使用全部护道材料；引气至筑基保留95%基础概率，不强制发展香火。

| 模式 | 随机种子 | 达到飞升条件 | 退境次数 | 身死次数 |
| --- | --- | --- | --- | --- |
| 必定突破参照 | 2 | 44.579小时 | 0 | 0 |
| 裸冲 | 2 | 64.487小时 | 1 | 1 |
| 裸冲 | 3 | 72小时内未完成，停在合体 | 5 | 0 |
| 满配 | 2 | 59.011小时 | 1 | 0 |
| 满配 | 3 | 44.750小时 | 0 | 0 |

满配两个样本相对参照分别增加0.171小时（0.4%）和14.432小时（32.4%）；裸冲完成样本增加19.908小时（44.7%）。这不是总体均值：概率路径会改变建设投资、研究顺序和材料囤积，额外护道准备也可能与原本的产业建设并行。

seed=3裸冲样本在合体阶段的灵气供给与分灵产线不足，观察期内尚未尝试大乘；72小时未完成不能全部归于突破概率。这也说明当前参照机器人在失败后的生产调整仍有局限，需要将样本时长与数学风险分开阅读。

seed=2满配在56.515小时冲渡劫失败，退回合体；56.517小时重新进入大乘，59.011小时完成渡劫。回境较快是因为其他产业与库存保留，但渡劫投料仍需重做。seed=2裸冲在15.993小时身死，获得16仙缘后重开，最终在64.487小时完成。

样本数量很少，且不含随机事件、主动转世、离线决策间隔或自适应护道策略，不能推广成所有玩家的固定通关时间。初步试跑曾遇到机器人分工与攒料冲突，最终比较统一采用主动分工策略；旧试跑不用于表中结论。

## 重试与回境的数学影响

只考虑某一境失败后仍能原地重试，平均尝试次数是1／成功率：

| 目标境界 | 裸冲 | 满配 |
| --- | ---: | ---: |
| 金丹 | 1.43 | 1.11 |
| 元婴 | 1.67 | 1.18 |
| 化神 | 1.82 | 1.25 |
| 炼虚 | 2.00 | 1.33 |
| 合体 | 5.00 | 1.43 |
| 大乘 | 6.67 | 1.54 |
| 渡劫 | 10.00 | 1.67 |

合体起实际上会退境或身死，因此上表不是整条路线的重做量。用当前状态、成功／失败、退一境、身死回凡体组成吸收马尔可夫链，计算直到达到渡劫的平均尝试次数：

| 指标 | 裸冲 | 金丹起满配 |
| --- | ---: | ---: |
| 一世内完成飞升概率 | 2.85% | 73.80% |
| 成功前平均身死次数 | 34.09 | 0.355 |
| 所有境界累计突破尝试 | 1,155.53 | 19.06 |
| 其中冲击炼虚次数 | 498.33 | 2.85 |
| 其中冲击合体次数 | 297.33 | 2.90 |
| 其中冲击大乘次数 | 66.67 | 2.56 |
| 其中冲击渡劫次数 | 10.00 | 1.67 |

模型假设一直遵循对应护道策略，最终能够备齐材料并继续尝试；不限制观察时间。它计算尝试次数与死亡概率，不模拟资源产能、建设速度、库存损失、决策间隔或重开后的仙缘提速。不能把1,155次尝试直接乘以一个统一准备时间当作实测通关时长。

## 哪些因素真正拖长时间

1. **重做投料**：失败消耗全部基础与护道材料，后期高级加工品影响最大。
2. **退境回圈**：冲合体失败会从炼虚退回化神，需要重新冲炼虚；冲大乘、渡劫失败会重做前一境突破。保留产业可以缩短回境，但不能省掉投料。
3. **身死重开**：清空本世产业与研究。仙缘减半结算能改善下一世生产，仍需重走解锁链。
4. **护道准备**：仙草、灵器、灵宝、阵印与香火需要额外产能和仓储。满配并非只把概率免费抬高；渡劫额外60阵印、2灵宝、12晶银、8九转丹与10000香火会推迟第一次尝试。
5. **短时减产影响较小**：单次5%减产120秒，若无其他叠加效果，损失约等于6秒正常产出；额外扣2%相关库存比减产更明显，但通常小于整次投料和重开损失。

## 设计判断

这套规则适合“准备充分才冲关，后期存在失败与重修”的节奏。裸冲已不是普通的省材料路线，而是低胜率、长尾很重的玩法；不宜再把裸冲当作默认通关节奏。满配也仍有约26.2%的一世身死概率，需要界面提前明确展示。

建议优先试玩验证合体前后护道材料与香火的准备体验，并增加更多种子、较长观察窗口和“只在后期满配”等自适应策略评估，再决定是否调整退境或身死比例。本次仅评估，没有修改游戏概率、材料费用或惩罚。

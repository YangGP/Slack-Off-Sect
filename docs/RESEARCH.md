# 修真研究结构与评估原则

更新：2026-10-14（v0.36）。本文描述当前结构；完整节点与前置只在 [TABLES.md](TABLES.md) 维护，未决定事项见 [ROADMAP.md](ROADMAP.md)。

## 体系分工

| 层次 | 职责 |
| --- | --- |
| 修真 · 灵气研究 | 认识灵气、凝聚、调控、离析与归源，开放产线及系统 |
| 修真 · 心法研究 | 心印传承、破境节料与修持成果，形成独立心法支线 |
| 修真 · 材料研究 | 按草木、金铁、符阵、丹道、香火、土木、山野组织原理、工艺与专业精研 |
| 修真 · 修真应用 | 把研究知识应用到生产的跨族 / 采集条目：灵流采集、营造、原理（资格型，附带解锁建筑）、仓储、灵能高阶 |
| 修真 · 宗门经营 | 制度、招募、离线、自动化和经营能力 |
| 技艺 | 普通生产、岗位、仓储、宜居度，以及标准装配、回收、模刻等工程增益 |
| 法宝 | 可重复祭炼的专业增益、防护、仓储和宜居度；由研究或产业链开放 |

材料发现、制作配方和专业精研属于修真材料线。符文为材料研究中的独立技术链，不新增可消耗的符文库存；材料决定载体与产物。该链及阵法、后期建材见 [CRAFT-PROGRESSION.md](CRAFT-PROGRESSION.md)。

工业加工共享工位容量；流水作坊、晶纹精修、灵纹锯阵、灵火冶炼分别提供设备容量、加工效率或节料能力。

## 灵气主线

| 章 | 问题与主要能力 |
| --- | --- |
| 观气 | 灵源考、观气与灵气测定，理解聚集、草木吸纳及破境，并把灵气按单位标准化 |
| 凝聚 | 凝气化液 → 凝液法 → 灵气纯化 → 凝晶原理，依次掌握配方、工位、纯化与凝晶知识 |
| 调控 | 观星、阵道与候时，约束灵气流与工程结构 |
| 拆解 | 离析灵气分子、偏极、湮灭与灵能输配 |
| 归源 | 因果、塔院与终局经营 |

章节描述认识与工程推进，不是强制通关清单。宗门境界与个人世界观能力分开：金丹可有内观解离认知，宗门工程需额外研究、材料与设备。分灵阵≥元婴、偏极阵≥化神、湮灭炉≥合体；固定境界的来源和仓容审计验证这些阶段可自举，不代表玩家必在该阶段投资。灵子论由凝晶原理与观星术承接，不再绕行三座含秘银的护山大阵；阴阳分灵由灵子论与复合符文承接。完整费用见生成表，实际投产专项可运行 `npm run audit:breakthrough -- power 12345 72`。灵石是含灵矿物，由采集或注灵制作取得。详细设定见 [SPIRIT-ENERGY.md](SPIRIT-ENERGY.md)。

## 凝聚章递进

凝聚章是一条四步递进链，凝气化液承接观气章的灵气测定，凝液法承接化液，凝晶原理同时要求符文入门。中间节点费用仍为 1500／6000／3000／8000 灵机；递进指前置知识和能力顺序，不要求单项价格逐级上涨。研究可以先行，工位及凝晶配方继续遵守各自的境界和工艺门槛。

## 心法支线

心法研究位于灵气五章之后、材料研究之前，收录凝灵诀，以及心印法 → 大乘心印 → 大乘心经。凝灵诀承接凝液法，保留节气满仓自动凝液；灵植术改由灵源考承接，早期产业无需绕行凝液研究。旧档已学凝灵诀继续保留，不为其补赠凝液研究。心印法仍承接调控章的候时法，费用、用料、效果及已学记录不变。拆解章集中为灵子论 → 阴阳分灵 → 湮灭法 → 灵能输配；心印三项仅调整归属和展示顺序，没有添加必须学满章节的门槛。修真应用单列灵流采集、营造、原理、仓储与灵能高阶五层。当前修真共 88 个节点：灵气五章 19、心法 4、材料与符文 34、修真应用 18、宗门经营 13。

## 依赖与产业推进

早期以灵源考为入口，分出观气与灵植两条线：灵植术直接承接灵源考，开放药圃后推进炼丹、探矿和木作；观气法与引气诀共同承接阵法精要，再开放聚灵大阵。木屋与清风小院增加居所营造前置，料场继续由凿石要诀开放；基础起步建筑保留建筑与材料条件。修真研究以灵机费用与仓容为主推进；少数条目保留境界门槛，因境界决定能观察到、能操作的内容（如营造、宜居配套）。知识、建筑规模与其他材料条件继续生效。建筑、配方、技艺和法宝仍使用各自境界条件，研究可以先掌握，实际应用需满足对应条件。

研究可跨材料族引用，如木作承接土木，符文与金属加工共同承接灵符。材料族专业精研可以要求已掌握的通用技艺，但需让依赖表达真实能力，避免新增只收费用的通行证。

金丹扩基础产能和材料库，并发展阵基、玄钢；元婴发展灵液、灵晶、仙草、混灵土与专藏。首次研究用料应来自上游，首座高级设施的成本应由前级仓储承接，不能依赖自身容量或自身产物启动。

叠匣术是普通装箱码放；后期纳物戒、须弥纳芥和洞天承接空间工程。灵能枢须持续供能，祭炼同时提高收益与耗能，缺供按比例运行。高阶建筑接入灵能后同样以 `upkeepQi`（灵气）/ `upkeepEnergy`（灵能）持续供能，断供停效、实体容量保留（见[DESIGN.md](DESIGN.md)）。

## 评估边界

- 破境、转世和飞升不要求学完研究；可选节点未完成不能直接判为死锁。
- 研究后应明确能建设、加工或改善什么。通用效率归技艺或法宝，材料专业增益归相应研究族。
- 专业制作收益与普通生产倍率分开；比较实际每件投入和边际增益，不能只看面板百分比。
- 自动配方争用上游材料，手动制作不受节拍限制；同时看供料、仓容、建设与操作频率。
- 比较进度时固定版本、仙缘／道果、事件和策略；建筑可达性、固定机器人进度和真实玩家体验分别评估。

仍待评估的跨线前置、阵法初解时机和个体成长统一列在路线图，本文不重复维护待办。

## 灵机仓容与研究费用

研究费用本身就是需容纳的库存量，没有新增硬性仓容判定；旧档保留的超仓库存仍可支付。各节点费用与设施容量以 [TABLES.md](TABLES.md) 为准，不在本文重复维护整条价格梯度。

扩仓由藏经阁→讲经堂→观星台→洞天等高级仓储承接，并结合灵机仓容研究、技艺与法宝。开放下一档设施的研究费用必须由上游容量承接，不能依赖尚未开放的自身容量。实际扩仓效果以生成表为准。

超过仓容且满足前置的研究在界面折叠显示所需上限。突破境界不再成批解锁研究；扩仓、掌握前置与发展材料产业分别推进研究。费用梯度为首轮试调，后续按实际扩仓频率与攒灵机时间调整。

## 链式解锁

灵源考是唯一修真入口，其余研究都必须沿知识链推进；灵机仓容与库存不能绕过研究前置。分支表达产业选择，不把所有研究串成一条必修线。

本轮补齐：观气法→灵气测定，把灵气按「一息」之度单位标准化；凝聚章以凝气化液承接测定，成为凝气成液配方的放行前置（凝聚工位仍由《凝液法》提供）。凝聚章另补入灵气纯化，剔杂提纯、灵气产出 +20%。符文入门→聚气纹→固形纹，再分向导灵、镇守与纳灵；凝灵诀→龟息功→定息法；香火志→祖师遗泽；营造法式与纳灵纹共同承接洞天福地；灵能输配承接加工驱动；因果通感由大乘心印与祖师遗泽承接，因果通感与塔院图共同承接因果参同契。建筑数量条件继续与研究前置共同生效。

研究链决定下一项何时出现，灵机仓容决定能否积累足够研究费用，其他材料决定产业是否已经发展到可应用阶段。

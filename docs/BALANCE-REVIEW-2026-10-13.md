# 2026-10-13 数值平衡复查

本轮测试保留现有游戏数值，检查前期木石分摊、知人善任与新逐出费用，并验证中后期可达性。结论：主线存在可达路线，四组普通参照模拟的每分钟抽样均未发现负数、非有限资源、断粮或拥挤减产；长期逐出费超过当前灵气仓容是最明确的平衡问题，木材加工需求与参照策略也需要继续检查。

## 条件与结果

全部从新档、0仙缘、0道果开始，每5秒决策、逐秒结算，不触发随机事务。普通参照使用 `tools/player-bot.mjs`，额外记录固定个人灵根／天赋种子、分工、资源与逐出费用；不主动培养个人境界、传功或出征。主动策略使用现有突破审计，优先准备破境材料，每分钟主动调配劳动力。两类脚本的个人随机源初始化不同，只用于路线对照；普通开启／关闭自动分工的一对测试使用相同初始化，便于比较这一开关的影响。

## 1. 逐出费用仍可能超过仓容

当前费用按每年基础口粮乘已满宗门年数加1计算，消除了旧公式的平方增长，但仍接近按当前基础口粮一次支付全部停留期间的消耗。游戏一年仅18分钟，长时间挂机后倍率仍会很大。

普通、必成、关闭自动分工的72小时筑基样本，68名弟子逐出费用范围为85,104～103,680灵气，中位数93,312，灵气仓容24,336：没有一名弟子能直接逐出，需先扩仓。开启自动分工的化神样本同样出现问题：76名弟子费用104,652～220,320，中位数179,928，灵气仓容37,417，均无法直接逐出。

这些弟子未主动提升个人境界。个人境界成长后，年基础口粮还会增加：宗门与弟子均为渡劫、停留整72小时的理论费用为6,507,000灵气。当前公式计算正确，但作为换人功能的成本仍可能过高。

建议优先评估费用上限或较低的停留倍率，让长期存档保有换人的能力。本轮未修改用户刚选定的公式；“超仓”是本次存档当下支付障碍，不表示永远无法扩仓解决。

## 2. 木石直接造价改善，间接耗木仍明显

普通参照、开启自动分工、必成的同一种子样本：

| 时间 | 灵木库存 / 上限 | 矿石库存 / 上限 |
| --- | --- | --- |
| 4h | 470.79 / 2,420 | 250 / 250 |
| 12h | 701.50 / 6,640 | 1,450 / 1,450 |
| 48h | 7,520.85 / 412,083 | 240,324.50 / 240,327.50 |
| 72h | 7,947.26 / 474,083 | 277,527.50 / 277,527.50 |

库存比例不能单独证明资源效率失衡，仓储配置与参照玩家的采购、制作优先级都会影响它。但样本中木材持续被加工和维护使用、矿石在后期满仓，说明前期直接造价分摊没有解决全部耗木压力。木板每份175木、符箓每份125木，木板又进入阵基与营造链；多座炉坊还有持续耗木。

建议下一轮按实际加工去向检查木板、符箓和炉坊维护，再决定减耗或增产；不宜仅凭这组库存继续提高建筑矿石价格。

## 3. 自动分工没有在样本中引发断粮，普通策略存在明显停滞

开启／关闭的一对普通样本均在7.265小时学会知人善任；开启后筑基由15.392小时提前至12.218小时，且后续到达化神。所有普通样本每分钟抽样的断粮、拥挤减产、灵气基础净额为负计数均为0。不能据此认定所有种子与所有手动分工组合都安全，但本轮没有看到自动分工破坏供粮。

普通参照出现符箓库存为0、配方已开放、仓容充足却长期停在筑基的情况；另一样本在化神缺灵晶。与此同时，主动准备材料的路线可到达渡劫。普通脚本包含持续采购、住房材料预留和加工限制，因此这些停滞不能直接判为游戏死锁；需要追踪其预留和制作决策，才能据此调整游戏数值。真实概率无护道样本的反复退境则来自已实现的风险规则，不能混入纯产能耗时。

来源审计131/131研究均在闭包内可参悟，建筑来源闭包可推进，无新增硬死锁。仍保留既有“兽材加工可见时兽材来源较晚”的提示。建筑仓容审计报告暖裘居室无兽材来源，是该工具未模拟猎杀取得材料的限制；本轮没有用这条提示认定游戏无来源。

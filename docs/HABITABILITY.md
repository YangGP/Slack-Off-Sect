# 宜居度试行设计

2026-10-10。替代士气，宜居度是点数，不是百分比。

设宜居度为H，弟子数为N：H = 20 + 建筑、技艺、法宝定额加成 + 已入住配套 + 断供惩罚。已入住配套 = min(弟子数, 居所容量) × 居所营造提供的每人点数。原士气加成等量转换；宜居度无上下限。正常断供惩罚仍在−60到0之间，每秒断供下降6点，供粮正常恢复2点。

| 条件 | 效果 |
| --- | --- |
| H < 0 | 全局倍率 = 1 − min(0.5, −H × 0.01) |
| H > N + 20 | 全局倍率 = 1 + min(0.5, (H − N − 20) × 0.005) |
| 其他 | 全局倍率 = 1 |
| N ≥ 20且H < N − 20 | 弟子岗位产出再乘0.5 |
| N ≥ 50且H < N − 50 | 每60秒检查一次离开概率，并暂停新弟子前来 |

全局倍率只作用于持续产出，包括建筑、弟子及法宝的基础产出。岗位惩罚只作用于弟子；两者相乘后岗位最低为正常产出的25%，建筑最低50%。口粮、建筑维护和每份合成收益不受宜居度倍率影响。

离开概率 = min(50%, (N − 50 − H) × 2%)，每次检查最多走1人。阈值相等不触发惩罚；小于20人免除岗位惩罚，小于50人免除宜居度流失。风险消失后清除检查计时并恢复来人，暂停期间不累积来人时间。大段来人结算逐人刷新风险。

长期断供仍独立按25秒走1人，不受高宜居度豁免。同一结算步两种原因重合时只走1人。优先离开闲散弟子，否则从非阵徒、人数最多的岗位离开，尽可能保留供粮职位。

在线和离线采用相同的风险公式、60秒检查周期和抽签机制。离线仍按每秒推进；随机结果不保证两次独立模拟相同。

原建筑加成数值保持不变，重复建设的宜居度收益继续叠加。历史士气版本和最初宜居度试行版本的通关耗时不代表增加配套后的节奏。

## 2026-10-10：补齐宜居度供给

前期正常发展以全局增产10%～20%为目标，即H在N+40～60之间。中后期建设、工艺和法宝进一步积累，达到50%上限是正常成长，不限制附带宜居度的生产建筑叠加。

| 条目 | 类型与阶段 | 宜居度效果 |
| --- | --- | --- |
| 清风小院 | 基础采集后建筑；灵木120、矿石80；涨价1.30 | 每座+4 |
| 膳养堂 | 药圃后建筑；灵木300、矿石120、灵草100；涨价1.32 | 每座+8 |
| 净身灵池 | 元婴建筑；混灵土4、灵液4、木板4；涨价1.35 | 每座+10 |
| 清幽园林 | 化神建筑；玄铁混灵土6、木板8、仙草10；涨价1.38 | 每座+14 |
| 居所营造 | 前期工艺；茅屋2、藏经阁1、采矿场1 | 每个已入住名额+1，空房不计，最多覆盖居所容量 |
| 引泉净水 | 筑基工艺；居所营造、寻脉 | +6；后续净身灵池的前置 |
| 园林营造 | 化神工艺；引泉净水、静心诀 | +8；后续清幽园林的前置 |
| 清尘铃 | 金丹法宝；炼器术、固形纹 | +6；可祭炼 |
| 安居灵幡 | 化神法宝；复合符文、静心诀 | +10；可祭炼 |

居所营造首先覆盖实际入住需求，生活设施与法宝再提供富余点数。例如4名弟子、足够居所、居所营造、清风小院5座时，H=20+4+20=44，增产10%；扩建后60名弟子全有居所时，H=100，仍增产10%。超员人口不获得额外入住配套，断供惩罚照常生效。

参照玩家优先学习居所营造。金丹及以前不足10%增产时补宜居设施，定额工艺和法宝尽量不超过20%；元婴以后目标提高为40%～50%，允许逐步达到上限。达到目标后暂停继续投资纯宜居条目，其他建筑仍可因产业需求而建设。以上是参照玩家的投资策略，游戏中玩家始终可以自行营造、学习和祭炼，没有20%硬上限。

补齐配套、尚未下调建筑收益与提高涨价倍率时的常规参照模拟（72小时上限、仙缘0、祭炼0、事件关闭）结果：

| 阶段 | 小时 | 宜居度增产 |
| --- | ---: | ---: |
| 引气入体 | 1.09 | 0% |
| 炼气 | 2.99 | 12% |
| 筑基 | 6.72 | 14% |
| 金丹 | 8.31 | 17% |
| 元婴 | 9.67 | 33.5% |
| 化神 | 10.87 | 44.5% |
| 炼虚 | 11.61 | 49% |
| 合体 | 13.34 | 50% |
| 大乘 | 16.07 | 50% |
| 渡劫并满足飞升条件 | 18.16 | 50% |

居所营造在47.4分钟学会，首座清风小院在90.1分钟建成。起步阶段仍需实际积累和营造才有正向增产；炼气至金丹的三个破境检查点落在10%～20%，中后期自然达到上限。学习居所营造后整个模拟没有触发岗位减半。结果为单次参照玩家观测，正常玩家的投入顺序和速度会不同。

## 2026-10-10：降低单座收益，提高重复营造成本

仅调整四种专门宜居建筑，首座造价与前置保持不变。当前条目表已同步更新。

| 建筑 | 单座宜居度 | 重复建造倍率 |
| --- | --- | --- |
| 清风小院 | 8 → 6 | 1.20 → 1.30 |
| 膳养堂 | 10 → 8 | 1.22 → 1.32 |
| 净身灵池 | 14 → 10 | 1.25 → 1.35 |
| 清幽园林 | 18 → 14 | 1.28 → 1.38 |

单座收益下降约20%～29%，每次涨价倍率增加0.10。以清风小院为例，第五座未折扣、取整前的单价从首座的2.07倍提高至2.86倍。仅靠小院取得12%增产，需要从3座增加到4座；工艺、法宝和原有建筑的宜居度规则保留，中后期达到50%仍属于正常成长。

相同常规模拟参数下，炼气3.67小时、增产10%；筑基6.75小时、10%；金丹8.37小时、15%；元婴9.38小时、18%；化神11.09小时、41%；炼虚12.00小时、41%；合体13.72小时、41%；大乘15.91小时、49%；渡劫并满足飞升条件18.47小时、50%。学习居所营造后无岗位减半。相比调整前18.16小时，整体耗时小幅增加，前期可维持目标区间。

## 2026-10-10：清风小院进一步收窄为入门设施

清风小院单座宜居度由6再降至4，首座灵木120、矿石80以及1.30涨价倍率保持不变。进入增产区间后，单座对应的全局增产从3个百分点降至2个百分点；单靠小院补到10%增产需要5座。膳养堂单座8点，是小院的两倍，引导后续投资转向更完整的生活设施与工艺。

相同参照模拟下，炼气3.72小时、增产10%；筑基7.84小时、12%；金丹8.71小时、15%；元婴9.75小时、18%；化神至合体40%；大乘20.68小时、50%；渡劫并满足飞升条件22.06小时、50%。学习居所营造后无岗位减半。与小院6点版本18.47小时相比推进放慢，前期增产目标仍可达到。952项逻辑检查、19项渲染检查、271项DOM检查与构建通过。

# 单局游戏节奏设计：宗门推进与产业链

更新：2026-10-24。状态：**主要规则已接入首版代码，时长与费用待联合校准；元婴阶段递进为新增设计草案，未实施**。下列测量项目仍待实际整局验证，不代表已经完成验收。

整体安排以[联合方案](REINCARNATION-PACING-PLAN.md)为准：不转世直推首飞约半年，中途转世显著提速；后期普通飞升可快，主要时间转到培养与终局备料。本文维护P0～P5的产业目标、现行边界和25项校准要求。

原1～2月直飞、29～55天及约42天中点预算已失效，不再作为验收标准，也不将各段按比例乘到半年。猫国的源码对照集中在[参考文档](KITTENS-RESEARCH-REFERENCE.md)，当前实现查[DESIGN](DESIGN.md)与[TABLES](TABLES.md)。

## 1. 阶段与经营目标

| 阶段 | 境界范围 | 主要约束与投资 | 接续收益 |
| --- | --- | --- | --- |
| P0 起步 | 凡体→炼气 | 基础材料与灵机双轨；采集、首批弟子及扩建 | 能持续经营，第一小时内有多次可执行变化 |
| P1 奠基 | 炼气→金丹 | 丹符器产线、非灵机破境材料、互市筹备 | 初步产业分工和交易入口 |
| P2 互市 | 金丹→元婴 | 灵晶供给、执符产速、汇率及仓储容错 | 观星台等投资改善知识引擎，元婴账单加入灵晶 |
| P3 分子 | 元婴→化神 | 灵气供给、分子产线、刻纹和凝聚扩产 | 化神账单加入分子，开放转世，接通下游燃料 |

| P5 收官 | 合体→渡劫普通飞升 | 仙灵力扩产、世界投资、复合材料与护道 | 普通飞升，或继续个人培养与公共护道产业 |

约半月到化神沿用为校准起点，不因首飞半年就自动后移。普通飞升不要求全员弟子修满。弟子自入宗并行成长，岗位境界、同心度与驻守占用均会改变产业供给，不能先独立定完宗门费用再机械叠加年度培养。

## 2. 节奏质量要求

1. 等待期间至少有两条实际可经营的并行线；不靠一个大账单、固定工程冷却或更高失败率补满半年。
2. 研究、建筑和产线形成小目标，突破形成大目标；在线应能看清下一个可达投资，不能只看到遥远总账单。
3. 前期基本操作保持可执行，后期减少重复点击、增加投资取舍；低频上线按联合方案的离线覆盖与自动突破配套。
4. 新资源先提供可见收益，再竞争扩产与突破；建设不回本时允许选择早飞，不能所有升级都成为隐性强制清单。
5. 比较各条实际完成时刻，计入共享资源、工位、人口与解锁竞争，不把并行耗时重复相加。
6. 旧阶段随永久投资减轻，新产业承接时间；半年是整体目标，不是每轮都要保留的固定周期。

## 3. P0／P1：材料与知识并行

前期研究、建筑或破境可加入基础材料条目，让采集配比与攒灵机共同形成投资。保持研究费用现有约束和来源可达性，不将所有学习变成一次满仓等待。

筑基、金丹的非灵机材料可温和调整，P1灵机费维持原方向，不做金丹账单大额通胀，也不为拉长硬添P1新体系。灵石可经点石成灵由灵气转化，材料压力应沿既有产线传导。

互市从筑基、邻宗往来和山门承接，作为P2的准备。早期材料预算与即时手动炼制、连续自动加工都需比较，不以自动耗时假设手动也必须等待。

### 校准要求（4项）

1. 双轨完成时间取实际较晚时刻，不能把材料半周期直接加到灵机周期上，进而宣称总时长翻倍。
2. 新增材料费须满足来源、前置、显示和仓容可达；采集来源先于必要消费开放，避免研究与建筑互锁。
3. 筑基／金丹非灵机材料先作温和调整，比较丹药、符箓、灵草、灵石及灵气供给；不能同时抬高所有费用再失去归因。
4. 邻宗往来、山门、执符堂和第一批交易在P1的投入须实际可达，不将纯预告记作已有产能或已填满的阶段内容。

## 4. P2：互市启动稀缺产业

元婴账单加入灵晶，投资灵晶产能与攒突破费形成取舍。增益族使用建筑和技法两类载体，主要改善执符产速、有效汇率及相关效率；仓容承接大额支付、离线与波动，不声称高频自动交易时扩仓仍等比提高长期吞吐。

星崖观在金丹提供灵晶启动来源，观星台消耗灵晶、改善灵机生产与仓储，反哺下一轮交易。银溪谷提供秘银启动来源，后续提炼产线接手；不将交换供给永久锁成唯一来源。

批量档位和自动互市方向保留。药藏需重设计以提供合理回报；净身灵池、试炼塔、清幽园林、护山大阵、锁灵阵、洞府的不限仓建材造价需检查，避免过低成本迅速堆满宜居收益，但不把“材料不限仓”直接等同于“无成本无限建造”。

### 校准要求（6项）

1. 灵晶总账包括观星台、元婴突破与后续建设，初步条目100～200仅作旧候选量级，不可未经测量宣称能卡2～3天。
2. 星崖观每回基础成本灵机900、香火120、信符50。即时批次按库存除单回费用后取整、再取最小值；日吞吐另计产速和交易周期。基础灵机仓200不足一回，须有可达扩仓路径。
3. 互市与猎杀共用信符，自动交易需要保留量或优先级，避免吃空其他行动与研究材料。
4. 外交和猎杀已经常驻，旧档关闭标记已有归一；沿用现状，不重复迁移或恢复开关。研究、境界、山门仍是进度条件。
5. 自动互市初始以60秒周期等候选参数定标，缺料跳过、不积压欠账，明确在线与有效离线内的一致结算。
6. 元婴后凝晶产业接替启动贸易，秘银每份基础用量0.01等按现行配方检查。无需因旧模块开关再补一条凝晶兜底，但仍需查供给闭包与真实吞吐。

## 5. P3：分子供给承接化神

现版化神候选账单包含灵气分子36000、道札400、道论80与灵符240；灵机尾款仍为10000，灵晶2100、灵液5400等保持原值。刻纹、凝聚工位与分子供给须联合评估，目标时长尚待长测确认。

分灵阵由元婴开放，基础产分子0.04/s、灵气动力8/s，涨价率1.5；结合分子仓储与技法投资接入化神后的偏极、湮灭链。以上为现版基础事实，不代表新账单终值已经确定。

### 校准要求（3项）

1. 分子账单终值须与产线建设、仓储和新增工位产能联合反推；旧800份候选只需数小时的基准产能，不能据此证明多日等待。分子在该段缺少其他去向，需避免建完后只剩被动攒账单。
2. 无其他增益、满供元婴基准下，境界生产倍率1.8使单列分子0.072/s、动力14.4灵气/s，基础投入比200:1；分资源增益会改变实际比值。若同时改变产速与动力，明确效率是否变化。
3. 粒子质量流、成对消耗、共用负荷及湮灭炉不自增粒子／灵能的边界保留，不新增另一种同义粒子资源来补时长。

### 元婴阶段递进草案

2026-10-24首版候选已按用户授权实施。2026-10-25，DS完成v12自然长测：元婴70.715小时、金丹49.572小时，首次实际化神转世143.6625小时，0死亡；扩阵、分子匣和回用均真实成交并提高有效产量。单样本时长达标，但136人仍只有1名香使，最后约4.17小时单等护道香火；灵符“待启用自动”对应手动制作策略，不是实际停产。候选报价暂保留，下一步先优化岗位策略，不能据此宣布经营体验与后境节奏已完成验收。用户明确要求元婴阶段应比金丹更久；以下安排用于初始永久环境、同一在线与操作口径的首转基准，不给所有周目设置固定停留时间。

**基线与目标。** `35933d9`／v11的已完成样本中，金丹停留49.572小时，元婴24.953小时；首座分灵阵在元婴约21.4小时建成，约3.55小时后即可化神。生产路径已打通，但首座新设施刚落地就结束本境，扩产选择来不及发挥作用。草案保持此前阶段与金丹报价，元婴目标65～75小时，约为当前金丹的1.3～1.5倍；按同一开局估算，首次化神转世约138～148小时（5.75～6.16个持续在线日）。这些是目标预算，不是新实测结果，也不代替半年首飞／全年培养验收。

**体验主线。** 金丹学会以旧产业启动稀缺材料，元婴要把凝晶、知识和分灵变成可扩建的稳定产业。贸易取得的少量催化剂应带来生产自主性；新产物在本境继续用于研究和建设，形成下一次投资机会，最后再承担化神准备。参考猫国的“交换启动—自建产线—回投扩张”，采用现有资源和工位，不增加装备或另一套进度货币。

| --- | --- | --- | --- |

**费用调整顺序。** 保留元婴银溪谷入口、每次真实交易费用及凝晶每份秘银0.01，保留阵基装配5%和晶纹精修原价。第一轮只调整冲化神的产业准备总量及元婴投资回报，不同时改开局、金丹、个人弟子修炼、基础产速和失败概率。

静态量级：元婴满供基准单阵0.072/s，不含其他加成；两阵加回用与分子匣为0.2232/s，37200分子（突破＋回用）约46.3小时。旧样本的元婴快照单阵净产0.088992/s，比裸产更高；人口、其他增益、两阵建成先后及前期库存会进一步改变准备时间，不能将46.3小时直接加在首阵21.4小时后当作新实测。灵符240按裸配方需要玄钢480、灵液480、纸480、灵气72000和香火48000，实际须应用增产、节料与已有库存；道论80裸配方需要道札1600、灵机120000和纸160，道札还需上游灵机与纸，不可忽略知识供料。法藏每座基础提供1000分子仓，实际受现有仓储增益影响；旧样本26300仓容需继续扩容至新账单，不能靠增加分子量制造不可支付的门槛。

v12机器人在元婴首阵之后，比较第二阵、分子匣、分子回用与直接备料。使用当前有效净产、真实涨价费用、供气余量、材料准备及支付后恢复突破材料的估算，逐项计入代价；预期节省须超过估算投资路线用时的10%且超过5分钟。最多将第二阵纳入这种可选投资，不增加破境数量门槛；研究选择也不成为通关条件。报价为当前快照估算，未精确模拟全部共享原料和未来季节，实际回本交由长测检查；成交记录位于 `result.json` 的 `decisionSummary.particleInvestments`。

**扩产如何值得做。** 保留已有晶核阵、符箓堂、分灵阵、科研设施和工程工艺，优先重排投资时机与真实报价，第一版不增加新建筑或新工艺ID。至少两次中期投资应能在剩余化神准备时间内回本，且比较时要扣除建设所占材料、研究所占知识、供养和运行消耗。扩建后确实提高有效供料，不能仅增加空转工位。若当前第二座分灵阵始终不回本，应先调整总准备量或投入构成，不强制建两座，也不直接将所有设施降价。

本境分子的回投采用既有研究费用：首座分灵阵及其全部上游保持不依赖灵气分子，取得首批分子之后才可以支付回用。分灵阵各次建设与拆除报价保持原规则，避免给旧档未支付过新材料的阵法凭空新增分子退款；不新增隐藏研究门槛。

**阶段提示。** 用现有修真、炼制和设施说明串起三个目标：“本地凝晶”“分灵阵首产”“化神备料”。每个目标说明材料来源、共享工位／供料短缺与可选扩产，不显示未经测量的精确剩余小时；提示和订单由玩家选择，不自动更改岗位或提前支付建设费用。

**后续阶段与旧档。** 炼虚与合体现有道论／阵图为80／10、160／20；每份阵图裸配方含10道论，知识原料量级分别为180、360道论，均高于化神的80，另需研究与高阶工业。大乘虽仅需2400份旧分子，却新增灵器480与玄金400，粒子也用于偏极、湮灭的持续运转；本轮保留后境报价，静态总量不能证明其阶段用时已经递增，须在首转校准后安排后境窗口，发现倒挂再按新产业调整，不统一乘价。已有化神及更高境界不回退，已开放转世不重新锁定；元婴已有库存、研究、建筑与加工进度保留，新报价只用于之后的尝试，不追缴已完成突破。

**验收。** 后续单样本首先复用12345、自然突破、满配可用护道、持续在线、每5秒一次决策及实际化神转世终点；保持前期策略，分开记录各阶段首次可冲关、实际冲关、失败重备、首产与扩建时点。检查元婴是否达到65～75小时、较金丹有清楚递进，并说明缩短／延长发生在哪里。另行安排多种子时观察阶段中位数，不要求每次自然失败后的单局耗时都严格递增。

记录至少一次“首产—回投—扩产”的闭环、两次有回本价值的投资和一条少扩建路线的成本对照。按真实并行推进统计，不相加重叠缺料时间，不把机器人不投资或来源缺失算作理想阶段时长。分清建线前等待与建成后积累；对比单次仙缘、每累计在线小时仙缘及后续重建，避免把延长停留误当成收益改善。实施时Codex仅做针对性快速检查；2026-10-25 DS已完成自然长测及全量回归，Codex只核对报告和指纹，见 [测试入口](../tools/BALANCE-TRACKING.md#元婴递进首版复测)。单阵自然对照及更多种子仍未进行。

## 6. P4：秘银、灵能与专业加工

秘银主要承接广储库和后续高阶建材；灵能改善工位额外容量与高阶设施运行。保持灵气基础和灵能高阶的选择，避免新产能与新增耗能只看毛产出。

偏极阵、湮灭炉在化神接入，灵能输配在炼虚解锁应用。采仙台实际须合体的仙灵初探，聚仙阵须大乘的仙灵聚合；因果池也受大乘研究约束，通天塔在大乘。不得仅按建筑自身较低realm字段安排提前收入。

阵印默认自动配方基础120秒／份，9000份在大乘默认调速1时约6.46天；自动调速可提速，手动批量即时结算可绕过时间。fixedYield只限制增产，不构成不可绕过的硬时钟，不为补时长取消便捷操作。

### 校准要求（5项）

1. 分灵、偏极、湮灭的实际供给比与灵气／灵能总账联合核算；高阶动力释放灵气但占灵能，不以基础1:1:1直接视为任意增益下均满供。
2. 合体护道投资比较账单损失和失败风险；保留原概率也会随准备时间变长放大现实代价，不能据“不提高概率”宣布风险已校准。
3. 秘银提炼、广储库与灵机大额研究联合检查，防止研究仓容和工业吞吐互相反锁。
4. 炼器、刻纹与凝聚的多配方竞争须实测；灵能驱动提供容量仍受供能、冷却、原料和保留量约束，不能假定全线永久翻倍。
5. 保留REACTOR_EXCLUDED的粒子与灵能排除边界，区分全局产出、工位效率、单份增产与维护的叠加层。

# 筑基到化神：当前节奏审计

更新：2026-10-17。基于64f10db及当前D2、悟道专精、知识链和本轮阶段费用调整。本轮测量在到达化神时停止，**不是新的完整首飞耗时测量**。

## 1. 先纠正备料策略

上轮模拟在自动库存目标尚未解锁时，每轮手动制作10份直至满仓，导致筑基前积累569枚丹药（实际只需26），随后金丹／元婴大量复用库存。它不符合玩家按近期需要手动停产的操作；旧“筑基约9小时、金丹到元婴9分钟”的数据不再作为当前按需备料路线。

已修正审计工具：未获得自动目标能力时，手动制作也按近期需求停产；不会替玩家提前解锁自动目标或增加游戏功能。修正后、未改游戏数值的同一投资参考为筑基3.744、金丹6.331、元婴6.735、化神9.779小时。筑基前丹药33，元婴前180。

阶段快照也显示，原金丹到元婴期间只新增dustBell法宝，丹药制作倍率约2.49→2.55；主要问题不是此时集中取得大量增产，而是使用同一批基础材料，阶段费用与产业准备承接不足。

## 4. 其他路线的可推进性

- 投资型真实护道种子1：筑基3.744、金丹8.236、元婴12.424、化神15.246小时；截至化神所有已尝试突破均一次成功。它与上表的一次成功裸费用参考在护道投入上不同，不用两者差值直接推算随机惩罚。
- 严格节省、一次成功参考：筑基5.386、金丹9.703、元婴19.035、化神26.642小时。与上一轮同策略约26.649小时化神相比，主要是把元婴后的准备前移，累计时间基本不变。该差异比较不是玩家人群平均。
- 来源和仓容闭包可到渡劫，全部研究与建筑均可达；闭包不估算真实生产时间，不替代实玩。

上述模式沿用先覆盖口粮、再按木4／矿3／药2／悟2／香1分配其余劳力；固定劳动比例和高频操作不是最优策略，也不代表低频上线玩家。

## 5. 后续观察

本轮不削减通用制作加成或灵机专精。优先观察金丹阶段的知识与凝液准备是否有明确反馈、首次讲经设施是否易发现，以及元婴后是否仍有过长纯等待。若继续调整，按实际阶段快照处理具体费用或过早开放的能力，不把所有增益统一砍掉。

完整首飞尚未在本轮费用和修正后的手动备料策略下重测。旧23.51小时参考也属于之前策略与报价，不能继续称作现版本首飞时间。后续仍需更多种子、真实事件、适度护道和低频上线对照，D2整体不标记完成。

# 弟子天赋：当前首版与升级预留

更新：2026-10-12。首版已实施：获得后类型固定，不洗练或替换，保留原天赋升级的潜力。本文获取概率、数量、词条和 Lv.1 效果为当前试调配置；升级触发、等级成长和潜力上限仍待策划。当前弟子规则见 [DISCIPLE-PROGRESSION.md](DISCIPLE-PROGRESSION.md)，历史草案见 [DISCIPLE-PROGRESSION-HISTORY.md](DISCIPLE-PROGRESSION-HISTORY.md)。

## 1. 首版范围

让弟子在灵根之外具有个人专长，使玩家能选择培养人选和岗位。灵根继续决定基础成长速度，天赋提供个人修炼、岗位专长或突破把握；不改变宗门境界上限。

首版围绕现有六类岗位及个人成长，不增加独立属性、负面天赋、洗练或炼丹／炼器岗位。升级属于原天赋的后续成长，先预留结构，触发与数值另行设计。个人词条不直接提高全宗产出、共享工位或每份制作收益。培养投入、师承和复杂失败风险另行策划。

## 2. 获取与数量

入宗提供先天差异，成功突破提供后天获取机会，配置集中在 [src/data/talents.js](../src/data/talents.js)：

| 项目 | 当前首版配置 |
| --- | --- |
| 入宗天赋数量 | 70% 无天赋、25% 一条、5% 两条 |
| 成功突破 | 每次成功后 10% 概率获得一条新天赋 |
| 总数量上限 | 每人最多三条 |
| 重复规则 | 相同 ID 不重复，同类专长最多一条 |
| 获取等级 | 黄 60%、玄 30%、地 9%、天 1% |
| 失败、调岗、读档 | 不触发天赋获取 |

“同类”分修炼、岗位、突破三类，目前同类最多一条。固定的是天赋身份与专长，例如采药专长不替换成矿工专长；后续通过升级提升原天赋能力。低级词条不会因此换成另一条天赋，不提供洗练或替换入口。

升级潜力的触发、成长等级、经验或消耗、是否能提升天地玄黄品级及效果上限尚未确定。首次抽取的品级与未来成长等级应分开描述，不能默认每次突破都升级，也不能用抽取另一条同类词条代替升级。

事件招入与正常收徒使用同一获取规则；未来特殊招募另设规则，不在本轮加入。实际抽取次数不得超过空余位置，不因为重试同一次成功突破重复发放。

每次抽取先排除已拥有 ID 和已占用类别，再从仍有可用词条的等级中按权重抽等级，最后在该等级候选池中等概率抽词条。无候选或已到数量上限时不抽取，不循环重抽；首版不设按境界限制词条的额外门槛。等级概率按当次有效等级权重归一化，不能把排除后的概率仍宣传为固定值。

## 3. 当前效果与词条

### 3.1 修炼类

| 品级 | 名称 | Lv.1 个人效果 |
| --- | --- | --- |
| 黄 | 勤修不辍 | 修炼速度 +10% |
| 玄 | 修炼奇才 | 修炼速度 +20% |
| 地 | 道心澄明 | 修炼速度 +35% |
| 天 | 天道眷顾 | 修炼速度 +50% |

与灵根相乘，不改变所需修为或直接赠送修为；修满后仍停止增长。工作、闲散、调息及离线都使用相同速度入口。

### 3.2 岗位类

每个岗位提供黄／玄／地三个品级的固定词条，名称与效果分别配置；本人对应岗位产出为 +10%／+20%／+35%。天级岗位词条待后续确认需求再补。当前库共 26 条：修炼 4、突破 4、岗位 18。

| 岗位 | 专长命名方向 | 实际作用范围 |
| --- | --- | --- |
| 阵徒 | 引气熟手／聚气通窍／气脉亲和 | 本人的灵气岗位产出 |
| 樵夫 | 识木／顺纹巧手／灵木亲和 | 本人的灵木岗位产出 |
| 矿工 | 辨石／寻脉巧手／地脉亲和 | 本人的矿石及已开放的玄铁、灵石岗位副产出 |
| 采药人 | 识草／百草通识／草木亲和 | 本人的灵草岗位产出 |
| 悟道者 | 勤思／触类旁通／悟道通明 | 本人的灵机岗位产出 |
| 香使 | 迎香／立愿通心／愿力亲和 | 本人的香火岗位产出 |

岗位词条仅在本人被分配到对应岗位时生效，闲散或调到其他岗位时不生效，但保留词条。未开放的资源和岗位仍需满足原条件，词条不能提前解锁产业。

### 3.3 突破类

| 品级 | 名称 | Lv.1 个人效果 |
| --- | --- | --- |
| 黄 | 心气沉稳 | 突破成功率 +2 个百分点 |
| 玄 | 行气通畅 | 突破成功率 +4 个百分点 |
| 地 | 道基稳固 | 突破成功率 +6 个百分点 |
| 天 | 破境通明 | 突破成功率 +8 个百分点 |

保留最高 99% 的上限，不绕过修为、调息、宗门境界和材料条件。不减少费用或失败修为损失，不新增死亡风险。

### 3.4 统一计算

同一效果内部按配置加总，并保留修炼 +50%、岗位 +50%、突破 +8 个百分点的防御性上限；首版同类唯一时通常只有一项。不同来源分开计算，不按弟子数量扩大为全局增益。

```text
个人修炼速度 = 基础速度 × 灵根系数 × (1 + 个人修炼天赋加成)
岗位有效权重 = Σ[该岗位弟子有效境界系数 × (1 + 该弟子对应岗位天赋加成)]
个人突破成功率 = min(99%, 弟子基础成功率 + 宗门指导加成 + 个人天赋百分点)
```

口粮继续使用原个人有效境界系数，岗位天赋不额外提高口粮，也不提高其他弟子的产出。需区分用于产出的岗位权重与用于口粮的境界权重，避免复用一个总量导致误增口粮。

当前弟子基础成功率为对应宗门基础成功率的 50%，宗门指导为每高一境 +10 个百分点。突破天赋在该基线上增加个人百分点，不恢复旧版“宗门失败率减半”的公式。未来天赋升级的效果上限需单独评估，不能默认沿用首版值作为所有等级的最终上限。

例：同境界三灵根弟子原修炼速度为 1，拥有玄级修炼词条后为 1.2；天灵根搭配天级词条为 3。两名同境界矿工中只有一名拥有 +20% 岗位天赋时，该岗位合计权重为原来的 2.2／2＝1.1 倍，不能给两人都加 20%。

## 4. 数据与存档约定

`talents` 已保存条目数组，每条包含固定 `id` 和独立成长 `level`。当前只开放 Lv.1，归一化将等级限制为 1，不因等级字段提前获得额外收益。名称、品级、类别、`bonus` 和展示说明从配置解析，岗位词条明确 `jobId`。成长经验、潜力上限与升级效果待规则确定后再添加。

原天赋升级不得改变身份或岗位专长，不占用额外天赋位置；新获取数量上限与单条天赋升级上限分别配置。具体升级值、是否提升品级及潜力差异仍需策划。

天赋使用独立的 `talentSeed`，不消耗既有 `rootSeed`、事件或突破随机序列。成功突破判定仍由原随机源完成，随后单独判定天赋；天赋加成会改变实际突破概率，但不能仅因天赋抽取扰动其他系统的随机序列。

旧弟子默认空天赋，不在每次读档重抽或自动补发；迁移后下一次真实成功突破可按新规则获取。若用户希望为旧弟子补先天天赋，需另设一次性迁移方案，不能直接在归一化中随机生成。

已在 `disciples` 内保存 `talentVersion: 1` 与 `talentSeed`，无需新增顶层存档字段。旧档缺少种子时从原灵根种子派生，个体归一化清理重复／未知 ID、类别冲突、数量和等级超限，不自动生成新天赋；合法 ID 原样保留。身份、天赋与种子在普通保存、导出和离线结算副本中一致保留。测试夹具通过人数补建的历史个体保持空天赋，真实收徒与事件招入仍正常抽取。

重修、转世或飞升继续清空弟子及个人天赋。随机序列如何重置需统一约定，并与同一存档重复加载的规则分开处理。

## 6. 下一步待确定

首版获取、数量、同类限制、词条和个人效果已实施。下一步通过多种子审计观察当前低基础概率及天赋加成的培养成本，再设计原天赋的升级触发、成长上限、潜力差异及是否提升品级；不增加洗练或类型替换。

# 资源层级与后期收益审计（2026-10-08）

本轮参考猫国的基础配方数量级调整为 v0.12。下列诊断数据来自修改前的 v0.11；最终方案采用有差异的配方成本与可持续成长的加工加成，不要求所有资源的实时产量永久保持100倍。

## 复现

```powershell
npx vite build --ssr tools/tier-audit.mjs --outDir .smoke-tier --emptyOutDir
node .smoke-tier/tier-audit.js 72 0
node .smoke-tier/tier-audit.js 72 202
npm run balance -- 72
```

使用现有参照玩家，无随机事件，每5秒决策。审计每5分钟检查库存非负且有限。加工产能沿配方递归估算，包含供料与节拍限制；各资源独立计算，不代表共享材料时可以同时实现全部产能，也不代表满仓后仍有实际收入。

## 层级差距消失的原因

单份产出为 `amount × (1 + 通用制作加成 + 专业制作加成)`。因此不能仅看配方的原始成本；应比较 `前阶投入 / 实际产出`。

| 加工链 | 原始主料/份 | 16小时每份产出 | 每件成品的有效主料 |
| --- | ---: | ---: | ---: |
| 灵草 → 丹药 | 25 | 5.48 | 4.56 |
| 法器 → 灵器 | 8 | 5.35 | 1.50 |
| 丹药 → 九转丹 | 10 | 5.48 | 1.82 |
| 符箓 → 灵符 | 12 | 5.25 | 2.29 |
| 灵器 → 灵宝 | 2 | 5.35 | 0.37 |

灵宝另需九转丹2、灵符3：折算每件灵宝只需九转丹0.37、灵符0.56。它是多支线汇合的资源，不能只用一个主料比例衡量总价值，但每条支线的数量级都明显没有拉开。

16小时的独立加工产能上界：法器1.783/s，灵器0.669/s，灵宝0.446/s。相邻比值只有2.67与1.50；并非100倍。阵基、灵晶等复合配方也存在加成后每件消耗不足一件中间材料的情况。

## 后期加成与真实瓶颈

全局加成采用相加后乘一次的公式。新增加成 `b` 在原有加成总和 `A` 上的实际提升为 `b / (1 + A)`。

| 条目 | 标称全局加成 | 16小时移除再恢复的实际增益 | 24小时实际增益 |
| --- | ---: | ---: | ---: |
| 阵纹精研 | +3% | 1.095% | 0.906% |
| 大乘心经 | +12% | 4.528% | 3.727% |
| 镇岳印（该状态未祭炼） | +5% | 1.838% | 1.520% |

渡劫期境界倍率只有20；道果每颗+5%，仙缘产出加成渐近+200%。这些数据确实偏温和，但它们只影响直接生产，`craftYield` 没有应用境界或全局产出倍率。

24小时状态下灵草毛产量3609/s，而丹药供料充足时最多2.94/s。丹药每2秒加工一份、九转丹每6秒一份、灵器每8秒一份，建筑数量没有增加并行加工份数。继续提高全局产出主要增加基础资源，不能解除加工节拍限制。

修改前基准在6.45小时到金丹、6.65小时到元婴、6.66小时到化神、19.05小时到渡劫。连续破境反映该策略下前期材料竞争与解锁后的储备集中释放，不能直接当作后期收益不足的证据。

## 猫国参考与最终方案

直接核对猫国[建筑源码](https://github.com/nuclear-unicorn/kittensgame/blob/master/js/buildings.js)、[配方源码](https://github.com/nuclear-unicorn/kittensgame/blob/master/js/workshop.js)与[职位源码](https://github.com/nuclear-unicorn/kittensgame/blob/master/js/village.js)：矿工基础产量0.05矿物/tick，冶炼炉消耗0.1矿物和0.05木材，产0.02铁；矿物到铁的基础转换是5:1。其木梁、石板、金属板分别消耗175木、250矿物、125铁；钢消耗100铁和100煤；齿轮、合金等组合加工采用其他成本。工坊每座+6%加工产出。因此本轮借鉴配方分层和设施成长，不把矿物与铁当作固定100:1的关系。

| 本作配方 | v0.12成本（每份基础产出1） |
| --- | --- |
| 丹药 | 灵草100 + 灵气60 |
| 木板 | 灵木175 |
| 符箓 | 灵木125 + 灵气60 |
| 法器 | 玄铁125 + 灵石12 |
| 玄钢 | 玄铁100 + 灵气120 |
| 仙草 | 灵草100 + 灵气200 |
| 阵基 | 木板25 + 符箓25 + 玄铁100 |
| 灵晶 | 灵气500 + 符箓10 |
| 九转丹 | 丹药100 + 仙草5 + 灵气500 |
| 灵符 | 符箓100 + 香火500 |
| 灵器 | 法器100 + 玄钢25 |
| 灵宝 | 灵器25 + 九转丹25 + 灵符50 |

凝气成石保持灵气45，维持开局货币来源。百工坊从每座+15%调整为+6%，专业设施、技艺和祭炼照常累加，制作不设置统一软上限。配方的有效兑换率会随设施建设逐步改善，允许同一层不同支线采用不同成本。

聚灵大阵基础灵气从0.5提高至3/s，晶核聚灵阵从2提高至15/s；灵兽园提供灵木1.2、灵草1.5、玄铁1/s。生产升级采用逐步提高的吞吐，未把所有高级设施统一放大100倍。

元婴至渡劫的境界倍率依次为3、5、8、14、24、40；金丹及之前保持原倍率。加工速度为 `max(1, sqrt(境界倍率 / 2))`，渡劫约4.47倍，应用于自动制作、离线制作、倒计时、材料耗速与事件产能估算，手动每份收益仍只由制作加成决定。小步与批量自动加工使用相同的浮点容差，避免在节拍边界丢掉一份。

阵纹精研全局加成从3%提高到30%，大乘心经从12%提高到80%，镇岳印从5%提高到40%；仍沿用现有相加乘区与祭炼规则。提高药藏的九转丹容量至每座25、法藏的灵符与灵器容量至每座50与25，支撑灵宝投料；参照玩家的囤货目标包含进阶加工的材料保留量。

旧档库存、建筑、研究与加工目标不迁移或扣除，后续制作使用新成本；已经设置较低自动库存目标的玩家需要根据新配方提高目标。资源储量仍保留整件计数与小数收益结转。

## 验证

生产构建、641项引擎断言、19项渲染断言与228项DOM交互断言通过。0仙缘参照玩家的72小时推演在约37.17小时到渡劫，36.91小时首次获得灵能；该策略在化神阶段较久，手动调整生产分工和加工目标可能明显改变节奏。终局可达不代表各阶段耗时已经最优。

0仙缘与202仙缘各72小时的最终代码审计均到渡劫，定期检查未发现负库存或非有限数值。0仙缘终局的独立产能上界为法器5.486/s、灵器0.202/s、灵宝0.021/s；当前加工设施已经改善了基础兑换率，相邻产能比约27倍、10倍，未强制维持百倍。该状态下阵纹精研、镇岳印、大乘心经的实际边际提升约6.9%、9.4%、20.8%，后期升级仍有明显收益。

## v0.13：高级营造与仓储配套

上述诊断与v0.12验证保留为历史记录。本轮继续提高高级建筑材料需求，并调整对应扩仓路径。不能仅扩大基础容量：首座高级仓库的成本必须能由前级设施承接，其增量容量还要足以支持下级建筑与重复购买。

参照玩家的进阶材料囤货目标随下一笔营造成本增长，并受实际容量限制；避免固定600件玄钢的模拟策略错误地阻止第二座通天塔。增加仓储自举检查，覆盖首座材料库、专藏、晶核阵、洞天、通天塔和涨价后的第二座通天塔。

0仙缘72小时参照玩家约32.29小时到渡劫、37.08小时首次获得灵能，72小时完成81项研究并建成终局产业。较v0.12更快达到渡劫，主要因为扩仓缓解了中期容量瓶颈；终局奇观的造价同时提高。该模型用于验证发展链可达，不代表真人最优进度。

最终验证：648项引擎、19项渲染、228项DOM断言通过，生产构建与编码检查通过。0仙缘与202仙缘各72小时库存审计均完成并达到渡劫，没有检测到非有限库存或负库存。新价格与容量均已更新到全量数据表及v0.13更新日志。

## 平衡与验证边界

历史首转3～5天目标及部分样本保留在 [BALANCE](BALANCE.md)，不直接套用于 v0.424 或新培养线。现版完整首飞、不同转世次数、事件／低频上线及多世收益仍需在冻结数值和策略后测量。

完整飞升测定统一使用 `npm run balance:track`，必须实际结算仙缘、道果、计数和重置后才算完成。到达某境、观察截止、进度快照、来源可达都不等于通关测定完成。命令与流水口径见 [工具说明](../tools/README.md) 和 [测定说明](../tools/BALANCE-TRACKING.md)。

不因历史文档曾运行长测而继承新的测试授权；执行范围服从当前项目规则及用户指令。暂不以提高失败／死亡率拖长经营进程。

## 保留的边界

- 弟子突破仍不引入死亡；新死亡来源为高危猎场与低于安全境界的世界驻守，死亡减免均不覆盖。
- 境界停滞、永久潜力损伤、独立力量／体质／悟性和洗练仍未纳入当前方向。
- 岗位分工由玩家决定，现有岗位专长自动匹配可暂停；不引入隐藏权重的后台改派。
- 新局首启来源、前级仓容、共享资源支付及在线／离线一致性须保持；后续内容更新的旧档按已确认简化策略处理，不要求维持旧产能或旧投资权益。
- 旧“道果主动改资质”、位面洞天出口及按飞升次数直接升级环境等方案，统一在新轮回策划中重新评审，不作为另一套并行已定规则。

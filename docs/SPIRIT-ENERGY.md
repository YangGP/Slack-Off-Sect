# 灵子与灵能设定

本文是世界观设定及功法应用草案。灵子、灵能及其运化之则属本世界的假定，以修行术语与天地之理相述，不求与世俗学说逐项对应。文中示例表示此道可发展的方向，不代表游戏中已实现的法门或设施。

## 一、核心框架

### 1. 基本关系

- **正灵子 / 负灵子**：两种相反而相成的基本灵质。“灵子”是微粒之体，“灵荷”是其所禀之性；正者外发、负者内敛，正负只言其性，不表善恶。
- **灵能**：正负灵子相感相激而生的运化之力，可蓄、可传、可化。气之流转、法之施放、器之驱转，皆赖此力。
- **灵气分子**：一枚正灵子与一枚负灵子相抱而成的稳定之体，是寻常灵气的基本单元。其外中和，其内却含可被外力引动的两仪之构。
- **灵气**：无数灵气分子与灵能激荡相生而成的天地之气。日常多指气态，广义亦含凝成的灵液与灵晶。寻常灵气整体中和，可含少量游离灵子。
- **灵能 / 灵力**：灵能是天地间可蓄、可传、可化之力；灵力是修士或器物能调动的有效之力。灵能是力之本体，不可与承载它的形势混作一谈。
- **仙灵力**：灵气分子在灵能充沛处受灵能催化、吸能聚合而成的稳定高阶结构，是飞升前最后一种基础材料；炼虚后即可发现，稳定不逸散。（v0.37已实现，见 §一.5）
- **灵石 / 灵晶 / 灵脉 / 灵泉**：灵石是含灵气的矿石，既可采自矿脉，也可将灵气灌入相宜石材养成；矿为承灵之器，灵气不能凭空化为凡石。灵晶是灵气分子纯净有序凝成的结晶；灵脉是汇聚输布灵气的地脉；灵泉是富含灵液或溶有灵气分子的泉水。

一句话：

> 正负灵子相抱成灵气分子，分子聚而为灵气，灵能运化其间；聚则成形，散则成力。

（补充设定）灵能虽与灵子、灵气同源，却非处处可得。宗门最早在化神立起湮灭炉、逼使正负灵子成对湮灭之时**观测**到它 —— 炉中翻出的第一缕灵能，让这一力量第一次可被认知；直到炼虚《灵能输配》定下蓄、传、回收之法，才算把它**定义**为可经营的库存之力，接入工位与建筑。而湮灭炉的座数本身，也成为宗门全局增产的一层来源。顺序上「应用可先于原理」：先有化神湮灭炉的灵能，才有炼虚成体系的灵能应用。已随 v0.37 实施（见本文 §十）。

### 2. 灵子相感之理

灵子之间的作用，古来以四条常理总括：

1. **同异相感**：正者外发、负者内敛，异性相引、同性相斥。
2. **环转不孤**：灵子之运化外无始终，其势成环，天地无孤生之形。
3. **动中生静**：灵势一变，即感应出另一层之力，动静相召。
4. **静中生动**：灵流一行，其周必起环转之势，如江行成涡、风过成旋。

此四理言力之如何生、如何传，未足以尽释分子何以相抱而稳、神魂何以长存、空间何以折叠；后者还须下面的束缚之则，以及相应的材料、生机与空间之缘。灵荷、灵压、灵流、灵阻，分别言其禀赋、驱动之势、灵质之输运与输运之阻碍。

### 3. 灵气是什么

灵气并非最根本之物，而是：

> **无数灵气分子与灵能激荡相生而成的天地之气。**

天地天然之灵气未必有序；修行与阵法可使其化为定向灵流、共鸣振荡或稳定之势。

灵气常见三种形貌：

- **气**：稀薄灵气分子弥漫天地。
- **液**：在相宜的灵压、温养与束缚之下凝成的高密灵液，可汇入灵泉。
- **晶**：分子循稳定晶格相叠，凝成灵晶。灵石中的分子由矿石孔隙、晶格与杂质共同承载，不等同于纯灵晶。

五行之属并非五种灵子，而是：

- **火**：易向外放灵能的躁动之性。
- **水**：绵延输运、柔顺应变之性。
- **金**：定向凝练、便于导引聚束之性。
- **木**：与生机代谢、生长相合之性。
- **土**：承载、缓冲、安定之势。

五行是分子排布、取向、振荡、形势与承载之介质共同呈现的禀性。同一分子可入不同属性的灵气，属性之间可混可化；具体转化须备材料与灵能。正负多寡主要改其净灵荷，不直接决定五行。

### 4. 聚散、解离与湮灭

本世界假定，灵子之间除灵荷相感之外，另有一层使分子稳固的短程束缚之则。寻常束缚与湮灭之间隔着一道门槛；整体中和只说其对外之性，稳固源于束缚之构与这道门槛。

| 过程 | 发生什么 | 灵能与物料去向 |
| --- | --- | --- |
| 离析 | 从天地灵气中提取、聚拢完整的灵气分子 | 耗操作之力，分子仍完整 |
| 解离 | 破开分子束缚，分出自由的正负灵子 | 输入解离之力，须有阵法维持分离 |
| 复合 | 正负灵子重归稳固的分子之抱 | 放出结合之力；数目与灵荷仍相配 |
| 湮灭 | 以特定阵势使正负灵子越过那道门槛 | 成对消去灵子，化为灵能、霞光与热；不留下原分子 |

寻常相撞或散或合，未必湮灭。湮灭炉须同调供料、灵势与阵形，方能持续提取灵能；单靠解离不会凭空放力。

灵能转化须有账可查：储能来自外供或燃耗，输运与炼制皆有损耗，积热须移往他处。解离—复合之循环不能净生之力；湮灭耗料，再造等量之料至少须补回相应之力。聚灵阵收天地之气，灵脉汇聚或由更大的天地循环相补，不能无条件无尽供力。所谓“纯净”指杂质少、易于调控，不表示没有余热。

### 5. 仙灵力的聚合与用途

（v0.37 已实施；炼虚后发现并参与后期发展。当前来源与后续用途见本文 §十一。）

- **微观**：多个灵气分子在灵能充沛之处，吸收并固结灵能，聚合为稳定的新结构。与"湮灭"（正负灵子成对化能为灵能，放能、耗料、易散）相反，仙灵力是**吸能、聚合、稳定化**的方向，故**不逸散**。
- **分工**：气、液、晶是灵气的不同形态；离析分子、解离灵子与湮灭连接能源产业；分子吸能聚合则通向仙灵材料产业。仙灵力是高阶基础投入，飞升阵印是专用工程成品；阵印配方不直接叠加仙灵力，仙灵力以替换方式进入成道准备的可选投入。
- **发现与工业**：炼虚后即可发现。初期（采仙台）采聚天地间自然聚合的微量仙灵力，可用灵气托起相激之场，仅供发现与首批用途；稳定量产（聚仙阵）于合体以后利用受控湮灭的灵能主动聚合固结，基础运行必须支付灵能，不以灵气档绕过固结所需能量。发现与量产分属不同途径。
- **用途**：作为飞升前最后一种基础材料，参与后期研究、营造、法宝和加工，并用于成道准备；分阶段引入，不要求所有后期条目都消耗它。首批用途、阶段费用以及与阵印的配方关系待设计。

## 二、正负灵子的用途

### 1. 正灵子

其用偏“放、生、明、攻、疗”。此为术法传统与材料感应之倾向，非善恶或秩序的固有之性；同样外放，既可疗伤，亦可灼毁。

- **修行**：炼体、开脉、淬骨、阳神、金丹、雷法。
- **法术**：光、热、雷、火、净化、疗愈、驱邪、破幻、增幅、御空。
- **炼器**：阳纹、飞剑加速、灵灯、炉火、爆裂法器、护身罡气。
- **阵法**：输出端、聚灵端、天罡阵眼、传讯节点。
- **丹药**：补气血、破瓶颈、淬体、延寿、驱阴毒。
- **灵植妖兽**：阳属性灵药，火、雷、光系妖兽。

过量之患：暴躁、自燃、经脉灼裂。

### 2. 负灵子

其用偏“收、藏、暗、噬、魂”。收敛可镇静、保存、封护、疗愈，亦可用于吞噬、咒诅；用途取决于阵势与施为者。

- **修行**：阴神、鬼道、魔功、元神、隐匿、吞噬、空间。
- **法术**：冰、暗、腐蚀、噬灵、控魂、咒诅、通幽、遁术、削弱、封禁。
- **炼器**：阴纹、储物、锁魂、冷却、隐匿、空间折叠、噬灵法器。
- **阵法**：吸收端、聚阴端、迷阵、封魂阵、噬灵阵、地煞阵眼。
- **丹药**：凝魂、化毒、阴丹、鬼丹、隐匿气息。
- **灵植妖兽**：阴属性、冥界灵植，影、冰、魂、毒系妖兽。

过量之患：阴寒入髓、神魂癫狂、易被阴物寄生。

### 3. 正负相合

- **正负相抱**：成灵气分子，分子之排布与所在介质决定灵气属性；游离灵子另改其灵荷。
- **正负湮灭**：越过那道门槛即成对消去，放出雄浑灵能。
- **正负相离**：成灵子之势差，如阴阳分判，驱动阵法、法器、傀儡。
- **正负灵流**：如灵脉中奔行之灵机，可演为灵枢推演、传讯之网。
- **正负双修**：正灵子炼体，负灵子炼魂，正负交替淬炼。
- **禁灵之域**：抽散或扰乱正负灵子，令术法失其凭依。
- **信息与魂魄**：流转之势常用于传念、广播；稳固之抱常用于存放记忆与执念。魂魄须赖生机所成之奇巧之构，不能等同于一团负灵子；两类灵子皆可参与信息流转。

## 三、灵子视野下的法术与修行

### 1. 术法的路数与施为

术法之效，同取决于其缓急、刚柔、虚实、形势、所依之介质与所对之对象。以下是常见路数，非术法等级表；势猛未必力强，路数相同亦可成不同法术。

- **潜行绵长之势**：传讯玉简、灵网、地脉探测。
- **中正平和之势**：护盾、御剑、御空、控物。
- **刚猛迅疾之势**：雷法、火法、破阵、炼器。
- **纤微精妙之势**：高精度探测、强烈局域激发及部分湮灭调控，须专门介质与防护。
- **神魂相引**：神魂攻击、幻术、咒诅，赖于识神、控相与信息编码，可跨多种势。
- **同气相求**：双修、疗伤、破禁、炼丹。
- **相消相扰**：隐身、禁灵、抵消法术。
- **屏蔽隔绝**：以导灵材料、吸收结构与补阵削弱特定之势。屏蔽有范围、宽窄与承载之限，不能无条件封尽所有术法。

### 2. 修行境界与灵子之知

下表的尺度是**个人**：修士本人能感知、操作到什么，不代表宗门已有可持续、可复制的法门或设施（三尺度对照见本节末）。游戏内破境链为 11 境（凡体 → 引气入体 → 炼气 → 筑基 → …），认知相同的「引气入体」与「炼气」在此合并为「炼气」一行，故本表为 10 行。

| 境界 | 对灵子的认知（个人尺度） |
|---|---|
| 凡人 | 只知风水地气，不知灵气。 |
| 炼气 | 能感灵气、引气入体，然只把灵气当作一团连绵之“气”。 |
| 筑基 | 内视经脉，能感灵压、灵流、灵阻，已有灵子之猜，却无从证验。 |
| 金丹 | 结丹之际内压骤紧，少许灵气分子短暂解离，于内观中窥见正负灵荷一闪而逝，是修士亲证“灵子”之始；仍难对外复现。 |
| 元婴 | 神识离体、灵场外放，能直接分辨并驱使正负灵子。 |
| 化神 | 神识与灵能合一，能见灵子之云、之波、之势。 |
| 炼虚 | 能摄取游离灵子，结成灵子束、灵子对，布下禁灵之域。 |
| 合体 | 与天地灵能相合，可于灵子之微重塑肉身。 |
| 大乘 | 尽握灵子与灵能相生运化之至理。 |
| 渡劫 | 天地之力强行贯穿，修士直面自身灵子层面的失衡。 |

分界线：

- **炼气、筑基**：只知灵气，不知灵子。
- **金丹**：内观亲证灵子，然尚模糊。
- **元婴**：真正感知并驱使灵子。
- **化神以上**：把灵子之学化为可施之工。

个人能感知、短暂操作某种现象，不等于宗门已有可持续、可复制的法门。世界观中的个人能力、文明工程与游戏研究解锁分属三个尺度：

| 尺度 | 含义 | 示例（游离灵子／灵气分子／灵能） |
|---|---|---|
| 个人能力（§3.2） | 修士本人能感知或短暂操作 | 金丹内观到正负灵荷；炼虚能摄取游离灵子 |
| 文明工程（§4，设定目标） | 宗门／社会可复制、可持续的法门 | 金丹粗解分子、元婴直御正负灵子、炼虚成自由灵子之工（灵能炉） |
| 游戏研究解锁（当前实现） | 当前版本实际生效的 `realm` 门槛 | 分灵阵（灵气分子）≥ 元婴；偏极阵（正负灵子）≥ 化神；湮灭炉（灵能，并给一层全局增产）≥ 化神；采仙台（仙灵力）≥ 炼虚 |

三者常相错开：同一个境界名，在个人尺度上是能力，在文明工程尺度上是法门，在游戏里则可能更晚才落地。§四 表内“游戏已实现”列给出对应门槛。本表“文明工程”行与 §四“核心能力”列以境界设定为目标；“游戏研究解锁”行与 §四“游戏已实现”列为当前游戏实现（分灵阵元婴、偏极阵化神、湮灭炉化神）。

## 七、与当前游戏术语的对应

游戏中的资源“灵气分子”（`qiParticle`）表示离析后可供加工的分子库存；普通灵气资源表示尚未离析的天地之气。两者之别在可加工之态，不表示分子直到离析时才存在。资源数值是归一化的库存与流量，不是逐个灵子之数。

世界观、游戏资源及相关文档统一使用“灵气分子”，资源 id 保持不变以兼容存档。本文的空间、神魂与工坊示例仍属扩展设定；仙灵力及采仙台、聚仙阵、仙灵玉已有游戏实现，门槛与费用以源码和生成表为准。

当前游戏以归一化库存、流量和有效加工收益表示物料，境界与法宝倍率包含处理能力、回收率及损耗改善，不按逐个灵子之数解释。偏极阵另消耗灵气承担解离供能，任一极满仓时为下游成对用量限流。当前灵能枢消耗灵能并分配加工供能容量，工位额外负荷按实际运行时间耗气或耗能；热排散以共享冷却容量表示，晶核阵承担冷却回路，冷凝换热提升回路能力。没有单列余热库存，也不逐一追踪每个灵子之质量与能量；这些仍是工程经营的游戏抽象。

## 八、香火与因果的设定边界

香火描述信众愿念凝聚而成的神魂之构与仪式之资，感悟描述修士所得之知与修行之验；两者皆不可直接视为无代价而生之力。以其炼符、祭炼或调控设施，仍须物料与供能之条件。

因果、仙缘与道果属跨世修行之记录与成长之则，四条相感之理不直接推导它们。游戏中的永久增益是这一层的成长抽象，不表示可以凭空制造燃料，也不把灵荷的正负等同于道德善恶。

## 九、后期建筑的供能与维持

2026-10-13 调整设定。以下供能原则已确定；游戏中的建筑供能档（`upkeepQi` / `upkeepEnergy`）与三态切换已实施（数值待进一步校准），炉内自用能已从湮灭毛输出扣减，能源竞争仍待测；具体见本文 §十一的校准清单。

### 1. 从灵气驱动到灵能供给

炼虚后发展的高阶建筑，其主动功能需要持续供能：阵场控制、聚灵与输运、加工、环境调节、仪式运行皆有耗能。建筑结构与主动运行分别计算。

设定中的「灵能」是广义之力，灵气驱动同样提供灵能；游戏库存「灵能」`qiEnergy` 则表示可回收、调节与分配的高阶灵能，当前主要由湮灭取得。低阶灵流设施不因此变成无耗设施，也不因名称含「灵能」就必须消耗尚未开放的 `qiEnergy`。

| 工程阶段 | 建筑供能方式 |
| --- | --- |
| 元婴离析 | 分灵阵以灵气驱动，连续提取完整分子 |
| 化神分流 | 偏极阵以分子为料、灵气为动力，准备正负燃料；尚不要求灵能库存 |
| 化神供能 | 湮灭炉于化神提供高阶灵能，掌握输配后可将兼容设施接入灵能运行；高阶主动功能由持续灵能供给维持。湮灭炉座数同时构成宗门全局增产 |

阶段说明当前工程门槛，不新增研究境界硬门槛。研究、材料及仓容仍需逐项建立，玩家可提前投资或延后投产。灵气基础运行与灵能运行分别支付动力；高阶档提高回收与有效收益，分灵、偏极的物料投入不按高阶倍率重复加收。断供停止或降载主动功能，回到基础运行需明确切换并支付灵气成本。

### 2. 供能之链可自零而起

分灵阵保留灵气驱动的基础离析；偏极阵保留灵气供给的解离与分离维持，同时消耗完整分子。二者不以已有高阶灵能作为基础运行的必要条件，因此第一份燃料与断供后的恢复均可由上游灵气取得。

湮灭炉以正负灵子为燃料。设定上启动与阵形控制需要动力；当前游戏将控制用能从当期毛输出直接扣减，不另收启动灵气或要求既有灵能库存。灵气只需供应上游离析与解离，燃料到位即可启动和恢复。炉内用能必须计入灵能之账；寻常解离或复合仍不能凭空生力。

分灵阵与偏极阵的灵能强化属可选运行能力，不代替基础启动路径；湮灭炉不设灵能档。基础数据每秒毛输出0.06、自用0.015、净输出0.045，实际产出和燃料维护随吞吐提速，回收增益另计。初次启动或能源缓冲耗尽后应先用灵气档恢复上游，再按净供能决定是否切换高阶档。

### 3. 断供而存其构

实体住房名额、实体仓储及建成时已锚定的空间容量，在断供和停用后保留。聚灵、参悟增益、环境调节、阵法防护与仪式收益则随实际供能缩放；完全断供时对应运行效果消失。

洞天的空间边界在建成时锚定，持续供能负责内部场流、环境与调节。断供不收回锚定空间，不把已有物资删除，也不因住房名额消失直接驱逐弟子；居住配套失效仍可能通过宜居度规则产生负担。洞府的实体住房与环境调节同样分开。

本轮不设计需要持续供电才能存在的临时空间，亦不增加封仓、取物耗能或断供塌缩机制。储能容量本身不收运行费，储能转换、输送与主动调节可以耗能。

### 4. 耗与益分账而记

灵能维持不能代替所有物料投入。湮灭继续消耗燃料，建筑修缮继续需要材料，因果池的参悟继续需要灵机；引入灵能维护时应区分原有消耗中的动力、物料与修行投入，避免同一动力需求重复收费。

建筑固定维持、工位实际额外负荷、炉内辅助用能分别列出，停止运行就停止对应费用与主动收益。灵能只为已有工程与仪式提供运行条件，不能凭供电直接创造香火、因果、仙缘或无原料的材料产出。

## 十、灵能与宗门增产

当前实现中，**湮灭炉本身就是那层全局增产**（不另立反应堆建筑）。它以正负灵子为燃料、于化神即可建造；每座运行的湮灭炉给出一层既定倍率，累加为 `(1 + 每座增益 × 有效座数)`，独立于既有全局乘区，与设施自身的高阶运行、特定产业增益和工位加工加速各有分工。顺序为：化神建湮灭炉产灵能＝全局增产（灵能被发现）→ 炼虚研究《灵能输配》开展应用 → 继而发现仙灵力（应用可先于原理）。仙灵力作为基础材料的连续产线可受益；该层不作用于粒子链（灵气分子、正负灵子与灵能），以保持其一对一配比与燃料自洽，其他来源的增益照常生效。具体门槛、造价、收益和耗能待校准；已随 v0.37 实施，待校准范围见本文 §十一。

### 未实施用途与设计约束

更多仙灵力高阶建筑、加工、节料技艺与渡劫护道用途尚未定案。可考虑替换部分高阶护道材料，或引入独立飞升工程，不在旧费用上无条件追加。飞升阵印配方目前不加入仙灵力；若改配方，须整体重定投入。

首个来源和必要研究不得消耗只能由自身提供的仙灵力，强制用途晚于可持续供给，冲炼虚不得要求炼虚后才可取得的物资。冲合体如采用仙灵力，先评估采聚能力，可选护道与基础费用分别决定。新方案同步数据、引擎、界面、规则及存档兼容，已有研究与建筑不追缴。

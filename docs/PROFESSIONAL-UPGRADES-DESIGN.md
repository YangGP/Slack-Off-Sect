## 4. 效果层与投资分工

| 效果层 | 职责与限制 |
| --- | --- |
| 资源比例／岗位比例 | 分别作用于指定资源、岗位；岗位可能同时影响主副产物，两层不合并 |
| 制作增产 | 每份成品增多，适用手动及自动，与加工速度不同 |
| 配方效率 | 同一工位完成更多指定配方工作，只改善自动加工 |
| 工位容量 | 同组共享能力增加，仍受动力、冷却、速限和供料约束 |
| 节料 | 减少指定配方全部原料，同层相加、上限50% |
| 法宝祭炼 | 依既有规则反复投资，与一次性技艺保留不同曲线 |
| 小界支援 | 消耗当段产流换取指定效果，没有实际工作时不保留免费收益 |

例：效率已有+50%，再加25个百分点，固定工位理论出货增加约16.7%，不是独立乘1.25；缺料时可能不增加出货。知识效率、容量和节料不能按文案百分比直接比较。

通灵枢作用于凝聚容量，丹髓炉作用于所选丹药效率，与地面技艺叠入对应层。六项小界技艺单列于[小界专题](SMALL-WORLDS-DESIGN.md)。三仙材和阵印的独立计时不自动接受普通配方效率；阵印仍固定每份一枚、不吃节料。

## 5. 保留与暂缓的删并

四件宜居法宝暂不合并，安居结不删除。静心蒲团／清尘铃、安居灵幡／试炼钟虽然效果相近，但取得时点、材料及供养阈值不同，未完成阈值比较前不继续删减。

入山谣与玄铁斧保留一次性技艺和可祭炼器物的区别；阵基规制与定纹模刻保留早期首启与后期深化；晶纹精修、校准和七宝晶灯保留节料／效率、一次性增产、可祭炼增产的区别。仓储技艺按实际资源与倍率层判断，不因部分加工品不限仓就删除仍影响原料的容量。

灵流／灵渠、知识及仓储系列的展示收拢仍是界面建议，尚未作为系列卡片实施；展示分组不等于减少购买节点。观星盘改职能、天工坊专精及更多法宝继续评估，不新增全局通用倍率或猎场／驻守免死。

# 基础生产设施的灵能改造

更新：2026-10-25。状态：**内容策划草案，未实施**。用户指定参照猫国，为适合的基础资源生产设施增加升级形态，升级后以灵能持续维护。具体产出、耗能与造价为首轮候选，不能当作现行规则或已验证平衡。

本文承接[专业应用升级](PROFESSIONAL-UPGRADES-DESIGN.md)，与[小界支援](SMALL-WORLDS-DESIGN.md)共享供能预算；旧档执行[已确认简化策略](ENGINEERING.md#后续内容重构的旧档策略)，只要求正常读写和继续游戏，不做旧投资或旧效果等价补偿。

## 1. 猫国参考与本作范围

本地猫国的 [buildings.js](../cat-zh-master/js/buildings.js) 提供分阶段建筑：牧场→太阳能设施、引水渠→水电设施、图书馆→数据中心等。建筑控制器的 `deltagrade` 在切阶段时把该类 `val` 和 `on` 清零，需要按新阶段价格重新建设；数据中心有持续能源需求。不是所有升级都消耗能源，前两项实际上是能源生产设施。

本作借鉴“改造改变设施能力、造价与运行成本”的结构，按用户要求把本轮高阶生产设施设为灵能消费者。首轮选择五类，不扩展所有建筑：

| 设施 | 是否本轮改造 | 原因 |
| --- | --- | --- |
| 伐木场 | 是 | 后期灵木需求仍在，以动力强化设施对持续采木的增益 |
| 采矿场 | 是 | 强化矿石供给，服务秘银与建材产业；兼顾已有矿产比例效果 |
| 炼铁炉 | 是 | 用灵能替代烧木供热，提高矿石转化规模，仍要消耗真实矿料 |
| 灵石矿 | 是 | 动力开采形成天然灵石的后期扩产选择，与早期灵液注灵分工 |
| 药圃 | 是 | 提高灵草生产增益，并支持已有育草工位，服务丹药与终局培养 |
| 聚灵阵、聚灵大阵 | 暂不纳入 | 保留不依赖灵能的基础引气与恢复手段，不把供养和能源启动一起改成强制耗能；聚灵大阵仍支付现有灵气维护 |

灵机、香火和信符分别属于知识、信仰与任务凭信，本轮不把藏经阁、山门和执符堂混入基础物资改造。分灵、偏极、湮灭及聚仙等设施继续沿用原有能源链，不借本次改造新增灵能产出或通用反应堆倍率。

## 2. 升级操作与建设方式

采用**同类建筑阶段改造**，每类只有基础／灵能两个阶段，同一类不同时保留两套数量。

1. 炼虚掌握《灵能输配》，再手动取得新的应用资格《灵能营造》（名称及新ID候选 `poweredProduction`），即可逐类选择改造；各类仍校验自身专业知识。
2. 主动点击“改造为灵能设施”后，该类旧建筑数量清零、不返还材料，阶段切为高阶，默认停用。界面预先明确损失的旧数量、新形态的首座价格、灵能维护与产出变化；不以普通开关伪装这个操作。
3. 玩家按高阶造价手动建设，并手动启用。改造本身不赠建筑，不自动消费一大批建材替玩家重建；高阶第一座不要求先拥有一座已经被清空的基础建筑，避免自锁。
4. 同类后续建设采用高阶自己的基础造价和涨价率；不能继续用早期木料价建设高阶设施。新阶段没有旧数量和旧价格指数继承。
5. 可主动退回基础阶段，同样清零当前类数量、不返材料，再按基础造价重建。不存在免费保留高阶数量并切回基础运行的方式。
6. 关闭只停止该类高阶设施的运行和维护，不降级、不退款；缺能只按供给降载，不自动改回基础阶段。

这套清零是玩家主动改造的经营规则，不是版本更新时把所有旧生产设施一并删除。旧档原建筑默认仍在基础阶段，由玩家选择改哪一类；需要真正删除的旧技艺另按第7节硬清理。

## 3. 五种升级形态与运行候选

下表均为**每座满供、未叠加其他增益的基础量**。比例指对应已有资源加成层的百分点，不是给最终产量再独立乘三倍；用能与资源收支必须显示实际值。

| 基础→高阶名称候选 | 高阶效果候选 | 每座灵能维护 | 其他运行物料 | 专业条件方向 |
| --- | --- | ---: | --- | --- |
| 伐木场→灵锯采木场 | 每座灵木持续产出比例+30%，基础形态为+10% | 0.002／秒，7.2／小时 | 无新增物料维护 | 灵纹锯阵；仍需樵夫等原有持续产木来源 |
| 采矿场→灵钻矿场 | 每座矿石产出比例+35%、玄铁及灵石各+10%；基础形态三项均+10% | 0.003／秒，10.8／小时 | 无新增物料维护 | 矿脉通灵；首轮把强化重点放在矿石，不同时大幅放大三类矿产 |
| 炼铁炉→灵能冶铁炉 | 每座基础产玄铁0.45／秒，原为0.15；矿石耗0.6／秒，原为0.3 | 0.008／秒，28.8／小时 | 不再烧灵木，保留矿石输入；缺矿与缺能均限制实际运行 | 灵火冶炼；不是直接产玄钢，也不自动提高炼器工位容量 |
| 灵石矿→灵脉采掘井 | 每座给每名有效矿工的天然灵石基础副产出0.0045／秒，原为0.0015 | 0.004／秒，14.4／小时 | 高阶不再用原灵液注灵，也不叠加其翻倍 | 注灵原理、秘银提炼；无人采矿时不产石且不收该井用能 |
| 药圃→灵能药圃 | 每座灵草持续产出比例+30%，原为+10%；每3座满供提供2单位育草容量，原为1 | 0.003／秒，10.8／小时 | 仙草配方原料仍照常支付，不凭空产仙草 | 百草育灵；原采药人与育草自动配方仍各守原条件 |

这些专业条件大部分是现有ID，不再为五类各新增一条内容重复的研究链。若某个专业条件在应用深化中合并，按最终新目录引用，不能让已删除ID继续充当前置。

### 3.1 一次性建设费用候选

取得改造资格的知识费用与每座建筑造价分开；不额外收一笔按历史数量计算的改造差价。以下为高阶首座对照报价，尚未冻结：

| 高阶设施 | 首座材料候选 | 同阶段建设涨价率候选 |
| --- | --- | ---: |
| 灵锯采木场 | 木板20、玄钢8、阵基4、灵晶10 | 1.25 |
| 灵钻矿场 | 石材200、玄钢10、秘银2、阵基6 | 1.25 |
| 灵能冶铁炉 | 玄铁混灵土12、玄钢10、秘银3、灵符4 | 1.30 |
| 灵脉采掘井 | 玄铁混灵土10、秘银5、灵晶20、灵符4 | 1.35 |
| 灵能药圃 | 混灵土12、阵基6、灵液20、仙草4 | 1.25 |

首座均只使用炼虚及以前已有材料，不用大乘晶银、界枢或未来世界独占产物。精确价格依据“舍弃基础设施→重建→取得净收益”的完整过程比较，不能只把新设施与已经涨价的第几十座旧设施做表面比较。

《灵能营造》资格只开放改造，不再附赠所有原料+25%；报价须与这个新职责匹配，不能机械继承旧《灵能引采》的150000灵机费用。全五类改造不是通往飞升的硬条件，原基础形态始终保留为可选路线。

## 4. 收益与维护的明确边界

### 4.1 按设施类型计算

- **伐木／采矿／药圃的资源比例**：只计算启用数量×实际供给比例带来的设施加成。断能后这部分为0；不会免费保留升级前的+10%。岗位本身原有的手工生产按既有条件继续，不把“设施加成停效”写成“所有弟子产出归零”。
- **灵能冶铁炉的直接产出**：矿石和灵能使用同一可支付运行比例。断任一种都不免费产铁；原矿工的手工玄铁副产出仍是独立来源，不因停炉被一起关闭。
- **灵脉采掘井的副产出**：必须把该井实际供给比例纳入矿工天然灵石副产出的计算。不能只清零建筑effects，却让岗位secondary仍按全部建成数继续产石；点石成灵的制作配方不受此升级直接放大。
- **灵能药圃的育草容量**：按有效供给增加容量，不按物理建成数免费提供满额工位；和《草脉温养》候选比例加成按工位公式计算。缺灵草或灵液时，扩大工位并不保证仙草持续出货。
- **灵石矿旧注灵**：基础阶段继续允许原灵液注灵；高阶阶段强制忽略并清理旧注灵开启状态，只收灵能、不再收这笔灵液，不能把0.0045再乘旧翻倍。退回基础阶段后注灵默认关闭，由玩家手动设置。

高阶维护基数按每座启用数计算，与实际供给同比缩减；不因为法宝祭炼、宜居或资源倍率而自动再次提高用能。炼铁的原料及出料倍率须沿用明确的现有结算层，不能为了实现新形态随意增加一层`throughput`，造成维护在旧公式之外重复放大。表中冶铁数字是基础账，最终产出与原料账需各按实际公式显示。

除天然灵石井明确要求矿工外，本轮不新增复杂的自动识别闲置／满仓停机机制；例如药圃无人采药但仍在加工仙草时依然需要运行，不能仅按岗位人数决定是否免费。启用但无实际需求时，玩家可以手动停用，界面应显示闲置用能。

### 4.2 灵能预算

五类各启用一座的满供维护合计 `0.020灵能／秒＝72／小时`，相当于当前一个基础聚灵小界采集级的灵能维护。作为量级参考，一座湮灭炉基础毛产0.06／秒、炉内自用0.015／秒，基础净供0.045／秒；五座用掉这个归一化净额约44.4%，还未计其他设施、灵能枢、加工、逸散及小界需求。这不是实际角色配置下“一座炉子保证供五类”的承诺。

10座每类的账是720灵能／小时；禁止把早期几十座基础建筑免费逐座转成高阶后立即满开。玩家应比较先改哪一类、重建多少座、是否还能供世界和地面加工。灵能与物料缺口、现有库存可支撑时间及高阶实际供给需直接展示，不以只列毛产量隐藏断供。

沿用共享供能的按比例降载，不在本轮加入优先级电网或后台自动改派。世界、法宝、工位与高阶生产设施不得各自消费同一份灵能库存；空仓时也要计入当段真实生成的可供量，不能一处认定有电、另一处又按库存重复扣。

### 4.3 供能恢复与循环

聚灵阵、阵徒和基础阶段生产路径保持可用。若改造导致缺矿、缺能或缺重建材料，允许玩家主动退回相应基础阶段重建，不加额外回退材料门槛。正常断供只停效，不毁建筑、不追加惩罚。

不能靠“高阶有数量”获得矿场供给、天然灵石或育草能力，再拿未供能的假产出去证明本段能源充足。供给求解只使用实际运行量，已有迭代需保持有界；不能让离线大步长绕过维护或以负库存补账。

## 5. 与专业应用和小界的取舍

现有技艺《灵能引采》`energyDrive`目前只提供木、草、玄铁、矿石、灵石各+25%，没有持续用能，也没有下游目录依赖。建议实际删除该旧条目，替换为新资格《灵能营造》；旧档已学的+25%直接移除，不折算、不退款，新资格未学。这是一个旧应用被一个新资格替代，不是另叠一层免费增产。

目录无下游不代表全仓库无引用：`tools/upgrade-source-audit.mjs`、`tools/power-scenarios.mjs`与`tools/smoke/catalog.mjs`仍引用旧ID。实施时同步调整对应审计和夹具，不能保留一个不起作用的旧标记来假装覆盖新设施供能。

- 伐木、矿石与灵草：高阶设施改善可扩建的生产设备；专业技艺仍负责其既定原料或工位效果，不再新增同义“灵能增产25%”。
- 炼铁：升级炉子生产玄铁；《灵火冶炼》改善玄钢／器物加工。输入和产物不同，不合并为一个没有物料成本的“金属产量”倍率。
- 药圃：高阶每3座提供2个基础育草容量，地面《草脉温养》再按同层容量比例计算；两者分别代表建设与工艺。首轮必须一起核算，不能各按孤立场景定成必买。
- 护道小界《协灵阵》首版仍只改善既定住房／宜居／洞天等目标，不自动覆盖本轮五类生产设施，以免新增供给和节能一开始就相互抵消。
- 聚灵小界和五类设施争用灵能，各有不同回报；不为逼迫改造同步抬高普通飞升仙灵力账单。

本轮是五种阶段变体，不把当前建筑50种直接说成55种新独立建筑；《灵能引采》替换资格也不计为新增一项净内容。若实现最终采用不同ID来表示阶段，统计时仍按“5种升级形态”单列。

## 6. 界面与数据实现边界

界面保留原生产分类，在对应建筑卡显示基础／灵能阶段、改造条件、下一阶段名称和首座价格。改造预览明确“本类现有N座将清零，需手动重建”，原数量不当作新形态的预期收益。材料不足以重建第一座时明确提示，玩家仍可自行决定时机。

高阶卡显示每座及全组灵能维护、实际供给比例、满供与当前产出、炼铁矿石支出和灵石井有效矿工人数；药圃另显示有效育草容量。高阶有启停按钮，没有灵气供能档；关闭、断供与退回基础三者文案分开。

现有代码可复用资源支付、启停和供给预算，但**只往元数据加`upkeepEnergy`和`powerMult`不够**：

1. 需要统一解析当前阶段的名字、造价、涨价率、效果、维护、岗位副产出与工位容量；建筑操作、价格提示、来源明细、解锁条件和模拟工具共用同一阶段数据。
2. 当前灵石矿副产出在`jobOutputs`另行计算，必须识别新阶段和真实供给；当前`boost`界面也写死了灵液注灵，需按阶段决定是否展示。
3. 当前育草基础容量由药圃数量取得，需识别高阶2／3系数与供给，防止效果、工位各乘一次升级倍率。
4. 同类数量清零时仍需保存阶段，避免改造后尚未建设、保存读档就丢失改造选择；改造或回退原子处理数量、启停、注灵设置和阶段。
5. 报价及静态金额缓存必须随阶段正确切换，不能显示高阶价格却扣基础价，或拆除按另一阶段返料。拆除只依据当前阶段实际建筑和对应现行规则，改造／回退不发拆除退款。

技术实现按必要范围展开，不为参考猫国引入完整多时代建筑树或复杂施工系统。

## 7. 旧档和重置

- 旧建筑没有阶段字段时默认基础形态，数量直接保留；不自动升级、不自动开灵能维护。
- 旧《灵能引采》及其自动重建引用直接清理，新《灵能营造》未学；永久资产和所有保留资源库存数字不变，不补偿25%产出差额。
- 其他未变研究、弟子和建筑保留。已有高阶形态的新存档正常保存阶段、数量和启停；再次读档不清零。只有玩家主动改造／回退才执行对应数量清理。
- 转世、飞升、身死按既有规则重置本世建筑和研究，下一世恢复基础形态；重建偏好不得越过当前境界和资格自动升级，新增改造默认由玩家手动选择。
- 兼容只要求能读写和继续经营、不报错、不留悬空引用、不重复扣费／退款、不出现非法库存；不保旧产能、旧投资或原经营路线。

## 8. 后续验证和定价

本次只做本地源码阅读、基础账目复算与策划整理，不修改业务代码，不运行游戏测试、构建或长模拟。实施前还需冻结资格费用、五类首座及边际造价、基础／高阶真实供料对照。

实施时优先复用现有单个供能／建筑／存档用例或5秒内短脚本，必要检查为：改造与回退清零且无退款；阶段0座可存档；新造价／拆除／缓存同源；断供停高阶效果；矿井副产出和育草容量不绕过供给；炼铁同时支付矿料与灵能；无人矿井不收费；高阶不叠旧注灵；旧档不自动改造；普通基础路线仍能启动并恢复供能。只检查新增运行规则，不扩展旧投资等价矩阵。

自然回本与完整周目仍需另获长测授权，不把每座比例三倍解释为宗门产出三倍，也不把理论满供结果写成现实耗时已达标。

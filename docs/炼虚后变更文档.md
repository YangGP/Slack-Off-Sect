## 变更 2–4：待测清单

修真应用、后期研究调整和建筑三态供能已实施，后续需要：

- 核对四座原理建筑与精研的重复收益，再决定是否设置叠加上限。
- 现有粒子研究与供能已做首轮校准；后续继续比较不同建设规模、祭炼等级、加工负荷与上线频率，避免只用固定夹具判断平衡。实际配置以 TABLES 为准。
- 评估大乘心经多产业增益和心印独立收费的价值。

- 如新增独立湮灭启动费用，需重新验证首启和恢复；当前控制用能从毛输出扣减，不另收启动费用。
- 评估缺供分配、自动备用，以及飞升预览中因果池有效收益的显示。
- 对比建筑扩建、灵能枢、加工驱动、灵能引采和飞升阵印之间的灵能竞争。
- 完整产线的零库存首启、断供恢复、停用、容量保留与在线／离线一致性已有回归；继续扩展长时经营、重修和不同旧档的组合场景。

住房名额、实体仓储与已锚定的洞天空间在停用或断供时保留；主动收益按运行模式与实际供给缩放。四座原理建筑保留早期启动职责，不自动增加灵能维护。完整运行规则以 DESIGN 为准。

## 变更 5：仙灵力（已实施，待校准）

**已定定位**：炼虚后即可发现，作为飞升前最后一种基础材料参与后期发展。它属于本世可积累、可消耗的物资；形成稳定结构、不逸散。发现与量产分两阶段设计，具体数值待校准。

仙灵力不能只作为渡劫前才开放的一项筹备材料。它应连接研究、建筑、法宝与加工，再进入飞升准备；各用途分阶段引入，不要求所有后期条目都消耗它。

**设定**：灵气分子吸收灵能，聚合为稳定的高阶结构。灵能既是输入之力，也有一部分被固结在产物中；具体催化、供能与物料消耗需分别记账。能源产业与仙灵材料产业是两条相连的分支，不用单条“形态阶梯”代替全部关系。

### 5.1 资源规格（已实施，数值待校准）

| 项 | 取值 | 说明 |
| --- | --- | --- |
| id | `immortalForce` | 已落库，与 `qiParticle`／`qiEnergy` 命名口径一致 |
| 名称 | 仙灵力 | 与文档、界面、世界观统一 |
| 分组 | 灵子与灵能 | 作为粒子链末端条目，排在灵能之后、飞升阵印之前 |
| 整数规则 | 非整数 | 与灵能同属可连续计量的能量—物料 |
| 逸散 | 无 | 与灵能（每秒 ×0.995 逸散）相反，稳定不逸散，不设衰减 |
| storageWeight | 0.5（待校准） | 高密度高阶材料，较常规物资省仓 |
| 基础容量 | 待校准 | 由已有洞天、通天塔与后续专门扩仓承接 |

- 仙灵力不新增独立资源倍率层；专业增益由对应研究／法宝提供，与既有粒子资源同口径。
- 发现前不预告可见资源；已有库存或历史峰值后按渐隐规则显示。

### 5.2 两阶段获取：采聚与聚合

「发现」与「稳定量产」分属两处设施、两个境界门槛：发现以低门槛采聚为主，量产须以灵能主动固结，不用灵气档绕过固结所需能量。

| 阶段 | 设施 | 境界 | 动力 | 输入 | 角色 |
| --- | --- | --- | --- | --- | --- |
| 发现 / 初期获取 | 采仙台 | 炼虚 | 灵气驱动 | 灵气分子 + 灵气维持 | 采聚天地间自然聚合的微量仙灵力，仅供发现与首批用途 |
| 稳定量产 | 聚仙阵 | 合体 | 灵能驱动（无灵气档） | 灵气分子 + 灵能 | 以受控湮灭灵能主动聚合固结，连续量产 |

**采仙台（炼虚，发现）**：炼虚设定中的「灵子相激之场」在宗门落地为采仙台 —— 以灵气托起相激之场，从天地灵能充沛处聚拢**自然生成**的仙灵力。它不是合成固结产线，故可用灵气驱动基础运行；产速与容量受严格限制，只够发现与首批用途，不构成量产。

- 设计：`needs: { realm: 7, upgrades: ['immortalDiscovery'] }`；`effects: { prod: { immortalForce: <微量/s> } }`；`upkeep: { qiParticle: <小> }`，`upkeepQi: <小>`。
- 边界：灵气档只能采聚，不能固结；真正的固结量产必须由灵能驱动的聚仙阵承担，不得以灵气档替代。

**聚仙阵（合体，量产）**：以分子为料、灵能为力，连续聚合固结。

- 设计：`needs: { realm: 8, upgrades: ['immortalIndustry'] }`（前置《灵能输配》与《仙灵初探》）；`effects: { prod: { immortalForce: <量/s> } }`；`upkeep: { qiParticle: <小> }`，`upkeepEnergy: <小>`，**不设 `upkeepQi`** —— 引擎中只有 `upkeepEnergy` 的建筑恒走灵能档（`upkeepQi == null` 时强制灵能），天然满足“必须支付固结灵能、不能用灵气档绕过”。
- 该设施与工位驱动、建筑高阶运行、阵印固结及湮灭炉的灵能去向争用灵能，应形成经营取舍。

| 阶段 | 用途 | 状态 |

| 炼虚 | 发现并接入首批用途：一项后期研究或一件法宝的祭炼投入 | 仙灵玉已接入，后续用途待设计 |
| 合体 | 聚仙阵量产已实现；更多高阶建筑与加工用途待设计 | 部分实施 |

- 冲合体是否采用仙灵力，取决于炼虚初期来源的可达性与产能，保留为**可选护道**而非强制基础费用。

### 5.4 与飞升阵印的分工（后续用途方案）

- 飞升阵印配方保持现状（灵能80 + 秘银2 + 灵符1），**不直接加入仙灵力**，避免新旧费用叠加。
- 仙灵力以**替换**方式进入渡劫护道可选方案：用仙灵力替代部分高阶材料，方案总费用不叠加；或另设一项非阵印的仙灵类飞升工程消耗仙灵力。
- 若后续确需把仙灵力接入阵印，须整体重定阵印用料，而非在现有配方上追加。

### 5.5 获取与自举约束

- 灵能自化神湮灭炉起即可得（见变更 6），炼虚发现仙灵力时灵能已开放，初期来源不再受“不能用灵能”限制；采仙台仍以灵气驱动采聚作为低门槛发现途径。发现与稳定量产分属不同途径。
- 首个来源、必要研究和首座产出设施不得消耗只能由自身提供的仙灵力；所有费用应由已开放材料与仓容承接。
- 每项强制用途必须晚于其可持续供给。
- 量产方案以分子和灵能连续生产；设施的基础运行必须支付必要的灵能投入。

### 5.6 旧档兼容（要求）

- 新资源不能预先断言无需迁移：按最终接入方式验证发现、解锁、自动加工与容量。
- 旧档缺 `immortalForce` 字段时按 0 补齐；已过炼虚的旧档不自动补发研究或设施，由玩家按新链参悟。
- 迁页或改名沿用原 id 与已学记录，防止重复收费或补偿。

### 5.7 待校准数值清单

- 采仙台：产速、灵气分子与灵气维持、容量上限、可否重复建设。
- 聚仙阵：产速、投入配比（分子／灵能）、造价与指数、仓容承接。
- 研究：《仙灵初探》(`immortalDiscovery`) 与《仙灵聚合》(`immortalIndustry`) 的费用、前置与解锁条目。
- 仙灵玉已接入仙灵力产出增益及祭炼消耗；其费用与收益待校准，更多用途及与阵印的替换关系仍待设计。

## 变更 6：湮灭炉的全局增产（化神解锁，已实施，待校准）

**已定定位**：不另立「灵能反应堆」建筑 —— **湮灭炉本身就是那层全局增产**（参考猫国核反应堆）。每座运行的湮灭炉（烧正负灵子、产灵能）提供固定的一层全局生产倍率，可重复建设、可启停，收益随有效运行座数叠加；它与工位加速、特定资源增益、既有 ratioAll 分别记账。

**解锁提前到化神**：湮灭炉由合体提前到化神（realm 6），研究《湮灭法》前置阴阳分灵。化神即可建炉、产灵能，**灵能由此被“发现”**（可见、可积累，应用尚未开放）；**炼虚**研究《灵能输配》才算**“定义”并开展应用**（工位驱动、建筑高阶档、灵能枢、灵能引采等），随后**最后发现仙灵力**。顺序：**化神建湮灭炉 → 产灵能＝全局增产 → 炼虚研究《灵能输配》开展应用 → 发现仙灵力**。

**灵能的发现与定义**：湮灭炉产出的灵能正是这一层的来源。炉中翻出的第一缕灵能，让宗门在化神**发现**这一力量（可见、可积累）；直到炼虚《灵能输配》才把它**定义**为可蓄、可传、可回收之力，接入工位与建筑。“应用可先于原理”：先有化神湮灭炉的灵能，才有炼虚成体系的灵能应用。

“增加一层”指新的生产倍率来源，不是只结算一次的奖励。多座湮灭炉的加成先相加，再作为这一层倍率参与生产；例如每座 +5% 的试调方案中，两座满供为 ×1.10，具体百分比待校准。

### 6.1 增益层机制（已采纳）

- 设每座可运行湮灭炉提供 +b 的增益，累加得 `reactorRatio = Σ b·供给比例`，产量公式新增一层 `(1 + reactorRatio)`。
- 作用域与 ratioAll 一致，覆盖宗门持续资源生产，含后续仙灵力产线；**排除项：粒子链（灵气分子、正负灵子、灵能 `qiEnergy`）** —— 三者互为燃料与产物，属能源产业闭环，排除后该链保持一对一配比、燃料不自增。其他来源的增益（ratioAll、专业资源增益、境界／仙缘／道果全局倍率）继续按各自规则生效。
- 不作用：点击收益、每份手动／自动制作收益、事件奖励、仙缘与道果结算。
- **维护费与产出分账**：该层只放大产出，不缩放任何维护费；**每座湮灭炉的燃料维护费固定**，不随该层、也不因增产而上涨。湮灭炉因此不会自吞燃料，扩建的边际成本只体现在指数造价与灵子供给上限。
- 断供或停用：`reactorRatio` 与维护费按实际供给比例同步缩放，完全断供时归零。

实现建议：新增 `acc.reactorRatio`（或给现有全局增益增加来源级过滤），在产量结算处对粒子链（`REACTOR_EXCLUDED`：灵气分子、正负灵子、灵能）跳过该层；不要为这一建筑把所有 ratioAll 一律关闭。同步全局倍率展示、资源来源、费用预览、缺供缩放、启停与审计策略。

### 6.2 建筑规格（已采纳）

| 项 | 取值 | 说明 |
| --- | --- | --- |
| id | `annihilationFurnace` | 沿用现有建筑，不新增条目 |
| 名称 | 湮灭炉 | |
| 分组 | 奇观 | 可重复建设 |
| 解锁 | 化神（realm 6）+ 研究《湮灭法》，前置 阴阳分灵 | 由合体提前到化神；工业滞后由 1 境收窄为 0 境 |
| 燃料 | `upkeep: { yangParticle, yinParticle }`（成对，现有） | 偏极阵化神即产 |
| 产物 | `prod: { qiEnergy }` + `selfUse`（现有，毛输出扣自用能） | 净输出＝毛输出−自用能 |
| 增产 | 新增字段如 `ratioReactor: 0.05/座`（待校准） | 多座相加为单层倍率，随供给比例缩放 |
| 启停 | 支持停用 | 停用即停料停费停益 |

- 指数造价限制扩建速度，不是硬上限；运行规模受灵子供给（偏极阵）与灵能去向承接。
- 湮灭炉既产灵能又给全局增产，是化神阶段的核心投资：多做几座，全局增益与灵能同时增长，但也更吃灵子。

### 6.3 收益与消耗边界

- 加成面向宗门的持续资源生产（含仙灵力产线），不限定为少数采集或加工设施。
- 湮灭炉与粒子链（灵气分子、正负灵子、灵能）不受该层放大；其他来源的增益继续按各自规则生效。
- 每份手动或自动制作收益、点击、事件奖励、仙缘与道果结算不自动套用这一倍率；若后续希望扩大范围，须另定义规则和成本。
- 该层不作用于粒子链，因此不会因增产而间接放宽燃料供给；净收益仍须按实际吞吐、燃料、维护与余能测量。
- 停用或断供时减少对应费用与收益；灵子在偏极阵、湮灭炉之间的分配，以及灵能在工位驱动、建筑高阶、因果池、阵印固结、仙灵力产线之间的分配，应形成经营取舍。

### 6.4 与其它用途的竞争（待校准）

- 化神阶段：灵子仅偏极阵一条来源，湮灭炉是其唯一去向，炉数直接决定全局倍率与灵能产出；灵能只积累、不应用。
- 炼虚及以后：灵能在工位灵能驱动（每额外容量 0.1 灵能/s）、建筑高阶档、灵能引采、因果池、飞升阵印固结、聚仙阵量产与湮灭炉自发增产之间分配。
- 粒子链被排除在该层之外，其增产收益取决于其余产出的增量能否覆盖燃料成本；对照测量需覆盖满供、断供、不同炉数组合、在线／离线及与仙灵产业争灵能的表现。

### 6.5 待校准数值清单

- 湮灭炉 realm 门槛（8→6）、《湮灭法》建筑前置，与《灵能输配》realm 7 及费用。
- 每座额外全局倍率 b；是否随扩建递减或不设上限。
- 现有毛输出 0.06／自用 0.015／净 0.045 在新增全局增产后的灵能平衡与炉数规模。
- 缺供分配口径；湮灭炉扩建的边际收益（每座固定燃料 vs 全局倍率）与灵子供给上限。
- 与仙灵力产线、工位驱动、阵印固结的投资回报和阶段节奏。

## 当前实现与剩余范围

仙灵力、采仙台、聚仙阵、仙灵玉、湮灭炉全局增产及对应研究、仓容、界面与旧档补零均已实施，不再保留旧实施待办。当前源码与 [TABLES.md](TABLES.md) 为参数依据。

- 仙灵力已有定额仓容（广储库、洞天、通天塔）与须弥纳芥比例扩仓，不再作为缺失功能登记。
- 湮灭炉化神开放、每座增产 5%；采仙台炼虚发现、聚仙阵合体量产。继续按 §5.7、§6.5 校准投入与收益。
- 仙灵玉已提供仙灵力增产；新增节料技艺及更多仙灵力用途仍属于候选方向，尚未定案。
- 缺供分配、自动备用与飞升预览等条目属于待评估体验项，不代表现行供能尚未实现。
- v0.384 长离线已采用有界近似；长期供能审计应允许其与在线逐秒结果存在误差，重点验证资源预算、容量与恢复行为，不能再要求长离线逐位相同。

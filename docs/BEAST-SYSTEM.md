# 猎杀、外交与周边事务

更新：2026-10-23，对照v0.424。六猎场及宜居／培养产物首版已实现，装备系统明确不加入。新方向见[轮回策划](REINCARNATION-REDESIGN.md#12-六猎场用途与最小玩法建议)，本文描述首版实现，费用与节奏尚待整体校准。

## 当前范围

山麓、山野猎法、执符堂、执符使、暖裘居室、兽材加工、兽骨炼器、四项猎杀技艺、猎杀天赋、即时结算与自动重复已有实现。新增深山、禁地、灵兽苑、玄灵谷、荒古境及内丹、灵髓内丹、疗养草、护身药散、灵绒静舍；仅荒古境有死亡。警戒／抑制生态和替代配方扩展未落地，不沿用旧三猎场草案的报价作为现价。

猎杀与外交始终启用，模块字段只声明代码归属。旧关闭标记不再隐藏内容、阻断生产或过滤猎杀天赋。

## 信符与普通猎场

猎杀和互市共用信符`warrant`。执符堂开放执符使并提供仓容；岗位按真实弟子境界、专长及普通生产倍率开具信符，不直接生产兽材。

山麓需要山野猎法、启用中的执符堂及筑基宗门；每队1～5人，按弟子有效境界和天赋逐人计算。单次猎杀基础消耗100信符，猎杀专属减耗上限90%，费用保留精确小数；互市每次50信符，不受猎杀专属减耗影响。完整资源、费用与研究前置见[TABLES](TABLES.md)。

山麓产灵兽皮、灵兽骨及少量内丹。兽皮用于暖裘居室建设与持续维护，兽骨可经兽材加工接入法器替代配方；常规矿材炼器仍可用。普通猎场不要求先飞升。

## 即时猎杀与自动周期

- 玩家勾选有猎杀专长的加成人选，所选人选优先；普通弟子按真实期望贡献补足至多5人，未选的加成人选不自动加入。
- 一次出征原子完成资格检查、扣信符、逐人判定和掉落入库。不占用弟子、不清空岗位、不创建新的在途任务。
- 预览不消耗随机数，显示预计成功人数与期望掉落；每人独立判定，不能把预计人数叫整队成功率。
- 自动重复默认关闭，间隔可调。每周期最多尝试一次，信符不足或名单失效时跳过，不形成欠账；手动成功重置自动计时。
- 改间隔只改变尝试频率，不改变单次收益。单次的基准时长用于换算掉落，不代表要等待返回。
- 掉落小数直接入库，受实际仓容限制；没有待凑整的额外奖励池，也不因溢出保留无限待领库存。

## 4. 成功率与收益

当前山麓每名弟子的主要因子为：

```text
有效境界 e = min(弟子实际境界, 宗门境界)
效率 A = 2 ^ clamp((e - 推荐境界) / 2, -2, 1)
宗门支持 C = 1 + 0.1 × clamp(宗门境界 - 猎场入口境界, 0, 4)
成功率 p = clamp(猎场基础值 + 0.06 × 境界差 + 宗门支持项 + 技艺 + 本人准头天赋, 0.35, 0.99)
本人收获 y = 1 + 本人猎杀收获天赋
基础档期望系数 = p + 0.2 × (1-p)
期望材料 = 基准秒产 × 单次基准时长 × C × Σ(A × y × 期望系数) × 猎杀收获技艺倍率
```

收获技艺倍率最多额外+100%，本人天赋只增加自身贡献。山麓基础档失败有20%保底。当前即时收益不直接乘普通生产全局倍率、制作加成或额外个人境界倍率，避免重复放大；普通生产倍率可以通过信符供给间接改善出征频率。

推荐名单按`A × y × (p + 0.2 × (1-p))`排序，同分按身份排序。灵根影响修炼和个人突破，不直接增加猎杀收益。其他猎场沿用同一基础收益公式；受伤和死亡按各场独立配置。

## 离线与存档兼容

长离线按可支付周期和期望掉落批量结算，逐人抽取本段首个伤亡事件；事件后本段不再派出该人，可能比在线恢复后重返更保守，不把跳过周期带回在线。与在线逐人随机判定可能存在统计差异，详见[工程约定](ENGINEERING.md#离线结算)。

`hunting.schemaVersion`当前为3，保存独立随机序列、名单、周期计时、有限结果与统计。成员身份和岗位以弟子表为权威；新猎杀不复制一套可独立成长的成员。

v1/v2旧档合法已付款任务按原快照结算一次，按有效仓容入库，恢复成员原岗位、清除旧任务后再运行新周期，不重复收费或发奖；损坏或未知版本不当成合法任务迁移。旧`huntPreparation`转为共享信符，旧合法小数余量一次性入库后清空。重修清空本世猎杀状态、信符和掉落库存。

## 宗门外交

筑基起可经邻宗往来和山门开放互市，使用执符使提供的信符。药泉谷、黑铁山、须弥寺、银溪谷和星崖观分别承接当前资源交换及机缘奖励；实际支付与获得数量以源码和生成表为准。

星崖观金丹开放，银溪谷化神开放；秘银与灵晶交换为前级产线补缺口，仍受信符和交易材料限制。不能因重设猎场入口而推迟外交信符来源；新解锁也不能要求先获得该来源自身产物。

互市支持单回、10回和尽量交易（手动最多100回）。金丹《互市定约》提高执符使产出25%，开放每60秒自动互市，设置宗门、每周期1／10／100回和信符保留；自动支付遵守逐项材料保留，缺料跳过。长离线合并费用与固定回报、按期望计机缘，不按次数循环，不积压欠账。

## 药圃防务



三级事件以金丹、炼虚为分界：一级金丹前，二级金丹至化神，三级炼虚起。金丹妖兽防务归二级，只在金丹、元婴、化神阶段抽取；后续中期散修和邻宗事务归二级，炼虚起的天劫与域外压力归三级。等级约束事件池，单条境界门槛可进一步细分，详细规则见 [DESIGN.md §10.1](DESIGN.md#101-事件等级)。

- 金丹起用「妖兽窥伺药圃」替代旧即时妖兽侵袭；与普通选择共用一处未决状态，不覆盖已有选择。
- 加固：阵基1、符箓2；已参悟阵法初解时符箓1。保护灵草库存，安宁15分钟。
- 驱逐：法器1、丹药3；建有静心池时丹药1。保护灵草库存，安宁30分钟。
- 收缩：不扣成品，灵草产出降低25%持续2分钟，安宁10分钟。
- 默认：不动用成品，灵草损失按触发时20秒产能估价，保底20、封顶80，再乘通用与灵草专项防灾减免（合计最高80%），最多扣现有库存。安宁5分钟。
- 处理期5分钟，超时或回来时已过期，结算一次默认防守。离线不产生新事务。同类冷却从结算起至少20分钟，并覆盖完整安宁期。
- 期限、损失估价、安宁与冷却随存档保存，转世清空。应对消耗按当前准备重新预览与结算，没有额外随机胜负。
- 当前准备能力复用阵法初解与静心池，不增加护卫职位、弟子个人战力或突破硬门槛。



## 后续方向

新方案为普通三猎场加三个道果解锁的高级猎场：猎场负责宜居度和弟子培养，外交负责宗门成长资源交换；通用灵晶等材料不再作为新猎场的核心掉落。死亡减免不覆盖猎场与世界驻守。首版已按此接入，掉落与配方见源码，节奏与报价继续校准。

散修来访、邻宗纠纷、长期准备和关系收益仍是候选。继续沿用可预览、有代价、默认方案有界、同类冷却、不覆盖未决选择及离线不新增事务的现行边界；是否增加生态与显式敌意数值另行决定，见[开发路线](ROADMAP.md)。

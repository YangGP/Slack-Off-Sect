# 《摸鱼宗门》顶层设计建议 v0.1

> **用途**：供独立思考、讨论与规划使用，**不是实施任务单，也不是最终设计定案**。\
> **日期**：2026-10-21\
> **依据**：`GAME-DESIGN-OVERVIEW.md`、`DESIGN.md`（v0.423）、`RESEARCH.md`、`CRAFT-PROGRESSION.md`。\
> **参考方向**：《猫国建设者》（Kittens Game）的渐进解锁、资源约束、旧系统复用与长期成长体验，而不是照搬具体数值或内容。

---

## 一、先给出结论

**不建议推翻《摸鱼宗门》现有系统，也不建议为了延长游戏时间，直接调高科技与建筑价格。**

当前已经拥有大量资源、建筑、研究、加工、弟子和跨世机制。真正需要重新审视的，是**内容之间如何形成有层次的长期成长循环**。

建议将核心设计目标暂定为：

> 玩家从零建立宗门；每隔一段时间，就能通过新知识、新设施或新的资源利用方式，解决一个过去难以解决的问题，同时发现下一层发展空间。旧资源和旧建筑不会简单失去价值，而会随着技术进步不断改变用途。转世与飞升则为重复发展提供新的效率或能力，而不替代单世经营乐趣。

这与“让玩家在炼气、金丹、元婴、化神之间选不同专精流派”不同。**无需预先设计几条互斥职业路线**；玩家大体上可以学会全部技术，主要决策来自有限资源下的投入次序、瓶颈破解和自动化组织。

### 建议保留的设计原则

1. **发现式推进**：开局只显示少量资源和操作，逐步揭示系统，而不是把所有终局内容摆出来。
2. **纵向成长**：后期新机制能反过来改变早期资源、建筑、研究的价值。
3. **多种瓶颈交替**：人口、原料、仓储、科研、加工吞吐、供能等轮流成为重点；但瓶颈必须有可理解、可执行的破解办法。
4. **从手动到自动**：玩家最初亲自分配、制作；后来用系统与产能解决重复操作，管理重点不断变化。
5. **重置是加速和扩展，不是唯一目标**：单世也应有持续推进的乐趣；转世／飞升需要让下一世更有意思。
6. **时间由内容决定**：先做成长结构，再确定真实游戏时长。不要为了“半年寿命”去设置半年空等。

## 二、当前设计已经有什么

以下是根据上传文档确认的事实，不应在重构时当作“缺失功能”重复开发：

| 已有系统 | 当前能力 | 建议态度 |
| --- | --- | --- |
| 基础资源／仓储 | 资源池、有限仓储、专属与通用扩仓、指数造价 | 保留，审查卡点和扩仓回报 |
| 弟子／职位 | 灵根、修为、境界、天赋、分工、宜居度 | 保留，检查每阶段是否产生有价值的决策 |
| 修真／技艺／法宝 | 研究开放新能力、技艺提效、法宝祭炼 | 保留分工，审查“研究成果到底改变了什么” |
| 加工产业 | 手动批量、自动配方、工位、权重、保留量、供能、冷却 | 保留，检查可读性、自动化收益与产能限制是否符合预期 |
| 灵气高阶链 | 气→液→晶→分子→正负灵子→灵能，并有仙灵力 | 保留，关注新资源能否反向赋能旧产业 |
| 香火／愿力／道心 | 本世与跨世成长、护道、防护等 | 保留，明确其独有的成长职责 |
| 仙缘／道果 | 转世、飞升、永久修持与效率提升 | 保留基础，重新规划长期节点和多世体验 |
| 事件／猎杀／外交 | 事件已经较多；猎杀与外交存在基础模块 | 暂缓扩张，先确认它们对主循环的实际价值 |

**关键判断（待验证）**：系统数量已经足够，但一些高级内容可能更像“通往下一次破境的成本”，而非“解锁了不同的经济能力”。这不是说系统没有反馈——例如灵能枢已经能反过来增强灵气、灵机生产——而是要核实这类反馈是否足够多、足够明显、足以改变玩家的选择。

## 三、最应该改的不是科技树，而是“资源生命周期”

建议为每种**重要资源**建立一张生命周期表。先不要一口气覆盖43种，从`灵气`、`灵机`、`灵木`、`灵液／灵晶`、`灵能`、`香火`这六组开始。

每组回答五个问题：

1. **何时发现？** 玩家第一次在什么困境下需要它？
2. **如何获得？** 从手动、稀缺获取到稳定生产，是否有明确的质变？
3. **主要消费在哪？** 是只作为下一项科技的门票，还是同时服务多种持续用途？
4. **后期为何仍重要？** 有没有高级设施、科技或系统重新抬高它的价值？
5. **什么时候变得轻松？** 过去耗费玩家大量精力的事情，能否因技术突破而成为自动或低成本操作？

### 示例：灵气的生命周期（现状与可考虑方向）

| 阶段 | 已有用途或结构 | 值得思考的问题 |
| --- | --- | --- |
| 开局 | 点击取灵气、聚灵阵、首座茅屋和弟子口粮 | 第一次自动生产是否足够早、足够有成就感？ |
| 初期 | 基础建设、材料转换、弟子供养 | 人口增长是否迫使玩家重新分配岗位？ |
| 中期 | 凝液、晶体、工坊及设施维护 | 玩家是否需要权衡“生产建设”和“投入新加工链”？ |
| 后期 | 粒子相关产线、工位超载、复杂供能 | 灵气是否从“万能基础货币”变成“经济系统的燃料”？ |
| 更后期 | 灵能枢等反馈到灵气／灵机产出的机制 | 反馈是否足够明显，能否让玩家主动重新投资早期产业？ |

上表没有要求额外增加资源，它提醒我们：**新科技最好改变现有资源的经济地位，而不只是让玩家继续攒更多数量。**

### 示例：灵机与知识加工

现有`道札→道论→阵图`，本质上已经具有多级知识加工链。当前文档给出的用途包括科研、建筑和突破的材料预算替换。

可以进一步检查：

- 道札、道论、阵图是否只是把一笔灵机费用拆成更复杂的材料费用？
- 当这些知识材料被持续消费时，是否会产生对讲经堂、观星台、刻纹工位的新投资需求？
- 是否存在有意义的“知识进步反过来提高知识生产或管理能力”的节点？
- 高级知识的主要价值应是**打开新机制**，还是**降低旧系统的摩擦**？两者可以兼有，但应有层次。

**不建议立即新增“百科全书式”材料来模仿猫国。** 优先发挥现有三类知识材料的作用。

## 四、重新区分“解锁”和“涨数值”

每项关键研究尽量说明它属于哪一种变化：

| 变化类型 | 玩家实际感受到什么 | 设计价值 |
| --- | --- | --- |
| **发现** | 第一次出现新资源／新用途／新页签 | 扩大可探索空间 |
| **新来源** | 过去靠转换或稀缺获取的材料，现在可以持续生产 | 改变供需结构 |
| **自动化** | 过去反复手动操作，现在可以设定目标并持续执行 | 减少重复劳动 |
| **上限突破** | 容量、吞吐、冷却或供能限制被新的方式突破 | 解决旧瓶颈 |
| **旧系统再利用** | 新技术让旧设施重新值得扩建 | 产生纵向联系 |
| **普通效率提高** | +10%、+25%、减耗等 | 重要但不宜成为主要内容 |

**建议做一次“科技价值盘点”**：

- 在关键研究节点旁标注上述类型，可多选。
- 不强求每个普通研究都带来新机制；增产和节料依然必要。
- 但一段较长的游戏进程里，如果连续解锁的东西几乎只有倍率和更昂贵的材料，说明这一段可能缺少**玩法质变节点**。
- 将有限的系统突破优先放在玩家刚经历过明显瓶颈之后，让“学会新知识”的价值容易感知。

**一个值得坚持的尺度**：研究不应该只回答“接下来买什么”，还要偶尔回答“从现在起，我可以用新的方式做什么”。

## 五、重构“瓶颈的顺序”，而不是延长瓶颈的时长

《摸鱼宗门》当前已经有多种瓶颈：灵机仓储、建筑原料、人口、工位容量、供能／冷却、科技前置、突破风险。这其实是优点。

问题不是瓶颈数量少，而是它们在什么顺序出现、玩家破解后有什么回报。

建议每个主要阶段设计一个循环：

> **目标出现 → 发现当前瓶颈 → 投入基础设施或研究 → 解除瓶颈 → 产能结构改变 → 新目标出现。**

例如（**是假设性的调整方向，并非现有规则**）：

- 金丹初期，玩家发现加工材料不足，于是扩建原料产业。
- 原料充足之后，新的瓶颈从“原料不够”转为“刻纹加工吞吐不够”。
- 升级工位与研究自动化后，材料可以稳定获得，新的瓶颈变为灵机／科技。
- 投资讲经设施后，能解锁元婴阶段的知识与资源用途。

这样每次瓶颈都要求不同的解决办法，而不是始终围绕同一个资源上限继续堆仓库。

### 关于当前历史卡点

总览文档记录过旧版长测：在炼虚→合体阶段，某次模拟遇到**突破需要90万灵机、可达容量约81.16万**的阻塞，持续很久。这是一条重要的历史异常，但**不能直接断言现行v0.423仍然相同**。

建议区分：

- **好的限制**：玩家看得出如何通过技术、建筑、资源调配解除。
- **无效等待**：玩家已确定唯一行动，但只剩下等待漫长的指数造价攀升。
- **软性死锁**：理论上可以继续发展，但实际成本大到玩家几乎不可能合理达到。
- **硬性死锁**：推进所需资源／仓容无可达路径。

尤其是“材料加工品不设仓容上限”与一些较早的知识加工文档中“知识典籍有上限”的描述存在版本差异。**最终必须以当前源码和生成的`TABLES.md`为准**，不要直接沿用旧测试口径。

## 六、重置系统现在先少动，重点检查“第二世是否有新体验”

目前系统已有：

- 化神起可转世，获得仙缘；
- 渡劫后可飞升，获得仙缘和道果；
- 道心与若干永久修持跨世保留；
- 首颗道果带来自动化和保留相关的能力；
- 大部分本世资源、建筑、研究、弟子需要重建。

这些系统已经能够形成长期循环，不需要马上再造一套“轮回货币”。

真正值得问的是：

1. 第一次转世后，玩家重新经营宗门的过程有哪些**明显不同**？
2. 第一次飞升后，玩家除了更快，是否获得了更便利或更深层的管理手段？
3. 第五次、第十次轮回之后，玩家是在优化不同的长期目标，还是单纯重复第一世的顺序？
4. 单世继续冲关与立即转世之间，是否存在合理的收益权衡？
5. **不重置的玩家**是否仍能走完主内容，只是效率较低？若某些内容必须重置才能进入，应明确它们是“主线必备”还是“轮回专属”内容。

我建议给长期系统安排三种奖励，但**不是每一次重置都要赠送新机制**：

- **日常收益型**：生产、仓储、减耗、造价折扣。
- **便利型**：自动配置、批量管理、缩短重复操作。
- **里程碑型**：少量关键节点带来新的长期目标或新的资源关系。

先把第一世与第二世的节奏对比做清楚，再规划第十世之后的奖励。

## 七、不要把“复杂”误当成“深度”

现有加工系统已经包括工位、容量、权重、目标库存、材料保留、动力、冷却和高阶供能；这可以成为深度，但也可能让玩家不知道产线为什么停止。

建议保留现有自动加工框架，并优先确保玩家始终能看到：

- 这条线目前**每分钟产出多少**；
- 限制它的是**原料、工位、动力、冷却、仓储还是目标库存**；
- 如果新增一座设施或购买一个技艺，预计哪个限制会改变；
- 玩家设置的保留量，是否意外阻塞了下一阶段的必需品。

这里也不建议急着取消手动即时制作。《猫国建设者》式的即时手动加工本来就有其体验价值。真正需要检查的是**手动批量与自动加工的收益差异是否使工业机制失去意义**。如果没有证据，不必强行引入“所有材料都必须等待制作”的新规定。

## 八、游戏时长如何规划

建议先规划**内容层级**，再校准游戏时长。下面的时间只是可供实验的假设范围，不能作为已确定的平衡指标。

| 游戏进度 | 应出现的体验变化（示例） | 不应只靠什么延时 |
| --- | --- | --- |
| 前30分钟 | 从手动积累过渡到最初的持续生产 | 重复点击 |
| 30分钟～数小时 | 人口、木石与基础设施形成第一个供需循环 | 建筑价格上涨 |
| 首日 | 科研、材料加工、仓容与岗位配置出现相互制约 | 相同资源反复攒钱 |
| 数日 | 高阶加工、自动化、破境与第一次跨世选择逐步成熟 | 单一硬门槛 |
| 数周 | 高阶资源链和跨世修持互相反馈 | 同一轮回无限重复 |
| 更长期 | 少量深层机制、优化目标和可选挑战 | 纯指数数值膨胀 |

不要先给后期每个建筑定出“需要等三天”的价格。应先确认玩家为何会在这三天里持续调整策略、迎来回报或产生新目标。

**可衡量的核心指标**比“预计通关几个月”更重要：

- 玩家在不同阶段，距离**下一项有意义的解锁**有多远？
- 某一阶段的时间里，玩家是否只有唯一合理决策？
- 新科技能否改变至少一项以前的经营选择？
- 过去10小时内，哪些限制被解除、哪些新限制出现？
- 重置后的头几个小时能否明显感受到区别？

## 九、推荐的第一轮审查顺序：只做分析，不改代码

### 第一轮：资源与科技关系（优先）

**范围**：灵气、灵机、灵木、灵液／灵晶、灵能、香火六组；配套筛选10～20个关键科技／建筑。

**产出**：一张“资源生命周期表”和一张“科技价值类型表”。

检查是否存在：

- 仅作为某次破境消耗、之后失去用途的中间材料；
- 高阶研究没有改变旧系统经济地位的长区段；
- 多条材料加工链共用同一种瓶颈，却缺乏可替代的改进方法；
- 玩家解锁新系统后，旧资源需求突然下降至几乎无意义。

### 第二轮：阶段体验

**范围**：先挑**筑基→金丹→元婴**，不要一次重写11个境界。

为每次突破写四句话：

1. 突破前的主要经营困难是：`__________`
2. 玩家可以通过这些既有系统解决：`__________`
3. 突破后新增的能力／经营变化是：`__________`
4. 新阶段将旧资源重新用于：`__________`

如果第二项只能填“多挂机、继续造仓”，或第三项只能填“全局倍率提高”，就值得重新设计这一段。

### 第三轮：首世／二世对比

**范围**：开局到化神转世，再到转世后重新达到金丹／化神。

**产出**：两条实际发展日志。比较研究顺序、设施数量、达到关键机制的用时、手动操作次数、瓶颈位置。

不要只比较通关速度，还要问：**第二世玩起来是否更顺畅、有新的目标，还是只是第一世的快进版？**

### 第四轮：才进入实施

按影响范围划分：

- **A：不改代码**——调整设计文档、重新归类现有科技价值。
- **B：微调现有数据**——重新安排研究前置、用途、建筑增益和阶段解锁。
- **C：修改少量机制**——针对明确问题改善资源反馈或自动化管理。
- **D：新增系统**——只有当前三类都不能解决某个长期体验问题时，才考虑增加新系统。

原则是**能用已有系统解决的问题，不优先增加一个新系统**。

## 十一、暂时不要做的事

- 暂时不要为了“像猫国一样能玩半年”而把所有费用乘以10或100。
- 暂时不要设计大量互斥的宗门流派、政策树或职业分支。
- 暂时不要扩充几十种新材料和高级建筑。
- 暂时不要在没有回合对比的情况下重做仙缘、道果与道心。
- 暂时不要用旧版本的长测结果直接给现行游戏定价。
- 暂时不要因一条工业疑点就取消所有即时手动加工。

**真正的第一步**：选取6组代表性资源，画出它们从开局到后期的用途变化；再挑一个境界过渡阶段，检验“旧系统因新科技而产生新价值”的感觉是否成立。

---

## 十二、一句话记住这个方向

> **《摸鱼宗门》不应该只是“更高境界需要更多材料”，而应该是“每次掌握更深的修真规律，玩家就能重新理解和利用自己已经建设的宗门”。**

如果这个方向成立，游戏时长会因为不断出现的新瓶颈、新工具和新反馈而自然增长，而不是只能依靠等待时间增长。

# 材料研究：丹道、香火与土木

更新：2026-10-17，对照v0.384。三条研究线已于v0.38实施，本页维护当前规则、兼容边界与剩余评估项；旧草案的改动清单不再作为待办。完整数值见 [TABLES](TABLES.md)，共用规则见 [DESIGN](DESIGN.md)，分组原则见 [RESEARCH](RESEARCH.md)。

## 0. 共有框架

材料按族组织原理、工艺和精研。承接新配方、设施或系统的节点进入修真材料族，纯数值增产、节料与仓储升级保留技艺页；分组只是导航，不要求学满整个章节。

研究与建筑的传递前置已等价时不重复加门槛。首个研究、来源或设施不能依赖自身产物，扩仓费用必须由前级仓容承接。跨族应用保留真实依赖，不为分组强拆产业链。

## 1. 丹道研究线

### 1.1 三层归位

《炼丹术》为原理，《丹道精微》为承接凝元炼丹与丹鼎的工艺，均在丹道族；独立精研层尚未扩展。《丹火纯青》为纯数值技艺，已解除炼器术前置，丹道可独立推进。

### 1.2 丹药递进

丹药 `pill` → 凝元丹 `condensePill` → 九转丹 `nineTurnPill` 已实现，均为整数资源。凝元丹衔接中阶护道与研究，九转丹用于高阶护道、研究与灵宝；具体消费以当前配置为准，不沿用旧草案的阶段建议。

### 1.3 研究节点

《丹道精微》`alchemyEssence` 要求炼丹术、丹火纯青和两座炼丹房，开放凝元炼丹及丹鼎。研究费用、资源仓容与配方参数统一查生成表。

### 1.4 配方与解锁

采药制丹经炼丹房传递依赖炼丹术；凝元炼丹要求元婴、丹道精微与炼丹房；九转炼丹要求化神、丹道精微与丹鼎。三者共用丹道工位。九转丹炉是增产法宝，不再作为新档九转炼丹的解锁条件。

### 1.5 建筑与兼容

丹鼎承接凝元丹／九转丹专业增产与周转仓，药藏承担进一步囤积。具体加工规则见 [工艺专题](CRAFT-PROGRESSION.md)。

丹道迁移由 `alchemyProgressionVersion: 1` 标记：仅对尚未迁移且已有九转丹炉的旧档补发丹道精微，并设置 `legacyNineTurnPill`，保留本世九转炼丹资格，不赠丹鼎。重复读档和后来新炼成法宝不补发；转世、飞升或身死重开清空旧资格。缺凝元丹库存补0，原有丹药照常使用，已学研究不追缴。

## 2. 香火研究线

### 2.1 研究与产出

香火愿、香火志、祖师遗泽与愿力研究已归入香火族，祖师遗泽不再放在宗门经营。香火由香使人力生产，山门解锁岗位；D7 起普通建筑不再直接增产，香火产出改由香火页的聚香法、大乘愿典与聚愿鼎提供，香火鼎、祖师殿、因果池只保留仓位、宜居、灵机与维护。

### 2.3 愿力与渡劫

《愿力》`vowPower` 已实现，是研究而非跨轮回货币，开放配套技艺《愿力护道》`vowGuard`。该技艺提供本世常驻、无需逐次投入的被动 `tribulationSafety`（失败后身死概率降低5个百分点，最低0%），作用于已有身死风险的突破；风险始于金丹冲元婴，不能理解为筑基冲金丹也有身死。

渡劫唯一的香火护道为《立愿应劫》：投入香火20000，提高成功率6个百分点并降低突破失败后的身死概率10个百分点。目标境界1～9保留各自香火祈愿，渡劫不同时再收第二笔香火祈愿。失败投料不退，预览与结算共用风险规则，旧选项id `10:2` 保留。

仙灵力尚未加入这项护道，未来如采用应按替换而非追加处理，见 [供能后续用途](SPIRIT-ENERGY.md#十一供能校准与后续用途)。跨轮回功能成长属于 [ROADMAP的D7](ROADMAP.md#d7香火长期成长)，尚未定案。

### 2.4 前置与兼容

香火志已显式要求两座山门；山门仓容后来已上调，不再用旧80仓位证明当前瓶颈。归组保留原id，已学条目不回锁，不因新增研究赠送护道加成。

## 3. 土木研究线

### 3.1 研究与制作增益

土木术、土木精要、营造法式、营造技艺和洞天福地均在土木族。《营造技艺》`masonryArt` 已实现，提供混灵土／玄铁混灵土专业制作增益，当前不提供建筑造价折扣，旧档已学者也按正常价格建设。

### 3.2 应用分工

居所营造、引泉净水与园林营造保留在修真应用的营造组，负责具体宜居与结构能力。材料加工和高阶建材的产业链见 [工艺专题](CRAFT-PROGRESSION.md#后期建筑材料)，不再另存完整费用副本。

### 3.3 仓储与材料自举

洞天／洞府因造价涉及玄金，已定为合体档；广储库在炼虚承接玄库到洞天之间的扩仓，造价不含玄金。通天塔保留大乘门槛，实体仓储、住房和已锚定空间在断供／停用时保留，主动收益按供给缩放。

《加固仓架》已补一座库房前置，下游仓储技艺沿研究链继承。归组不改id，已学条目与已建建筑保留，不追缴前置。

## 4. 剩余评估与设计边界

- 丹道：丹道精微的首次投入、三级丹药的加工／仓储预算、丹鼎回报与护道费用。额外丹道专属增产技艺仍为可选方向，未定案。
- 香火：愿力研究与护道技艺的投入回报、立愿应劫的费用和风险减免；额外香使技艺、香火类奇观／法宝仍是候选，不当作已实现。香火→愿力→道心的长期进阶统一由路线图D7维护。
- 土木：营造技艺收益、营造法式是否进一步承接该工艺、广储库回报与高级住宅／综合仓材料竞争。已定的合体门槛不再列为待实施。
- 共同边界：首启来源、前级仓容、材料可达性、旧档迁移一次性与当前护道预览一致。可达性不估算生产时间，不能据此宣称首飞节奏完成。

## 1. 结论

1. **三包可拆且必须按 A→B→C 顺序落地**：A（灵纸）只动知识／符咒与纸链；B（石材）只动基础建材与建筑砌基；C（灵纹石）依赖 A 的纸和 B 的石材，是二阶构件。任意一包单独回滚都不会留下悬空引用。
2. **4.5 只做“必要前置”，不做全量重排**：本阶段只保证“造价含纸要先有纸、造价含石材要先会压制、灵纹石要化神档”，不实施金丹前链式解锁、金丹后材料双门禁、技艺全挂修真、法宝多重门槛（那是 4.5 本体，留待后续）。
3. **不新增研究节点之外的系统**：只新增 1 个研究《抄纸法》和 3 个配方；石材复用《凿石要诀》，灵纹石复用《营造法式》。材料总数从 26 增至 29，正好用满 4.2 的额度。
4. **两处防死锁锚点要显式处理**：百工坊保留吃原矿石（压制工位所在）；炼铁炉改用石材后，原“造价 180 < 矿石上限 250”的防死锁约束失效，但前置链加深，必须用审计与前期节奏验证替代。
5. **前期会多两步手动**（抄纸、压制石材），且炼铁炉前要多学《凿石要诀》。这是有意的前期加层，净效应以 PACING 为准；不通过减免其他费用预补偿。

## 5. 工位与前置链影响

- **木作工位**：木板→纸→石材三配方共用，手动期为筑基～金丹；自动期容量由百工坊、疾炼法、流水作坊、灵纹锯阵承接。元婴～化神峰值五配方（板／土／砼／纸／石），4.2 已评估为可破解瓶颈，本阶段不新增工位。
- **刻纹工位**：知识链＋符箓＋阵基＋灵符＋灵纹石，C 包再加一档；扩建杠杆现成（符箓堂 1.25、定纹模刻 +100%）。
- **炼铁炉前置**：原仅需《探矿术》，现需《凿石要诀》。凿石要诀只需居所营造＋采石场，属筑基前链，不引入跨线依赖。
- **开局手动步骤**：筑基金丹段 +2 步（抄纸、压制石材），且首次炼铁炉前多一次研究。属于 4.1／4.2 已声明的前期加层，必须用 PACING 复核。

## 7. 风险与开放项

1. **前期变慢**：A＋B 叠加可能把筑基～金丹推长；若 PACING 超预算，优先调纸量（2→1）或把炼铁炉改回“石材 45 但前置不变”，不先动数值大项。
2. **千枚灵石拆分**：因果池 300,000 灵石 → 195,000 石材＋60,000 灵石，是最大单笔改动；石材无上限，压力从灵石转到矿石与木作工位，需在阶段 3 与 4.4 一起复核。
3. **猎杀模块**：执符堂／暖裘居室同步换算，避免模块建筑成为“唯一还吃原矿石”的例外；若模块测试受影响，可单独回滚这两座。
4. **灵纹石与 4.3 的边界**：本阶段不加破境费，避免两种改法叠加。
5. **文档再生**：落地后跑 `npm run docs:tables`，同步 `TABLES.md`；`REALM-UPGRADE-MAP.md` 若存在生成命令再补。

## 变更 4：后期建筑持续供能（设定已定，机制与数值待策划）

完整设定见[灵能场设定 §九](SPIRIT-ENERGY.md#九后期建筑的供能与维持)。

### 4.1 已定原则

- 炼虚 / 合体以灵气起步，大乘形成湮灭供能；高阶建筑接入灵能后，其完整主动功能需要持续供能。范围按功能界定，不对所有旧建筑统一加费。
- 能源产线可从零灵能启动，并在库存耗尽后恢复。
- 断供缩放或停止主动收益；住房名额、实体仓储、建成时已锚定的洞天空间容量保留。宜居配套失效仍按既有宜居规则影响经营。
- 动力、燃料、修缮材料与参悟分别记账，同一动力需求不重复收费；已学研究成果不因建筑断供撤销。

精舍、园林等按功能列入评估，不统一改为炼虚解锁。变更 2 的四座原理建筑另按早期启动职责策划，不自动转为灵能维护。

### 4.3 运行与启动

兼容建筑拟提供「停用 / 灵气基础 / 灵能高阶」三种状态；灵能接入由输配研究承接。两种运行模式的效果份额、费用待定，同一收益不重复结算。首版建议手动切回灵气，自动备用另议；灵能枢仍是专用灵能设施。

基础启动：**灵气驱动分灵 → 分子与灵气驱动偏极 → 正负燃料与灵气控制湮灭 → 灵能净输出 → 建筑与工位**。

湮灭炉稳定运行时，从当期毛输出扣辅助自用能再分配；启动不要求已有灵能库存。自用能若替代同一控制功能，停止重复收取该部分灵气费。缺燃料停炉，恢复需燃料与启动动力。

**能源账**：净供能 = 湮灭毛输出 − 炉内自用；总需求 = 建筑维持 + 灵能枢维持 + 实际额外加工负荷 + 其他已定义用能。仓储只能缓冲，不能弥补长期亏损。需统一核对吞吐倍率对产出、燃料、动力与自用能的影响。

现行湮灭炉基础输出 0.06 灵能/s，未祭炼灵能枢基础维护 1 灵能/s；新增维护需按实际倍率、炉数及重复造价测算。

### 4.4 待策划与验证

- 逐建筑确定灵气 / 灵能模式效果、维护率、保留的物料维护；再定炉内自用率与启动耗气。
- 决定自动备用及缺供分配方式；飞升预览显示因果池等设施当前有效收益。
- 验证零库存首启、断供恢复、缺燃料、满仓、停用、离线、重修及旧档升级；比较建筑扩建与飞升阵印的用能竞争。
- 变更 3 的建筑效果保留仅作为基线，主动效果与维护按本变更重新测算。

# 弟子培养：当前规则与后续完善

更新：2026-10-19。本文区分当前实现与待设计内容；整理文档不改变游戏规则。弟子成长、灵根、管理、天赋等级成长、传功与个人护道均已实现，培养数值仍为试调值；§2.2.1 重点培养名单、§2.2.2 培养预算与 §2.2.3 自动突破均已实施（2026-10-19，v0.42），§2.5 主动招募与招募模式已实施。整体经营见 [DESIGN.md](DESIGN.md)，工程实现见 [ENGINEERING.md](ENGINEERING.md)，后续方向见 [ROADMAP.md](ROADMAP.md)。

## 1. 当前实现

### 1.1 个体与系统边界

弟子拥有持久化身份、姓名、岗位、境界、修为、灵根和调息记录。自动前来与普通事件入门的弟子从凡体、零修为开始，主动礼聘可按档位带来较高起点；姓名按身份生成，允许重名，读档不重新生成有效姓名。弟子自动修炼，突破由玩家单人或批量发起。

| 机制 | 当前作用 |
| --- | --- |
| 宗门境界 | 提供现有全局产出及口粮倍率，限制弟子下一次突破的目标境界 |
| 弟子境界 | 提高本人岗位产出系数，同时按相同系数提高个人口粮 |
| 灵根 | 影响个人修炼速度与个人突破成功率 |
| 天赋 | 固定个人专长，提供修炼、对应岗位产出或突破加成；随成功突破升至 Lv.1–Lv.3 |
| 培养 | 手动传功：持续耗灵气加速本人修炼（不停岗）；个人护道：预付材料加成其下一次突破 |
| 突破 | 消耗资源并判定成功或失败，不自动使用宗门护道方案 |
| 岗位 | 决定个人提供哪类资源，工作与闲散都继续修炼 |

首版已增加 32 条天地玄黄天赋（含天级岗位词条），获取、效果、固定身份及 Lv.1–Lv.3 升级见 [DISCIPLE-TALENTS.md](DISCIPLE-TALENTS.md)。手动培养（传功／个人护道）见 §2.1。尚无专用培养设施、师承传承、游戏内自动突破、境界停滞或个人突破死亡。

### 1.2 灵根与自动修炼

配置集中在 [src/data/disciples.js](../src/data/disciples.js)。基础速度为每秒 1 点修为，乘以下灵根系数：

| 灵根 | 出现概率 | 修炼速度系数 | 突破加成 |
| --- | ---: | ---: | ---: |
| 天灵根 | 1% | 2.0 | +6pt |
| 异灵根 | 4% | 1.6 | +4pt |
| 双灵根 | 10% | 1.3 | +2pt |
| 三灵根 | 25% | 1.0 | 0 |
| 四灵根 | 30% | 0.9 | −1pt |
| 五灵根 | 30% | 0.8 | −2pt |

加权平均速度系数为 0.974。灵根同时影响个人修炼速度与个人突破成功率（突破加成为百分点，三灵根为基准 0）；不改变岗位产出、口粮或调息时间。

到来或事件招入时只抽取一次灵根，使用存档内独立随机序列；收徒不改变事件及突破的随机序列。已有有效灵根原样保留，旧档缺失或无效灵根补三灵根，读取存档不重新抽取。不使用阻塞式轮盘，在线纪事直接显示收徒结果。

```text
实际修炼速度 = 基础速度 × 灵根系数 × (1 + 个人修炼天赋加成)
修为增长 = 实际修炼速度 × 已结算时间
当前修为最多达到本境突破要求，不预存后续境界的修为
```

工作、闲散及调息期间均继续修炼。达到宗门上限仍可修满本境，但不能突破至宗门境界之上。个人渡劫后不再积累后续突破修为。

离线沿用宗门当前离线收益上限，新招入弟子只计算入门后的时间。不超过60秒的读档与后台恢复按逐秒规则结算；更长窗口走有界近似（修炼、停留与口粮按段累计，断粮流失按次数与概率批量估算），加载提示与结算后更新界面的行为见 [ENGINEERING.md](ENGINEERING.md#离线结算)。

### 1.3 修炼时间与突破概率

下表净修炼时间以无修炼天赋的三灵根为基准，指从上一境开始到修满、可尝试本次突破的时间，不含宗门上限等待、备料和失败重修。天灵根时间减半，五灵根时间增加 25%；修炼天赋另行加速。

| 突破目标 | 本段净修炼时间 | 从凡体累计 | 弟子基础成功率 |
| --- | ---: | ---: | ---: |
| 引气入体 | 1小时 | 1小时 | 47.5% |
| 炼气期 | 3小时 | 4小时 | 47.5% |
| 筑基期 | 8小时 | 12小时 | 47.5% |
| 金丹期 | 16小时 | 28小时 | 35% |
| 元婴期 | 24小时 | 52小时 | 30% |
| 化神期 | 36小时 | 88小时 | 27.5% |
| 炼虚期 | 48小时 | 136小时 | 25% |
| 合体期 | 72小时 | 208小时 | 10% |
| 大乘期 | 96小时 | 304小时 | 7.5% |
| 渡劫期 | 120小时 | 424小时 | 5% |

2026-10-12 调整：弟子基础成功率为对应宗门基础成功率的一半；宗门高于目标时，每高一境增加 10 个百分点成功率，最高 99%。目标高于宗门时不可发起。宗门与弟子共用基础概率入口，宗门护道材料不自动用于弟子。

```text
境界差 = 宗门境界下标 − 弟子突破目标境界下标
弟子基础成功率 = 对应宗门基础成功率 × 50%
成功率 = min(99%, 弟子基础成功率 + max(0, 境界差) × 10% + 个人突破天赋百分点 + 灵根突破加成 + 个人护道百分点)

例如元婴宗门指导弟子结丹，三灵根为 45%，天灵根为 51%。灵根按 §1.2 的突破加成叠加（天/异/双/三/四/五 = +6/+4/+2/0/−1/−2 个百分点），仍受 99% 封顶。基础成功率降低后，失败重修及材料消耗的累计成本需重新测量，旧审计不能作为当前培养节奏结论。

### 1.4 材料、失败与批量突破

当前费用由目标宗门境界的基础费用派生，比例单独配置为 1%，尚未建立独立的弟子逐境费用表：

```text
每种突破材料 = max(1, ceil(目标宗门基础费用中该项数量 × 1%))
```

只对目标费用实际包含的资源计价，不套用宗门费用折扣或护道材料。调整宗门基础费用会同时改变弟子费用；是否拆成独立配置属于后续待决定事项。

成功后境界提升一层、修为归零。失败仍消耗全部本次材料，损失 20% 本境修为并调息 60 秒，不降境、不停滞、不死亡。调息期间继续修炼，但不能再次突破。

失败的主要等待成本来自重修损失，而非固定的 60 秒。以三灵根为例，结丹失败需补回约 3.2 小时修为，冲击合体失败约 14.4 小时；重修与调息并行，不能简单相加。

批量突破按个体记录顺序逐人检查、扣料和判定；不满足条件的人选跳过，遇到材料不足则停止，不超支。界面排序不改变实际执行顺序。不同目标境界可同时选中，游戏目前没有自动突破或宗门材料预留策略。

### 1.5 产出、口粮与宗门退境

个人系数复用现有境界倍率，并按有效境界计算：

```text
有效境界 = min(弟子实际境界, 当前宗门境界)
个人系数 = 有效境界对应的境界倍率
岗位实际产出 = 岗位基础产出 × Σ[该岗位弟子个人系数 × (1 + 本人对应岗位天赋加成)] × 现有岗位、资源与全局倍率
全体弟子口粮 = 0.25 × 宗门境界倍率 × Σ(全体弟子个人系数) × (1 − 有效减耗比例)
```

当前口粮随宗门倍率的指数为 1，有效减耗比例上限为 85%。闲散弟子也承担口粮。个人系数只作用于本人岗位产出与口粮，不额外提高每份制作收益、工业容量或建筑自带产出。

宗门与弟子同为金丹时，两层境界乘积为 2×2＝4；同为渡劫时为 10×10＝100。个人境界提高单位人口的产能与口粮，不直接改善该弟子的产出／口粮比。

宗门退境保留弟子实际境界及修为，只暂时降低有效境界系数。宗门恢复后无需重新培养已取得的境界。宗门身死重修、转世或飞升清空个体。

### 1.6 管理、调岗与逐出

弟子页默认展示职位分配；点击“弟子管理”后管理区覆盖职位分配区域，收起或在管理区按 Esc 返回。同页开合保留筛选与选择，重新进入页面默认收起。

- 按境界、灵根组合筛选，按入门先后、本境进度比例、修炼速度稳定排序。
- 每页 30 人，可选择当前筛选内全部人选跨页操作；切换筛选清除选择，排序保留身份选择。
- 支持指定人选单人或批量调岗、突破和逐出，批量操作限于当前筛选内所选人选。
- 列表保留姓名、境界、灵根、岗位、状态及操作；修为、实际速度、预计时间、个人系数、口粮、概率及费用通过悬停行或键盘聚焦姓名查看。
- 缺料与调息状态直接显示。页面统一滚动，筛选在窄屏换行，选择与批量操作独立排列。
- 职位表“每人／秒”显示已分配弟子的平均实际产出，无人岗位显示凡体参考值；口粮摘要显示总量与平均量。

逐出费用逐人向上取整后合计：

```text
当前每年基础口粮 = 0.25 × 当前宗门境界倍率^口粮指数 × 弟子当前有效境界倍率 × 1080
单人逐出费用 = ceil(当前每年基础口粮 × (在宗门已满游戏年数 + 1))
```

一年为360游戏天，即1080现实秒（18分钟）；口粮指数沿用配置，弟子有效境界取本人实际境界与当前宗门境界中较低者。年基础口粮不计减耗、断供、传功或历史突破费用，随当前境界更新。累计口粮与突破消耗仍作为历史统计保存，不参与逐出定价；停留在线／离线持续记录。逐出需确认，执行时重新校验人数、费用与支付能力，费用变化或材料不足时整批不执行。成功后移除对应个体、更新人口与岗位，新弟子沿用递增身份，不复用被逐出者的成长记录。

## 2. 培养投入与后续完善

§2.1 为已实施的手动培养规则；§2.2.1 重点名单、§2.2.2 培养预算与 §2.2.3 自动突破均已实施（2026-10-19）；§2.5 主动招募与招募模式已实施；§2.3–§2.4 记录评估与暂缓事项，具体状态以各项标注为准。保持放置经营体验，玩家决定重点人选与资源投入。

### 2.1 培养投入与个人费用

已实施（2026-10-13）。手动培养分两项，由同一研究解锁，只作用于玩家指定的个别弟子，不改变他人或全宗产出；基础修炼、灵根速度与境界系数仍是基线。数值均为试调，见 [src/data/disciples.js](../src/data/disciples.js) 的 `DISCIPLE_TRAINING` 与 `DISCIPLE_AIDS`。

**解锁**：修真·宗门经营新增《传功授业》，前置《讲经法》与《口传心授》。未掌握时弟子页不显示培养入口；培养不占用建筑或岗位容量。

**传功（持续加速修炼）**

- 在弟子管理页对选中弟子开始或停止传功；弟子照常上岗，口粮与岗位产出不变，只加速本人修炼。
- 效果：个人修炼速度 ×(1 + 传功加成)，与灵根、修炼天赋相乘，加成有上限。

  ```text
  个人修炼速度 = 基础速度 × 灵根系数 × (1 + 修炼天赋) × (1 + 传功加成)
  ```

- 消耗：按弟子有效境界递增的每秒灵气（灵气为主要投入）。
- 停止条件：本境修为已满时该弟子不扣灵气、加成无效，突破后自动恢复；灵气不足时（口粮与维护优先）整批传功暂停、不欠账，恢复后继续。
- 在线与离线同一结算；离线不自动突破，故修为满后离线同样暂停。

**个人护道（突破加成）**

- 为指定弟子的下一次突破预付一组按目标境界配置的材料，个人突破成功率增加固定百分点，手动触发、即时扣料。
- 只作用于本人该次突破，不用于宗门破境或其他弟子；叠加在“弟子基础成功率 + 宗门指导 + 个人天赋”之上，仍受 99% 封顶，不绕过修为、调息、宗门境界与材料条件。
- 成功或失败后清除待生效加成，再次护道须重新支付；同一弟子最多一层。
- 材料随目标境界更换（丹药→仙草→九转丹→灵宝等），与宗门护道同源但按个人规模缩放，属弟子个人费用的一部分。

**费用与竞争**：传功是持续灵气开销，与口粮、建筑维护、凝石、加工共用灵气池，排在其后；护道是一次性材料开销，与宗门破境、弟子突破和制作竞争同一批材料。弟子逐境突破基础费用沿用现值（目标宗门费用的 1%），护道材料另计，不并入基础费用。

| 项目 | 设计值（试调） |
| --- | --- |
| 传功加速 | 个人修炼速度 +75%（约 ×1.75） |
| 传功灵气/秒 | 0.4 × 弟子有效境界倍率（约本人基础口粮的 1.6 倍） |
| 护道加成 | 按目标境界 +4～+10 百分点（见下表） |
| 上限 | 修为上限、99% 成功率与材料条件均保留 |

护道加成按突破目标境界配置，材料与加成为试调：

| 目标 | 材料 | 加成 |
| --- | --- | --- |
| 引气入体 | 灵气60 | +4 |
| 炼气期 | 灵草40 | +4 |
| 筑基期 | 丹药4 | +5 |
| 金丹期 | 仙草2 | +6 |
| 元婴期 | 仙草5 | +7 |
| 化神期 | 九转丹1 | +8 |
| 炼虚期 | 九转丹2 | +9 |
| 合体期 | 秘银6 | +10 |
| 大乘期 | 灵气分子20 | +10 |
| 渡劫期 | 灵宝1 | +10 |

**数据与存档**：`members[]` 增加 `mentored`（是否受传功，缺省 false）与 `aidBonus`（待生效护道百分点，缺省 0）；归一化清理非法值与超限，旧档默认关闭，不自动补钱或补护道，培养状态随保存、导出与离线副本保留。培养消耗逐人结算并计入灵气／材料出项，批量操作逐人扣料、不足即停、不超支。

**界面与验证**：弟子管理页每行提供传功开关与护道入口，详情提示显示传功消耗/秒、当前传功加成与待生效护道；增加“传功中”“已护道”筛选。验收：传功只加速修炼、不停岗、不改口粮与岗位产出；修为满不扣费；灵气不足停功不欠账；护道只作用于本人下一次突破并被清除；旧档不重抽；在线与离线一致。

原“培养设施、师承”等方案由上表取代：本轮不新增培养建筑；自动突破按 §2.2.3 于 2026-10-19 实施；个人死亡、境界停滞与独立属性仍按 2.4 暂缓。

### 2.2 培养策略与低操作负担

已实施（2026-10-19，v0.42）。目标是在保持放置经营与「玩家决定重点人选与资源投入」的前提下降低批量管理负担：新增能力一律 opt-in、经研究门槛、可随时关闭，且不擅自改动玩家既有分工与资源分配。数值仍为试调，后续校准见 §2.3 待办与 §3.2 验证要求。

现有审计中的“保留材料／直接培养”仅为模拟策略，不等于游戏已实现这些开关。

#### 2.2.1 重点培养名单与执行顺序

已实施（2026-10-19）。个体新增 `focus`（布尔，缺省 false），弟子管理页逐行「标为重点／取消重点」与批量标记均已进入代码，重点名单在任一排序下置顶、提供「仅重点」筛选，随保存、导出与离线副本保留；旧档默认全部非重点，不自动标记。仅作排序与筛选依据，不改变产出、口粮、概率或费用；自动突破的执行顺序已随之落地：先重点名单，再按个体记录顺序结算，保证可复现。

待校准：

- [ ] 评估按灵根、岗位和进度选择人选的收益，确认是否需要在「重点」之外提供其它人选口径。

#### 2.2.2 培养与破境预算预留

已实施（2026-10-19，v0.42）。破境材料、口粮与传功共用灵气池与材料池（§2.1），自动培养可能在玩家不察觉时耗尽经营资源，故先给预留规则、再谈自动化。《传功授业》解锁后在弟子管理页提供设置组「培养预算」：

| 项目 | 默认 | 作用 |
| --- | --- | --- |
| 灵气底线 `trainingQiFloorSeconds` | 30 秒（可调 0–300 秒，0 关闭） | 传功与自动突破的灵气支出不得使灵气跌破 `upkeep × N 秒` 的库存，不足即暂停、不欠账；传功在重算门控中按本段时长折算校验，在线与离线同一口径 |
| 宗门破境材料保留 `sectBreakthroughReserve` | 开启 | 批量突破与自动突破不得动用「当前宗门下一境破境所需材料」：扣除该弟子本次费用后，对应资源仍须 ≥ `realmCost(state.realm+1)` 的该项（只检查本次费用实际包含的资源） |
| 传功人数上限 `mentorLimit` | 20（可调 0–999） | 限制同时受传功人数，避免灵气被过量侵蚀 |

- 手动单人突破不受预留限制（玩家显式操作）；已确认（2026-10-19）：手动批量突破同样受「宗门破境材料保留」开关约束，开关开启时不得动用保留材料，想动用需先关闭开关。
- 预留只在动作结算前判断，预览与实际使用同一费用入口，不部分执行、不超支；批量手动到保留线即停止并提示，自动跳过并等待。
- 已确认（2026-10-19）：传功人数上限在开关时校验——`setMentored` 为唯一开启入口，开启时检查当前受传功人数、达上限即拒绝本次操作并说明原因；人数仅因逐出／流失减少，不自动补位、不擅自改动玩家分配。

#### 2.2.3 自动突破

已实施（2026-10-19，v0.42）。已确认（2026-10-19）：自动突破仅在线生效，离线维持现状（修为封顶、不突破、传功照常在修满后暂停），不引入离线批量突破次数与随机策略设计，「离线不自动突破」的现有描述与回归断言原样保留。

- 门槛与开关：新增研究《因材施教》（前置《传功授业》与《知人善任》），`effects.autoDiscipleBreakthrough: true`；`settings.autoBreakthrough` 默认 false，随存档保留，旧档默认关。
- 适用人选：默认「仅重点名单」，可选「全部弟子」。
- 目标境界上限：默认「不高于当前宗门境界」（即所有可突破者）；可下调为具体境界（如止步金丹），高于上限者不自动突破。设置项形如 `autoBreakthroughCap`（`'sect'` 或具体境界下标），非法值归一化回 `'sect'`。
- 结算：每名符合条件的弟子在修为满、无调息、目标 ≤ 宗门境界且扣预留后材料足够时，按 `discipleBreakthroughPreview` 立即结算一次；费用与概率沿用现有入口，不使用个人护道。
- 失败惩罚：沿用现行规则（失败全额扣料、损失 20% 本境修为并调息 60 秒），不另设自动重试频率上限。20% 重修损失是天然节流：失败后需补回 3～24 小时修为（境界越高越长），自动重试不会高频刷料；边界突破（目标＝宗门、无指导加成）的材料期望倍数（低成功率下约 10～20 倍单次）及传功加速重修的交互，按 §2.3 待办随 P2.4 一并测量。
- 缺料处理：跳过并等待，不超支、不进负债、不自动降级目标；预留规则优先于自动突破。
- 在线／离线边界：仅在线结算，口径以 60 秒为界（≤60 秒后台窗口走逐秒结算、照常触发；更长离线修为封顶、不自动突破、传功照常暂停）。离线不消耗突破材料；离线摘要提示「N 名弟子修满待突破」，设置处说明该差异。

已确认（2026-10-19）：

- [x] 自动突破仅在线生效：离线不自动突破、修为封顶、传功照常在修满后暂停；「离线不自动突破、修为满即暂停传功」的现有描述与回归断言原样保留，设置处说明在线／离线差异。
- [x] 目标境界上限默认「不高于当前宗门境界」；边界突破的材料期望成本由「仅重点」默认、宗门破境材料保留与在线可随时关闭共同兜底。
- [x] 离线摘要新增「N 名弟子修满待突破」提示：离线归来汇总修为已满人数，不依赖自动突破开关，现状离线修满即适用。

#### 2.2.4 自动推荐岗位

本轮决定**不引入**后台岗位自动推荐，理由：

- 《知人善任》已按「岗位专长」自动分配，依据单一可解释；再叠加产出缺口等依据会让后台擅自打乱玩家分工，与「玩家决定分工」冲突。
- 现有组合筛选＋排序＋「选择本分类」已能以低成本完成人工分工。
- 若后续确需引入，依据必须是单一可解释项（仅岗位专长，或玩家显式设定的岗位配额），默认关闭并可在执行前预览，不得按隐藏权重改派。

### 2.5 主动招募与招募模式（已实施）

已实施（2026-10-15）。目标是在既有「有空房自动来一人」之外，提供一条以资源换取「更高质量弟子」的路径，让玩家在**自由来人**（免费、天赋随机）与**付费招募**（可控、偏高天赋）之间取舍。研究名、花费与概率均为试调值。

#### 2.5.1 解锁与模式切换

- 新增研究《招贤纳士》（glyph「贤」），金丹起开放（`realm: 4`），前置《香火愿》（`incenseVow`）、《知人善任》（`talentAssignment`）及一座山门；费用为灵机1000、香火150、灵石400。不依赖《广开山门》及其阵基、讲经、香火志研究链；`effects.recruitMode: true`，派生 `derived.recruitModeUnlocked`。
- `settings.recruitMode`：`'auto'`（默认，即现状）或 `'manual'`；随存档保留，旧档默认 `'auto'`。未解锁时不可切换、界面入口隐藏。
- 切到 `'manual'` 后停止自动前来：`recruitArrivals` 不再计时并清零 `arrivalTimer`，免费来人暂停；切回 `'auto'` 恢复，并从零重新计时。

#### 2.5.2 主动招募与礼聘档位

在弟子页（团队面板）提供按「礼聘」档位一次性花费资源、立即结算一名弟子的招募。档位越高，花费越多、越容易刷出高品级天赋，起点境界也越可能更高：

| 档位 | 花费（试调） | 起点偏移权重 0/1/2/3/4 | 天赋品级权重 黄/玄/地/天 | 天赋条数权重 0/1/2 |
| --- | --- | --- | --- | --- |
| 薄礼 | 灵气 300 × 宗门境界倍率 | 4/8/18/28/42 | 45/35/16/4 | 70/25/5（同现状） |
| 厚礼 | 灵气 800 × 宗门境界倍率、香火 150 | 10/20/30/25/15 | 30/35/25/10 | 60/30/10 |
| 重金 | 灵气 1600 × 宗门境界倍率、香火 400、灵机 300 | 32/30/22/11/5 | 15/30/35/20 | 40/40/20 |

- **起点境界（概率）**：按档位权重抽取「相对宗门的偏移」（0 = 与宗门同境），`起点境界 = max(0, 宗门境界 − 偏移)`；修为从 0 起算。宗门境界越高、档位越高，抽到的偏移越小，起点境界越高（如渡劫宗门「重金」多在渡劫／大乘，而「薄礼」多在炼虚上下）。因入宗即具境界，其岗位系数、口粮与逐出费用按该境界计（§1.5），起步越高的收益与负担同时更高。
- 花费与档位为试调；具体资源种类与缩放口径见「已确认」。
- 档位越高，天／地级出现概率越高（替换 `TALENT_TIERS` 的抽取权重），并可更高概率一次带 2 条天赋（替换 `birthTalents` 的 `birthCounts`）；天赋条数上限仍为 3。
- 灵根仍按原权重独立抽取，不因礼聘提高。
- 每次招募立即扣料并调用 `newDisciple`，使用既有 `rootSeed`／`talentSeed` 序列，起点境界用独立的 `recruitSeed` 序列，均不扰动事件与突破的随机序列；纪事记录「花费…招募 1 名弟子（档位）」，并计入 `stats.recruits`。

#### 2.5.3 约束与一致性

- 仍受居所容量（`maxDisciples`）限制；满员不可招募，与自动一致。
- 沿用自动前来的暂停条件（断粮、宜居度离开风险）：存在离开风险时暂停招募，避免招进来即流失。
- 在线离线一致：模式与礼聘结果随存档保留；离线不自动招募（需玩家动作），故离线不消耗招募资源，档位切换在下次上线生效。
- 归一化：`recruitMode` 非法值回 `'auto'`；礼聘只影响抽取权重，不引入新的个体字段（复用现有 `talents`），旧档既有弟子不受影响。`recruitSeed` 缺失时从 `rootSeed` 派生，不在重复读档时推进。

#### 2.5.4 界面与验证

- 弟子页在解锁后显示模式切换；`'manual'` 时显示三档招募按钮与花费，满员／风险／付不起时禁用并给出原因；悬停展示该档的起点境界区间与天赋品级概率。
- 验收：未解锁不显示、不能切换；`'manual'` 时停止自动前来、切回恢复；扣料与出人原子（付不起不扣料、不超支）；起点境界落在档位区间内且宗门越高／档位越高平均越高、天赋权重按档位偏移且可确定性验证；随机序列与旧档兼容；在线离线一致。

已确认（2026-10-15）：

- 花费采用**组合资源**：以灵气为主（随宗门境界倍率缩放），高档次叠加香火、灵机，见上表。
- 招募模式与自动前来**互斥**：切到主动招募即停止免费来人，切回恢复。
- 招到弟子的**起点境界按概率抽取**：宗门境界越高、档位越高，抽到的起点境界越高，见 §2.5.2。

## 3. 数据、兼容与验证

### 3.1 当前数据契约

运行时以 `disciples.members` 为权威记录，`total` 与 `jobs` 为人数及岗位汇总。`nextId` 分配递增身份，`rootSeed` 保存灵根随机序列，`talentSeed` 保存天赋序列，`recruitSeed` 保存主动招募的起点境界序列。

| 字段 | 当前含义 |
| --- | --- |
| `id` / `name` | 持久化身份与姓名 |
| `roleId` | 岗位标识，闲散为 `null` |
| `realm` / `cultivation` | 实际境界与本境修为 |
| `spiritualRoot` | 灵根标识 |
| `talents` | 固定天赋条目 `{ id, level }`，等级范围 Lv.1–Lv.3 |
| `mentored` / `aidBonus` | 是否受传功；待生效的个人护道百分点（0 表示无） |
| `cooldown` | 突破调息剩余秒数 |
| `residenceSeconds` | 入宗后累计已结算秒数 |
| `totalQiConsumed` | 累计个人灵气消耗 |

速度、有效境界、突破状态、费用及成功率动态计算，不保存 `cultivationRate` 或 `breakthroughStatus`。当前身份字段为 `id`。`talents` 已进入归一化；`talentSeed` 与 `talentVersion: 2` 保存于 `disciples`。旧弟子不补发随机天赋、不自动升级，种子缺失时从原灵根种子派生，不在重复读档时推进。

旧人数档按原人口与岗位补凡体、零修为个体；缺失停留与消耗补零，从更新后开始累计，不估算历史投入。已有有效记录保留。人数兼容接口按现有顺序补充闲散人选或移除超额人选，不自动挑选高境界者。

### 3.2 后续改动的验证要求

- 保持修为上限、宗门上限、个人有效境界与实际境界的区分。
- 逐人扣料与批量停止不超支，预览和执行使用同一费用及概率入口。
- 培养、修炼、调息、新人入门和资源消费使用一致的在线／离线时间轴。
- 随机结果持久化，迁移可重复读取而不重抽、不重复补发。
- 个人效果只作用于明确的人选、岗位或产线，避免重复计算宗门倍率。
- 大量弟子、批量操作和长时间离线正常结算，列表与加载提示保持可用。

# 科研与材料合成价格对照

更新：2026-10-16，基于 v0.384 工作区。第1～6节记录价格诊断及先前试调，第7节记录悟道专精；**当前已接入道札／道论／阵图，相关现价和规则见 [KNOWLEDGE-CRAFTS](KNOWLEDGE-CRAFTS.md)**。早期价格及未采用候选不代表现行数据，完整报价以生成表为准。建筑部分见 [BUILDING-PRICE-COMPARISON.md](BUILDING-PRICE-COMPARISON.md)。

本作依据 `src/data/upgrades.js`、`techniques.js`、`crafts.js`、`buildings.js` 及 `src/game/systems/craftingRules.js`。猫国参考本地源码，并核对官方 [science.js](https://raw.githubusercontent.com/nuclear-unicorn/kittensgame/master/js/science.js)、[workshop.js](https://raw.githubusercontent.com/nuclear-unicorn/kittensgame/master/js/workshop.js)。本地猫国副本并非最新，例如纲要配方旧版为科学10000＋手稿50，官方当前为科学9000＋手稿55；下文采用官方现值。

## 1. 判断

科研主要是**中后期费用与供给不匹配、研究用料未充分承接产业层级**。合成主要是**高档建材仍大量直接使用基础资源，且多段增产会进一步降低实际成本**。两者与高档住宅、科研设施和综合仓形成扩张循环，不能只按列表数字判断便宜与否。

优先处理高档建材及其用途、关键研究的材料预算，再校准后期灵机费用与破境需求；保留早期木板和基础能力的承接。不建议所有科研、配方统一翻倍，也不建议取消制作增产。

猫国科学与本作灵机单位、劳动产出、仓容和重置条件不同，以下是费用结构对照，不是同单位购买力比较，更不能据此认定首飞应固定耗时几天。

## 2. 科研：数字递增已有，实际准备时间递增不足

猫国代表节点的科学费用为：历法30、文字3600、神学20000、天文学28000、物理50000、工业化100000、核裂变150000。神学还需手稿35，物理需纲要35，工业化需蓝图25，核裂变需蓝图100。随着研究推进，除了科学库存，还要投入不同层级的加工成果。

本作并非没有材料费用，但有些后期节点的副材料仍停留在数量很小的前级产物：

| 研究 | 灵机 | 其他费用 |
| --- | ---: | --- |
| 凝气化液 | 1500 | 灵木200、灵石60 |
| 讲经法 | 1600 | 无 |
| 凝晶原理 | 8000 | 无 |
| 观星术 | 12000 | 符箓6 |
| 灵子论 | 18000 | 灵晶40、灵符6 |
| 阴阳分灵 | 36000 | 灵石12000、灵器6 |
| 湮灭法 | 90000 | 九转丹20、灵符20 |
| 灵能输配 | 120000 | 灵晶30、灵器8 |
| 仙灵初探 | 160000 | 灵晶40、灵器6 |
| 仙灵聚合 | 320000 | 九转丹30、灵器10、玄金4 |

例如仙灵初探比灵能输配更贵，但灵器从8件降到6件；仙灵聚合才增加玄金，也只有4份。相比单纯加灵机，更值得检查这些新能力是否真正要求宗门完成相应产业准备。数量不必逐节点机械递增，关键节点应有明确的材料预算。

### 当前供给能覆盖多少价格

前轮未加规模口粮的24小时审计样本，灵机产出943.309/s，库存约144.7万；加入规模口粮后的同策略样本仍有911.52/s、库存约153.6万。前者仅用于估算成熟宗门的供给量级：

| 费用 | 以943.309/s补回所需时间 |
| ---: | ---: |
| 18000 | 19秒 |
| 36000 | 38秒 |
| 90000 | 95秒 |
| 120000 | 127秒 |
| 160000 | 170秒 |
| 320000 | 339秒 |

这不是研究首次开放时的等待时间：当时人口、设施、材料和仓容可能更少，也不含前置准备。但它说明后期产能建成后，十几万灵机无法持续充当阶段门槛。单纯把90000提到180000，在这个量级下也只增加约95秒。

讲经堂每座灵机+35%、观星台+50%，再叠藏经阁、典籍库、人口、境界和其他乘区；“灵机没有规模效应”已不能作为当前调参依据。

此外，后两次宗主破境基础灵机只需5000、8000，已有优惠还会降低费用。前轮样本的下一次需求4800，仅约5.1秒产出。**研究贵而破境便宜时，玩家可跳过可选研究直冲飞升**；提高因果池等可选项目价格不能稳定拉长首飞。飞升不要求研究全部买完。

### 科研建议

1. 保留开局和已压平的100～600旧价格段，不整体撤回 D1；当时解决的是局部筑基阶段瓶颈。
2. 联同建筑专题，让科研扩建与研究争用灵机和加工品，检查讲经堂、观星台、综合仓带来的扩产／扩仓收益。
3. 从凝晶、灵子、湮灭等关键能力节点开始按开放时的产量校准。先记下灵机净产、库存、容量、材料净产与竞争用途，再用“预期主动准备时间×可投入净产”定价。不能用24小时成熟产量反推早期价格。
4. 优先重估灵能输配、仙灵初探、仙灵聚合的材料预算，使用当时上游已经开放的灵晶、灵器、九转丹、玄金；不能要求研究自身才开放的产物。首次湮灭仍要能靠前级仓容和产线启动。
5. 同时检查元婴之后真正必经的破境预算。只涨可选科研会加剧“研究不划算，直接突破”的倾向，不强制学完整棵树来制造时长。

## 3. 合成：基础配方接近，后期建材压缩不足

猫国木梁用木175、铁板用铁125、脚手架用木梁50、钢用铁100＋煤100；混凝土用石板2500＋钢25，合金用钢75＋钛10。其后期建材大量消耗前级加工品，并引入其他原料来源。

| 本作产物 | 每份基础投入 | 评估 |
| --- | --- | --- |
| 木板 | 灵木175 | 与木梁同量，广泛承担早期建造，不优先涨 |
| 法器 | 玄铁125、灵石12 | 基础器材，承担灵器上游，不宜统一大涨 |
| 阵基 | 木板10、玄铁100、灵气300 | 已有二级链；可观察后期用量，保留首份承接 |
| 玄钢 | 玄铁100、灵气120 | 第二原料是通用灵气，缺少独立原料线的约束；不必为此强加新资源 |
| 混灵土 | 灵石20、灵液2 | 高档建材入口，基础投入较轻 |
| 玄铁混灵土 | 混灵土2、玄铁50 | 只放大2份上游建材，且再享一次增产 |
| 秘银 | 矿石150、灵气150 | 炼虚开放，却直接用基础矿石／灵气，易被成熟供给覆盖 |
| 玄金 | 灵液8、玄铁100、秘银4 | 已有链，秘银需求小，二次增产继续稀释 |
| 晶银 | 灵晶8、秘银4 | 两条支线汇合，但基础需求同样不高 |
| 灵器 | 法器100、玄钢25 | 已有较重前级投入，应区别于廉价建材 |
| 灵宝 | 灵器25、九转丹25、灵符50 | 三线汇合、链条长，不优先涨 |
| 飞升阵印 | 灵能80、秘银2、灵符1 | 固定产出，不享制作增产或节料；重点看灵能净流量与总需求 |

不能把混灵土直接改成猫国混凝土的2500份前料：两者所处阶段、建筑用量和仓储不同。可借鉴的是高级建材需要持续消耗中级产业成果。

### 增产如何改变实际成本

本作单次产出为 `基础产出×(1＋全局制作加成＋该成品专业加成)`。同一次的全局与专业加成相加，跨多段加工则会逐段降低单位成品耗料。小数产出有进度累计，下列按长期平均估算，非单次报价。

仅取前轮样本的33座工坊，忽略所有研究及专业加成，全局制作倍率已为 `1＋33×0.06＝2.98`：

- 木板实际平均耗灵木约58.72，而非175。
- 秘银平均耗矿石50.34、灵气50.34，而非各150。
- 玄铁混灵土展开混灵土后，平均仅耗灵石4.50、灵液0.45、玄铁16.78。灵液自身的制作增产还可继续压低上游灵气成本。

再考虑样本31座炼器坊，法器制作倍率至少 `2.98＋31×0.08＝5.46`，每件平均用玄铁22.89；32座丹房的基础丹药倍率至少5.54。上述均未计研究、精研设施等额外收益。

灵宝则不能只看“25＋25＋50”：不计任何增产，单件仅灵器支线就含法器2500、玄钢625；九转丹支线展开还涉及大量丹药与仙草。因此，不能用建材便宜的结论去统一提高所有终阶配方。

节料当前实际仅见15%木板、15%玄钢、10%法器／灵器、15%凝液、20%凝晶等；代码50%是防御上限，不是每种材料都已节省一半。整数材料逐项向上取整，例如凝晶的3瓶灵液减少20%仍需3瓶，不能直接按2.4瓶估价。

## 4. 建议的第一轮候选范围

以下只是用于后续对照的搜索范围，不能同时全量叠加后宣布完成平衡。先测建材改动，再决定是否还要调整其下游建筑基础价，避免两头重复加价。

| 对象 | 当前 | 候选与理由 |
| --- | --- | --- |
| 混灵土 | 灵石20、灵液2 | 先试灵石60～100、灵液4；提高土木产业预算，同时观察灵石是否挤占破境与交易 |
| 玄铁混灵土 | 混灵土2、玄铁50 | 上游混灵土4～6、玄铁暂留50；先建立持续的中级建材需求 |
| 秘银 | 矿石150、灵气150 | 先试矿石300～450、灵气暂留150；若仍被秒供覆盖，再评估使用已经开放的加工品，暂不增加新资源 |
| 玄金／晶银 | 秘银各4 | 秘银8～12；先观察秘银改价的传导，未必需要同时涨 |
| 木板／基础丹药／法器／灵宝 | 现价 | 首轮保留，避免开局变慢或长链成本剧烈膨胀 |
| 飞升阵印 | 现价、固定产出 | 先核算180枚等实际破境需求对应的灵能14400及炉子净产，不靠修改手工等待时间拖长进度 |

手动制作当前是即时转换，配方 `time` 用于自动加工节拍；阵印的120秒也不是强制手工等待。只提高 `time` 会主要惩罚离线和自动玩家，并不能可靠延长主动玩家的首飞，因此本轮不建议以它作为主要价格杠杆。

## 5. 实施前的最小验证

- 选取首次解锁、该阶段发展中和成熟宗门三类快照，记录报价／有效单位成本／材料净产／仓容／竞争用途；估算不能替代真实完整链条运行。
- 复用来源与建筑可达性审计，确认首份材料、首座设施、扩仓研究均由上游承接；若混灵土涨价，特别复查精舍、洞府、综合仓和宜居设施。
- 补齐现有节奏机器人对湮灭炉和阵印的准备，再做相同策略、多种子与低频上线对照；记录实际是否飞升。已有24小时结果停在大乘，不是首飞耗时。
- 价格落地后更新生成表与变更说明。旧档不追缴费用、不删除已学研究或已造建筑；旧库存会暂时缓冲涨价，必须区分新档与旧档结果。

## 7. 科技加成复核与悟道专精补充（已实施试用）

复核依据同上所列官方猫国源码，以及本作 `techniques.js` 和 `economy.js`。不能把所有标注科学／灵机的升级都归为持续增产。

### 猫国的升级分别改善什么

- 图书馆基础科学+10%、学院+20%、天文台+25%、生物实验室+35%；部分升级和启用状态另有影响。
- 星盘将天文台自身基础科学仓容1000提高到1500，不是科学持续产量+50%。
- 钛镜等反射镜升级通过天文台数量放大图书馆科学仓容，`libraryRatio` 在此处作用于 `scienceMax`，不能解释成图书馆产量倍率。
- Uplink使数据中心与实验室互相改善仓容；不是把两个建筑的持续科学加成相乘。

其科研成长包含扩仓、设施升级、关联效果等不同收获，不能根据升级名称多就认定持续产出倍率更高。猫国科学侧并不是一整排直接增加学者产量的斧头式升级。

### 本作当前有哪些灵机加成

| 类型 | 已有条目 | 生效位置 |
| --- | --- | --- |
| 技艺 | 口传心授+10%、星象推演+15% | 灵机资源加成，与建筑的同类加成相加 |
| 职位专精 | 坐忘功+35%、经义互证+25%、观象参同+35% | 悟道者岗位加成相加，先改善职业产出，再乘资源层；后两项为本轮新增 |
| 法宝 | 传音玉简+15%、观星盘+20%、灵能枢+25% | 同一资源加成层，可祭炼；每级让该法宝效果增加其基础值的30% |
| 研究 | 大乘心经：灵机+120% | 同一资源加成层，不是最终灵机产量独立乘2.2 |
| 建筑 | 藏经阁+10%、典籍库+5%、讲经堂+35%、观星台+50%／座 | 可重复建设，同类相加；另有试炼塔、祖师殿、通天塔、因果池等 |
| 其他 | 境界、仙缘、道果、宜居度、个体岗位权重、增益与湮灭炉等 | 按现行结算公式作用，不能只由技艺页估总产量 |

所以“总加成很少”不准确；本轮补充前的主要问题是一次性悟道专精少、阶段性升级缺乏存在感：原先只有坐忘功直接增加 `jobRatio.scholar`，后面主要靠加建筑和祭炼。

例：已有建筑／资源加成+1000%，购买资源层+10%的技艺，产量由11倍变11.1倍，实际只增加约0.91%。若已有坐忘功+35%，新技艺给予岗位层+25个百分点，则岗位倍率1.35→1.60，实际约+18.5%，其余条件相同且同一悟道者组成下成立。差异来自加成位置，而非面板的10与25本身。

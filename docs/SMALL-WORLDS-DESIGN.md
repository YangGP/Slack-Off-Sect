# 小界经营：现行规则与设计取舍

更新：2026-10-25，v0.425。6设施、3修真、6技艺及段内分流预算已实施，长期经营平衡待验证。报价与前置查[生成表](TABLES.md)，实现见[设施数据](../src/data/worldFacilities.js)、[段内预算](../src/game/systems/worldRules.js)和[世界结算](../src/game/systems/samsara.js)。

## 1. 经营目标与边界

小界形成取得资源、选择回投或留存、改善瓶颈、决定继续扩建或停投的循环。优先深化现有三界，不新增货币、旅行等待、装备或世界专属岗位。

聚灵负责仙灵力扩产，洗髓负责个人终极准备，护道负责集体公共备料。普通飞升保留独立出口，洗髓／护道及六项新设施均可跳过；不为强迫投资增加普通飞升账单。

每界一名驻守、最多三名，驻守让出地面岗位。安全境界仍为化神／合体／大乘，不提高风险来抵消新增收益，也不增加猎场／驻守免死。风险按实际驻守时间结算，停产不等于召回。

## 2. 基础采集、承载与收支

有效采集级数为 `min(采集级数, 1 + 承载级数)`，需要有效驻守。采集和承载各自按1.35增长，承载基础费用为对应采集基础费用的一半，再计适用永久折扣。世界产出不默认叠地面全局生产或制作倍率。

| 世界 | 建设／安全驻守境界 | 每有效级基础产出／小时 | 灵能维护／小时 | 天砖维护／小时 |
| --- | --- | ---: | ---: | ---: |
| 聚灵 | 合体／化神 | 仙灵力10.8 | 72 | 0.036 |
| 洗髓 | 大乘／合体 | 清灵髓2.16 | 144 | 0.072 |
| 护道 | 大乘／大乘 | 镇界砂3.6 | 216 | 0.108 |

基础账示例，不含增产、节料、其他建材及失岗成本：聚灵首座20天砖所含仙灵力1000，基础每小时天砖维护折合仙灵力1.8，单看仙灵力子账净额9／小时，约111.1小时回收。再升一级有效采集需采集27天砖、承载10天砖，合计折合仙灵力1850，同口径约205.6小时。首座与后续投资不能套同一个回本时间。

个人准备需清灵髓30／人；公共护道10级共需镇界砂275N。它们是材料需求，不是固定等待；真实耗时还受扩建、维护和人手竞争影响。三仙材、清灵髓及镇界砂当前不限仓，不新增无用途仓库。

## 3. 六项专属设施

每种单座，建造即时付费，默认关闭／分流0。先有对应小界采集点，再研究界脉导引、澄髓合炼或界壁调律，开放本界两设施。它们不反锁首座基础产线。

| 小界／设施 | 当前作用 | 持续代价及停用边界 |
| --- | --- | --- |
| 聚灵：归元环 `returnRing` | 本界灵能维护相对−15%，归元校准后−25% | 额外付本界基础天砖维护10%，该附加部分不吃镇界碑减免 |
| 聚灵：通灵枢 `spiritHub` | 分流仙灵力支援凝聚工位容量，上限20%，通灵配流后30% | 仅在存在可运行且容量不足的凝液／凝晶需求时分流；不增加每份产物或减配方费用 |
| 洗髓：澄髓池 `marrowPool` | 清灵髓额外产出25%，药液循养后40% | 每有效运行级每小时另耗灵草1800、灵液7.2；缺料只降低强化，不停基础产线 |
| 洗髓：丹髓炉 `marrowFurnace` | 分流清灵髓，提高选定凝元丹或九转丹自动效率，上限20%，丹髓定候后30% | 只支持玩家所选一种配方；无有效工单不消耗，不直接加弟子修为或贡献 |
| 护道：镇界碑 `boundaryStele` | 分流镇界砂，降低三界基础天砖维护，上限15%，镇界定额后25% | 不减归元环附加维护、不返建材、不加公共护道等级 |
| 护道：协灵阵 `cooperativeArray` | 分流镇界砂，降低精舍、洞府、清幽园林、洞天的灵能档维护，上限10%，协灵分账后15% | 不含五类新生产阶段、湮灭自用、聚仙、世界、工位、逸散或配方用能 |

六项专业技艺均已实施，各要求对应设施和理论，按本世重新取得。不再为每项复制一个法宝。通灵容量与已有容量比例同层相加；丹髓效率与配方效率同层相加，不独立乘最终吞吐。

## 4. 分流曲线与段内预算

每条支援可设0、25%、50%，同界合计最多50%；超额设置被拒绝，不暗中改另一条。分流使用当段可支付产流，不燃烧历史库存，扣除后才净入库。没有运行对象时不分流。

现行曲线为 `E = Emax × Q / (Q + Q50)`。Q按每小时表示，由当段保守预预算的可支付产流与分流比例确定；Q50分别为仙灵力2.7、清灵髓0.54、镇界砂0.9／小时。Emax取对应设施及技艺上限。不能把分流25%解释为支援固定增加25%。

例如聚灵一个满供采集级分流25%，Q=2.7，未学通灵配流时容量增加10个百分点；四级同分流时增加16个百分点。这里是容量比例层，不是最终出货额外独立增加10%或16%。

结算采用保守的同段预算：

1. 先计地面需求及能源衰减等非负约束，求本段世界可支付运行量，预预算已纳入归元环、澄髓池等合法变化。
2. 按可支付产流和有效目标确定支援预算及强度，不借上一帧效果，不循环放大支援。
3. 地面用同一支援重算后，只求最终可支付运行量；支援改善后的新增产流不在本段再次提高Q。
4. 世界维护进入统一费用只付一次。段内记录真实工业工作时间，段末将未使用的通灵枢／丹髓炉预留分流返入主产物库存，不重复记为新生产。

基础供给不足时世界产出与支援受限；澄髓池另缺草／液只降强化。长期报告须区分毛产、预留、实际消耗、返流和净入库，不能重复扣维护或把支援与净产同时算全额收益。在线、离线沿用相同预算，离线分段有界。

## 5. 玩家选择与界面边界

普通飞升路线可在聚灵扩产、支援凝聚和留存仙灵力间选择；后两界不强制参与。长期培养路线在丹药短缺时支援、个人准备接近需求时留存清灵髓。全员收官路线在剩余培养期长且维护重时支援、临近收官时优先积攒镇界砂；提前备料不会自动开启挑战。

保留世界页，提供采集／承载、驻守、设施启停、分流及丹药目标控制。完整地面岗位机会成本、目标缺口和停用原因解释属于继续评估的展示内容，不把设计期页面草图当作已完成界面验收。

回本不把仙灵力、清灵髓、镇界砂与其他材料直接相加。按当前稳定边际产能比较建材、维护、失岗和完成目标的等待；无稳定来源时只报告无法可靠外推。原3～7天首处、7～14天较深投资属于比较方向，不是强制等待或实测承诺。

## 6. 兼容与轮回

统一按[旧档策略](ENGINEERING.md#后续内容重构的旧档策略)保留永久资产、图纸、名录和合法库存数字。既有世界ID未替换时保留采集、承载、驻守与风险预算；六设施和新研究默认未取得、关闭，由玩家手动全价取得，不折抵历史投入。

设施拥有、开关、分流及丹药目标保存；支援和供给派生值重算。重复读档不清空新内容、不重抽旧风险预算；超仓库存不裁掉。正常转世／飞升／身死仍清本世设施、研究、物资与驻守，永久资格按既有规则保留。

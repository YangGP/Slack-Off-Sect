## 主干与关键分叉

| 主线 | 研究与能力 |
| --- | --- |
| 观气 | 灵源考 → 观气法 → 灵气测定，理解来源并建立计量 |
| 凝聚 | 凝气化液 → 凝液法 → 灵气纯化 → 凝晶原理，开放灵液与晶体知识 |
| 调控 | 讲经、观星、阵道与候时，承接科研设施、阵法与心印 |
| 拆解 | 灵子论 → 阴阳分灵 → 湮灭法 → 灵能输配 → 仙灵初探 → 仙灵聚合，开放粒子、供能与仙灵材料产业 |
| 归源 | 大乘心印、因果与塔院知识，承接终局建设与经营 |

灵源考是修真唯一入口，早期分出观气、灵植、营造等方向。分支以已有知识成果承接，不要求学满章节，不把整棵树串成单条必修线。凝晶原理还要求符文入门；灵子论由凝晶与观星共同承接；阴阳分灵还要求复合符文。完整条件以数据为准。

关键节点可以开放两三项研究，普通节点尽量少量开放下一步。页面没有固定最多三项的显示上限；积累未研究分支时，可见项仍会增加。

## 金丹阶段

共同前置已学、原先报告的九项尚未学时，修真先显示凝气化液、土木精要、导灵纹：

| 入口 | 后续研究与应用 |
| --- | --- |
| 凝气化液 | 继续凝聚主干；破境心法作为技艺页的节料应用 |
| 土木精要 | 淬玄工艺 → 兽材加工、器道精微等材料研究 |
| 导灵纹 | 阵基装配 → 讲经法 → 香火志；技艺页另开放流水作坊 |

流水作坊要求木作器械、心有灵犀与阵基装配，不再依赖淬玄工艺。玄钢与机械扩产分别推进，避免为缩短列表而强接不同能力。兽材加工仍要求猎法、炼器与淬玄知识。

土木精要只是淬玄工艺的研究前置，不要求先建使用玄钢的材料库。讲经法承接讲经堂建材所需的阵基装配，香火志仍保留香火愿前置，并显式补「山门 ≥ 2」（其费用含香火200，而基础上限仅100、香火鼎又由它自己解锁）。自动制作由木作、炼丹和炼器基础知识承接，不要求先购买丹火纯青；疾炼法由自动制作、阵基装配和凝液知识承接，不要求先购买流水作坊。

## 产业、费用与仓容

已接入[知识加工链](KNOWLEDGE-CRAFTS.md)：金丹记录道札、元婴汇编道论、化神绘制阵图，逐步用于观星／灵子／湮灭／仙灵科研及部分高级工程。相关报价减少一部分现付灵机，改为消耗知识成品；首座讲经堂费用保留。知识由既有研究开放配方，不需要先消耗自身产物来研究其制作方法。当前完整报价以生成表为准，早期D2试调值不作为现价。

研究费用就是需要容纳的库存量，仓容由典籍库 → 讲经堂 → 观星台 → 洞天等设施及升级承接。藏经阁承担研读增产，典籍库提供早期灵机仓容及少量查阅增产，口传心授仅扩大典籍库自身仓容。超过仓容的已开放研究折叠显示，旧档超仓库存仍可支付，没有额外硬性仓容判定。

**费用曲线**：灵机 100～600 这一段已于 2026-10-15 压平（`new = 100 + (原价 − 100) × 0.5`），涉及 34 个节点，段内合计 9,050 → 5,828、单笔最高 600 → 350；低于 100 与高于 600 的部分不动。该调整针对早期局部瓶颈，不能据此继续增加全期灵机供给。当前讲经堂每座灵机+35%、观星台+50%，还叠加人口、境界与其他效果，灵机具有明显规模效应。2026-10-16 审计的成熟宗门快照达到约912～943灵机/s，后期研究和破境费用需结合开放时产能、仓容与材料预算重新校准；不得把成熟快照当作早期等待时间。分析和未实施建议见 [RESEARCH-CRAFT-PRICE-COMPARISON.md](RESEARCH-CRAFT-PRICE-COMPARISON.md)。

首次研究用料必须来自上游，扩仓研究费用必须由前级仓容承接。不能要求自身产物才能开放首座产业，不能要求先建自身才能解锁研究。完整研究图与资源、建筑依赖均需检查。

2026-10-16第一轮试调已提高灵子、湮灭、仙灵主线的部分灵机和材料预算，讲经堂／观星台增加灵机建设费；知识链随后将观星台调整为灵机600、道札6。2026-10-17平顺阶段费用后，元婴破境基础灵机3000，另需道札30／灵液60；化神至渡劫基础灵机为9000／30000／60000／120000／240000。通过增加用途使科研、扩产和破境产生取舍，不增加悟道者基础产出或修改仓容公式。当前阶段对照见 [PACING-AUDIT](PACING-AUDIT.md)，完整报价见生成表；旧档已学研究和已造建筑不追缴。

知识可先行，配方和设施继续遵守各自条件。分灵阵≥元婴、偏极阵≥化神、湮灭炉≥化神，采仙台≥炼虚、聚仙阵≥合体；《灵能输配》在炼虚参悟。设定见 [SPIRIT-ENERGY.md](SPIRIT-ENERGY.md)。工业加工共享专业工位，应用升级改善容量、效率或耗料，不赠送原料。

## 兼容与验证

迁移不换 ID、不清除已学记录、不补赠前置。旧档已学应用升级在技艺页展示，加成、破境优惠和供能维护继续生效；未学项按当前前置显示。

检查两页归属、迁移数据一致性、真实参悟后的显示、旧档效果、完整依赖及各境界来源和仓容可达性。飞升只要求渡劫期，不要求完成全部研究；重组后的飞升耗时需要重新模拟，不能由列表数量推算。

# DOM 交互检查

运行 `npm run check:dom`。`../dom-check.mjs` 只负责环境、执行清单和结果汇总。

`checks.mjs` 明确列出场景顺序；`environment.mjs` 在导入 Vue 前安装 jsdom 全局量，捕获异常和警告，并在结束或失败后释放循环、挂载和浏览器环境。断言统计复用 `../lib/checks.mjs`。

按功能修改同名场景文件。所有场景共享同一局游戏，必须保留执行顺序；通过 `context` 显式接收依赖，把后续场景需要的变量写回 `context`。不要在导入模块时挂载应用或执行断言。可独立创建状态的引擎用例应放入 smoke，而不依赖这些交互场景。

拆分保留原有 460 项断言及顺序。新增场景需登记到清单；最终以运行输出为准。jsdom 不能验证真实浏览器的视觉布局。

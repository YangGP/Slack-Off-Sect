# 灵子与灵能场设定

本文是世界观设定及工程应用草案。正负灵子、灵气分子和灵能场的规则属于本世界的假定；借用电磁学术语帮助描述，不要求与现实物理逐项对应。工程示例表示文明可发展的方向，不代表游戏中已实现的设施。

## 一、核心框架

### 1. 基本关系

- **正灵子 / 负灵子**：分别携带正、负灵荷的基本粒子。“灵子”是粒子，“灵荷”是其属性；正负不表示善恶。
- **灵能场**：正负灵荷及其运动共同激发的场，可分为灵电场与灵磁场。场能传递作用、携带能量，并影响灵气分子的取向与运动。
- **灵气分子**：一个正灵子与一个负灵子形成的稳定束缚体，是普通灵气的基本组成单元。整体灵荷为零，内部具有可被外场极化的双极结构。
- **灵气**：大量灵气分子与灵能场激发构成的宏观介质。日常通常指气态；广义也包括凝成的灵液与灵晶。普通灵气整体准中性，可含少量游离灵子。
- **灵能 / 灵力**：灵能是体系中可储存、传递与转换的能量；灵力是修士或器物能调动的有效灵能。灵能场是能量的载体之一，不能与能量本身混为同一个概念。
- **灵石 / 灵晶 / 灵脉 / 灵泉**：灵石是含灵气的矿物，既可从矿脉采集，也可将灵气灌入适宜的石材制作；矿物是承载灵气分子的载体，灵气不能凭空变成普通石材。灵晶是灵气分子的高纯有序结晶；灵脉是汇聚、输送灵气的地质通道；灵泉是富含灵液或溶有灵气分子的泉水。

一句话：

> 正负灵子携带灵荷，束缚成灵气分子；分子组成灵气，灵能场联系它们的运动与作用。

### 2. 灵能场四律

1. **高斯灵律**：正灵子发散灵电场，负灵子汇聚灵电场。
2. **灵磁闭合律**：没有单独灵磁荷，灵磁线闭合。
3. **法拉第灵感应律**：灵磁场变化会感应出灵电场。
4. **安培—麦克斯韦灵律**：灵流和变化灵电场会产生灵磁场。

四律描述场如何产生和传播，不单独解释分子为何稳定、神魂如何存续或空间如何折叠；这些现象还需下面的束缚规则及相应的材料、生命和空间条件。灵荷、灵压、灵流和灵阻分别描述带荷属性、驱动势差、灵荷输运及输运阻碍。

### 3. 灵气是什么

灵气不是基本粒子，而是：

> **大量灵气分子与灵能场激发共同组成的宏观介质。**

天然稀薄灵气不必高度有序；修炼与阵法可以使其形成定向灵流、相干振荡或稳定场形。

灵气的三种常见相态：

- **灵气态**：稀薄灵气分子气体，遍布天地。
- **灵液态**：在合适灵压、温度与束缚条件下形成的高密度分子流体，可汇入灵泉。
- **灵晶态**：分子按稳定晶格排列，形成灵晶。灵石中的分子由矿物孔隙、晶格与杂质共同承载，不等同于纯灵晶。

五行属性不是五种灵子，而是：

- **火**：易向外释放能量的极化振荡与场模。
- **水**：连续输运、柔性响应的分子取向流。
- **金**：定向性强、便于传导和聚束的有序结构。
- **木**：与生命代谢、组织生长相耦合的场模。
- **土**：承载、缓冲与固定场形的稳定晶格或介质结构。

五行是分子排列、取向、振荡、场形及承载介质共同形成的响应类型。同一种分子可以参与不同属性的灵气，属性之间可混合、转化；具体转化需要材料与能量条件。正负数量失衡主要改变净灵荷，不直接决定五行。

### 4. 束缚、解离与湮灭

本世界假定灵子间除了灵荷作用，还存在形成稳定分子的短程束缚规则。正常束缚态与湮灭态之间有转换门槛；整体中性只描述对外灵荷，稳定性来自束缚结构与这道门槛。

| 过程 | 发生什么 | 能量与物料去向 |
| --- | --- | --- |
| 离析 | 从宏观灵气中提取、集中完整灵气分子 | 消耗操作能量，分子仍然完整 |
| 解离 | 打开分子束缚，分出自由正负灵子 | 输入解离能，需要设施维持分离 |
| 复合 | 正负灵子回到稳定分子束缚态 | 释放结合能；数量和灵荷保持配对 |
| 湮灭 | 通过特定场形使正负灵子越过转换门槛 | 成对消耗灵子，转为场能、辐射及热；不留下原分子 |

普通碰撞可能散射或复合，不必然湮灭。湮灭炉需要同时控制供料、相位与场形，才可持续提取灵能；单靠解离不会凭空放出巨大能量。

能量转换必须有账可查：储能来自外部供能或燃料消耗，输运与加工有损耗，冷却要把热转移到别处。解离—复合循环不能净产能；湮灭消耗燃料，重新制造等量燃料至少需要补回相应能量。聚灵阵收集环境灵气，灵脉汇集或由更大的天地循环补给，不能无条件无限供能。湮灭所称“纯净”指杂质少、便于调控，不表示没有废热。

## 二、正负灵子的用途

### 1. 正灵子

常见应用偏“放、生、明、攻、疗”。这些是术法传统与材料响应形成的倾向，不是善恶或秩序的固有属性；同样的外放作用既可疗伤，也可灼毁组织。

- **修炼**：炼体、开脉、淬骨、阳神、金丹、雷法。
- **法术**：光、热、雷、火、净化、治疗、驱邪、破幻、增幅、飞行。
- **炼器**：阳纹、飞剑加速、灵灯、炉火、爆裂法器、护身罡气。
- **阵法**：输出端、聚灵端、天罡阵眼、传讯节点。
- **丹药**：补气血、破瓶颈、淬体、延寿、驱阴毒。
- **灵植妖兽**：阳属性灵药，火、雷、光系妖兽。

过量后果：暴躁、自燃、经脉灼裂。

### 2. 负灵子

常见应用偏“收、藏、暗、噬、魂”。收敛作用可用于镇静、保存、封护与治疗，也可用于吞噬、诅咒；用途取决于场形和操作者。

- **修炼**：阴神、鬼道、魔功、元神、隐匿、吞噬、空间。
- **法术**：冰、暗、腐蚀、噬灵、控魂、诅咒、通幽、遁术、削弱、封禁。
- **炼器**：阴纹、储物、锁魂、冷却、隐匿、空间折叠、噬灵法器。
- **阵法**：吸收端、聚阴端、迷阵、封魂阵、噬灵阵、地煞阵眼。
- **丹药**：凝魂、化毒、阴丹、鬼丹、隐匿气息。
- **灵植妖兽**：阴属性、冥界灵植，影、冰、魂、毒系妖兽。

过量后果：阴寒入髓、神魂癫狂、易被阴物寄生。

### 3. 正负组合

- **正负成对束缚**：形成灵气分子，分子组织方式与介质条件决定灵气属性；额外游离灵子改变带荷状态。
- **正负湮灭**：在满足转换门槛时成对消耗，释放高强度灵能。
- **正负分离场**：形成灵子电势差，驱动法阵、法器、傀儡。
- **正负灵子流**：模拟灵力电流，发展灵子计算机、传讯网络。
- **正负双极体**：正灵子炼体，负灵子炼魂，正负交替淬炼。
- **禁灵领域**：抽走或打乱正负灵子，让法术失效。
- **信息与魂魄**：传播型场模常用于传念、广播；稳定束缚结构常用于记忆与执念保存。魂魄需要生命形成的复杂组织，不能等同于一团负灵子；两类灵子都可参与信息处理。

## 三、灵能场视角下的法术与修炼

### 1. 法术的典型频段与控制方式

法术效果同时取决于频率、功率、相位、场形、介质和作用对象。以下是常见工作区间，不是法术等级表；高频未必高功率，频率相同也能形成不同术法。

- **低频灵波**：传讯玉简、灵网、地脉探测。
- **中频灵波**：护盾、御剑、飞行、控物。
- **高频灵波**：雷法、火法、破阵、炼器。
- **极高频灵波**：高精度探测、强局域激发及部分湮灭控制过程，需要专门介质和防护。
- **神魂共振与调制**：神魂攻击、幻术、诅咒依赖对目标结构的识别、相位控制及信息编码，可跨多个频段。
- **灵场共振**：双修、疗伤、破禁、炼丹。
- **灵场干涉**：隐身、禁灵、抵消法术。
- **灵场屏蔽**：用导灵材料、吸收结构及补偿阵削弱特定频段和场形。屏蔽效果有范围、带宽与承载上限，不能无条件封住所有术法。

### 2. 修炼境界与灵子认知

| 境界 | 对灵子的认知 |
|---|---|
| 凡人 | 只知风水地气，不知灵气。 |
| 炼气 | 能感知灵气，引气入体，但认为灵气是连续“气”。 |
| 筑基 | 内视经脉，感知灵压、灵流、灵阻，有灵子假说但无法验证。 |
| 金丹 | 结丹时局部高压使少量灵气分子短暂解离，内观到正负灵荷，首次获得灵子存在的个人证据；仍难对外复现。 |
| 元婴 | 神识离体，灵场外放，能直接分辨并操控正负灵子。 |
| 化神 | 神识与灵能场合一，能看见灵子云、灵子波、场线。 |
| 炼虚 | 能提取自由灵子，制造灵子束、灵子对、禁灵场。 |
| 合体 | 与天地灵能场共振，可灵子级重塑肉身。 |
| 大乘 | 掌握灵子—灵能场统一规律。 |
| 渡劫 | 天地灵能场强制击穿，修士面对自身灵子层面失衡。 |

分界线：

- **炼气、筑基**：只知灵气，不知灵子。
- **金丹**：内观证实灵子，但模糊。
- **元婴**：真正感知并操控灵子。
- **化神以上**：把灵子学变成工程学。

个人能感知、短暂操作某种现象，不等于宗门已有可持续、可复制的设施。世界观中的个人能力、文明工程水平和游戏研究解锁分别描述三个尺度：例如金丹已有短暂解离的内观经验，游戏中的分灵阵到合体才代表宗门掌握连续离析产线，偏极阵及湮灭炉到大乘才形成稳定工业流程。

## 四、不同境界的日常工程应用

| 境界 | 核心能力 | 日常工程代表 |
|---|---|---|
| 凡人 | 自然利用 | 灵泉、灵木、灵矿、风水选址 |
| 炼气 | 感知灵气、低功率灵流 | 灵灯、灵火灶、净水符、短距传讯 |
| 筑基 | 稳定灵流回路 | 村镇灵网、灵能水泵、灵能冷库、灵符印刷 |
| 金丹 | 内观灵子、局部解离分子、高压储能 | 灵子电池、城市灵能网、灵能冶炼、灵能列车 |
| 元婴 | 直接操控正负灵子、灵场外放 | 灵子手术、灵子刻蚀、灵子通讯、灵能计算机 |
| 化神 | 神识与灵能场合一、场域工程 | 城市聚灵/禁灵、灵网覆盖、气候调节、传送阵网 |
| 炼虚 | 自由灵子工业、空间折叠 | 灵能反应堆、灵子对撞机、空间储物、传送门 |
| 合体 | 与天地灵能场共振、行星工程 | 地脉改造、沙漠灵田、生态圈、行星灵网 |
| 大乘 | 掌握统一规律、调控局部有效规则 | 定制灵场介质、世界级灵网、飞升通道 |
| 渡劫 | 天地灵能场强制击穿 | 渡劫场平衡、劫云发电、灵子分流 |

### 1. 凡人

- 灵泉当矿泉水，灵木当建材，灵矿当燃料。
- 风水师找地脉，本质是找天然灵能场梯度。
- 灵兽、灵植、灵火，都是现成灵能节点。

### 2. 炼气

- **照明**：灵灯符、灵火符。
- **炊事**：灵火灶、保温符。
- **净水**：净水符、驱虫符。
- **农业**：催芽符、灵雨符。
- **通讯**：短距传讯玉简。
- **医疗**：止血符、止痛符、驱寒符。

本质：用自身灵流驱动低功率灵气器件。

### 3. 筑基

- **村镇灵网**：小型聚灵阵 + 灵流管道。
- **灵能水泵**：用灵压差抽水、灌溉。
- **灵能冷库**：以收敛场模把库内热量搬运至外部散热阵，持续运行需要供能。
- **灵符印刷**：标准化灵纹，批量生产低阶符箓。
- **基础法器量产**：灵剑、灵盾及普通符匣，不涉及空间收纳或折叠。空间技艺从炼虚阶段开始。
- **灵能磨坊**：灵流驱动磨盘、织机。

本质：灵流回路工程，修仙版电气化早期。

### 4. 金丹

- **灵子电池**：把正负灵子分开储存，形成灵压差。
- **城市灵能网**：金丹修士或金丹级灵核作为中央电站。
- **灵能冶炼**：用受控灵流和场振荡把输入灵能转为热与压力，炼灵钢、灵晶；解离是操作步骤，不是免费热源。
- **灵能列车**：灵磁悬浮 + 灵流推进。
- **灵能灯塔**：大范围灵场信标，导航、预警。
- **灵能空调**：用不同场模控制热量释放与转移，调温能力受供能和散热限制。

本质：灵子工业萌芽，但只能粗糙解离，不能精密操控。

### 5. 元婴

- **灵子显微镜**：观察灵荷分布、灵气分子结构与排列。
- **灵子手术刀**：精准切除病灶，不伤经脉。
- **灵子刻蚀机**：在灵石、灵器上刻灵纹，精度到灵子级。
- **灵子通讯**：灵子束定向通讯，城市级灵网。
- **灵能雷达**：灵场回波探测，找矿、找人、找妖。
- **灵能计算机**：正负灵子作逻辑门，灵场作总线。
- **灵子打印机**：灵子级 3D 打印，量产法器零件。
- **灵子净水**：利用灵场与不同杂质的耦合差异分离污染物；普通物质不因此被定义为由灵子组成。

本质：灵子级精密制造与信息工程。

### 6. 化神

- **城市聚灵场**：整个城市灵气浓度可调。
- **禁灵监狱**：抑制外放灵场和环境供气，限制修士施法；已炼成的肉身和内储灵力不会自动消失。
- **气候调节**：灵能场控云雨、温度、风向。
- **灵网覆盖**：城市级灵子通讯、广播、遥感。
- **传送阵网络**：依赖天然空间节点或高阶修士预制的锚点，维护固定站台、中距传送；不能任意开门。
- **灵田场调控**：加速灵植生长，抑制虫害。
- **灵能交通管制**：空中灵舟航道、灵磁悬浮轨道。

本质：场域基础设施，修仙版智慧城市。

### 7. 炼虚

- **灵能反应堆**：正负灵子湮灭发电。
- **灵子对撞机**：研究灵子物理，制造新灵材。
- **空间储物**：大容量储物戒、储物洞天。
- **传送门**：远距固定门，跨城跨域。
- **灵子束加工**：切割、焊接、表面改性。
- **禁灵场发生器**：大范围禁灵，用于安防、战争。
- **灵子广播**：通过中继和固定通道实现跨域灵网；传播、编码与排队均有延迟，距离及干扰限制带宽。

本质：自由灵子工业 + 空间工程。

### 8. 合体

- **地脉改造**：引入已有灵源、重建地质通道，把贫瘠之地纳入灵脉循环；持续输出需要上游补给。
- **沙漠灵田**：大范围灵雨、灵场调温。
- **生态圈设计**：灵植、灵兽、灵脉循环。
- **行星灵网**：全球灵子通讯、能源网。
- **灵能气候**：控制大陆级气候。
- **灵脉移植**：搬山填海，重画灵脉图。

本质：行星级灵能场工程。

### 9. 大乘

- **定制灵场介质**：构造特殊束缚态与人工介质，使局部灵场呈现不同的有效响应。
- **世界级灵网**：跨星球、跨位面通讯。
- **飞升通道**：稳定跨界通道。
- **灵能常数调整**：在有边界的阵域内改变有效耦合与传播条件；需要稳定锚点、持续供能和负荷控制，无法任意改写全世界的基础常数。
- **造物**：按掌握的结构组织材料，构造生命载体、法器、洞天；原料、能量和结构信息缺一不可，塑成肉身也不自动生成完整魂魄。

本质：掌握局部有效规则的工程。“写定律”是修士的说法，效果限于维持中的阵域；跨界工程还需要空间锚点与目标侧条件。

### 10. 渡劫

- **灵子分流**：用避雷阵分散劫雷。

## 七、与当前游戏术语的对应

游戏中的资源“灵气分子”（`qiParticle`）表示离析后可供工业处理的分子库存；普通灵气资源表示尚未离析的宏观介质。两者区别在可加工状态，不表示分子直到离析时才存在。资源数值是归一化的库存与流量，不是逐枚粒子的个数。

世界观、游戏资源及相关文档统一使用“灵气分子”，资源 id 保持不变以兼容存档。本文的空间、神魂与工业设施示例仍属扩展设定，不能据此推定已有游戏机制。

当前游戏以归一化库存、流量和有效加工收益表示物料，境界与法宝倍率包含处理能力、回收率及损耗改善，不按单个分子的粒子数解释。偏极阵另消耗灵气承担解离供能，灵能枢消耗灵能驱动设施；热排散暂作为设备设计条件，不单列废热资源。这些是游戏抽象，不能据产出倍率宣称严格的微观质量与能量守恒。

## 八、香火与因果的设定边界

香火描述信众愿念凝聚形成的神魂组织与仪式资源，感悟描述修士获得的知识与修行经验；两者都不能直接视为无代价产生的能量。利用它们炼符、祭炼或调控设施，还需要物料和供能条件。

因果、仙缘与道果属于跨世修行记录及成长规则，四条灵场定律不直接推导它们。游戏中的永久增益是这一层的成长抽象，不表示可以凭空制造燃料，也不把灵荷的正负等同于道德善恶。

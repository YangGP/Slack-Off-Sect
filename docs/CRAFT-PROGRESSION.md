# 工艺、符文与后期建材

更新：2026-10-11（v0.31）。本文说明当前设计与材料分工；完整造价、效果、配方和前置见 [TABLES.md](TABLES.md)，历次测量见 [BALANCE.md](BALANCE.md)。

## 制作与产业分工

制作收益 = amount ×（1 + 通用制作加成 + 对应成品的专业制作加成），小数收益结转为整件资源。普通生产与宜居度倍率不直接提高每份制作收益。金丹前自动制作按配方独立计时；金丹起专业配方共用设备加工容量。优先配方控制同一时刻的扣料顺序，分配权重控制工位份额。

百工坊在基础采木采矿阶段开放，首座灵木150、矿石100，涨价倍率1.30，无维护费，每座通用制作产出+6%。专业工坊强化各自成品，带维护费设施的制作增益按有效供给缩放。

金丹发展基础产能、仓储、阵基与玄钢，元婴开放灵液、灵晶、仙草及复合建材。研究代表工艺掌握，建筑承接实际加工与营造；首次研究只消耗已可取得的上游材料。

## 工业加工（v0.31）

容量单位表示每秒完成的基础加工秒数。百工坊、炼器坊、符箓堂、炼丹房每座分别提供1单位木作、炼器、刻纹、丹道容量；每3座启用药圃提供1单位育草容量。凝液法提供1单位基础凝聚容量，每座晶核凝炼阵另加1。配方与工位对应关系以生成数据表为准。

设备容量 =（基础工位 + 启用设施数量 × 维护供给比例）×（1 + 同类容量升级之和）。同工位可运行配方按1～100权重分配容量，默认1；单条产线容量需求不超过自动速限，达到速限后的容量分配给其他产线。缺料、保留量不足、满仓、库存达标、取消自动及总开关关闭均不占工位。

每秒加工份数 = 分得容量 ×（1 + 配方加工效率之和）÷ 境界折算后的基础耗时。计时保存已完成的基础加工秒数；调速、改权重与停机不会丢失半份工作，也不会在停工期间积攒突发加工。结算推进至下一份完成时刻，随后重新分配容量，使达标及上下游供料变化可以在同一时间段内生效。在线与离线共用此规则。

| 工程升级 | 设备或工艺变化 |
| --- | --- |
| 阵基规制（金丹技艺） | 阵基装配效率+50%，消耗上游木板、玄铁，不要求先造阵基 |
| 流水作坊 | 木作容量+50% |
| 凝液回流（元婴技艺） | 凝液每份耗气−15%，升级用玄钢与阵基，不依赖晶核阵 |
| 定纹模刻（元婴技艺） | 符箓、阵基加工效率各+100%；灵符不享受低阶模刻 |
| 晶纹精修 | 凝晶每份耗料−20%，加工效率+25% |
| 灵纹锯阵 | 木作容量+100%，解板效率+50%，每份灵木耗料−15% |
| 灵火冶炼 | 炼器容量+100%，淬钢效率+50%；玄钢耗料−15%，法器与灵器耗料−10% |
| 疾炼法 | 木作、炼器、刻纹、丹道与凝聚容量各+100%，解锁1/2/5/10倍自动速限 |

每份费用 = 基础费用 ×（1 − 节料比例之和），节料最多50%，整枚原料向上取整。加工效率与节料不增加单份成品数量；原有工坊、法宝的制作收益仍单独计算。手动与自动制作、批量支付、材料保留、价格显示和事件产能估价统一使用节料后费用。飞升阵印不参与节料。

炼制页显示各工位已用／总容量、配方分配比例、当前节拍的每分钟投入产出、具体停工原因、输入缺口与库存缓冲。速率是当前库存和工位下的自动加工能力，不能视为上游已保证的长期供料。手动制作即时结算；节气满仓凝液、催生灵木、点石成灵和固结阵印保持原规则。

工位设计参考仓库内猫国版本的设备专属升级、连续加工和扩产供给关系。同一工业批次包含动力、散热与双极分流控制。

## 动力与冷却（v0.31）

各工位默认普通加工。疾炼法后可以选择灵气超载，灵能应用后可以选择灵能驱动；两种方式都最多增加一倍基础容量。只对实际超出基础容量的工作收费：每额外容量秒消耗10灵气或0.1灵能。配方每份材料费用与产出数量不变；灵能替代高负荷耗气，仍需要供能设施。v0.31已取消根据灵能库存免费放大产量和制作收益的规则。

额外容量受总冷却量限制：全体基础工位提供25%自然散热，每座运行中的晶核阵额外提供2容量，按维护供给缩放。化神技艺冷凝换热将晶核阵的冷却贡献翻倍，使用已能从上游制造的玄钢、阵基与灵液，不需要灵能才能启动。

灵能枢满供提供4单位加工供能容量，祭炼与断供同时影响容量。枢的基础维持费仍每秒1灵能，随祭炼同比增长；加工动力另按额外工作量支付。总供能与总冷却不足时各工位均分，工位内部继续遵守配方权重和速限。先提高配方速限，再选择驱动，才会出现实际额外负荷。

动力耗尽、到达保留量或冷却不足时减少加速，普通容量继续可用。缺料、满仓、达标与没有额外负荷时不耗加工动力；驱动还会留下一份当前可开工配方需要的同种原料。动力逐加工事件结算，与配方扣料分开，离线共用同一套规则。旧存档默认普通驱动，设置随存档与转世偏好保留，但每一世仍需重新解锁研究。

偏极阵两侧共用运行负荷。任一侧库存已满，就将分流降到下游实际成对消耗可容纳的流量；没有下游需求则停工，不再白耗灵气分子。炼制页同时显示两极库存、设施流量及偏极阵负荷；专业倍率造成的不等库存不会自动兑换或被强行清零。

## 手动合成与旧订单兼容（v0.31）

所有手动配方恢复点击后立即扣料和出货，“制作”“¼料”“½料”“全部”按当前原料与仓容结算，保留专业增产、节料和小数结转。手动不受自动总开关、库存目标、材料保留量或工位运行状态限制，不推进或清空自动加工计时。自动制作仍按工位、供料、动力和冷却约束运行。

新操作不再生成订单。旧存档已有订单继续共用自动计时和工位，优先完成订单再补库，可以超过补库目标，仍遵守仓储和材料保留。自动总开关不暂停旧订单；订单暂停不影响自动补库。取消未完成订单不收材料费，保留该配方已有的加工进度；完成手动合成后，旧订单会按剩余原料继续加工或等待补料。

剩余份数、暂停状态随存档保存；旧档没有订单，本世重置时清空。离线加工遵循相同工位与供料规则。输入缺口按当前总净流量计算，缓冲时间按可用库存除以缺口估计，不能当作固定的未来停机时刻。

## 符文科技线

### 原理与载体

符文是固定成特定形状的灵气结构。符文决定效果，材料决定承载能力，组合方式决定产物。符文属于可掌握的技术，不是要反复制造的库存物品。实体刻纹载体采用灵木与金属：基础符箓使用灵木符牌，高阶灵符使用玄钢符牌，阵基使用木板与玄铁组合。灵液负责注灵，香火辅助定纹，均不是实体载体。符箓不能作为所有刻纹工艺的通用中间材料。

符箓堂承担灵木与金属上的刻纹工艺。现有符箓及其建筑、事件、研究用途继续保留；本版不拆分聚气符、镇守符等库存，待出现独立消耗玩法再扩展。

阵基装配、凝晶工艺仍是独立的材料应用研究。凝晶工艺需固形纹，晶纹精修负责提高成品率。须弥纳芥增加纳灵纹前置，使储存技术与符文原理相连。

以上修真研究均不设境界门槛，通过灵机仓容、知识与产业积累推进。下表中的境界指配方应用条件，研究可以提前掌握。

### 设计边界

阵基去掉符箓套娃并减少木板消耗，降低金丹设施的木材投资。灵晶从消耗符箓转为消耗灵气，强化元婴的灵气生产需求。灵符不再用百张符箓堆量升级，而是从灵木载体升级到玄钢载体，串联符文与金属加工研究；灵器正式放在化神。

这会显著降低高级符阵的木材需求，不能沿用调整前的时间测量。验证应覆盖实际研究解锁、制作扣料、自动制作、建筑可达性及完整推进模拟。节奏模拟是机器人策略下的结果，不能直接等同于玩家通关时间。

暂不扩展自由绘符、符文插槽、符纸/灵墨库存、独立符箓消耗按钮，防护分工见下节。这些玩法需要单独设计界面和用途。

### 凝聚加工

晶核阵不直接生产灵液或灵晶，也不再提高灵气原料产出。增产采用现有专业制作加成，手动、连续、自动制作及满仓自动凝液共享同一收益计算，小数产出继续结转。多座阵法的加成相加，关闭或缺供会相应停止增产。凝晶原理仍能提前展示建筑目标，真正开工还需掌握凝晶工艺并备齐材料。

### 防护结算

护山大阵是常驻通用防护，镇岳符是重点资源防护；每种资源的减损比例取两者之和，上限仍为80%。二者在同一个事件预览和实际结算函数中生效，适用于比例灾损与有界损失，不减免交易、主动支付和其他固定消耗。镇岳符的效果按现有法宝祭炼规则放大，仍受总减免上限约束。

护山阵盘使用现有专业制作增益，保留原祭炼成本及阵法初解、器道精微前置。它不增加防灾数值；未掌握配方时不能凭法宝制造资源。


## 后期建筑材料

材料负责建筑结构与储灵部件，阵基负责符文布置，灵符负责特殊功能。本版沿用已有制作、仓储、自动炼制与目标库存机制，不增加独立矿场或灵石粉末库存。

| 材料 | 开放阶段 | 每份基础用料 | 用途 |
| --- | --- | --- | --- |
| 混灵土 | 元婴 | 灵石20、灵液2 | 灵石现场磨粉，以灵液胶结；玄库、药藏、静心池地基与池壁 |
| 玄铁混灵土 | 化神 | 混灵土2、玄铁50 | 玄铁骨架增强强度；精舍、试炼塔、祖师殿、护山大阵主体 |
| 秘银 | 炼虚 | 矿石150、灵气150 | 从矿石提炼的储灵金属；护山大阵、锁灵阵内衬及合金原料 |
| 玄金 | 合体 | 灵液8、玄铁100、秘银4 | 顶级储灵合金；洞府、洞天、分灵与偏极设施 |
| 晶银 | 大乘 | 灵晶8、秘银4 | 秘银承托有序晶体结构；通天塔、湮灭炉、因果池的精密控制核心，也是固印原料与渡劫辅助材料 |

秘银的储灵性质通过建筑用途体现，库存秘银本身不额外增加灵子容量。玄钢保留为坚固结构材料，玄金承担高阶储灵合金功能，晶银承担精密晶核功能。后两种材料用配方限定应用境界，工艺研究通过灵机仓容推进，不靠过量配料制造门槛，也不消耗尚待这些设施生产的灵子或灵能。

研究依赖：混灵土工艺接土木精要、凝液法；玄铁混灵土接混灵土工艺、淬玄工艺；秘银提炼接探矿术、纳灵纹；玄金熔炼接秘银提炼、复合符文；晶银复合接玄金熔炼、晶纹精修。

### 仓储与启动

材料库在金丹维持原配方，提前提供新材料仓位；元婴玄库扩充五种材料容量。基础容量按混灵土100、玄铁混灵土60、秘银30、玄金20、晶银20设置，保证第一座对应设施能启动。材料库和玄库继续重复扩建，洞天等通用仓储按建材权重折算。


地基采用混灵土，主体结构采用玄铁混灵土，高阶储灵部件采用秘银与玄金，精密晶核采用晶银。完整建筑造价只在生成数据表维护，避免手写副本漂移。

## 验证边界

检查分阶段研究、实际制作扣料、自动加工与库存目标、营造与仓储自举、带维护费设施的供料和停用、防护预览与实扣。用可达性审计验证来源与容量，用节奏模拟验证实际供料和时间约束；模拟不能代替真实游玩。

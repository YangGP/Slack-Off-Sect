## 本轮取舍

- **实施主合并**：`forgeApp`、`steelBatching` 合为新ID `forgeBatchStandards`，保留原三类效果，以两项原总价作为首版报价；不是自动赠送旧档。
- **保留宜居内容**：四件宜居法宝暂不真正合并；`bondKnot` 保留ID、价格和+4宜居，名称改“安居结”。原因是尚无取消这些早期投资后的供养阈值依据，不因为兼容简化而顺带删减人口支撑。
- **保留不同层次投资**：岗位倍率、资源倍率、制作增产、节料、配方速度、工位容量仍分开；不为压缩列表把它们改成一个倍率。展示同源关系即可，不新增强制互斥专精。
- **十项地面补足全部进入首版**：P1先实现，P2随后在同一批补齐；它们都是可跳过的效率投资，不成为基础配方前置。首版价格可在后续测量后调整，本轮不以回本已达标作结论。
- **五类设施使用同ID阶段**：旧建筑保留基础形态；只有玩家主动切换阶段才清零该类数量，不退款、不自动重建。新资格另用ID，旧灵能引采直接清理。
- **小界控制循环**：首版采用当段保守预预算确定支援流量，不用上一帧免费支援，不将支援改善后的增量在同段反复放大；具体顺序见[小界专题](SMALL-WORLDS-DESIGN.md)。百分比是可分流预算上限。
- **商店保持边界**：现有永久等级不删不合，宿慧同ID改职责且保留原价格；新增12项全部有上限，道心5项仍在香火页。
- **解锁资格减少新历史字段**：新增仙缘商品使用已有最高境界、飞升计数和小界图纸，道果新增项沿用开店资格，不为“曾经用过一次”另做全套追溯记录。条件见[商店专题](PERMANENT-SHOP-DESIGN.md)及生成表。

当前规则文档、源码生成表及本版更新记录已同步。未经用户要求不升版本、不提交、不推送、不发布，不改变既有首飞与全员终局账单来迫使玩家购买新增内容。

# 游戏设计与当前规则（v0.2）

更新：2026-10-09。本文描述当前实现。完整条目、费用与门槛由 [TABLES.md](TABLES.md) 从源码生成；修真、工艺与境界的依赖审视见 [CULTIVATION-REVIEW.md](CULTIVATION-REVIEW.md)。历史平衡与测量保存在 [BALANCE.md](BALANCE.md)，未实施方向见 [ROADMAP.md](ROADMAP.md)。

## 1. 定位与设计目标

纯前端宗门放置经营游戏，参考猫国的资源池、劳动力分配、叠加建筑和加工体系。主要决策是生产分工、研究投资、加工目标、营造扩仓与重置时机。当前境界属于宗门整体，没有弟子个人修为、灵根或突破成功率。

## 2. 核心循环

点击取得灵气 → 聚灵阵生产 → 首间茅屋与弟子 → 徒手采木、扩仓与采石 → 职位及原料产业 → 修真和技艺 → 加工、建设、扩仓 → 破境 → 转世／飞升。

开局没有资源、弟子或建筑。第一座聚灵阵需灵气25，每世第一间茅屋仅需灵气80，后续茅屋按灵气80与灵木20的基础价格递增。首屋优惠随存档保存，拆除不再次领取，转世或飞升重置。樵夫无需伐木场即可采木；基础木材容量200，伐木场需要茅屋，基础造价为灵气150与木材60；先以木材180建谷仓扩仓，伐木场与谷仓均建成后可用木材300建采矿场，派遣矿工后持续供料。木屋需灵木300与灵石20，不再依赖玄铁。早期建筑以木材营造，石材从采矿场之后的库房与聚灵大阵等建设开始引入。移除拾取石材与凝气成石，保留点石成灵（石矿3与灵气15）及矿工的天然灵石副产出。凝灵诀也使用点石成灵，必须有采矿场与足够材料。

## 3. 资源系统

共27种资源。灵气、灵木、石矿、玄铁、灵草、灵机和香火支撑生产与经营，加工品连接建设及破境；灵液承接凝聚配方（凝晶、育仙草），灵气分子、正负灵子与灵能构成后期粒子产线。灵气形态阶梯为气→液→晶→灵气分子→正负灵子→灵能（灵气分子是一正一负两枚灵子相抱的最小稳定单元，见 [SPIRIT-ENERGY.md](./SPIRIT-ENERGY.md)）；灵石是含灵气的矿物，采集与制作双来源，不在阶梯上；石矿是普通岩石，凡石砌基的建材，点石成灵以石矿3加灵气15凝成灵石。仙缘和道果是永久成长记录，不走常规每秒生产。

### 3.1 数量与价格

标记 integer 的资源整件计数：费用向上取整、库存与奖励按相应规则取整。制作收益的小数累计在 craftProgress，累计足一件才入库。资源增加受实际容量限制，旧档或拆仓后超额库存允许消费，不能继续增长。

### 3.2 仓储上限模型

上限 =（基础容量 + 专属扩仓 + 通用扩仓 × 该资源 storageWeight）× 仙缘仓储倍率；整件资源最后向下取整。基础物资、普通成品、进阶成品采用不同权重；专属仓储全额计入。完整权重和容量见数据表。

谷仓、库房、材料库、药藏、法藏、洞天和通天塔构成扩仓链。建筑的 storage、storageAll、maxDisciples 按已建数量生效，停用或缺料不移除这些容量／人口效果；生产、加工增益及带维护费建筑的士气、防灾等运行效果按有效供给生效。

### 3.3 灵气与点击

灵气同时用于弟子口粮、凝石、加工与设施维护。点击收益不乘全局产出倍率：2.5 + 0.5 × 有效聚灵阵数；前20座全额计入，超过20的部分按 √(超出数量) 折算。

宗门页提供开局可用的催生灵木按钮：每次10灵气兑换1灵木，不受生产或制作倍率影响；满仓时不扣费，剩余容量不足1时按实际收益同比扣费。

### 3.4 渐进露出

建筑已建过则持续显示；未建时需满足全部 needs，并让各项造价资源的历史峰值达到基础成本的 unlockRatio（默认30%）。部分建设目标设为0，前置满足即显示。花光库存不抹去峰值。

修真、技艺与炼制配方不在开局展示整棵树。未解锁条目只有在境界达标、研究前置全部掌握后才预告；没有研究前置的基础条目则需先建立对应产业，才提示下一档建筑数量要求。已掌握内容始终保留显示，实际参悟与制作仍需满足完整前置和材料费用。

引气诀与口传心授需先参悟灵源考；伐木要术需先参悟木作器械；阵法精要需先掌握观气法与引气诀。上述研究前置与原有建筑前置共同生效。

## 4. 弟子、职位与士气

有空房时默认每15秒来一名弟子，到来间隔 = 15 ×（1 − min(0.8, arrivalBonus)）。满员时停止并清空到来计时。

六种职位为阵徒、樵夫、矿工、采药人、悟道者、香使；分配人数不得超过总人口，闲置弟子也消耗口粮。采矿场或玄铁矿开放矿工；每名矿工在采矿场启用时产出0.15石矿／秒、玄铁矿启用时产出0.08玄铁／秒、灵石矿启用时另产0.0008灵石／秒。多种矿场同时启用时同一批矿工同时产出，不随矿场数量重复放大人力。旧档采石工与矿工人数相加迁移，人口总数不变。每名弟子基础消耗为0.25 × 当前境界倍率灵气／秒，减耗最多85%。

普通聚灵阵保留每座0.3灵气／秒自带产出。其它建筑不再自带灵气、灵木、石矿、玄铁、灵石、灵草、灵机或香火产出；需要分配弟子到对应职位。建筑仍提供现有的岗位解锁、产出加成、仓储、士气和其它效果，维护费照常。分灵阵、偏极阵、湮灭炉的特殊资源产线保留。

矿工每人每秒基础产出0.08玄铁；建成且启用灵石矿时，另产0.0008灵石，为玄铁基础产出的1/100。副产出使用矿工职位加成与灵石资源倍率，记入资源来源明细；多座灵石矿不重复放大人力，停用后副产出停止。

士气 = clamp(100 + 士气加成 + 断供惩罚, 15, 200)，以士气／100进入全局产出。断供惩罚按6／秒增加，正常供给按2／秒恢复，惩罚下限−60。长期断粮会独立触发流失，不会被高舒适度抵消；低于45%士气也会触发流失，计时间隔25秒。

## 5. 建筑系统

共8组38种建筑，价格按现有数量指数递增。连续购买从现有数量开始逐座累计造价，整件材料按价格函数取整。拆除返还被拆数量对应原购价的一半，实际入库仍受容量约束。

### 5.1 效果字段语义

| 字段 | 用途 |
| --- | --- |
| prod | 每秒基础产出 |
| ratio / jobRatio | 对应资源普通生产／岗位增产 |
| craftBonus / craftBonusByResource | 通用／专业制作收益 |
| storage / storageAll / maxDisciples | 专属容量／按权重折算容量／人口容量 |
| morale / disasterGuard / consumeRatio | 士气／防灾／弟子减耗 |
| autoCraft / autoCondense | 常驻自动加工／节气满仓凝石 |
| offlineHours / arrivalBonus / breakthroughDiscount | 离线上限／招募加速／破境减费 |
| ascendBonus / karmaRatio | 仙缘结算收益／仙缘产出乘区固定附加值 |

建筑、技艺与法宝的永久产业增益按资源区分，当前条目不提供 ratioAll；成就全局奖励当前也为0。引擎仍保留该字段的处理能力。

### 5.2 维护费与停用

带 upkeep 的设施可以停用。有效运行数量为已建数量 × 启用状态 × 供给比例，维护费与运行收益同步缩放；缺料按供给运行而非负库存借贷。容量与人口效果按3.2节处理。

## 6. 修真与技艺·法宝

金丹前以灵源考为唯一研究入口，核心链逐步推进：灵源考 → 观气法 → 凝灵诀 → 灵植术 → 炼丹术 → 探矿术 → 木作器械 → 土木术 → 炼器术 → 丹火纯青 → 心有灵犀。灵植术后需先建药圃，木作器械需炼铁炉与两座伐木场，其他建筑前置也继续生效。

支线保留选择：炼器术后先建炼器坊，再开放符箓入门；掌握土木、符箓并建符箓堂后开放香火愿，再以山门×3开放广开山门。筑基期破境心法需掌握土木术与丹火纯青，不要求先发展香火；流水作坊接在心有灵犀之后，不作为其他早期产业的必修前置。研究按产业与知识递进，不限定同时可参悟数量。御剑术到金丹期掌握淬玄工艺后才开放。旧档已掌握条目继续生效。

55项修真、22项技艺、24件法宝，共101项。共享灵机与已学记录；building、buildings、upgrade、upgrades、realm 前置共同生效，允许跨层引用。

早期没有空间技艺：储物袋、纳物诀已删除，旧档对应已学记录读档时清理；叠匣术为库房解锁的普通装箱码放。空间收纳与洞天营造由后期洞天福地、纳物戒承接。

灵能枢需要持续供能：未祭炼时每秒满供消耗1灵能，灵气产出+50%、灵机产出+25%；祭炼倍率同时放大效果与耗能。库存与实时产出共同承担供能，不足时效果和消耗同比缩减，无供能时停效。消耗列入资源账目，灵能逸散另行结算；法宝页显示当前效果、供能比例及满供耗能。

修真页按两条研究线加一个经营组组织（方案见 [RESEARCH.md](RESEARCH.md)）：主线「灵气研究」按境界分五章——观气、凝聚、调控、拆解、归源，对应灵气从感知到本源的问题序列；辅线「材料研究」按草木、金铁、符阵、丹道、香火、土木六族分「原理→工艺→精研」三层，其中11个工艺/精研节点与2个主线成果兑现节点自技艺页迁入，id不变；制度、招募、离线等经营节点收进「宗门经营」组。主线与经营节点仍只做解锁与系统开关；材料研究线携带专业制作增益。技艺页收敛为通用产量、仓储、灵机、防灾等增益；法宝可以反复祭炼。

法宝基础效果在炼成时生效，n级祭炼效果为基础 ×（1 + 0.3n）。下一次费用的非灵机部分沿用炼成材料 ×1.7^当前等级；灵机用 refine.insight ×1.7^当前等级。部分法宝到指定等级另加进阶材料，从该等级起按1.7倍增长，无等级硬上限。

全部节点及实际前置疑点见修真审视文档。

## 7. 制作

15个配方。每份收益 = amount ×（1 + craftBonus + craftBonusByResource[out]）；普通生产倍率不直接提高配方收益。制作增产相加，没有统一上限。手动制作瞬时完成，自动加工的间隔为配方 time ÷ max(1, √(境界倍率／2))。

点石成灵（石矿3+灵气15→灵石，需采矿场）与凝气成石（石矿1+灵气45→灵石，开局可用）并存：筛选更多石材可减少灵气消耗，两者都需要矿物载体。凝灵诀在节气收取满仓灵气时也按份消耗石材，缺料暂停。凝液法开放凝气成液（灵气→灵液），凝气结晶与培育仙草以灵液为原料。木作器械开放木板；金丹的阵基装配、淬玄工艺、凝晶工艺分别开放阵基、玄钢、灵晶。丹药、符箓、法器通过专业建筑开放，其余高级配方使用设施、法宝或研究前置，并不统一按境界分层。

凝灵诀在每个节气检查满仓灵气，尝试用半仓凝石；心有灵犀开放常驻自动加工；首颗道果永久开放自动、单个优先配方及材料保留。凝灵诀或常驻自动入口均开放库存目标，0表示不限，消费后补货。

炼制页的“全部自动”复选框在常驻自动解锁后可用：勾选开启全部当前已解锁配方，不受列表筛选影响；取消勾选清除所有配方的自动选择。部分配方已选时显示半选状态，之后新解锁的配方仍需选择。操作立即保存，总开关、节气凝石、库存目标、材料保留与优先配方设置保持不变。

各配方独立计时；常规按数据顺序处理，材料不足或成品满仓暂停，最多保留一份加工时间。道果优先设置只把指定配方排在前面，不提供共享工位。百工坊每座通用制作+6%；专业设施按成品分别加成。

## 8. 境界与飞升

### 8.1 境界

凡体 → 引气入体 → 炼气 → 筑基 → 金丹 → 元婴 → 化神 → 炼虚 → 合体 → 大乘 → 渡劫。全局倍率依次为1、1.15、1.35、1.6、2、3、5、8、14、24、40。

破境只检查下一境费用，足额支付后必定成功。破境心法、候时法、心印法的折扣相加为40%；引擎折扣上限90%。当前没有渡劫战斗或必须完成指定研究的突破条件。

筑基基础费用为灵机500、灵石300、丹药25；金丹为灵机1500、灵石650、丹药100、法器60。材料费用按该阶段可达仓储固定设定，不随当前仓容动态增加。金丹前不依赖药藏或法藏；后续境界丹药与法器费用递增。完整费用见TABLES，试调结果见BALANCE。

### 8.2 飞升

渡劫可以飞升，获得仙缘及1颗道果；不要求先转世或学完科技树。资源、人口、建筑、修真、技艺、法宝及祭炼、境界、加工进度、临时增益与事务状态重置。

### 8.3 转世

化神起可转世，只结算仙缘，重置范围与飞升相同。永久仙缘、道果、成就、长期统计与相关偏好保留。

### 8.4 道果与仙缘

仙缘结算 = floor(√(本世累计入库灵机／2000) ×（1 + 境界下标×0.3）×（1 + ascendBonus）×（1 + 道果数×0.1）)，可结算时至少1点。已花灵机仍计入，满仓被截断的部分不计入。

每点仙缘带来+2%产出与+0.15%仓储，分别通过 softCap 渐近+200%与+50%；前75%上限线性，之后收益递减。每颗道果提供+5%产出与+10%仙缘结算收益，首颗同时提供自动化规则。

因果通感另向仙缘产出乘区固定加0.005，不按仙缘点数放大；其仙缘结算加成为30%。

## 9. 成就

25项，记录阈值与行为，转世／飞升保留。ACHIEVEMENT_REWARD 当前为0，无全局产出奖励；后续奖励设计未实施。

## 10. 随机事件

### 10.1 事件等级（v0.10）

34条事件，等级与处理类型分开：一级金丹前，二级金丹至化神，三级炼虚起；单条 minRealm／maxRealm 与等级范围取交集。类型分环境、突发、选择。

### 10.2 触发与结算

初始事件计划在开局90秒后，后续随机间隔150～420秒；选择类共用一个未决状态。限时增减益进入相应乘区；资源机缘、交易和灾损使用产能估价、库存比例、保底或固定材料，交易需足额支付，防灾减免最高80%。

金丹药圃威胁有5分钟处理期，支持加固、驱逐、收缩、默认防守；超时默认结算一次，并进入安宁／冷却。离线不生成新随机事务，已有超时威胁仍处理。现行应对费用与扩展草案见 [MIDGAME-EVENTS.md](MIDGAME-EVENTS.md)。

## 11. 产量公式与时间模型

### 11.1 产量与收支

普通产出 = 基础建筑产出与已含岗位加成的职位产出之和 ×（1 + 资源ratio）×（1 + ratioAll）×（1 + 季节加成）× 全局倍率 ×（1 + 指定资源临时增益）。

全局倍率 = 境界倍率 × 仙缘乘区 × 士气／100 ×（1 + 道果数×0.05）×（1 + 全局临时增益）。当前士气乘区也用于普通建筑产出。

实际结算净额扣弟子口粮和维护费；自动加工逐份扣料，不并入 expense 以免双扣。界面 resourceFlow 另外计入当前运行配方耗料，因此显示净额可以与内部 derived.net 不同。

### 11.2 时间模型

主循环100ms，默认每20秒存档。离线按1秒步长补算，默认最多8小时；龟息功、定息法各增加8小时。超过1秒的 tick 也拆为至多1秒小步。

### 11.3 历法与灵能

一天3秒，节气15天／45秒，季节90天／4.5分钟，一年360天／18分钟。四季产出因资源而异，六种常规资源的全年平均季节增益均在±5%内。

合体通过灵子论开放分灵阵，把灵气离析成灵气分子；大乘经阴阳分灵开放偏极阵，把灵气分子解离成正负灵子；湮灭法开放湮灭炉，正负相遇产出灵能。基础数据按一对一供料配置：一座分灵阵供给一座偏极阵，一座偏极阵供给一座湮灭炉；境界和专业加成会改变实际比例。灵能每秒乘0.995，增益 = softCap(库存×0.02, 5)，渐近+500%，并非250库存时硬封顶。此增益先写入指定基础资源的普通生产ratio。参悟《灵能应用》后，同一份灵能增益同时写入灵石（凝气成石、点石成灵）与木板（刨木成板）的制作收益。稳态需按实际炉产出、全局倍率及供料估算，不能把每炉基础0.06／秒直接当作最终产出。

## 13. 存档设计

localStorage 键 slack-off-sect.save.v1，存档结构版本1，与游戏v0.2版本号分别维护。状态包含资源、峰值、人口与岗位、建筑、已学条目、成就、祭炼、自动加工计时与目标、境界、仙缘、道果、历法、事务、统计及偏好；derived 重算，不保存。

不含 qiParticle 资源字段的旧档在首次读取时迁移：已建分灵阵补同数量、同启停状态的偏极阵及灵子论；已研究凝晶或制作仙草的旧档补凝液法，原先自动凝晶／育仙草的产线补开自动凝液。资源字段随后补齐，重复读档不再发放设施；新版存档仍需按新研究链建设。

序列化排除 __ 开头内存字段，纪事只保存最近60条。设置页导出直接下载带时间戳的.txt文件，内容为base64编码的JSON；读取通过选择本地文件导入，兼容旧版文本存档与原始JSON，成功后立即保存。取消文件选择不改变进度，读取失败提示错误并保留当前进度，同一文件可重复选择。normalizeState补齐缺失字段并归一化。新字段兼容及非法输入边界由测试验证，不承诺任意未来规则都无需迁移。

存档按浏览器同源隔离，协议、域名或端口改变会使用不同存储；同源下仅改变路径仍访问同一localStorage。清除浏览器数据会删除存档，设置页提供导出备份。

### 1.1 灵机高疑点（优先验证项）

破境费用链（`realms.js`）：炼虚 216 万 → 合体 150 万 → 大乘 300 万 → **渡劫 600 万**（均为一次性支付，需仓容 ≥ 费用）。

灵机仓容出口：典籍库 80、讲经堂 800、观星台 3000、玄库 12000（realm 5）、广储库 12000（realm 7）、洞天 15000（realm 8，priceRatio 1.35）、通天塔 40000（realm 9，priceRatio 1.6）；**通用仓容全额折算给灵机**（storageWeight 默认 1，`economy.js`）：洞天 12000/座、通天塔 25000/座、广储库 4000/座、叠匣术 1200、纳物戒 500/层；比例技艺：叠匣术 +30%、星象推演 +50%、坐忘功 +60%；仙缘乘区上限约 +60%（软上限 +50% × 因果田 1.2）。

静态推算（含通用仓容修正）：装下 600 万需定额+通用基数约 150 万以上，对应数十座通天塔 / 洞天级设施——第 30 座通天塔造价 stone 60000×1.6²⁹ ≈ 1.6×10¹¹ 灵石，**价格曲线不可行**。`PACING-AUDIT.md` §4 记录"来源和仓容闭包可到渡劫，闭包不估算真实生产时间"——数学可达与价格曲线不可行同时成立，恰为 v0.1 §5 定义的**软性死锁**候选；且现有模拟均为 `stopRealm 6`（化神停止），**600 万门槛从未被实测走到**。这是第五点瓶颈复核的头号项。

### 1.2 知识加工链专项检查（回答 v0.1 §3 的四问）

1. **道札→道论→阵图是否只是把灵机费用拆成材料费用？——不是简单拆分，但隐含计费偏高。**
   实价（`crafts.js`）：一张阵图的完全成本 ≈ 20 道札 × 10 + 灵机 6000 + 50 符箓 + 320 s 刻纹工位 ≈ **41,000 灵机**/张。它不省钱，而是把科研从"攒一笔钱"改成"维持一条产线"——真正价值在刻纹工位容量（与符箓、阵基、灵符共享）成为新取舍。
2. **是否产生对讲经堂、观星台、刻纹工位的新投资需求？——刻纹工位是，讲经堂/观星台否。**
   讲经堂/观星台只服务灵机产出，与知识产量**无任何耦合**（仅观星台造价含道札 6）。这是一个空洞。
3. **"知识进步反过来提高知识生产"的节点？——只有灵机侧，没有知识侧。**
   口传心授 / 星象推演 / 坐忘功强化灵机产出与仓容；但全技艺表中**没有任何一条**提升道札/道论/阵图的产出或效率（`craftSpeedByRecipe` 不含知识配方）。知识链是一条**无反馈裸链**。
4. **高级知识的价值是打开新机制还是降低旧摩擦？——以打开新机制为主**（道札→观星台 / 元婴破境，道论→灵子研究，阵图→湮灭 / 仙灵 / 通天塔），合格。

### 1.3 版本口径核实（v0.1 §5 遗留问题）

### 1.4 灵木使用链（补充分析）

**产出端**：樵夫 0.15 木/s/人；催生灵木 5 气/份（应急通道，1.25× 劳动溢价）；四季春 +10% / 秋 +20% / 冬 −15%；事件 loot。产出加成 10+ 条（伐木场、伐木要术、铁木工艺、御剑术、灵流要诀、灵渠网络、灵能引采、飞剑、入山谣、玄铁斧、百炼工具），为全游戏加成条目最多的基础资源。

**消费端四类出口**：

| 出口 | 明细 |
| --- | --- |
| 建筑造价 | 早期全线吃原木（采矿场 300、木屋 300、炼丹房 360、符箓堂 420、山门 360、精舍 1000）；元婴后无高级建筑直接用原木 |
| 配方消耗 | 刨板 175 木/板（板→阵基 10 板/基、观星台 30）；刻符 125 木/张；道札 50 木/张 |
| 研究费 | 约 45 条，从 25（居所营造）到 6000（符法精微）、4000（纳物戒） |
| 维护费 | 工坊柴火合计约 1.72/s（铁炉 0.15 / 丹房 0.25 / 丹鼎 0.5 / 器坊 0.5 / 符堂 0.2 / 香鼎 0.12）；**通天塔 10 木/s·座**为后期最大单点 |

另：突破护道"灵木引气"仅第一大境界（20 木）；外交互市有条目支付 600 木；三系灾难（妖兽 / 风暴 / 山火）均以灵木为损失资源，镇岳符对木 / 草灾损额外减免 15%。

**阶段角色演变**：基建主料（开局~金丹）→ 板材中转（金丹~元婴：原木→板→阵基）→ 载体 + 柴火（化神：高级建筑改用混灵土系）→ 燃料回归（渡劫：通天塔维护、防灾资产、外交支付）。

**判断**：

1. 健康点：原木→板→阵基三级加工链在后期仍活跃（粒子链建筑每座吃 8~15 阵基）；通天塔 10 木/s·座是"新科技重新抬高旧资源价值"的教科书设计；贴顶可调离樵夫自救，不卡进度。
2. 风险点：产出加成过剩（后期数百/s vs 消费仅"通天塔 10×N + 柴火 ~2/s"），渡劫段大概率长期贴顶；低阶符箓在化神破境 560 张后退出主线，灵符改吃玄钢 + 灵液，灵木"符载体"角色实际在化神断档——炼虚~大乘存在"无存在感"空档，末段仅锚定通天塔一个消费点。

### 1.5 矿石使用链（补充分析）

**产出端**：矿工 0.15 岩/s/人，**唯一来源**（同岗副产玄铁 0.015、灵石 0.0015 × 灵石矿座数）。产出加成仅 4 类（采矿场 +10% 岩/铁/灵石同乘、凿石要诀 +30%、玄铁镐 +30%——注释明确"只加矿石"、灵能引采 +25%），为基础资源中加成最少（对比灵木 10+ 条；灵渠网络、御剑术、飞剑等"原料系"加成均不含矿石）。

**消费端：矿石是"纯原料"，自身几乎不当终产品，共四条出口**：

| 出口 | 转化 | 下游需求规模 |
| --- | --- | --- |
| ① 点石成灵（3 岩 + 15 气 → 1 灵石） | 配方 | **全期主干**：破境（筑基 310 / 金丹 1100 / 元婴 8400）、后期建筑（玄库 2000 → 粒子链每座 1.2 万~4 万 → 通天塔 6 万 → 因果池 30 万）、研究（因果通感 4 万、塔院图 8 万）、法宝多条、炼气护道 |
| ② 炼铁炉（2 岩 + 1 木 → 1 铁，0.15 铁/s·座） | 建筑级转换 | 玄铁是炼器 / 淬钢 / 混灵土的根基；炉子同时是唯一持续烧岩点（upkeep 0.3 岩/s·座） |
| ③ 提炼秘银（300 岩 + 150 气 → 1 秘银，炼虚配方） | 配方 | 渡劫隐藏账单（见下） |
| ④ 早期建筑砌基（直接消费） | 一次性 | 炼铁炉 180、聚灵大阵 400、膳养堂 240、炼丹房 / 炼器坊 240、山门 200、库房 / 料场 200 等 15 座；**混灵土出现后建筑全面改用灵石 / 加工材，矿石直接消费在化神段停止** |

研究费仅 8 条少量（120~1000，最大秘银提炼 1000）；护道、灾难、四季、外交均无矿石条目——**不受灾、不受季节，低风险资产**。

**渡劫隐藏账单**：沿阵印链回溯（每枚阵印耗秘银 2 → 渡劫 9000 枚 = 18000 秘银；晶银 1200 又耗秘银 4800），渡劫合计约 **22,800 秘银 ≈ 684 万矿石 + 342 万灵气**；百名矿工基础采集需约 35 小时纯采集——与"灵宝链回溯约 18 万丹药"并列渡劫前两大隐藏账单。

**阶段角色演变**：仓容陷阱段（baseMax 250 为最低仓之一，炼铁炉造价 180 < 250 的防死锁注释即为此）→ 砌基 + 炼铁期（筑基~金丹）→ 灵石工厂期（元婴~化神，点石成灵供破境账单）→ 秘银原料期（炼虚~渡劫，684 万岩账单 + 持续点石成灵）。

**判断**：

1. 健康点：三条转换链覆盖三个阶段（灵石全期 / 炼铁炉筑基~化神 / 秘银炼虚~渡劫），**没有灵木那种"炼虚空档"**，每段都有明确职责；早期防死锁有明确维护意识；仓容出口完整（料场 500 → 库房 600 → 材料库 3000 → 玄库 1 万 → 广储库 5 万 → 洞天 7.5 万 → 通天塔 15 万），后期流量不受仓容约束。
2. 风险点：**点石成灵是第二条裸链**——全技艺表无任何 `craftSpeedByRecipe` / `craftCostReduction` 覆盖 infuseStone，唯一制作加成为聚灵大阵 +5%，后期 30 万级灵石账单（因果池 = 90 万岩 + 450 万气）全靠堆时间；**矿工单岗三责**（矿石唯一来源 + 玄铁唯一来源 + 灵石副产），rock / ore 争抢同一产能，设备层缺乏第二条产能来源；渡劫 684 万岩账单的可达性待验证。

**元婴灵机墙的调平范式**：`PACING-AUDIT.md` §2 记录元婴费用从纯灵机 700 改为"灵机 3000 + 道札 30 + 灵液 60"——**把灵机账单换成产业准备**，是处理同类墙的好范式，可复制到渡劫段。

**判断**：

1. 健康点：**全游戏唯一完整的反身闭环**——研究产出反过来提高研究产能（口传心授→星象推演→坐忘功→经义互证→观象参同→大乘心经），"知识→知识生产"在灵机侧成立（对比知识链、点石成灵两条裸链）；因果池"吃灵机也给灵机"的自反维护收益条件明确可算；跨世加成（仙缘 / 道果 / 道心）让第二世灵机曲线整体前移。
2. 风险点：渡劫 600 万仓容是全游戏第一硬墙（§1.1：软性死锁候选，从未被模拟走到）；灵机几乎无"燃料"角色（唯一维护是因果池），是纯账单货币——v0.1 §3"主要消费是否服务多种持续用途"一问上，灵机在研究 / 建筑 / 祭炼三出口分布良好，但**缺持续吞吐型消费**（对比灵木通天塔 10 木/s、矿石炼铁炉 0.3 岩/s）。

**三资源对比**：灵木是"角色转换型"、矿石是"持续转换型"，**灵机是"账单型"资源**——它的链不是供需链而是收入-支出曲线，成长感靠三个台阶，死穴是最后一笔账单超出仓容系统承载。

### 2.1 类型分布统计

- 修真页约 78 个核心节点中，**能力型（发现/新来源/自动化/上限/里程碑）约 55%**，资格前置约 12%，纯效率约 33%——比例健康。
- 技艺页以效率为主是其定位分工（`RESEARCH.md` 明确"修真开放能力、技艺兑现应用"），**结构上已把涨数值隔离到独立页面，这是好的架构**。

### 2.2 问题区段（v0.1 §4"连续解锁几乎只有倍率"）

1. **化神段**：技艺页两条效率三连（共 6 节点）全部串成链式必修（丹：凝元分炉需丹火定候、连炉九转需凝元分炉；器同构），加上晶纹校准 / 灵纹器具 / 仓容比例条目，该段投资几乎全是倍率；同时该段研究的建筑成果大量延迟落地（洞天 realm 8、通天塔 realm 9、因果池 realm 8）——"学会了但用不上"削弱质变感。
2. **渡劫前备料段**（合体→渡劫）：无新机制开放，主要活动是凑齐 9000 飞升阵印（72 万灵能 + 18000 秘银）、360 灵宝（沿丹符器链回溯放大，隐含约 18 万枚丹药级需求）、1200 晶银与 600 万灵机——v0.1 §2 担心的"通往下一次破境的成本"形态，**在这一段最明显**。

## 三、建议（均为 B 类微调方向，不新增系统）

1. **优先验证**灵机仓容对渡劫 600 万的可达性（同时是第五点头号核查项）；若坐实，优先考虑给通天塔增加灵机仓容比例、或调整后期破境灵机费，而非新增建筑。
2. 化神两条效率三连：改为并联可选（去掉链式前置）或并入既有设施加成——消除"强制买倍率"段落。
3. 知识链裸链：把某条既有刻纹技艺（如定纹模刻）的效果**扩展到知识配方**，即形成"知识→知识效率"的反馈闭环，无需新节点。
4. 渡劫备料段：用既有跨世系统（立愿应劫、因果池修持、仙缘囤积 vs 消费的决策）填充活跃度，而非新增机制。

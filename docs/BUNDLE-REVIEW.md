## 评估结论

保留两线研究重组、石矿／灵液／灵气分子产业链以及新增技艺和法宝。迁移研究节点使用原 id，现有已学记录仍参与效果计算；配方与建筑的前置引用完整，现有检查没有发现容量自举死锁。新增法宝有明确的研究来源和重复祭炼去处。

灵能加成按成品资源写入制作收益，因此凝气成石和点石成灵都会受益。原文案只提凝气成石，现已明确两条灵石路线均受益。

## 节奏与限制

同一参照玩家、初始仙缘和道果均为 0、随机事件关闭、每 5 秒决策一次、tick 为 1 秒：6.01 小时化神，6.93 小时炼虚，42.79 小时合体，45.40 小时大乘，51.24 小时渡劫，62.74 小时首次灵能。72 小时时 504 名弟子、1108 座建筑、103 项已学条目，灵能库存约 3744。

这条曲线说明全链可达，但炼虚阶段停留较长；参照玩家还有每次只手动加工一份进阶品、优先建造等策略限制，不能把单次推演直接等同于所有玩家体验。本轮不凭早期版本时间表调高产量或降低破境成本。后续若要专门调平衡，应同时比较手动、自动与较低回访频率的玩家。

粒子链的一对一供料关系仅指基础数据。境界、全局倍率和资源专属加成会改变实际产出，而维护消耗不按同一倍率增长；实际生产和稳态以引擎供料结算为准。

验证使用现有编码、引擎、渲染、DOM 检查和生产构建，另补旧档迁移、迁移幂等、多路线加工、深层加工等待和两条灵石路线的灵能收益回归检查。最终 `npm run check` 通过：716 项引擎检查、19 项渲染检查、239 项 DOM 检查，共 974 项；生产构建、编码检查及 `git diff --check` 均通过。

# 合体前护道准备专项评估

评估日期：2026-10-11，游戏版本：0.3.0。原始摘要见 [14 个情景的数据](BREAKTHROUGH-FOCUS-DATA.json)。专项模拟使用当时规则；炼虚冲合体失败后的身死概率曾从10%降至5%，现按用户要求恢复为10%。

## 判断

**当前已实施：炼虚冲合体失败后的身死概率恢复为10%，存活时退境；合体和大乘阶段保持15%、20%，金丹、元婴、化神新增的1%、2%、3%风险保留。**

满配护道本身的补料负担没有占满准备窗口，主要瓶颈是基础突破所需灵气的仓储和供给。退境保留产业，仍能在约半小时至一个半小时内重新准备；身死会丢掉整套产业，即使带着减半仙缘并让后续突破全部成功，回到合体仍需约 10～12 小时。首次接触身死风险时，这个损失远大于一次完整护道准备。

恢复后，满配单次冲合体为70%成功、27%退境、3%身死；裸冲为20%成功、72%退境、8%身死。仙缘减半、减产和扣库存保持原值。

同时优先改善灵气仓储提示和扩容准备；仅降低死亡概率无法解决第一次备料等待。

当前规则保留金丹冲元婴、元婴冲化神、化神冲炼虚的失败后身死概率1%、2%、3%，存活不退境；炼虚起为10%、15%、20%，存活退境。重新运行固定策略数学模型：金丹起满配的一世内完成飞升概率为72.17%，成功前平均身死次数为0.386。模型验证通过；这些是概率结果，不是重新实测的通关小时数。上面的14个时间情景仍是旧规则的历史记录。

## 模拟条件

使用真实引擎的生产、仓储、研究、制作、支付、减产、退境与重生。零仙缘、零道果开局，关闭随机事件，每 5 秒决策、每 60 秒调整岗位。炼虚之前采用原来的满配参考玩家，并保留真实随机突破结果。

计时从第一次进入炼虚开始，到材料齐备并实际冲合体为止。第一次数值比较强制成功；恢复情景强制第一次冲合体退境或身死，之后每次突破强制成功，隔离重做材料和重建产业的时间。**恢复时间是这个生产策略下的顺利突破参考，不能当作随机游玩的平均恢复时间。** 本轮属于引擎模拟，尚未代替真人界面试玩。

总计 14 个完成情景：6 个种子的满配准备、同种子的 4 个护道组合对照、2 个种子的退境和身死恢复。6 个种子只形成 3 种不同的炼虚入口状态，因此不是 6 份独立的生产体验。所有同种子对照均核对了入口库存和研究完全一致。

## 满配准备

合体护道：九转丹 4（+16 个百分点）；秘银 12 + 灵器 3（+24 个百分点）；香火 2400（+10 个百分点）。合计将 20% 提升至 70%。

| 种子 | 进入炼虚的累计时长 | 九转丹首次够用 | 银器组合首次够用 | 香火首次够用 | 基础材料与满配均齐备 | 灵气容量不足的累计时间 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| 1、6 | 15.790 小时 | 0 分钟 | 46.08 分钟 | 1.67 分钟 | 140.58 分钟 | 134.08 分钟 |
| 2、4、5 | 15.643 小时 | 0 分钟 | 44.75 分钟 | 1.83 分钟 | 102.33 分钟 | 94.25 分钟 |
| 3 | 15.772 小时 | 0 分钟 | 44.25 分钟 | 1.67 分钟 | 48.58 分钟 | 17.00 分钟 |

各组时间为该项首次达到要求，不是独立制作耗时；不能相加。原来的机器人会预先囤积高级材料，所以“九转丹 0 分钟”只表示进入炼虚时已有足够库存，不表示九转丹没有成本。容量不足按每 5 秒采样累计，材料短缺的区间可以重叠。

所有满配情景，最后齐备的资源都是灵气。例：种子 2 进入炼虚时，灵气容量 25392，突破报价 30000；种子 3 已有部分折扣，报价 25500，仍略高于容量 25392。基础材料报价会随后续折扣研究变化。

秘银的主要前置也不是 12 份材料本身：入口尚未研究“秘银提炼”，其研究要求灵机 30000、矿石 1000、灵气 1000。因此银器组合约 44～46 分钟的首次等待包含研究投入。灵器在种子 2、3 进入炼虚后约 5 秒即通过已有材料制作齐备。香火入口容量已超过 2400，没有发生香火扩容阻塞；这不代表从未建设香火产业的玩家也只需两分钟。

## 同一起点的组合对照

种子 2 各分支在炼虚入口的库存和研究相同，只改变合体使用的护道组合，第一次数值测试均强制成功。

| 护道组合 | 实际成功率 | 材料齐备并尝试的时间 |
| --- | ---: | ---: |
| 无 | 20% | 131.00 分钟 |
| 仅九转丹 | 36% | 131.00 分钟 |
| 仅银器组合 | 44% | 102.33 分钟 |
| 仅香火 | 30% | 131.00 分钟 |
| 全部 | 70% | 102.33 分钟 |

满配更快不能解释为护道材料免费或提高生产。参考机器人会根据下一境需求调整制作与采购；选择银器组合改变了后续投资顺序，使灵气扩容更早完成。这里比较的是相同起点下完整策略的表现，不是固定产业、固定投资顺序下增加一组材料的纯增量成本。

## 失败后恢复

以下均为第一次满配冲合体失败之后，到再次备齐满配并成功进入合体的额外时间，包含重新冲炼虚。

| 种子 | 强制退境后的恢复 | 强制身死后的恢复 | 身死取得仙缘 |
| --- | ---: | ---: | ---: |
| 2 | 32.59 分钟 | 610.34 分钟（10.17 小时） | 16 |
| 3 | 87.09 分钟 | 727.00 分钟（12.12 小时） | 13 |

身死比同种子的退境恢复多花约 9.6～10.7 小时，即使恢复阶段没有再次突破失败。退境恢复也受产业、库存和容量影响，并非固定只罚几十分钟。

当前满配冲合体单次身死风险为3%。如果所有退境都能回到炼虚，且不在其他环节身死或主动重开，最终冲过这一关前身死的概率为 `0.03 / (0.70 + 0.03) ≈ 4.11%`。先前失败后的身死率为5%时是 `0.015 / (0.70 + 0.015) ≈ 2.10%`。这是单关的概率推导，与整条飞升路线的死亡概率不同，也没有计入生产时间。

## 复现

```sh
npm run audit:breakthrough -- focus 2 48 full success
npm run audit:breakthrough -- focus 3 48 full success
npm run audit:breakthrough -- focus 2 48 none success
npm run audit:breakthrough -- focus 2 48 equipment success
npm run audit:breakthrough -- focus 2 48 full regression
npm run audit:breakthrough -- focus 2 48 full death
```

将种子换为 1～6 可复现准备情景；组合参数还支持 `pill`、`faith`，恢复情景也评估了种子 3。命令输出 JSON 文件中的入口库存、容量、报价、首次就绪时间与实际尝试记录，用于区分仓储、供给与风险损失。

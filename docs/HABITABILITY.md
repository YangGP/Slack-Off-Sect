# 宜居度规则与供给

规则与供给说明（整理：2026-10-14）。替代士气，宜居度是点数，不是百分比。现行造价、前置与效果以 [TABLES.md](TABLES.md) 为准；下列条目只说明职责。

设宜居度为H，弟子数为N：H = 20 + 建筑、技艺、法宝定额加成 + 已入住配套 + 断供惩罚。已入住配套 = min(弟子数, 居所容量) × 居所营造提供的每人点数。原士气加成等量转换；宜居度无上下限。正常断供惩罚仍在−60到0之间，每秒断供下降6点，供粮正常恢复2点。

| 条件 | 效果 |
| --- | --- |
| H < 0 | 全局倍率 = 1 − min(0.5, −H × 0.01) |
| H > N + 20 | 全局倍率 = 1 + min(0.5, (H − N − 20) × 0.0025) |
| 其他 | 全局倍率 = 1 |
| N ≥ 20且H < N − 20 | 弟子岗位产出再乘0.5 |
| N ≥ 50且H < N − 50 | 每60秒检查一次离开概率，并暂停新弟子前来 |

全局倍率只作用于持续产出，包括建筑、弟子及法宝的基础产出。岗位惩罚只作用于弟子；两者相乘后岗位最低为正常产出的25%，建筑最低50%。口粮、建筑维护和每份合成收益不受宜居度倍率影响。

离开概率 = min(50%, (N − 50 − H) × 2%)，每次检查最多走1人。阈值相等不触发惩罚；小于20人免除岗位惩罚，小于50人免除宜居度流失。风险消失后清除检查计时并恢复来人，暂停期间不累积来人时间。大段来人结算逐人刷新风险。

长期断供仍独立按25秒走1人，不受高宜居度豁免。同一结算步两种原因重合时只走1人。优先离开闲散弟子，否则从非阵徒、人数最多的岗位离开，尽可能保留供粮职位。

在线和离线采用相同的风险公式、60秒检查周期和抽签机制。离线仍按每秒推进；随机结果不保证两次独立模拟相同。

重复建设的宜居度收益继续叠加；带维护或动力费用的生活设施按实际供给、运行模式缩放，住房与实体仓储按已建数保留。

## 建筑、工艺与法宝

前期H在N+40～60之间时，全局增产5%～10%。增产10%～20%需要H在N+60～100之间；达到50%上限需要H至少为N+220。中后期建设、工艺和法宝可继续积累，不限制附带宜居度的生产建筑叠加。H=186、N=84时，增产为20.5%。

| 条目 | 类型与阶段 | 宜居度效果 |
| --- | --- | --- |
| 清风小院 | 基础采集后生活建筑 | 每座+4 |
| 膳养堂 | 药圃后生活建筑 | 每座+8 |
| 净身灵池 | 元婴生活建筑 | 每座+10 |
| 清幽园林 | 化神生活建筑；主动收益随供能缩放 | 每座+14 |
| 居所营造 | 前期工艺；茅屋2、藏经阁1、采矿场1 | 每个已入住名额+1，空房不计，最多覆盖居所容量 |
| 引泉净水 | 筑基工艺；居所营造、寻脉 | +6；后续净身灵池的前置 |
| 园林营造 | 化神工艺；引泉净水、静心诀 | +8；后续清幽园林的前置 |
| 清尘铃 | 金丹法宝；炼器术、固形纹 | +6；可祭炼 |
| 安居灵幡 | 化神法宝；复合符文、静心诀 | +10；可祭炼 |

居所营造首先覆盖实际入住需求，生活设施与法宝再提供富余点数。例如4名弟子、足够居所、居所营造、清风小院5座时，H=20+4+20=44，增产5%；扩建后60名弟子全有居所时，H=100，仍增产5%。超员人口不获得额外入住配套，断供惩罚照常生效。

参照玩家优先学习居所营造。采购策略仍以宜居度点数判断：金丹及以前不足N+40时补宜居设施，定额工艺和法宝尽量不超过N+60；元婴以后范围提高为N+100～120。新规则下分别对应5%～10%与20%～25%的增产。达到目标后暂停继续投资纯宜居条目，其他建筑仍可因产业需求而建设。游戏中玩家始终可以自行营造、学习和祭炼，没有20%硬上限。

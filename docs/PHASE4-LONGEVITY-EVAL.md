## 1. 4.8 宜居度减耗（已实施）

### 1.1 规则

| 项 | 改前 | 改后 |
| --- | ---: | ---: |
| 弟子基础口粮 `DISCIPLE_UPKEEP` | 0.25 气/秒 | **0.30 气/秒** |
| 宜居度减耗 | 无 | 高于基础值 20 后，每点 **−0.2%**，最多 **−20%** |
| 与阵法减耗的关系 | 单一 `consumeRatio` 通道，合计上限 85% | 独立乘区，只减不加；低于基础值不额外加耗 |

公式：

```
口粮 = 基础 × 境界倍率 × 人口规模倍率 × 弟子权重
     × (1 − min(85%, 阵法减耗))
     × (1 − min(20%, max(0, 宜居度 − 20) × 0.2%))
```

- 早期 +20% 基准压力；宜居度 120 以上时总减耗 20%，实际口粮 0.24/秒，略低于旧版 0.25——**“营居省粮”在后期真正兑现**，但不会把供养压力抹平。
- 只减不加：断供导致宜居度下降时，只会失去减耗，不会反过来加耗，避免“断供→宜居下降→加耗→断供更狠”的正反馈。
- 独立上限：与锁灵阵等阵法减耗各自封顶，两线叠满约 −88%，仍保留至少 12% 的供养压力。

### 1.2 界面与验证

- 宜居度提示新增“弟子口粮减耗”当前值与独立上限，规则说明补一行。
- `npm run smoke`：1108 项通过（含“高于基础值按点减耗”“低于基础值只取消减耗、不额外加耗”“极低宜居度仍不额外加耗”）。
- `npm run check:render`：22 项通过。

**风险**：基准 +20% 与减耗 20% 在“宜居度刚好 120”附近几乎抵消；早期（宜居度 20～40）是净加压。若后续长测显示开局供养过紧，优先调 `DISCIPLE_UPKEEP` 回 0.28，而不是取消减耗。

## 2. 4.6 首转提速（候选已写入，待对照测量）

### 2.1 现状证据

`REINCARNATION-PACING.md`：化神立即转世三组得仙缘 21／21／22，产出乘区 1.42～1.44、仓储乘区 1.0315～1.033；重建后的最后一世比直飞快，但**累计首飞仍慢 10.3%～18.8%**。按 v0.41 口径，每点仙缘约 +2% 产出（21 点≈1.42），软上限 +200%。

### 2.2 已写入的候选：首转结算 ×2

- `CONFIG.FIRST_REINCARNATION_KARMA_MULT = 2`，只在 `stats.reincarnations === 0` 时作用于 `reincarnationGain`；
- 飞升结算不变，第二次及以后转世恢复常规公式；
- 界面上首次可转世时显示“首次转世结算 ×2”。

**算术边界（必须如实说明）**：首转 21～22 点翻倍到 42～44，若按 2%/点，产出乘区约 1.84；以旧样本“首世 24h＋重建 37h”估算，重建约 29h，累计约 53h，对比直飞 55.4h 只是**接近打平**，达不到文档候选的“累计 −25%”。原因是仙缘产出乘区本身有 +200% 软上限（最高 3×），单靠首转翻倍无法把 37h 重建压到 17h。

因此这只是一个**可回滚的第一步**，不是已达标的结论。要让首转明显为正，还需要下列第二根杠杆之一：

1. 首转后额外一层独立乘区（例如重建期 +30% 产出，持续到首次化神）；
2. 首转直接发放一次性启动资源／建筑（缩短前 2 小时，而非全程提速）；
3. 降低重建段的固定成本（前几境研究费、住房），让每一世更短。

建议先跑配对测量，再决定杠杆，不叠加多项猜测。

### 2.3 道果主动消费（待拍板）

三个口径（见 4.6 评估）：

| 口径 | 做法 | 侵入度 | 建议 |
| --- | --- | --- | --- |
| a | 道果换“下一世招募灵根权重”，不做跨世弟子状态 | 低：只改招募随机权重 | **推荐** |
| b | 下一世对已招募弟子逐个使用道果提升灵根 | 中：需要新界面与弟子字段 | 备选 |

推荐 a 的理由：转世会清空弟子（`createInitialState`），a 的收益窗口天然覆盖整世；不需要跨世保存弟子；与现有“灵根出生随机权重”直接耦合，定价可按权重表换算（天灵根权重 1／异 4／双 10／三 25／四 30／五 30）。

### 4.1 补上参照机器人的秘银行为后的 72h 复测

第一次复测仍卡在元婴：灵晶缺料 56.654h。根因不是数值，而是参照机器人从不外交／猎杀，拿不到秘银催化剂。给 `player-bot` 补三条行为后复测：

- 元婴起自动研究《邻宗往来》；
- 需要时建执符堂并派 1 名执符使，攒信符；
- 秘银不足 2 且富余玄铁／灵石足够时，去银溪谷换 3 秘银。

**新的晚期瓶颈**：渡劫需要 9,000 枚飞升阵印。按基础 120 秒/枚、疾炼法 10× 估算，单是固结就要约 30 小时，另需 72 万灵能与 18,000 秘银；这是第一阶段 §9 已列出的独立风险，72h 样本远不足以走到。**4.6 的累计首飞对照需要 ≥150h 的样本，且必须先决定 9,000 阵印的时长是否调整**；在此之前不宣称首转达标。

### 4.2 同种子 0／1 转对照（72h，一次转世）

| 事件 | 直飞 | 一次转世 |
| --- | ---: | ---: |
| 第一世到化神 | 31.874 | 31.874（随后转世） |
| 重修到化神 | — | 53.557（重修 21.683h） |
| 到炼虚 | 54.246 | 67.578 |
| 到合体 | 60.340 | 71.719 |
| 到大乘 | 68.083 | 未到达 |

- 重修到化神 21.683h，比第一世同段 31.874h 快 **31.9%**，首转 ×2 的提速确实存在。
- 但累计到炼虚／合体仍落后直飞约 13h／11h，因为第一世 31.874h 是沉没成本；**首次转世在 72h 窗口内仍未回本**，累计首飞更无从谈起。
- 该结果说明：×2 只够让重修段明显变快，不够让累计路线胜出；第二根杠杆（首转后独立乘区或缩减前几境固定成本）仍需要，且必须在 ≥150h 的完整飞升样本上验证。

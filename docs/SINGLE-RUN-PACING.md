阶梯性质：基础材料（实物产出）→ 灵机（经营主资源）→ 仓容（空间投资）→ 灵气分子（深加工转化）→ 秘银/灵能（关键材料+能源）→ 仙灵力（终局货币）。每段瓶颈是新维度而非同一堵墙加高，"产出→储存→转化→能源→终局货币"逐级升维；玩家每段的"该投资什么"答案不同，这是路径 C 所需决策密度的来源。合计已收口至 1~2 月锚点内；分段实测后各段再收幅。

### 1.3 节奏质量原则（草案已获方向认可）

1. 等待要有事做：每段至少两条并行线，纯挂机墙单次不超过一个作息周期。
2. 瓶颈阶梯切换：相邻段瓶颈资源不同，且新瓶颈尽量由前段产物承接（P4 秘银/灵能→P5 阵印已天然衔接：固结飞升阵印每份灵能80+秘银2，9000份=灵能72万+秘银1.8万）。
3. 解锁脉冲：任何在线 30 分钟内可见下一个可达目标；境界突破是大脉冲，研究/建筑是小脉冲。
4. 操作密度递减、决策深度递增：P0 分钟级→P5 小时级。
5. 不靠风险拖时长：不通过提高失败率/身死率实现拉长（ROADMAP 保留边界）。

### 1.4 与轮回重构的衔接

- "1~2 月"以实际飞升结算为终点，渡劫后的弟子培养停留窗口计入首局时长；首局玩家同样会为道果收益停留。停留窗口内并行内容（弟子培养、香火深耕、猎场、万千世界）由轮回重构线设计，本框架只预留：化神起每段须与这些并行线共存而非互斥。
- 化神转世出口（≈15 天）与轮回重构"化神起可转世"一致；P0→化神由 P0(1~1.5)+P1(2~3)+P2(4~5)+P3(4~6) 构成，合计 11~16 天（中位 ≈13.5），锚点吻合。

## 二、P3 定稿：瓶颈换轴到灵气分子（元婴→化神）

### 2.1 现状诊断

1. **灵机墙已部分拆除**：化神破境灵机费 30 万→1 万（v0.424），历史 108h 缺口主因已处理。
2. **卡点转移至知识链**：化神账单道札 400+道论 40 ≈ 18 万灵机当量（道札 100/份、道论 3500/份隐含口径），且刻纹工位同时承载道札/道论/阵图/符箓/阵基/灵符/灵纹 7 类配方，工位竞争级联等待。
3. **凝聚链压力**：灵晶 2100 份倒推灵液 6300 份，加账单灵液 5400，共 11700 份挤凝聚工位（与灵液共 2 配方）。
4. **粒子链在段内空转**：分灵阵（灵气分子）元婴即可建（《灵子论》realm 5），但化神前分子无任何用途；偏极阵、湮灭炉均为化神建筑；化神期灵能只积累无下游（灵能输配是炼虚研究）。段内真正的化神门槛是知识材料＋工位产能，粒子产线是"预备役"。

### 2.2 设计决定

| 项 | 决定 |
| --- | --- |
| 瓶颈载体 | **灵气分子产量**（产能型瓶颈，非存量墙） |
| 挂账位置 | 化神破境费**新增灵气分子条目**；道札 400/道论 40 账单**不动**（保留知识链作次级压力） |
| 基础产能增强 | **加强刻纹、凝聚工位产能**（符箓堂/晶核凝炼阵扩容或新增产能建筑，具体载体实施时定），缓解 7 配方争用与灵液级联 |
| 投资点 | 分灵阵列数（0.04/秒/列、涨价率 1.5、维护 8 灵气/秒/列）＋法藏扩容（分子基础仓容仅 100，法藏+1000/座）＋符匣分装 +25%＋《分子回用》+30% |
| 段时长 | 4~6 天 |

载体选型依据：分灵阵是段内唯一提前可用的粒子资源（时间位置刚好）；"灵气维护→列数上限"天然构成"基础产能增强（灵气）但分子产量受限"结构；仓容投资复用 P2 主题形成递进；化神后分子直接转化为灵能瓶颈的供给端，P3→P4 瓶颈接力（分子→灵能）闭合。

### 2.3 校准提示（实施时须验证，不改结构）

1. **分子终值**：初稿 800 份在 0.04/秒/列下纯产时间仅数小时，作为门槛偏小。终值按"产线建设（列数灵机投资＋法藏链）＋攒料合计占段内 2~3 天"反推，预计落点数千至万级，与法藏座数、符匣加成联校。分子在元婴期无其他去向，全部产出流向账单，无竞争损耗。
2. **灵气流依赖（吞吐型修正）**：分灵阵产出与维护同乘全局倍率，元婴期实际维护 8×1.8=14.4 灵气/秒/列、产出 0.072/秒/列（灵气:分子 200:1 不变）。4 列 ≈ 58 灵气/秒持续消耗，远超账单灵气 1.8 万的一次性量——"基础产能增强"的实际落点是金丹~元婴段灵气产能须支撑列维护，这把 P2（基础材料/仓容）与 P3 的产能链咬合。若校准后灵气压力过大，优先调分子单列产出，不动 200:1 比值结构。
3. **粒子链机制不动**：湮灭炉乘区已排除粒子（无自我放大）、偏极阵一对一供料规则、共用负荷限流均保留；本段不新增粒子资源。

## 三、P2 定稿：互市时代（金丹→元婴）

2026-10-23 增补：按用户要求对照猫国中期（贸易船段）源码后修订。v1 的"仓容限制增益项"主题不变，落地机制改以互市吞吐为主轴。

### 3.1 现状诊断

1. **元婴账单对仓储链考核太轻**：灵气 12000（约 2 座法藏可装）、灵机 12000（1~2 座观星台+讲经堂）、灵石 2400（数座料场/库房）；药藏、玄库均为 realm 5 建筑，账单支付前建不了——金丹期可用仓储投资只有谷仓/料场/库房/法藏＋技法（叠匣术/加固仓架/叠石固本/液藏之术等）。
2. **药藏确认为坏设计**（意见.md 投诉属实）：只给灵草 6000 单项仓容，造价含 500 灵草（自储资源）＋混灵土 8，无任何增益；对比法藏（realm 4、同 1.22 涨价、5 种资源共 9200 仓容、造价不含自储资源）各项严格劣于法藏。
3. **净身灵池是 P2 窗口内的无限建造漏洞**：造价全为不限仓加工品（混灵土4+灵液4+木板4），宜居+10/座，可极低成本把宜居堆到全局产出+50% 的机制上限。同结构建筑共 6 座（净身灵池、试炼塔、清幽园林、护山大阵、锁灵阵、洞府，后 5 座在化神~合体窗口）——意见.md"理论上可以无限建造"的具体落点。另：显形门槛"费用资源历史峰值达基础造价 30%"对不限仓资源形同虚设。
4. **时长现实**：旧基线机器人 12h 到金丹、17.67h 到元婴，金丹→元婴仅约 6 小时；v0.424 未动元婴账单，现状大概率仍此量级。框架草案的"4~5 天"意味着该段拉伸 3~5 倍以上，是各段中拉伸比最大的一段。
5. **P2→P3 咬合**：元婴期全宗灵气盈余约 30~40/秒 ≈ 全宗口粮（20 名元婴弟子约 28/s）＋1 列分灵阵；灵气收入主力是阵徒人力＋聚灵阵堆叠＋宜居。P2 建立的灵气产能与仓储规模直接决定 P3 能同时跑几列分子产线。
6. **互市系统已有猫国式雏形且优于预期**（外交模块，筑基起+《邻宗往来》+模块开关）：
   - 信符经济：执符使 0.2/秒（技法 +25%）、信符仓容基础 100+执符堂 300/座（隔离仓容）、互市 50 信符/回，与猎杀（100/趟）共用同一池。
   - 五家邻宗固定汇率：药泉谷（灵草300→灵石25）、黑铁山（灵木600→灵石30+矿石20）、须弥寺（香火150→灵石20）、银溪谷（矿石500+石材300→秘银3）、星崖观（灵机900+香火120→灵晶10）。
   - 机缘骰：8%+1%/启用山门，封顶 35%；掉落按产能定价（120 秒）+保底+仓容份额截断（20%）。
   - **垄断结构已在**：星崖观是金丹期灵晶唯一稳定来源（观星台造价含灵晶 50——灵机引擎建材）；银溪谷是炼虚前唯一稳定秘银来源（凝晶每份耗秘银 0.01——P3 灵晶产线上游）。
   - **正反馈环已隐式存在**：灵机囤满→互市灵晶→观星台（灵机+50%/座、仓+3000）→灵机引擎扩容→更大批次。
   - **缺口**：零条互市增益项（无贸易比率类投资）；机缘概率无递减曲线；元婴账单与互市零关联；纯交换无纵深（模块自述首版）。

### 3.2 猫国贸易船段模式提取（cat-zh-master 源码调研，2026-10-23）

来源：cat-zh-master/js/diplomacy.js（种族/贸易核心）、buildings.js（港口/交易所/铸币厂）、science.js（解锁链）、workshop.js（船配方）、calendar.js（天文事件）、game.js（递减公式）。要点五条：

1. **存量上限＝贸易批次**：贸易即时结算无冷却，单次上限=min(金子存量÷15, 猫力÷50, 买入资源)；金子有仓容上限（港口+船%放大）——节奏为"囤满→清仓→等回复"批次循环，**仓容投资＝吞吐投资**，港口成为中期最大仓储投资轴。船不载货：只给港口仓储 +1%/艘（168 艘后递减、上限+225%）、斑马钛概率与数量、种族门槛（蜘蛛需船≥100）。
2. **稀缺资源垄断于贸易**：钛中期唯一规模来源＝斑马贸易（矿井不产钛）；香料只能贸易获得（35%/次）；蓝图 10%/次。中期瓶颈资源经由"玩家选择的阀门"供给，而非等待墙。
3. **多条平行增益轴各有递减**：交易所 +1.5%/座贸易比率、大使馆 +1% 概率/级（递减封顶 +75%）、船仓储 +1%/艘（递减封顶）；政策二选一（绥靖 vs 好战）创造取舍。
4. **态度/季节/失败率＝时机纹理**：斑马基础 30% 失败、各族货物四季修正 ±35%，轻量时机决策非硬墙。
5. **贸易反哺下一时代**：贸易攒的钛直接是太空任务建材；龙的铀、利维坦的时间水晶持续由贸易供给。

边界：猫国贸易无现实航行时长、本体无离线进度与自动贸易（仓库根目录的 kitten-scientists.user.js 为第三方脚本）。我们不照搬的：无理由引入随机失败惩罚类纹理（除非另立任务）；贸易仍保持在线主动操作。

### 3.4 设计方案 v2：互市时代

主循环（把既有隐式反馈环升格为有意的节奏主轴）：

```
灵机/香火盈余（仓容受限）─┐
                          ├→ 互市（信符批次 50/回）→ 灵晶 → 观星台 → 灵机引擎扩容 → 更大批次
执符使产信符（执符堂仓容）─┘                    ↘ 秘银（银溪谷）→ 凝晶备料 → P3 灵子线
```

## 七、整体自检（2026-10-23，整理时评估）

### 7.1 一致性结论

1. **锚点闭合**：化神出口 11~16 天（≈半月锚点）；全段合计 29~55 天（中位 ≈42 天，落在 1~2 月锚点内且已收口）；分段实测后各段再收幅。

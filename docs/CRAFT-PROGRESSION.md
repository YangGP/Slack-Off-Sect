## 制作与产业分工

单份收益＝基础产量×（1＋通用制作加成＋该成品专业加成），小数直接入库。普通生产与宜居度不直接提高每份收益；人数、建筑数、等级和制作批数仍按整数。

百工坊由木作器械开放，提供通用制作增益。金丹前自动制作按配方独立计时，金丹起专业配方共用对应工位。自动总开关、逐项选择、优先扣料顺序、分配权重、库存目标与材料保留分别控制运行；手动即时合成与自动节拍分开。

## 工业加工

容量单位表示每秒完成的基础加工秒数。百工坊、炼器坊、符箓堂、炼丹房每座分别提供1单位木作、炼器、刻纹、丹道容量；每3座启用药圃提供1单位育草容量。凝液法提供1单位基础凝聚容量，每座晶核凝炼阵另加1。配方与工位对应关系以生成数据表为准。

设备容量 =（基础工位 + 启用设施数量 × 维护供给比例）×（1 + 同类容量升级之和）。同工位可运行配方按1～100权重分配容量，默认1；单条产线容量需求不超过自动速限，达到速限后的容量分配给其他产线。缺料、保留量不足、满仓、库存达标、取消自动及总开关关闭均不占工位。

每秒加工份数 = 分得容量 ×（1 + 配方加工效率之和）÷ 境界折算后的基础耗时。计时保存已完成的基础加工秒数；调速、改权重与停机不会丢失半份工作，也不会在停工期间积攒突发加工。在线与不超过60秒的离线推进至下一份完成时刻，随后重新分配容量，使达标及上下游供料变化可以在同一时间段内生效；长离线改为有界批量：每段冻结一次工位分配，按**剩余真实时间**一次算清份数，多轮只是重分配同一段时间，而且原料与这一份自己的加工动力算作同一份完整代价、共用同一份库存，缺料或满仓时小数进度最多保留一份待完成量 —— 因此恢复在线不会补做欠账，也不会出现「产值已入库、动力却付不出」（见 [ENGINEERING.md](ENGINEERING.md#离线结算)）。

| 工程升级 | 设备或工艺变化 |
| --- | --- |
| 阵基规制（金丹技艺） | 阵基装配效率+50%，消耗上游木板、玄铁，不要求先造阵基 |
| 流水作坊 | 木作容量+50% |
| 凝液回流（元婴技艺） | 凝液每份耗气−15%，升级用玄钢与阵基，不依赖晶核阵 |
| 定纹模刻（元婴技艺） | 符箓、阵基加工效率各+100%；灵符不享受低阶模刻 |
| 晶纹精修 | 凝晶每份耗料−20%，加工效率+25% |
| 灵纹锯阵 | 木作容量+100%，解板效率+50%，每份灵木耗料−15% |
| 灵火冶炼 | 炼器容量+100%，淬钢效率+50%；玄钢耗料−15%，法器与灵器耗料−10% |
| 疾炼法 | 木作、炼器、刻纹、丹道与凝聚容量各+100%，解锁1/2/5/10倍自动速限 |

每份费用 = 基础费用 ×（1 − 节料比例之和），节料最多50%，所有材料费用保留精确小数，不按整枚向上取整。加工效率与节料不增加单份成品数量；原有工坊、法宝的制作收益仍单独计算。手动与自动制作、批量支付、材料保留、价格显示和事件产能估价统一使用节料后费用。飞升阵印不参与节料。

炼制页显示各工位已用／总容量、配方分配比例、当前节拍的每分钟投入产出、具体停工原因、输入缺口与库存缓冲。速率是当前库存和工位下的自动加工能力，不能视为上游已保证的长期供料。手动制作即时结算；节气满仓凝液、催生灵木、点石成灵和固结阵印保持原规则。

工位设计参考仓库内猫国版本的设备专属升级、连续加工和扩产供给关系。同一工业批次包含动力、散热与双极分流控制。

## 动力与冷却

各工位默认普通加工。疾炼法后可以选择灵气超载，灵能输配后可以选择灵能驱动；两种方式都最多增加一倍基础容量。只对实际超出基础容量的工作收费：每额外容量秒消耗10灵气或0.1灵能。配方每份材料费用与产出数量不变；灵能替代高负荷耗气，仍需要供能设施。

额外容量受总冷却量限制：全体基础工位提供25%自然散热，每座运行中的晶核阵额外提供2容量，按维护供给缩放。化神技艺冷凝换热将晶核阵的冷却贡献翻倍，使用已能从上游制造的玄钢、阵基与灵液，不需要灵能才能启动。

灵能枢满供提供4单位加工供能容量，祭炼与断供同时影响容量。枢的基础维持费每秒0.1灵能，随祭炼同比增长；加工动力另按额外工作量支付。总供能与总冷却不足时各工位均分，工位内部继续遵守配方权重和速限。先提高配方速限，再选择驱动，才会出现实际额外负荷。

动力耗尽、到达保留量或冷却不足时减少加速，普通容量继续可用。缺料、满仓、达标与没有额外负荷时不耗加工动力；驱动还会留下一份当前可开工配方需要的同种原料。动力与配方扣料分开记账，长离线只为实际发生加工的时段扣除动力。旧存档默认普通驱动，设置随存档与转世偏好保留，但每一世仍需重新解锁研究。

偏极阵两侧共用运行负荷。任一侧库存已满，就将分流降到下游实际成对消耗可容纳的流量；没有下游需求则停工，不再白耗灵气分子。炼制页同时显示两极库存、设施流量及偏极阵负荷；专业倍率造成的不等库存不会自动兑换或被强行清零。

## 手动合成与旧订单兼容

所有手动配方点击后立即扣料和出货，“制作”“¼料”“½料”“全部”按当前原料与仓容结算，保留专业增产、节料和小数直接入库。手动不受自动总开关、库存目标、材料保留量或工位运行状态限制，不推进或清空自动加工计时。自动制作仍按工位、供料、动力和冷却约束运行。

新操作不再生成订单。旧存档已有订单继续共用自动计时和工位，优先完成订单再补库，可以超过补库目标，仍遵守仓储和材料保留。自动总开关不暂停旧订单；订单暂停不影响自动补库。取消未完成订单不收材料费，保留该配方已有的加工进度；完成手动合成后，旧订单会按剩余原料继续加工或等待补料。

剩余份数、暂停状态随存档保存；旧档没有订单，本世重置时清空。离线加工遵循相同工位与供料规则。输入缺口按当前总净流量计算，缓冲时间按可用库存除以缺口估计，不能当作固定的未来停机时刻。

## 符文与材料载体

符文是灵气结构，材料负责承载。灵纸承接知识记录和符样，木板与玄铁承接阵基，玄钢承接高阶灵符，灵液注灵，香火辅助定纹。现行符箓已使用灵纸，不再沿用“基础符箓只用灵木符牌”的旧报价。

固形纹支撑凝晶，导灵纹支撑阵基，纳灵纹与复合符文支撑灵符和灵器。灵宝汇合器、丹、符三条支线。具体配方应用境界见生成表，不能据研究已学提前制作。

晶核凝炼阵通过专业制作增益改善凝液、凝晶，并提供凝聚工位及冷却；不直接生产灵液／灵晶。护山大阵提供通用防灾，镇岳符重点保护灵木／灵草，按资源合并后受80%总减免限制；灾损减免不用于交易和主动付款。护山阵盘改善阵基与灵符制作。

## 后期建筑材料

灵木→木板→阵基与矿石→石材→灵纹石形成结构件层次。灵纸同时参与知识、符箓和刻纹构件。百工坊的首启不能依赖尚待自身开放的加工品。

混灵土承接基础胶结，玄铁混灵土提供加强骨架，秘银用于储灵金属，玄金用于高阶合金，晶银用于精密晶核。材料用于建筑结构和储灵部件，库存秘银本身不免费增加灵子容量。仓储收敛为谷仓、库房、法藏和洞天：洞天在炼虚以秘银与玄铁混灵土起步，不依赖合体玄金；合体《洞天福地》负责强化洞天和开放洞府，通天塔仍按原材料与境界开放。

仓储工艺针对已建建筑自身定额，同类百分比相加；对资源总仓容的加成在之后计算。既有工艺ID与已学资格保留，未学的仍需满足新前置并付费。

## 知识加工

灵纸→道札→道论→阵图接入同一手动／自动系统。金丹记录道札、元婴汇编道论、化神绘制阵图；知识加工共用刻纹工位，与符箓、阵基和灵纹石竞争容量。完整用料从生成表读取，不再保存旧试调报价副本。

知识材料不能逆换成灵机。藏经阁承担研读增产，典籍库承担早期灵机容量，讲经堂与观星台接续科研。道论按持有量增加临时灵机仓容，受现有容量相关上限约束；消耗道论后超额库存可继续支付，新增收入受实际容量限制。

新档默认保留道札20、道论2、灵纸10；旧档缺失保留量保持原值或0，不自动追设。目标为0表示不限，达到目标停线，消费后补库；制作批数为整数，最后一批允许超过目标不到一批产量。

首座讲经堂不要求先记录其自身才能解锁的知识；道札来源不反锁讲经堂，阵图不依赖湮灭炉首启。化神至渡劫的账单已由知识材料承接主要准备，具体灵机尾款和材料数量以现价为准。更多知识工艺和设施反馈仍待策划及平衡验证。

## 材料研究与兼容

- 丹道：炼丹术与丹道精微承接丹药→凝元丹→九转丹；丹火纯青是应用技艺。丹鼎承担高级丹药能力，九转丹炉为增产法宝。材料与费用保留小数。
- 香火：香使人力供给香火，金丹凝愿、化神证心；本世仪轨与永久道心分别保存。愿力护道提供本世宗门身死减免，长期护道规则见游戏总览。
- 土木：土木术／土木精要承接扩仓，营造技艺提供混灵土及玄铁混灵土制作增益，不提供建筑折扣；居所、净水与园林承接生活配套。
- 纸张兼容：已经制作纸张下游成品或配置相关自动产线的旧档补抄纸法，已学研究和已造建筑不追缴材料差价。
- 丹道迁移：`alchemyProgressionVersion:1`仅为尚未迁移且已持九转丹炉的旧档补丹道精微及`legacyNineTurnPill`，保留本世旧九转炼丹资格，不赠丹鼎，不因重读档重复补发；重修清空旧资格。
- 仓储迁移：料场／材料库／玄库／药藏与旧库房合并为库房，广储库并入洞天。合并前定额及更早的容量权益折算成旧建筑容量下限，保存时保留Decimal；拆除后减少，重建不恢复，轮回清空。工艺强化不再次乘大保留权益，不补授工艺、不重复返还材料。重建计划同步映射。
- 小数迁移：旧制作与猎杀合法余量一次性转入库存并清空；每份凝晶直接支付秘银0.01，旧催化进度不追缴，废弃字段移除。

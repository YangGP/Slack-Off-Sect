# 修真 / 技艺解锁结构审核（2026-10-21）

> **数据源**：`src/data/upgrades.js`（`CULTIVATION`，83 项）、`src/data/techniques.js`（`TECHNIQUES`，54 项技艺 + 24 项法宝）。
> **方法**：用 Vite SSR 读取实际导出数据，计算前置深度、直接扇出、同前置兄弟组与跨页依赖；不改代码，不运行测试。
> **结论**：问题不是“总节点太多”，而是 **3 个枢纽的直接扇出过宽**、**境界门禁只覆盖 26/161**、**深度 ≥13 的 60 项里有 46 项没有境界门禁**。4.5 设计的“金丹后境界＋材料双门禁、技艺全挂修真”尚未落地。
>
> **2026-10-21 追加**：后续新增《纸坊规制》《石作规制》《造纸技艺》《石作技艺》4 项（现为修真 85／技艺 56／法宝 24）。本文清单与指标为追加前的 161 项基线，新条目见 docs/TABLES.md。

## 三、审核结论

### P1：境界门禁只到炼虚，后期没有境界节奏

26 个境界门禁全部落在筑基～炼虚；合体、大乘、渡劫没有一条研究被境界卡住。深度 ≥13 的 60 项里有 46 项无境界门槛，包括仙灵聚合、因果参同契、塔院图、洞天福地、须弥纳芥之后的全部内容。

后果：
- 炼虚之后研究只受前置链和材料/造价约束，境界推进不再改变“能研究什么”；
- 4.5 要求的“金丹后境界＋材料双门禁”没有实现，金丹～炼虚的门禁又多数落在深节点上（观星术深度 14、灵子论 15、灵能输配 18），实际起不到“到境界才开分支”的作用。

**判定：不合理。** 应把境界门禁放在**分支入口**，而不是深节点；并补合体/大乘的晚期入口。

### P2：三个枢纽的直接扇出 10～11，形成“节点墙”

淬玄工艺 11 个直接子节点、木作器械 10、凝晶工艺 10；符文入门和炼器术各 9。深度 13～15 三段合计 40 项，玩家在同一阶段会同时看到十余条独立线。

这些子节点本身大多合理，但**同一枢纽一次性全部露出**，造成：
- 不知道先做哪条；
- 每条都差一点材料，体感像“到处都卡”；
- 研究页在金丹～化神段最长，和实际推进速度不匹配。

**判定：不合理，属于披露节奏问题，不是依赖错误。** 建议加中间“分支门”或把部分子节点串成 2～3 段，不删除内容。

### P3：11 组同前置兄弟，纯并行缺少取舍

最明显的是：
- 香火志 → 广开山门 / 祖师遗泽 / 山门志（3 条都只差香火志）；
- 山野猎法 → 识踪诀 / 踏山步 / 筹猎章（3 条小加成）；
- 阵基装配 → 符匣分装 / 阵基规制（2 条）；
- 营造法式 → 候时法 / 试炼法（2 条）。

这些节点互相没有依赖，玩家只能按价格/效果硬选。少量并行是选择，3 条以上同起点会稀释每条的存在感。

**判定：部分不合理。** 建议把“同一系统的小加成”串成一条链，或合并为一个节点的多级效果。

### P4：22 个节点前置 ≥3，破境心法要 5 个

普通节点最多 2 个前置已经足够表达“跨系统准备”；22 个节点要 3 个以上，破境心法同时要观气法、炼丹术、丹火纯青、土木术、凝气化液。

后果：
- 玩家要同时维护 5 条线才能点一个“破境 −15%”的通用节点；
- 前置越多，越容易误以为“树很乱”，实际是入口太分散。

**判定：偏多。** 建议普通节点 ≤2，里程碑/终极节点 ≤3；破境心法这类通用节点改成“任选 2 条”或拆成两个前置层。

### P5：3 条修真→技艺反向边，跨页阅读成本高

阵法精要（修真）要引气诀（技艺）、丹道精微（修真）要丹火纯青（技艺）、传功授业（修真）要口传心授（技艺）。虽然不成环，但玩家在修真页看到“要先去技艺页”的提示，回到技艺页又看到它挂修真，容易迷路。

4.5 已允许“技艺至少含一个修真前置、允许穿插”，但这 3 条是修真侧反向引用，建议改为：
- 把技艺前置折进修真节点的造价/建筑门槛；或
- 明确标成“回授”节点并在 UI 显示跨页跳转。

### P6：命名相近，放大“重复节点”感

`凝晶原理` / `凝晶工艺` / `晶纹精修` / `晶纹校准`；`灵火冶炼` / `灵火锻采`；`灵纹锯阵` / `灵纹器具`。功能不同，但名称过近，玩家会误以为同一件事拆成多个节点。

**判定：命名问题，不是结构问题。** 建议成对改名（原理/工艺保留，具体应用改“炉/器/阵”前缀）。

## 四、建议的收敛方案

### R1：先处理 3 个宽扇出枢纽（收益最大）

不删节点，只加“分支门”或改链：

1. **淬玄工艺（11）**：按用途分 3 组，各加一个中间节点或改前置：
   - 器：器道精微 → 御剑术 / 灵火冶炼 / 灵火锻采 / 回火原理；
   - 纹：纳灵纹 → 复合符文 / 符法精微；
   - 营造：营造法式 → 洞天福地 / 塔院图；
   - 玄铁骨架、凝液回流、兽材加工、百炼工具保留直连，但放到不同深度。
2. **木作器械（10）**：把 `流水作坊` 挂到 `阵基装配` 之后；`灵流要诀` 挂 `灵植术` 之后；`铁木工艺` 已挂 `伐木要术`，保留；`玄铁斧` 作为早期法宝单独露出。
3. **凝晶工艺（10）**：`晶纹精修 → 晶纹校准` 已有链，继续保留；`凝析原理` 并入 `晶纹校准` 的前置；`灵纹锯阵` 挂 `流水作坊`；`百草育灵` 挂 `药圃轮作`；`定纹模刻` 挂 `阵基规制`；减少同一层直接子节点。

### R2：境界门禁放到分支入口，并补晚期

- 保留现有 4 个主轴锚点（观星术金丹、灵子论元婴、园林营造化神、灵能输配炼虚）；
- 给晚期分支入口补境界：仙灵初探/仙灵聚合（合体）、因果参同契/塔院图（大乘）、须弥纳芥（炼虚已）、洞天福地（合体）；
- 把深节点上的冗余境界门禁上移或删掉：观星术（深度 14）、灵子论（15）、灵能输配（18）已由前置链自然到达，不必再卡境界；
- 目标：每个分支入口有境界门禁，深节点只保留材料/前置，避免“到了境界却早已能点”。

### R3：合并/串联 11 组同前置兄弟

优先处理 3 条组：
- 香火志 → 广开山门 → 山门志；祖师遗泽独立挂祖师殿；
- 山野猎法 → 识踪诀 → 踏山步 → 筹猎章，或合并为“猎法总纲”三级效果；
- 阵基装配 → 阵基规制 → 符匣分装（或反过来，按容量/效率分工）。

2 条组可保留并行，但 UI 上合并为一组“二选一”展示，避免当成两条独立线。

### R4：前置数量收敛

- 普通节点 ≤2 个前置；
- 里程碑/终极节点 ≤3；
- 破境心法 5 个前置拆成“观气法＋炼丹术”与“土木术＋凝气化液”两层，或改成“任选 2”。

### R5：去掉 3 条修真→技艺反向边

`阵法精要`、`丹道精微`、`传功授业` 的技艺前置改为对应修真的材料/建筑门槛，或明确标注“回授”并提供跳转；保持“修真 → 技艺”主方向。

### R6：UI 先做“分支折叠”

在数据调整前，研究页可按现有 `CULTIVATION_STAGES` 分段默认折叠，只展开当前境界可用的 1～2 段；每个枢纽显示“还有 N 条分支”，避免一次铺满。这是低风险缓解，不改变 DAG。

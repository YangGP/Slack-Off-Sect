# 产业增益审计（v0.14）

## 猫国的参考结构

查阅时间：2026-10-08；参考官方仓库 master 的实现。以下示例用于辨认增益的作用范围，不代表所有存档的后期产量。

| 类别 | 专业增益 | 公共增益及边界 |
| --- | --- | --- |
| 基础资源：木材 | 六种斧具合计给伐木岗位 +320%；伐木场基础每座 +10%，五种锯具合计将每座提高到 +19.5% | 岗位升级、建筑倍率分别结算，再叠加威望、磁电机/蒸汽工场、反应堆、太阳革命等适用增益 |
| 中间资源：铁 | 熔炉、电解冶炼（熔炉倍率 +95%）；另一条来源为煅烧炉及氧化、回转窑等专用升级 | 自动生产有自己的计算路径，不能把矿工岗位和矿石建筑倍率直接套给铁；威望对自动生产的系数也不同 |
| 加工品：钢、板材 | 工坊每座 +6%；工厂基础每座 +5%，物流升级后 +6%；工程师领袖、材料类别领袖及资源专属制作增益 | 手动加工使用制作倍率。钢厂自动炼钢另有专门规则，不能把基础资源的全部生产倍率再乘一次 |

来源：[工坊升级](https://github.com/nuclear-unicorn/kittensgame/blob/master/js/workshop.js)、[建筑与自动生产](https://github.com/nuclear-unicorn/kittensgame/blob/master/js/buildings.js)、[资源生产与制作公式](https://github.com/nuclear-unicorn/kittensgame/blob/master/game.js)。

例如，把斧具和锯具全部学会，再造 100 座伐木场，仅岗位升级与伐木场两层，就有 `4.2 × (1 + 100 × 0.195) = 86.1` 倍；还没计入其他来源。50 座工坊和20座未升级工厂则使一般加工的每批产量达到 `1 + 50 × 0.06 + 20 × 0.05 = 5`，未计领袖等其他收益。这说明后期应当同时发展原料扩产与加工收益，且二者走不同公式。

因此，“相邻层级约百倍”采用百份原料级配方作为基准。增益和设施数量会改变有效转化率与每秒产量，不将所有相邻资源的实际产量锁死为100:1。

## 验证与实际收益

专业增益隔离检查覆盖9项技艺/法宝：固定生产来源与供料后，目标资源或制作收益提高，非目标资源及公共倍率不变。另检查通天塔的叠加和停用、三项产业技艺的境界门槛。加工链审计改为分别记录实际资源增产和每批制作增产，保留祭炼等级后再做移除比较。

0仙缘、无随机事件、每5秒决策的参照玩家：合体43.61小时、大乘47.54小时、渡劫53.34小时，63.25小时首次获得灵能；72小时完成84项研究。上版同策略约32.29小时渡劫，本轮去掉公共增益后节奏变慢，原料与专业设施的选择更影响进度。单一机器人策略不是所有玩家的预计时长。

72小时独立供料产能上界：灵木约19177/秒，玄铁15547/秒，灵草15577/秒；木板10.584/秒、玄钢5.836/秒、丹药11.628/秒；九转丹0.605/秒、灵符0.540/秒、灵器0.406/秒；灵宝0.055/秒。加工产能按每条配方单独供料计算，不能当成所有配方同时运行的收入。

后期技能显示的百分比会受同类加成累计影响：此存档阵纹精研使阵基每批实际增加约8.70%，大乘心经使仙草每批实际增加约15.53%、九转丹约10.64%；镇岳印使阵基每批实际增加约11.94%。它们已直接作用于对应加工品，而非只提高原料产量。

0与202仙缘各72小时审计均到渡劫，未发现负库存或非有限数值；671项引擎、19项渲染、228项DOM检查共918项通过，生产构建、编码检查与差异格式检查通过。

复现：`npm run balance -- 72`；`npx vite build --ssr tools/tier-audit.mjs --outDir .smoke-tier --emptyOutDir` 后运行 `node .smoke-tier/tier-audit.js 72 0` 或 `node .smoke-tier/tier-audit.js 72 202`。

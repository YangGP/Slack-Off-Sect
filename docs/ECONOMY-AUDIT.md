## 点击修改与测量方法

前20座聚灵阵保持原点击收益；以后额外聚灵阵按平方根折算。45座时每次25 → 15灵气，每秒4次额外100 → 60灵气，仍不乘全局倍率。

首版从第11座递减使参照玩家金丹时间延迟到约5.07小时，因此改为第21座起递减；这说明点击也影响开局购买与研究顺序，不能只看化神终点。

`npm run balance:clicks -- 12` 比较额外不点击、每秒1次、每秒4次，参照玩家均每5秒决策，无随机事件。额外不点击模式仍包含原机器人开局少量点击。每秒聚合点击是测量模型，不代表真人能连续点击12小时。

`npm run audit:economy` 列出当前资源容量、基础需求及去向；`npm run balance -- 72` 验证终局可达。参照玩家不主动祭炼，新消费入口由实际扣料与层级门槛回归验证，不能将模拟进度解释成祭炼收益。

## 改后实测与判断

相同决策脚本、无随机事件，单位为小时：

| 额外点击 | 改前金丹 / 元婴 / 化神 | 改后金丹 / 元婴 / 化神 |
| --- | --- | --- |
| 无 | 2.65 / 8.05 / 9.83 | 2.65 / 7.20 / 9.22 |
| 每秒1次 | 3.31 / 5.24 / 6.90 | 1.84 / 4.99 / 6.67 |
| 每秒4次 | 2.45 / 3.77 / 5.31 | 2.39 / 3.78 / 5.17 |

每秒4次模型的12小时实际点击入库灵气由3,966,363降至2,605,291，约减少34%。但仓储和消费链也改变了决策顺序，组合修改后的化神时间没有延长；不能据此宣称已经解决快速通关。不同点击频率的金丹时间不单调，同样反映固定购买策略，不代表玩家最优路线。

本轮优先修正容量与用途，让主动点击优势继续存在。若希望活跃玩家化神阶段明显变长，下一轮应根据真实游玩记录调整突破材料和阶段目标，继续增加该阶段的有效选择；不能只削弱点击。

72小时终局模拟在24.55小时到大乘、32.05小时首次产出灵能、34.61小时到渡劫。515项引擎、17项渲染、173项交互断言全部通过，生产构建与编码检查通过。

## 第三轮：仙缘仓储（当前实现）

另一张渡劫期截图为202仙缘，库房45、旧石殿25、洞天13，仍是分类仓库之前的版本。下一座库房约需34.33万灵木，下一座旧石殿约需39.70万灵石，超过图中33.6万与32.1万容量，属于仓储限制。

增加独立的仙缘仓储倍率：每点 +0.15%，250点前线性，此后递减、渐近 +50%。基础容量和各种扩仓先合计，再统一乘一次，整枚资源最后取整。202点为 +30.3%，按截图近似容量换算，灵木33.6万 → 43.78万、灵石32.1万 → 41.83万，可以支付上述两次扩建。此计算用于核对旧截图的瓶颈，不代替当前分类仓库的真实存档测量。

仓库价格仍指数上涨，仙缘提供额外余地；产出公式、人口容量保持原规则，不凭空发放库存。无仙缘的首世不受影响，转世后基础容量也受益，无限资源保持无限，原超额库存保护继续有效。

`npm run balance -- 24 202` 同策略无事件重修：化神4.50小时、首次灵能21.26小时、渡劫22.32小时，不含额外连续点击与道果。该结果包含仙缘原有产出加成，不能解释为仅靠新增仓储节省的时间。541项引擎、17项渲染、177项交互断言通过。

## 第四轮：降低高阶居所人口（当前实现）

茅屋2、木屋6保持不变；精舍20 → 10、洞府60 → 24，造价与其他效果不变。首座精舍在5茅屋与5木屋的40人口基础上，由增加50%容量改为增加25%。旧截图13精舍、10洞府原本提供860名额，占总1002容量的86%；同数量住房按新曲线总容量512。

精舍在化神后解锁，本轮主要缓和此后的劳动力扩张，不影响此前点击加速。已有旧档人口及分工保留，超过新容量时停收徒；当前旧档产能不会立刻下降，新档和转世后完整采用新曲线。

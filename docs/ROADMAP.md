# 后续方向（未排期）

更新：2026-10-14。本文只记录尚待决定或完成的工作。当前实现见 [DESIGN.md](DESIGN.md)。

## 1. 研究与后期供能

当前研究分组与依赖见 [RESEARCH.md](RESEARCH.md)。修真应用与粒子产线前移已实施，后续只列未完成设计与待测事项。

### 待完善的材料研究

以下三条修真研究线列入后续完善范围，具体节点、费用和效果尚待策划，不代表已调整：

- [ ] **丹道研究**：梳理炼丹术、丹火纯青及后续高阶丹药的递进，评估原理、工艺与专业精研是否完整；检查炼器跨线前置、炼丹设施与配方的解锁顺序。
- [ ] **香火研究**：梳理香火愿、香火志与祖师遗泽的衔接，明确香火获取、愿力研究及高阶用途的能力递进；检查山门、香火鼎和祖师堂的前置与产出闭环。
- [ ] **土木研究**：梳理土木术、土木精要、营造法式及洞天福地的递进，明确与居所营造等技艺的分工；检查住房、宜居设施、仓储和复合建材的前置，避免扩仓与造价形成循环。

### 待完善：供能数值与灵能高阶方案

- [ ] **现有供能与应用校准**：研究费用、建筑主动收益与维护、湮灭自用能、加工与阵印争用灵能的长期节奏；含湮灭炉全局增产（每座倍率、炉数规模）与仙灵力（采仙台／聚仙阵产速与用料）的数值校准。具体清单见 [炼虚后变更文档](炼虚后变更文档.md) §5.7、§6.5。

物质还原灵气、宗门制度选择仍为可选机制：前者需避免与凝石形成获利循环，后者应在口粮、宜居度与作息之间形成真实取舍，尚未实施。

## 2. 中期经营与周边事务

金丹药圃妖兽威胁、四种应对、默认防守、安宁期与冷却已实现。散修、邻宗事务及长期准备能力尚待扩展，保留讨论稿 [MIDGAME-EVENTS.md](MIDGAME-EVENTS.md)。后续观察材料选择是否有真实取舍，事务频率是否适合上班间歇操作。

### 猎杀兽材与来袭关联

猎妖师积累猎备、按猎场与弟子境界出征，兽材用于起居和炼器，并预留妖兽来袭关联。方案见 [BEAST-SYSTEM.md](BEAST-SYSTEM.md)。首轮猎杀（山麓闭环）已实现，深山与禁地、剩余强化技艺及生态关联尚未实现。

后续待策划（未排期）：**伤亡情况**——出征失败或高阶猎场的弟子受伤／身死，及其对队伍、材料和宗门的影响（是否伤残、概率、恢复、身死清空范围等），尚未设计，本次不实现。

## 3. 阶段节奏与重置比较

在当前版本的产业、宜居度和仓储下重新比较每境停留、提前转世及继续冲关的收益。阶段费用结构可以调整，应结合现行产业链与失败机制评估。转世轮次模拟工具尚可补充，优先复用 player-bot 和现有审计工具。

首颗道果已提供自动制作、优先配方和材料保留，后续可评估更多规则或内容解锁。成就目前只记录行为、奖励为0；可考虑专门能力、仓储或事件关联，避免重复永久全局乘区。

## 5. 弟子个体成长

个体成长、基础概率突破、灵根差异、组合筛选与批量管理均已实现。当前规则、数据契约及待设计问题见 [DISCIPLE-PROGRESSION.md](DISCIPLE-PROGRESSION.md)。

- 已实施培养投入：传功（持续灵气加速本人修炼）与个人护道（预付材料加成下一次突破），由《传功授业》研究解锁，见 [DISCIPLE-PROGRESSION.md](DISCIPLE-PROGRESSION.md) §2.1。弟子逐境突破基础费用沿用现值，护道材料另计。
- 待设计培养策略：明确重点人选、材料预留、执行顺序及自动突破的适用范围，降低批量管理负担。
- **天赋后续评估与专长扩展**。首版 32 条天赋（含天级岗位词条）、获取、个人效果、独立随机、旧档规则和组合筛选已实施；原天赋升级（随成功突破自动提升、Lv.1–Lv.3、品级固定）已实施，见 [DISCIPLE-TALENTS.md](DISCIPLE-TALENTS.md)。类型固定、不洗练或替换。炼丹、炼器类效果需先定义弟子如何参与共享加工。
- 个人死亡、境界停滞和独立属性继续暂缓，先评估现有慢修炼与失败重修成本。

培养审计中的材料预留与直接培养只是模拟策略。数值决策前应运行当前版本、多种子及不同上线频率的对照；待设计内容尚未确定具体数值或开发排期。

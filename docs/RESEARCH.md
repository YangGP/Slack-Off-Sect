# 修真线研究：把「修真」做成关于世界本源的科学

> 这是一份**设计研究**，不是已生效的规则。规则在 [DESIGN.md](./DESIGN.md)，
> 实施计划在 [ROADMAP.md](./ROADMAP.md)，改动账本在 [BALANCE.md](./BALANCE.md)。

## 1. 一条判据：修真 vs 技艺

| 层 | 是什么 | 只能做什么 |
| --- | --- | --- |
| **修真** | 对**世界本源**的探索（理论 + 工程） | **解锁**（新建筑 / 新配方 / 新系统）与**规则**（自动化、挂机、折扣） |
| **技艺·法宝** | 手上的功夫（应用与打磨） | 只做**数字**（各种 ratio） |

这条判据已经由断言守着（「修真层以解锁/系统效果为主」「技艺层不含任何解锁/系统效果」）。
所以修真线的优化方向不是"加更多数值"，而是**让解锁本身讲出一个完整的故事**：
每一门学问都要回答"世界是怎么回事"，并因此放行一件新事物。

## 2. 现状盘点（21 个节点）

| 段位（现状） | 节点 | 效果 |
| --- | --- | --- |
| 取材 | 灵植术 / 探矿术 / 土木术 / 香火愿 | 解锁 药圃 / 玄铁矿 / 库房 / 山门 |
| 理论 | 灵源考 | **空效果**（只当描述） |
| 加工 | 炼丹术 / 炼器术 / 符箓入门 | 解锁 炼丹房 / 炼器坊 / 符箓堂 |
| 组织 | 讲经法 / 观星术 | 解锁 讲经堂 / 观星台 |
| 工法 | 阵法初解 / 阵道精通 | 解锁 护山大阵 / 锁灵阵 |
| 分支 | 静心诀 / 灵兽驯养 / 祖师遗泽 / 洞天福地 | 解锁 静心池 / 灵兽园 / 祖师殿 / 洞天·洞府 |
| 系统 | 心有灵犀 / 龟息功 / 广开山门 / 破境心法 | 自动制作 / 离线 +8h / 弟子来得更快 / 破境折扣 |
| 法则 | 因果通感 | 飞升加成 + 仙缘比例 |

**四个问题**：

1. **「聚集灵气」没有理论** —— 灵脉井靠"盖够 10 座聚灵阵"放行、聚灵大阵靠"有藏经阁"放行，
   与猫国"先研究出农业，才能建牧场"的科学感相比，少了"先懂原理"这一步。
2. **「利用率」散落各处**，而且最直接的那根杠杆没人管：**凝气成石的 45 灵气 → 1 灵石**
   （玩家自己提过"灵石缺口有点大"）。
3. **完全没有「物 → 气」的方向** —— 只有气凝成物（凝气成石），没有"剥离物质中的灵气"。
   这正是你提的那条，而且它是唯一能同时解决**灵木过剩**的机制（见 §5.2）。
4. **物资主题只有"获取"没有"精炼"** —— 灵木/灵草/玄铁 各有产出建筑，
   但没有"深入研究这种物质、把它拆开用"的学问。

## 3. 五段主线（从"气"到"则"）

| 段 | 这一段的科学问题 | 该段放行什么 | 该段的材料花费来自 |
| --- | --- | --- | --- |
| **Ⅰ 感知** | 灵气是什么？从哪来？怎么快点聚起来？ | 聚灵阵 → 灵脉井 → 聚灵大阵 的**理论前置** | 灵木、灵石 |
| **Ⅱ 转化** | 气能不能变成物？物能不能**还原**成气？ | 凝气成石（已有）、**化物质气**（新）、铸币效率 | 灵石、灵木 |
| **Ⅲ 分化** | 不同的物质里藏着**不同的气** | 木 / 草 / 铁 各自的「取 → 炼 → 用」小链 | 灵草、玄铁、丹药 |
| **Ⅳ 利用** | 怎么少耗多用？怎么让宗门自己运转？ | 自动制作、挂机、破境折扣、弟子口粮制度 | 丹药、符箓、法器 |
| **Ⅴ 法则** | 星象、因果、飞升之上的东西 | 观星、阵法、因果、洞天、道果 | 符箓、法器、香火 |

这条主线的好处：**每一段都对应一种"新提问方式"**，而不是"更贵的同类条目"。
玩家读到节点名就能猜到它在问什么 —— 这就是"像科学一样"的体感来源。

## 5. 三个值得单独说的机制

### 5.1 铸币成本研究 = 最直接的「灵气利用率」

`凝气成石` 现在固定 45 灵气/枚。加两档研究降到 40 / 35 —— 这直接回应用户提过的
"灵石缺口有点大"，而且**它是利用率而不是产量**，符合"加大对灵气的利用率"这个提法。

### 5.2 「化物质气」= 剥离物质中的灵气（**同时是灵木的泄洪口**）

| | 数值 |
| --- | --- |
| 配方 | **炼木归元**：灵木 100 + 时间 1.5 秒 → 灵气 60 |
| 持续排水 | 满速连续制作 = **67 灵木/秒** ≈ 12 小时灵木流入（145/秒）的 **45%** |
| 灵气回补 | 40 灵气/秒 ≈ 12 小时灵气净额（约 150/秒）的 **27%** |

为什么它重要：上一轮做「木板」时得出的教训是**一次性建材追不上指数产量**
（12 小时 6,650 方木板，加大需求后推演轨迹一字不差）。而这条配方是**持续消耗**，
正好补上那个缺口 —— 所以**木板解决"建材层级"，炼木归元解决"泄洪"**，两者不冲突。

风险：它是**新的灵气来源**（会放大整条曲线）。所以放在 Ⅱ 段偏后（感悟 600），
并且要按 §8 的方法实测；若放大过头，先降产率（60 → 45）而不是取消。

### 5.3 精炼阶梯：不新增效果键

「木灵萃取」这类"越研究越出材"的节点，**不需要新的效果字段** ——
`craftBonus` 本来就会放大配方产出（小数累积，见 DESIGN §7）。
所以精炼阶梯可以完全用现有词汇实现，只加数据。

成本规范两条：

1. **材料花费必须来自它所在的时代**（Ⅰ：灵木灵石；Ⅱ：+灵草玄铁；Ⅲ：+丹药符箓；Ⅴ：+法器香火）；
2. **同段内相邻节点约 ×1.5~2 倍**，跨段约 ×3 —— 现有曲线大致如此，规范化只是让它可预测。

## 9. 风险与不变量

1. **新配方会放大曲线**（炼木归元是新的灵气来源）→ 一次只加一条，加完立刻跑 12/48 小时对照；
2. **降铸币成本实测过影响很大**：45 → 40 曾让 12 小时人口从 142 涨到 176 ——
   所以两档都要配上更晚的门槛，或把上限停在 35；
3. **不变量要守住**：修真层只放解锁/系统效果（已有断言）、每个解锁节点必须真的解锁某物、
   每座新建筑都要能自举（仓储定点断言会盯着）；
4. **不要为了"好看"加纯数值节点** —— 那是技艺层的工作，混进来会破坏两层的分工。

**推迟的一项**：原草案里的 **「地脉图」**（"灵脉井的效果按地脉放大"）**没有做** ——
它是纯数值节点，会破坏"修真只做解锁与规则、技艺才做数字"的分工（§1 的判据）。
要保留这个想法，得让它**解锁某样东西**，例如：

- 解锁灵脉井的**第二档形态**（新建筑，如「地脉井」）；
- 或者解锁一条**规则**（例如"灵脉井可以像工坊那样停用/超频"）。

实测：24 小时剩 5 项、48 小时剩 2 项、72 小时剩 1 项（改造前是 24 小时 21/22、之后一路空白）。

## 12. 与猫国科技树的对比

### 12.1 结构对照（都是从源码/数据里数出来的）

| 维度 | 猫国 | 我们 |
| --- | --- | --- |
| **跨度** | science **30 → 数十万**（后期是多资源复合成本，如 `science 275,000 + blueprint 250`）—— 约 **一万倍** | 感悟 **40 → 50,000** —— 约 **1,250 倍** |
| **能撑多久** | 铺满数月（科技贯穿整个游戏） | **24 小时参悟 21/22、48 小时仍是 21/22**，72 小时才 22/22 |
| **依赖表达** | **没有 `reqs`（0 处）**：靠 `unlocks.tech: [...]` **正向声明** + 价格阶梯 | `needs` **反向声明**（"我要谁"）+ 价格 |
| **解锁清单** | 每个科技都有显式 `unlocks: { buildings, jobs, tech, upgrades }`，界面直接列出来 | 22 个节点里**只有 6 个**写了 `note`，其余要靠反查被解锁条目的 `needs` |
| **数值效果** | 45/109 条科技带 `effects`，并单开一栏 `effectDesc` 说明 | **刻意不做**（数值归技艺层）—— 这条分工我们要保住 |
| **选择/分支** | 有**政策层**（文化购买、互斥：君主 / 共和 / 社会主义 / 法西斯） | 无 |
| **解锁类别** | tech / buildings / jobs / upgrades / policies / challenges | 建筑 + 系统开关 |

### 12.2 由此得到的优化建议（按性价比排序）

**A. 把节点铺满时间线（最重要）**
现在的问题很具体：**第二天起研究线是空的**。目标可以量化 ——
**任何时刻都还有 5~10 个没研究完的节点**（直接写成断言：`24 小时未参悟数 ≥ 8`）。
做法：五段各补 3~5 个，且后期节点的花费**吃当期产物**（丹药 / 符箓 / 法器 / 木板 / 香火），
这样"研究"与"生产"在每个时代都咬合（猫国的后期科技正是这个形状）。

**B. 补「解锁清单」（最便宜、立刻见效）**
猫国把 `unlocks` 做成显式字段，玩家一眼看到"这门学问开了什么"。
我们两条路：

1. 手写 `note`（6/22 → 22/22）；
2. **让界面自动推导**：扫描所有建筑 / 配方 / 技艺 / 法宝的 `needs`，反查"谁解锁了我"，渲染成清单。

推荐 2 —— 不会与数据脱节，而且可以配一条断言：
**每个修真节点至少被一样东西需要**（否则它就是装饰品，见 §1 的判据）。

**C. 界面按五段分组显示**
数据里已经有五段注释（第 1 步重排时写的），但面板仍是平铺列表。
加小标题即可让"从气到则"的主线真正可见。

**D.（可选）学 `unlocks.tech` 的正向索引**
为每个节点声明"它开启了谁"（可由 B 的推导自动生成），
好处是 UI 与校验都能直接用，不必反查。

**E.（可选、较大）政策层 = 道统选择**
猫国最有意思的一层不是科技而是**政策**：用文化买、**互斥**、逼玩家做选择。
我们可以在 Ⅴ 段或道果层做「**道统**」（剑修 / 丹修 / 符修，半互斥），
它提供的是"分支抉择"，与现有的线性解锁互补 —— 这也是现在整棵树唯一缺的东西。

**F. `effectDesc` 的启示（小）**
猫国给数值效果单开一栏说明。我们的修真节点目前**没有效果说明**，
节点名之外看不到"研究了会怎样"。每个节点补一句"因此如何"，成本极低。

### 12.3 不该学的

猫国让科技直接给产能乘区（45 条带 `effects`）。我们的分工更清楚 ——
**修真只解锁与定规则、技艺只做数字**（已有断言守着）。
混进来会让"我该去哪里找数值成长"这个问题失去答案。

## 13. 第二种驱动：阴阳分灵与湮灭（灵气分子层）

> **状态：已实施（方案 A：逸散）**。采用与否见下：灵宝暂不参与（用户要求先不做），
> 实施记录与两次"造价超过仓储上限"的翻车见 [BALANCE.md](./BALANCE.md)
> 《第二种驱动：阴阳分灵 → 湮灭 → 灵能（方案 A 已实施）》。

### 13.1 一句话

**灵气不是基本粒子**：它由**正灵子**与**负灵子**结合而成的**灵气分子**构成。
聚灵阵收来的是"分子态"的灵气；把分子拆开（**阴阳分灵**），再让正负灵子**湮灭**，
就能得到密度极高的**灵能** —— 而灵能会**反过来把基础物资的产出拉高一个数量级**。

对照猫国的**核反应堆**：那边是"反应堆 → 能量 → 磁电机/油井/加速器全部提速"。
我们这边多了一层好玩的对称：**原料也是灵气本身**（拆分子要烧灵气，湮灭又不再产出灵气），
所以它既是产能引擎，也是灵气最大的去处 —— 中期那个"灵石缺口 / 灵气被吃光"的老问题，
到了这里会变成一个**值得权衡的取舍**，而不是单纯的通胀。

### 13.2 三个新资源

| 资源 | id | 计数 | 来源 | 去向 |
| --- | --- | --- | --- | --- |
| **正灵子** | `yangParticle` | 小数 | 阴阳分灵阵（烧灵气） | 湮灭炉（与负灵子成对消耗） |
| **负灵子** | `yinParticle` | 小数 | 阴阳分灵阵（与正灵子等量） | 湮灭炉（同上） |
| **灵能** | `qiEnergy` | 小数 | 湮灭炉 | **不消耗，而是逸散**（见下）；存量换算成基础物资倍率 |

三者都用**小数**计数 —— 这是刻意的对比：前面所有高级材料（木板/丹药/…/灵宝）都是**整枚**，
而粒子与能量是"物理量"，本来就该是连续的。

### 13.3 两座建筑 + 两个修真节点

| 建筑 | id | 造价 | 维护费 | 产出 | 门槛 |
| --- | --- | --- | --- | --- | --- |
| **阴阳分灵阵** | `splitArray` | 灵石 40 万 + 感悟 15 万 + 法器 80 | **灵气 8/秒** | 正灵子 +0.02/秒、负灵子 +0.02/秒 | 《阴阳分灵》 |
| **湮灭炉** | `annihilationFurnace` | 灵木 20 万 + 灵石 60 万 + **灵宝 4** | 正灵子 0.02/秒 + 负灵子 0.02/秒 | **灵能 +0.06/秒** | 《湮灭法》 |

| 修真节点（Ⅴ 段） | 花费 | 作用 |
| --- | --- | --- |
| **阴阳分灵** | 感悟 12 万 + 灵石 8 万 + 灵器 6 | 解锁阴阳分灵阵 |
| **湮灭法** | 感悟 30 万 + **灵宝 2** + 九转丹 20 | 解锁湮灭炉 |

注意湮灭炉要吃 **灵宝 4** —— 于是"第二种驱动"不是凭空起飞的：
它站在**整条进阶品链**（玄钢 → 灵器 → 灵宝）的肩膀上。这也让进阶品的"可重复去向"多了一处。

### 13.4 灵能怎么变成产能（核心机制）

两种做法，我推荐第一种：

**A. 逸散（推荐）**：灵能**不消耗**，而是**每秒逸散 0.5%**。
于是存量稳态 = 产出 ÷ 0.005 = **200 秒的产出**。
好处：不需要为每座建筑记"耗能"的账本，机制只有一条公式；
而且"湮灭能不稳定、会逸散"本身就是设定。

```
稳态灵能 ≈ 湮灭炉数量 × 0.06 ÷ 0.005 = 炉数 × 12
基础物资倍率 = 1 + softCap(灵能 × 0.02, 5)      // 上限 +500%
```

**B. 消耗（猫国式）**：每座受益建筑按秒吃掉灵能，不够就降速。
更贴近猫国，但要给每座建筑记一条能耗，状态与界面都要复杂一档。

### 13.5 数值直觉（按方案 A）

| 湮灭炉 | 稳态灵能 | 基础物资倍率 | 代价（灵气） |
| --- | --- | --- | --- |
| 1 | 12 | **+24%** | 分灵阵 8/秒 |
| 5 | 60 | **+120%** | 40/秒 |
| 10 | 120 | **+240%** | 80/秒 |
| 21 | 250 | **+500%（上限）** | 168/秒 |

也就是说：**满配的第二种驱动给基础物资 +500%，代价是 168 灵气/秒**（还要 21 座分灵阵与湮灭炉的造价）。
这是个真正"极大加强"的档位，但它同时是**灵气黑洞** —— 要不要上，取决于玩家怎么分配灵气。

**只作用于基础物资**：灵木 / 灵石 / 玄铁 / 灵草 / 木板（引擎里就是往 `acc.ratio[res]` 里加一项）。
丹药以上的成品、感悟、香火**不吃**这个加成 —— 否则后期会变成"一条倍率通吃"，
把之前辛苦分开的三层（资源 / 精料 / 学术）又糊成一团。

### 13.6 为什么这是"第二种驱动"而不是又一个加成

- 它的**输入是灵气**（第一种驱动是聚灵阵把灵气做出来）→ 两者咬合，而不是并列；
- 它的**输出是基础物资倍率**（而不是新资源）→ 直接放大前面所有玩法的底噪；
- 它的**代价是持续的灵气开销**（不是一次性造价）→ 玩家要为它调整阵徒/灵脉井/凝石的配比；
- 它是**第一个"存量驱动"的机制**（其余全是"建造即生效"）→ 界面上需要一行新的读数（灵能与其倍率）。

### 13.7 风险与验收

| 风险 | 挡法 |
| --- | --- |
| 让前期失衡 | 门槛压在 Ⅴ 段（两个新修真节点 + 灵宝 4），到不了就是到不了 |
| 灵气被抽干导致游戏卡死 | 分灵阵的维护费是**可停用**的（本作所有维护费建筑都能停）；停用即回血 |
| 加成溢出到不该吃的资源 | 只写进 5 种基础物资的 `acc.ratio`；加断言：丹药/感悟/香火不吃该加成 |
| 稳态无界（一直涨） | 逸散使其有界：稳态 = 产出/0.005；断言"长时间空转后灵能收敛" |
| 成为唯一正解 | 代价是 168 灵气/秒；在渡劫期灵气净产出有限时，上满它要牺牲凝石/维护余量 |

**验收方式**：`npm run balance -- 48 72 96` 看它把 96 小时那一档推到哪里；
`npm run audit -- qi 96` 看灵气的进项/去向是否被它改写；断言四条（见上表最后两行 + 审计的两条通用规则）。

### 13.8 实施顺序（每步都能单独验证）

1. **粒子与分灵阵**：加两个粒子资源 + 阴阳分灵阵 + 《阴阳分灵》，跑审计（来源/去向齐全）；
2. **湮灭炉与灵能**：加灵能资源（小数）+ 湮灭炉 + 《湮灭法》 + 逸散机制，断言"空转后收敛"；
3. **倍率与界面**：把灵能写进基础物资的 `ratio`，界面加一行读数（灵能 / 当前倍率），
   并加断言"只作用于 5 种基础物资"；
4. **节奏与文档**：重跑节奏表、更新 TABLES、BALANCE 记一笔。

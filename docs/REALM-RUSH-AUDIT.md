# 冲境优先策略耗时实测

测量日期：2026-10-14；游戏版本：0.36.0。

本报告记录同类研究递进链进一步收紧前的规则；后续研究前置调整后的飞升耗时需重新测量。

2026-10-15 已复测当前工作区：固定种子 1、主动分工、无事件、强制成功的 baseline 路线 21.215 小时可飞升。此结果包含后续研究与仓储调整，条件和限制见 [提交前数值检查](NUMERIC-AUDIT-2026-10-15.md)，下表保留原测量历史。

## 测量条件

- 全新存档，初始仙缘、道果均为 0，不主动转世、不祭炼法宝。
- 使用真实引擎支付资源、生产、加工、研究、建设和破境；每 5 秒决策，每分钟调整基础岗位。
- 时间为累计有效运行小时，不是游戏历法，也不是玩家手动操作时长。
- 关闭随机事件；仅开局手动吸气，之后没有持续连点。未模拟离线上限截断。
- 固定随机种子 1。单个样本不能作为平均耗时、理论最快纪录或普遍下限。

## 结果

| 策略 | 破境结果 | 飞升耗时 |
| --- | --- | --- |
| 参照玩家保留常规发展，优先制作破境材料、材料齐即冲境 | 强制全部成功，不带辅助材料 | 25.058 小时，约 25 小时 3 分钟 |
| 同一参照玩家，筑基之后选择全部辅助材料 | 真实随机判定 | 28.782 小时，约 28 小时 47 分钟 |
| 跳过非必要发展，只保留材料前置、扩仓、住满时扩屋、拥挤时改善宜居 | 强制全部成功，不带辅助材料 | 模拟 168 小时仍未飞升，停在大乘 |

严格冲境模式在大乘阶段追踪两套分灵、偏极、湮灭设施作为供能建设目标；仍须实际支付材料，未赠送设施或资源。

| 首次到达 | 常规发展、冲境优先、真实随机 | 严格冲境、全部成功 |
| --- | ---: | ---: |
| 筑基 | 13.476 小时 | 5.004 小时 |
| 金丹 | 13.683 小时 | 8.978 小时 |
| 元婴 | 13.918 小时 | 14.454 小时 |
| 化神 | 15.933 小时 | 24.378 小时 |
| 炼虚 | 17.276 小时 | 29.997 小时 |
| 合体 | 17.753 小时 | 38.439 小时 |
| 大乘 | 18.967 小时 | 105.436 小时 |
| 渡劫 / 可飞升 | 28.782 小时 | 168 小时内未到达 |

随机样本在冲炼虚时失败一次，没有掉境或身死；后期顺利，因此这个样本的耗时不代表风险较大的完整分布。

## 对节奏的判断

保留常规发展时，确实有中段连续跨境现象：全部成功的样本，从筑基到元婴仅约 4.6 分钟；真实随机样本也仅约 26.5 分钟。突破后没有额外发展完成度门槛，飞升唯一条件是到达渡劫。

完全跳过非必要投资会降低前期支出，但会削弱后期供料和加工能力。这次严格冲境样本在 168 小时拥有足够的直接破境灵机、灵气和晶银，但飞升阵印为 0/300、灵宝为 0/12，尚未准备好最后一次冲关。不能据此推出所有冲境策略都至少需要七天，也不能声称其已找到最快玩法。

目前测量支持的结论是：有常规产业发展的顺利冲境路线约一天可飞升，中段跨境尤其短；字面意义上的“其它发展全跳过”在这套策略中反而慢得多。若要估计真实玩家平均耗时，仍需多种岗位与投资策略、多随机种子，以及实际上线频率的样本。

## 复现

先构建一次，再逐个运行，避免重复构建清空结果目录：

```powershell
npx vite build --ssr tools/breakthrough-time-audit.mjs --outDir .smoke-breakthrough-time --emptyOutDir
node .smoke-breakthrough-time/breakthrough-time-audit.js baseline 1 72
node .smoke-breakthrough-time/breakthrough-time-audit.js aided 1 72
node .smoke-breakthrough-time/breakthrough-time-audit.js rush 1 168
```

`rush-naked`、`rush-aided` 可分别测量严格冲境策略下不带辅助材料、带辅助材料的真实随机结果。

本次只扩充审计策略；验证通过 `npm run check:tools`、`npm run check:encoding` 与 `git diff --check`。编码检查有原有参考目录的 CRLF 提示。

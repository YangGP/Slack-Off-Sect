# 修真研究方向

更新：2026-10-09。当前规则与全部39项节点见 [CULTIVATION-REVIEW.md](CULTIVATION-REVIEW.md)，本文只保留尚值得讨论的研究问题。已实施节点、旧费用草案与重复实施清单移出本文；改动历史见 [BALANCE.md](BALANCE.md)。

## 当前定位

修真负责理解原理、开放建设与系统；技艺负责掌握加工和提高专业收益；法宝负责可祭炼的专门效果。三者共用感悟与材料，允许跨层前置。五段分类已实现，分灵→湮灭的逸散机制已实现，但五段并不构成顺序阶段。

## 需要确定的边界

| 问题 | 当前事实 | 审视方向 |
| --- | --- | --- |
| 修真研究与修行 | 宗门整体支付资源破境，没有个人修炼过程 | 科技树是否继续承载修真主题，或要引入阶段性的修行规则？ |
| 原理与工艺 | 修真依赖技艺，也有同名节点 | 理清发现、应用、精研三类成果的命名及依赖 |
| 五段分类 | 制度组含器道、符法与洞天 | 根据玩家可理解的研究问题重分组，或保留主题分类 |
| 原料与加工增益 | ratio 与制作收益分别结算 | 每个研究应明确改善供料、配方、产出、仓储或规则中的哪一项 |
| 灵能受益范围 | 普通生产ratio包含灵石、木板，但不提高相关加工收益 | 决定是否调整受益资源、增加专门加工机制，或修正对外说明 |

## 保留的可选机制

- **凝石利用率研究**：研究降低45灵气的基础兑换成本。仍未实现；旧40／35草案不作为预定数值，需重新测量对早期货币、人口和建设的影响。
- **物质还原为灵气**：为富余原料增加持续去处。仍未实现；需避免与凝石形成可无限获利的循环，也不能假定当前灵木始终富余。
- **宗门制度选择**：以口粮、士气或作息之间的取舍改变经营方式。仍未实现，不应仅成为另一项永久百分比加成。
- **弟子个体成长**：独立于宗门境界的修炼、突破、灵根和天赋草案见 [DISCIPLE-PROGRESSION.md](DISCIPLE-PROGRESSION.md)，尚未排期。

## 评估原则

新增节点需回答“研究后能做什么”；纯效率强化优先归入技艺或法宝。前置与境界以实际完整链为准，初学费用不能要求尚无来源的本工艺产物。高级材料需要有建设、祭炼或持续经营的去处。

先确定体系定位及每境新能力，再安排产业链和成本。用相同策略、事件设置及历法比较改前／改后，关注阶段停留、容量自举与手动／自动加工差异；不得用早期版本的时间表直接校准当前版本。

# 游戏设计与当前规则（v0.33）

更新：2026-10-12。本文描述当前实现。完整条目、费用与门槛由 [TABLES.md](TABLES.md) 从源码生成；研究结构见 [RESEARCH.md](RESEARCH.md)，符文与建材见 [CRAFT-PROGRESSION.md](CRAFT-PROGRESSION.md)。历史平衡与测量保存在 [BALANCE.md](BALANCE.md)，未实施方向见 [ROADMAP.md](ROADMAP.md)。

## 1. 定位与设计目标

纯前端宗门放置经营游戏，参考猫国的资源池、劳动力分配、叠加建筑和加工体系。主要决策是生产分工、研究投资、加工目标、营造扩仓和重置时机。宗门境界提供全局倍率，弟子拥有独立修为、境界与灵根，个人天赋已加入；宗门破境按概率结算，可用天材地宝与香火增加成功率。

## 2. 核心循环

点击取得灵气 → 聚灵阵生产 → 首间茅屋与弟子 → 徒手采木、扩仓与采石 → 职位及原料产业 → 修真和技艺 → 加工、建设、扩仓 → 破境 → 转世／飞升。

开局没有资源、弟子或建筑。第一座聚灵阵需灵气25，每世第一间茅屋仅需灵气80，后续茅屋按灵气80与灵木20的基础价格递增。首屋优惠随存档保存，拆除不再次领取，转世或飞升重置。樵夫无需伐木场即可采木；基础木材容量200，伐木场需要茅屋，基础造价为灵气150与木材60；先以木材180建谷仓扩仓，伐木场与谷仓均建成后可用木材300建采矿场，派遣矿工后持续供料。木屋需灵木300与灵石20，并要求茅屋×5与居所营造，不再依赖玄铁。早期建筑以木材营造，石材从采矿场之后的库房与聚灵大阵等建设开始引入。移除拾取石材与凝气成石，保留点石成灵（矿石3与灵气15）；凝灵诀改为在凝液法之后参悟，节气满仓时按凝气成液配方自动凝液。

## 3. 资源系统

资源包括基础物资、加工品与永久成长记录。灵气、灵木、矿石、玄铁、灵草、灵机和香火支撑生产与经营，加工品连接建设及破境；灵液承接凝聚配方（凝晶、育仙草），灵气分子、正负灵子与灵能构成后期粒子产线。灵气形态阶梯为气→液→晶→灵气分子→正负灵子→灵能（灵气分子是一正一负两枚灵子相抱的最小稳定单元，见 [SPIRIT-ENERGY.md](./SPIRIT-ENERGY.md)）；灵石是含灵气的矿物，采集与制作双来源，不在阶梯上；矿石是普通岩石，凡石砌基的建材，点石成灵以矿石3加灵气15凝成灵石。仙缘和道果是永久成长记录，不走常规每秒生产。

### 3.1 数量与价格

标记 integer 的资源整件计数：费用向上取整、库存与奖励按相应规则取整。制作收益的小数累计在 craftProgress，累计足一件才入库。资源增加受实际容量限制，旧档或拆仓后超额库存允许消费，不能继续增长。

### 3.2 仓储上限模型

上限 =（基础容量 + 专属扩仓 + 通用扩仓 × 该资源 storageWeight）× 仙缘仓储倍率；整件资源最后向下取整。基础物资、普通成品、进阶成品采用不同权重；专属仓储全额计入。完整权重和容量见数据表。

谷仓、库房、材料库、玄库、药藏、法藏、洞天和通天塔构成扩仓链。建筑的 storage、storageAll、maxDisciples 按已建数量生效，停用或缺料不移除这些容量／人口效果；生产、加工增益及带维护费建筑的宜居度、防灾等运行效果按有效供给生效。

### 3.3 灵气与点击

灵气同时用于弟子口粮、凝石、加工与设施维护。点击收益不乘全局产出倍率：2.5 + 0.5 × 折算聚灵阵数；按已建数量计算，前20座全额计入，超过20的部分按 √(超出数量) 折算。

宗门页提供开局可用的催生灵木入口，与炼制页共用配方：每份灵气5换灵木1，受通用制作加成影响，可批量与自动制作，满仓暂停；不受普通生产或宜居度倍率影响。

### 3.4 渐进露出

建筑已建过则持续显示；未建时需满足全部 needs，并让各项造价资源的历史峰值达到基础成本的 unlockRatio（默认30%）。部分建设目标设为0，前置满足即显示。花光库存不抹去峰值。

修真、技艺与炼制配方不在开局展示整棵树。未解锁条目只有在自身条件中的境界达标（如有）、研究前置全部掌握后才预告；没有研究前置的基础条目则需先建立对应产业，才提示下一档建筑数量要求。已掌握内容始终保留显示，实际参悟与制作仍需满足完整前置和材料费用。修真不设境界条件；前置满足但灵机费用超过当前仓容的研究归入“需扩充灵机上限”折叠区，扩仓后进入参悟列表；已有库存可支付时仍直接显示。

引气诀与口传心授需先参悟灵源考；伐木要术需先参悟木作器械；阵法精要需先掌握观气法与引气诀。上述研究前置与原有建筑前置共同生效。

## 4. 弟子、职位与宜居度

弟子职位人数输入框在 input 事件时立即分配，支持原生增减按钮；编辑中的草稿不随产出刷新被覆盖，提交或失焦时按可用人数与整数规则归一化显示。

有空房时默认每15秒来一名弟子，到来间隔 = 15 ×（1 − min(0.8, arrivalBonus)）。满员、断粮或宜居度存在离开风险时暂停来人；满员及拥挤风险暂停期间不积累到来时间。

六种职位为阵徒、樵夫、矿工、采药人、悟道者、香使；分配人数不得超过总人口，闲置弟子也消耗口粮。每名弟子消耗0.25 × 宗门境界倍率 × 个人有效境界倍率灵气／秒，减耗最多85%。个人有效境界取实际境界与宗门境界中较低者，其倍率只增加自身岗位产出与口粮，不增加建筑产出或每份制作收益。矿工的多个产物共享同一批人力，具体来源与倍率见下文和数据表。

弟子从凡体开始，基础每秒1修为乘灵根速度，工作与离线同样修炼；三灵根各段净修炼时间为1、3、8、16、24、36、48、72、96、120小时，满本境修为停止，等待玩家突破。突破目标不能高于宗门；宗门退境保留弟子实际境界和修为，个人有效倍率与口粮暂时下降，宗门恢复后恢复。最高个人境界为渡劫。

新弟子入门时按天／异／双／三／四／五灵根的1%／4%／10%／25%／30%／30%权重抽取一次，修炼速度系数为2／1.6／1.3／1／0.9／0.8。灵根只影响修炼速度，不直接影响岗位产出、口粮、突破成功率或失败损失。结果及独立抽取序列持久化，读档不重抽；已有弟子缺灵根时补三灵根，保留进度。管理栏支持境界与灵根组合筛选、按本境进度比例或速度排序，批量操作限于当前筛选内人选；收徒纪事展示灵根。

个人突破逐项消耗目标宗门基础破境费用的1%，向上取整且每种至少1件，不使用宗门折扣或护道材料。个人基础成功率为对应宗门基础成功率的50%，宗门每高于目标一境加10个百分点成功率，最高99%；失败损失20%本境修为，调息60秒，不降境或死亡。批量突破逐人扣料与判定，跳过未就绪者，遇材料不足停止，不在离线期间自动突破。

弟子管理默认收起，点击展开后在原职位分配区域覆盖显示，点击收起或按Esc返回职位分配；同页开合保留筛选和选择，重新进入弟子页默认收起。按境界分类显示人数及待突破人数，每页30名，支持跨页选择当前分类、批量调岗与突破；职位表显示该岗位平均个人产出。旧档保留人口与职位，补建凡体、零修为的独立记录，姓名及身份持久化。到来、事件招入及流失同步维护个体；转世、飞升及宗门身死重修清空个体。完整设计与后续方向见[弟子成长](DISCIPLE-PROGRESSION.md)。

普通聚灵阵保留每座0.3灵气／秒自带产出。其它建筑不再自带灵气、灵木、矿石、玄铁、灵石、灵草、灵机或香火产出；需要分配弟子到对应职位。建筑仍提供现有的岗位解锁、产出加成、仓储、宜居度和其它效果，维护费照常。分灵阵、偏极阵、湮灭炉的特殊资源产线保留。

采矿场启用时，矿工每人每秒基础产出矿石0.15；掌握探矿术后同时附产玄铁0.015，每座启用灵矿石另为每人附产灵石0.0015。矿工岗位加成和对应资源倍率共同生效。每座启用采矿场提供矿石、玄铁、灵石生产产出各10%的资源加成，多座相加，停用移除。矿石与玄铁的人力基础产出不随矿场数量重复叠加，灵石附产按灵矿石启用数量叠加。

每座启用药圃提供灵草生产产出10%的资源加成，多座相加，停用移除；采药人基础产出不随药圃座数重复叠加。建筑效果条目按资源栏的可见口径展示：首次取得前隐藏对应资源的产出、制作加成、仓储及职位产出等效果；已有库存、历史峰值或已发现记录时显示，库存归零不会再次隐藏。此规则仅控制效果展示，实际结算及价格、维护和解锁条件仍按数据计算。

弟子管理可单人或批量逐出师门。每人费用＝累计灵气消耗×（在宗门已满游戏年数＋1），向上取整后合计支付；累计消耗包括个人口粮和个人突破支付的灵气，口粮按当时实际境界、减耗和供给比例记账。未满一年按1倍，满一年按2倍，以此类推；一年为360游戏天，即1080现实秒。在线与离线均累计，修满或调息期间继续计时；新弟子只累计入门后时间。旧档缺少历史停留和消耗时两项补零，从更新后开始记录，不推测历史。逐出前显示费用并确认，移除个体成长、总人口和岗位分配，空出的居所按原规则继续招入新弟子；只操作当前筛选内的所选个体，灵气不足时整批不扣费、不移除。

宜居度H = 20 + 定额加成 + 已入住配套 + 断供惩罚。H低于0时每点全局减产1%，H高于弟子数N+20时每点全局增产0.25%，最高增减50%。N≥20且H<N−20时岗位产出乘0.5；N≥50且H<N−50时每60秒检查离开概率并暂停收徒。断供惩罚范围−60～0，断供每秒下降6，正常供粮每秒恢复2；长期断粮独立按25秒流失。完整公式、边界及供给见 [HABITABILITY.md](HABITABILITY.md)。

## 5. 建筑系统

建筑按产业与用途分组，价格按现有数量指数递增。连续购买从现有数量开始逐座累计造价，整件材料按价格函数取整。拆除返还被拆数量对应原购价的一半，实际入库仍受容量约束。

### 5.1 效果字段语义

| 字段 | 用途 |
| --- | --- |
| prod | 每秒基础产出 |
| ratio / jobRatio | 对应资源普通生产／岗位增产 |
| craftBonus / craftBonusByResource | 通用／专业制作收益 |
| storage / storageAll / maxDisciples | 专属容量／按权重折算容量／人口容量 |
| habitability / habitabilityPerHousing | 定额宜居度／每个已入住名额的配套 |
| disasterGuard / disasterGuardByResource / consumeRatio | 通用防灾／指定资源防灾／弟子减耗 |
| autoCraft / autoCondense | 常驻自动加工／节气满仓凝石 |
| offlineHours / arrivalBonus / breakthroughDiscount | 离线上限／招募加速／破境减费 |
| ascendBonus / karmaRatio | 仙缘结算收益／仙缘产出乘区固定附加值 |

建筑、技艺与法宝的永久产业增益按资源区分，当前条目不提供 ratioAll；成就全局奖励当前也为0。引擎仍保留该字段的处理能力。

### 5.2 维护费与停用

带 upkeep 的设施可以停用。有效运行数量为已建数量 × 启用状态 × 供给比例，维护费与运行收益同步缩放；缺料按供给运行而非负库存借贷。容量与人口效果按3.2节处理。

## 6. 修真与技艺·法宝

v0.34 移除灵兽园、灵兽驯养与驭兽铃。旧档在未知条目过滤前按参考费用补偿：旧园累计造价返还 50%，研究和法宝炼成、祭炼投入全额返还；独立兽系退役标记防止重复补偿，超仓材料可保留并正常消费。新狩猎体系、狩猎技艺及来袭关联见 [BEAST-SYSTEM.md](BEAST-SYSTEM.md)，仍为待实现方案。

金丹前以灵源考为唯一研究入口，核心链逐步推进：灵源考 → 灵植术 → 炼丹术 → 探矿术 → 木作器械 → 土木术 → 炼器术 → 丹火纯青 → 心有灵犀。灵源考另分出观气法；观气法与引气诀共同承接阵法精要，掌握后开放聚灵大阵；观气法还分出《灵气测定》，把氤氲灵气按「一息」之度单位标准化；凝聚章的《凝气化液》承接测定，作为凝气成液配方的放行前置。灵植术后需先建药圃，木作器械需炼铁炉与两座伐木场，其他建筑前置也继续生效。

支线保留选择：炼器术后先建炼器坊，再开放符文入门；掌握土木、符箓并建符箓堂后开放香火愿，再以山门×3开放广开山门。破境心法需掌握土木术与丹火纯青，不要求先发展香火；流水作坊接在心有灵犀之后，不作为其他早期产业的必修前置。研究按产业与知识递进，灵源考是唯一修真入口，其他研究均沿前置知识链开放；灵机仓容不能代替前置研究，不限定同时可参悟数量。御剑术需掌握淬玄工艺并积累12000灵机。旧档已掌握条目继续生效。

修真、技艺和法宝共享灵机与已学记录；building、buildings、upgrade、upgrades、realm 前置共同生效，允许跨层引用。

早期没有空间技艺：储物袋、纳物诀已删除，旧档对应已学记录读档时清理；叠匣术为库房解锁的普通装箱码放。空间收纳与洞天营造由后期洞天福地、纳物戒承接。

灵能枢需要持续供能：未祭炼时每秒满供消耗1灵能，灵气产出+50%、灵机产出+25%；祭炼倍率同时放大效果与耗能。库存与实时产出共同承担供能，不足时效果和消耗同比缩减，无供能时停效。消耗列入资源账目，灵能逸散另行结算；法宝页显示当前效果、供能比例及满供耗能。

修真页按灵气五章、独立心法支线、材料六族和宗门经营组织（见 [RESEARCH.md](RESEARCH.md)）。灵气五章为观气、凝聚、调控、拆解、归源；拆解集中展示灵子、分流、湮灭和灵能应用。心印法、大乘心印与大乘心经归入「心法研究 · 心印与修持」，仍由候时法承接，费用、效果、前置和存档 id 不变。材料研究按草木、金铁、符文、丹道、香火、土木组织原理、工艺与精研；经营组承接制度、招募、离线和自动化。研究负责知识解锁、系统及专业成果，技艺负责通用增益，法宝可重复祭炼；分组只是导航，不要求依次学满章节。

法宝基础效果在炼成时生效，n级祭炼效果为基础 ×（1 + 0.3n）。下一次费用的非灵机部分沿用炼成材料 ×1.7^当前等级；灵机用 refine.insight ×1.7^当前等级。部分法宝到指定等级另加进阶材料，从该等级起按1.7倍增长，无等级硬上限。

当前节点与完整前置见生成数据表；未决定的结构调整统一见路线图。

## 7. 制作

自动速限在各配方行分别设置，灵石、丹药等可选择不同档位。金丹前保持独立自动节拍；金丹起专业配方共用工位容量，速限与分配权重共同决定实际速度。独立配方调速换算当前进度，工业配方保存已完成的基础加工秒数。旧档的统一速度迁移为各配方的初始档位，新档默认均为1×。

修真「宗门经营」的疾炼法前置心有灵犀、流水作坊与凝液法，费用为1200灵机、5阵基、10灵液。参悟后选择1×、2×、5×、10×自动速限，金丹起主要工位容量各+100%。实际加工受设备容量、权重与配方效率约束；速限本身不改变每份用料及收益。原料保留、库存目标、优先顺序与仓储限制继续生效，离线采用相同规则。事件产能估价不随玩家选择的速限变化，但采用设备能力与节料费用。

配方覆盖基础、进阶与后期建材。每份收益 = amount ×（1 + craftBonus + craftBonusByResource[out]）；普通生产倍率不直接提高配方收益。制作增产相加，没有统一上限。手动制作瞬时完成，自动加工的间隔为配方 time ÷ max(1, √(境界倍率／2))。

点石成灵（矿石3+灵气15→灵石）需采矿场，旧凝气成石配方已移除。凝聚知识按凝气化液 → 凝液法 → 灵气纯化 → 凝晶原理递进：化液开放配方，凝液法在金丹工业阶段提供基础工位，纯化使灵气产出+20%，凝晶原理承接纯化并要求符文入门；实际加工灵晶仍需凝晶工艺和元婴配方。凝晶和育仙草以灵液为原料。木作器械开放木板，金丹阵基装配与淬玄工艺开放阵基和玄钢。符箓刻在灵木符牌上，元婴灵符用玄钢载体与灵液注灵，复合符文配合化神配方开放灵器；后期混灵土、玄铁混灵土、秘银、玄金与晶银承接营造。具体链路见 [CRAFT-PROGRESSION.md](CRAFT-PROGRESSION.md)。

凝灵诀承接凝液法，在每个节气检查满仓灵气，尝试用半仓凝液；心有灵犀开放常驻自动加工、单个优先配方及逐项材料保留。逐项保留为资源绝对数量，扩仓不改变保留量；首颗道果永久开放重修自动加工及按仓储比例保留，与逐项保留取较高值。凝灵诀或常驻自动入口均开放库存目标，0表示不限，消费后补货。

炼制页的“全部自动”复选框在常驻自动解锁后可用：勾选开启全部当前已解锁配方，不受列表筛选影响；取消勾选清除所有配方的自动选择。部分配方已选时显示半选状态，之后新解锁的配方仍需选择。操作立即保存，总开关、节气凝石、库存目标、材料保留与优先配方设置保持不变。

金丹起木作、炼器、刻纹、丹道、凝聚与育草配方共用各自工位，扩建增加容量，停用与维护断供降低容量，缺料或达标释放工位。凝液法自带基础凝聚工位，避免首座晶核阵依赖自身产物。百工坊每座通用制作+6%；专业设施按成品分别加成。工程升级分别提高容量、加工效率或降低每份耗料，规则见 [CRAFT-PROGRESSION.md](CRAFT-PROGRESSION.md)。飞升阵印每份固定一枚，不受制作增产及节料影响；每份消耗灵能80、晶银1、灵符1，自动加工基础耗时120秒，仍独立计时并受境界加工速度影响，可离线积累并遵守库存目标和材料保留。

## 8. 境界与飞升

### 8.1 境界

凡体 → 引气入体 → 炼气 → 筑基 → 金丹 → 元婴 → 化神 → 炼虚 → 合体 → 大乘 → 渡劫。全局倍率依次为1、1.15、1.35、1.6、2、2.6、3.4、4.4、5.8、7.5、10。

破境先检查下一境费用与勾选的护道材料，足额支付后按概率结算；失败不退回任何投料。引气至筑基基础成功率95%，筑基冲金丹基础成功率70%，两者失败均无额外惩罚。风险按冲关前的境界划分：金丹冲元婴起引入渡劫，元婴、化神、炼虚基础成功率为60%、55%、50%；合体、大乘、渡劫基础成功率为20%、15%、10%，体现后期强冲的高风险。破境心法、候时法、心印法的折扣相加为40%；引擎折扣上限90%，折扣仅作用于基础破境费用。当前没有渡劫战斗或必须完成指定研究的突破条件。

### 8.2 飞升

渡劫可以飞升，获得仙缘及1颗道果；不要求先转世或学完科技树。资源、人口、建筑、修真、技艺、法宝及祭炼、境界、加工进度、临时增益与事务状态重置。

### 8.3 转世

化神起可转世，只结算仙缘，重置范围与飞升相同。永久仙缘、道果、成就、长期统计与相关偏好保留。

### 8.4 道果与仙缘

仙缘结算 = floor(√(本世累计入库灵机／2000) ×（1 + 境界下标×0.3）×（1 + ascendBonus）×（1 + 道果数×0.1）)，可结算时至少1点。已花灵机仍计入，满仓被截断的部分不计入。

每点仙缘带来+2%产出与+0.15%仓储，分别通过 softCap 渐近+200%与+50%；前75%上限线性，之后收益递减。每颗道果提供+5%产出与+10%仙缘结算收益，首颗同时提供自动化规则。

因果通感另向仙缘产出乘区固定加0.005，不按仙缘点数放大；其仙缘结算加成为30%。

25项，记录阈值与行为，转世／飞升保留。ACHIEVEMENT_REWARD 当前为0，无全局产出奖励；后续奖励设计未实施。

## 10. 随机事件

### 10.1 事件等级（v0.10）

34条事件，等级与处理类型分开：一级金丹前，二级金丹至化神，三级炼虚起；单条 minRealm／maxRealm 与等级范围取交集。类型分环境、突发、选择。

### 10.2 触发与结算

初始事件计划在开局90秒后，后续随机间隔150～420秒；选择类共用一个未决状态。限时增减益进入相应乘区；资源机缘、交易和灾损使用产能估价、库存比例、保底或固定材料。每种资源单次奖励（含保底）最多为仓储容量的20%，再按剩余空位到账；满仓溢出不返还交易费用。交易需足额支付，防灾减免最高80%。

金丹药圃威胁有5分钟处理期，支持加固、驱逐、收缩、默认防守；超时默认结算一次，并进入安宁／冷却。离线不生成新随机事务，已有超时威胁仍处理。现行应对费用与扩展草案见 [MIDGAME-EVENTS.md](MIDGAME-EVENTS.md)。

## 11. 产量公式与时间模型

### 11.1 产量与收支

普通产出 = 基础建筑产出与已含岗位加成的职位产出之和 ×（1 + 资源ratio）×（1 + ratioAll）×（1 + 季节加成）× 全局倍率 ×（1 + 指定资源临时增益）。

全局倍率 = 境界倍率 × 仙缘乘区 × 宜居度倍率 ×（1 + 道果数×0.05）×（1 + 全局临时增益）。宜居度倍率也用于建筑持续产出；职位基础产出另计岗位拥挤倍率。

实际结算净额扣弟子口粮和维护费；自动加工逐份扣料，不并入 expense 以免双扣。界面 resourceFlow 另外计入当前运行配方耗料，因此显示净额可以与内部 derived.net 不同。

### 11.2 时间模型

主循环100ms，默认每20秒存档。离线按1秒步长补算，默认最多8小时；龟息功、定息法各增加8小时。超过1秒的 tick 也拆为至多1秒小步。

### 11.3 历法与灵能

一天3秒，节气15天／45秒，季节90天／4.5分钟，一年360天／18分钟。四季产出因资源而异，六种常规资源的全年平均季节增益均在±5%内。

合体通过灵子论开放分灵阵，把灵气离析成灵气分子；大乘经阴阳分灵开放偏极阵，把灵气分子解离成正负灵子；湮灭法开放湮灭炉，正负相遇产出灵能。三种设施的产出与维护费同时乘全局倍率，缺料时按实际供给运行；基础数据按一对一供料配置，全局倍率不改变此配比，专业资源增益可提高转化收益。偏极阵的两种产物共用负荷，任一侧满仓就按下游实际消耗限流，减少库存溢出与原料浪费。

灵能每秒乘0.995。v0.31取消按灵能库存获得的免费产量与制作收益倍率，灵能应用改为解锁工位灵能驱动。疾炼法解锁灵气超载；两种驱动最多增加一倍基础工位容量，每额外容量秒分别耗10灵气、0.1灵能，共用冷却容量。自然冷却为全体基础容量的25%，每座运行且维护有供的晶核阵另提供2容量；冷凝换热将晶核阵贡献翻倍。灵能枢满供时提供4加工供能容量，随祭炼与供给比例变化，基础维持费仍独立结算。

加工动力按实际工作时间支付；缺料、仓满、达标或需求未超过基础容量时不收额外动力费。动力耗尽、到达保留库存、供能或散热不足时自动减少加速，普通容量继续可用。驱动会保留当前可开工配方的一份同种原料，避免加速烧掉开工材料。各工位平分紧张的供能与冷却容量，配方权重继续控制工位内分配。飞升阵印稳定保存且随本世重置。灵能枢等带维护费的法宝可在技艺页停用，收益和耗料同时停止，便于优先积累固印用能。

## 13. 存档设计

localStorage 键 slack-off-sect.save.v1，存档结构版本1，与界面迭代版本及包版本分别维护。状态包含资源、峰值、人口与岗位、建筑、已学条目、成就、祭炼、自动加工计时与目标、境界、仙缘、道果、历法、事务、统计及偏好；derived 重算，不保存。

不含 qiParticle 资源字段的旧档首次读取时迁移分灵设施：补同数量、同启停状态的偏极阵及灵子论；已研究凝晶或制作仙草的旧档补凝液法，原自动凝晶／育仙草产线补开自动凝液。凝聚研究由独立的 qiLiquidVersion 标记迁移，当前值为2：旧档按已掌握的最高凝聚节点补齐新增上游，凝晶原理补纯化，纯化补凝液法，凝液法补化液，化液补测定，不依赖 qiParticle 是否存在。重复读档不重复补研究，新档从创建时带新版标记，按递进链支付研究。

序列化排除 __ 开头内存字段，纪事只保存最近60条。设置页导出直接下载带时间戳的.txt文件，内容为base64编码的JSON；读取通过选择本地文件导入，兼容旧版文本存档与原始JSON，成功后立即保存。取消文件选择不改变进度，读取失败提示错误并保留当前进度，同一文件可重复选择。normalizeState补齐缺失字段并归一化。新字段兼容及非法输入边界由测试验证，不承诺任意未来规则都无需迁移。

存档按浏览器同源隔离，协议、域名或端口改变会使用不同存储；同源下仅改变路径仍访问同一localStorage。清除浏览器数据会删除存档，设置页提供导出备份。

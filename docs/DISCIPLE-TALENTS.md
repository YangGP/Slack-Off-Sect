# 弟子天赋：首版与升级

更新：2026-10-19。首版已实施：获得后类型固定，不洗练或替换。v0.421 新增猎杀类两条（准头／收获，随狩猎页自动组队改版）。本文获取概率、数量、词条与 Lv.1–Lv.3 升级成长、天级岗位词条均为当前试调配置。当前弟子规则见 [DISCIPLE-PROGRESSION.md](DISCIPLE-PROGRESSION.md)。

## 1. 首版范围

让弟子在灵根之外具有个人专长，使玩家能选择培养人选和岗位。灵根继续决定基础成长速度并影响突破概率，天赋提供个人修炼、岗位专长、突破把握或猎杀专长；不改变宗门境界上限。

首版围绕现有六类岗位及个人成长，不增加独立属性、负面天赋、洗练或炼丹／炼器岗位；v0.421 增加猎杀类（准头／收获），作用于妖兽猎杀出征。升级属于原天赋的后续成长，规则见第 4 节。个人词条不直接提高全宗产出、共享工位或每份制作收益。培养投入、师承和复杂失败风险另行策划。

## 2. 获取与数量

入宗提供先天差异，成功突破提供后天获取机会，配置集中在 [src/data/talents.js](../src/data/talents.js)：

| 项目 | 当前首版配置 |
| --- | --- |
| 入宗天赋数量 | 70% 无天赋、25% 一条、5% 两条 |
| 成功突破 | 每次成功后 10% 概率获得一条新天赋 |
| 总数量上限 | 每人最多三条 |
| 重复规则 | 相同 ID 不重复，同类专长最多一条 |
| 获取等级 | 黄 60%、玄 30%、地 9%、天 1% |
| 失败、调岗、读档 | 不触发天赋获取 |

“同类”分修炼、岗位、突破、猎杀（准头／收获各为一类）五类，目前同类最多一条。固定的是天赋身份与专长，例如采药专长不替换成矿工专长；后续通过升级提升原天赋能力。低级词条不会因此换成另一条天赋，不提供洗练或替换入口。

升级属原天赋的成长：随弟子成功突破自动提升已有天赋等级，上限 Lv.3，天地玄黄品级固定不升，不消耗额外资源、修为或经验，也不占用天赋位置，详见第 4 节。抽取品级与成长等级分开描述，不能默认每次突破都升级，也不能用抽取另一条同类词条代替升级。

事件招入与正常收徒使用同一获取规则；未来特殊招募另设规则，不在本轮加入。实际抽取次数不得超过空余位置，不因为重试同一次成功突破重复发放。

每次抽取先排除已拥有 ID 和已占用类别，再从仍有可用词条的等级中按权重抽等级，最后在该等级候选池中等概率抽词条。无候选或已到数量上限时不抽取，不循环重抽；首版不设按境界限制词条的额外门槛。等级概率按当次有效等级权重归一化，不能把排除后的概率仍宣传为固定值。

### 3.4 猎杀类（v0.421）

随猎杀页即时结算改版新增，仅作用于妖兽猎杀持有人本人（公式见 [BEAST-SYSTEM.md](BEAST-SYSTEM.md) §4）。两条各为一类，同一弟子可同时持有「准头」与「收获」。

| 品级 | 准头名称 | 收获名称 | 准头 Lv.1／2／3 | 收获 Lv.1／2／3 |
| --- | --- | --- | --- | --- |
| 黄 | 耳聪目明 | 手快眼疾 | +2／+3／+4 pt | +10%／+15%／+18% |
| 玄 | 识兽有方 | 剥取利落 | +4／+6／+7 pt | +20%／+30%／+36% |
| 地 | 兽性通明 | 庖丁之术 | +6／+9／+11 pt | +35%／+52%／+63% |
| 天 | 天生猎瞳 | 解牛神技 | +8／+12／+14 pt | +50%／+75%／+90% |

「准头」（huntSuccess）按百分点加本人猎杀成功率，口径同突破类、上限 +14 pt；「收获」（huntYield）按比例加本人收获倍率 y（y = 1 + 加成），口径同修炼／岗位类、上限 +90%。二者与宗门级猎杀技艺（识踪诀／剥取法等）独立叠加；不影响其他弟子，也没有行程时长。玩家在猎杀页明确勾选名单；推荐阵容按真实期望贡献排序，但不自动替换手动名单。

猎杀天赋元数据标记所属模块。模块关闭时，自动来人、主动招募、事件招人及成功突破领悟四个入口只从候选池排除猎杀词条，不删除已有身份、不洗练、不补抽；重新开启后原词条恢复用途。开局尚未研究《山野猎法》不影响该过滤，只看模块开关。

### 3.5 统一计算

同一效果内部按配置加总，并保留修炼 +90%、岗位 +90%、突破 +14 个百分点、猎杀准头 +14 个百分点、猎杀收获 +90% 的防御性上限（对应天级 Lv.3）；同类唯一时通常只有一项。不同来源分开计算，不按弟子数量扩大为全局增益。

```text
个人修炼速度 = 基础速度 × 灵根系数 × (1 + 个人修炼天赋加成)
岗位有效权重 = Σ[该岗位弟子有效境界系数 × (1 + 该弟子对应岗位天赋加成)]
个人突破成功率 = min(99%, 弟子基础成功率 + 宗门指导加成 + 个人天赋百分点 + 灵根突破加成)
```

口粮继续使用原个人有效境界系数，岗位天赋不额外提高口粮，也不提高其他弟子的产出。需区分用于产出的岗位权重与用于口粮的境界权重，避免复用一个总量导致误增口粮。

当前弟子基础成功率为对应宗门基础成功率的 50%，宗门指导为每高一境 +10 个百分点，灵根按 ±(0～6) 个百分点另行叠加（见 [DISCIPLE-PROGRESSION.md](DISCIPLE-PROGRESSION.md) §1.2）。突破天赋在该基线上增加个人百分点。

例：同境界三灵根弟子原修炼速度为 1，拥有黄级修炼词条 Lv.1 后为 1.1、Lv.3 后为 1.18；天灵根搭配天级词条 Lv.1 为 3、Lv.3 为 3.8。两名同境界矿工中只有一名拥有 +20% 岗位天赋时，该岗位合计权重为原来的 2.2／2＝1.1 倍，不能给两人都加 20%。

## 4. 升级成长

升级只提升原天赋的等级与效果，不改变身份、品级或岗位专长，不占用额外位置，不消耗资源、修为或经验，也不新增玩家操作。玩家通过选择重点培养人选（安排更多突破机会）间接决定升级速度。

### 4.1 触发与目标

- 触发：每次弟子成功突破后，在原有“10% 获取新天赋”判定之外，独立进行一次升级判定，概率 40%；与获取互不排斥，同一次突破可以既获取又升级。
- 无未满级天赋时不进行升级判定，不消耗该次随机数。
- 目标：在本人未满级天赋中选择等级最低者提升 1 级；同级取获取顺序最早的一条。选择确定、不随机挑条，避免某条独大。
- 失败突破、调岗、闲散、读档、离线都不触发升级；沿用现有突破后处理顺序（先获取新天赋，再判定升级）。

### 4.2 等级与品级

- 每条天赋等级上限 Lv.3，从 Lv.1 起算，最多提升两次。
- 天地玄黄品级在获取时固定；升级不升品级、不改名称，也不把低级词条换成另一条同类词条。
- 品级决定起点与顶点，等级是同一身份内的成长：同等级下高品级更强；刚获取的天级（Lv.1）不低于已满级的地级，地级满级可接近但不超过天级同级，形成“高品级起点高、低品级靠培养追赶”的重心选择。

### 4.3 成长曲线

各品级按 Lv.1 的同一比例成长：Lv.2 为 Lv.1 的 1.5 倍、Lv.3 为 1.8 倍，逐级增量递减（先 +50% 再 +30%）。数值见第 3 节各表，均为试调值：

| 类别 | 黄 | 玄 | 地 | 天 |
| --- | --- | --- | --- | --- |
| 修炼 Lv.1／2／3 | 10／15／18% | 20／30／36% | 35／52／63% | 50／75／90% |
| 岗位 Lv.1／2／3 | 10／15／18% | 20／30／36% | 35／52／63% | 50／75／90% |
| 突破 Lv.1／2／3 | 2／3／4 | 4／6／7 | 6／9／11 | 8／12／14 |
| 猎杀·准头 Lv.1／2／3 | 2／3／4 | 4／6／7 | 6／9／11 | 8／12／14 |
| 猎杀·收获 Lv.1／2／3 | 10／15／18% | 20／30／36% | 35／52／63% | 50／75／90% |

升级收益上限与首版值分开维护：类别上限由首版天级 Lv.1（修炼／岗位 +50%、突破 8 点）提升到天级 Lv.3（+90%／+90%／14 点）。是否新增更高等级或调整曲线属后续试调，不默认沿用 Lv.1 值作为上限。

### 4.4 随机与持久化

升级判定与目标选择复用独立 `talentSeed`，不扰动突破判定、事件与灵根的随机序列。等级随 `talents` 条目持久化，读档、导出与离线结算保持一致，不重抽、不重复升级。

## 5. 数据与存档约定

`talents` 已保存条目数组，每条包含固定 `id` 和独立成长 `level`，等级范围 Lv.1–Lv.3。名称、品级、类别、`jobId` 与各等级数值（`values`）从配置解析，展示说明按等级生成，不另存派生值。

原天赋升级不得改变身份或岗位专长，不占用额外天赋位置；新获取数量上限与单条天赋升级上限分别配置（`maxCount` 与 `maxLevel`）。

天赋使用独立的 `talentSeed`，不消耗既有 `rootSeed`、事件或突破随机序列。成功突破判定仍由原随机源完成，随后单独判定天赋；天赋加成会改变实际突破概率，但不能仅因天赋抽取扰动其他系统的随机序列。

旧弟子默认空天赋或仅 Lv.1，不因本次升级设计在每次读档时重抽、自动补发或自动升级；迁移后下一次真实成功突破可按新规则获取或升级。若用户希望为旧弟子补先天或补成长，需另设一次性迁移方案，不能直接在归一化中随机生成或升级。

已在 `disciples` 内保存 `talentVersion: 2` 与 `talentSeed`，无需新增顶层存档字段。旧档缺少种子时从原灵根种子派生，个体归一化清理重复／未知 ID、类别冲突、数量和等级超限，不自动生成或升级天赋；合法 ID 与等级原样保留。身份、天赋、等级与种子在普通保存、导出和离线结算副本中一致保留。测试夹具通过人数补建的历史个体保持空天赋，真实收徒与事件招入仍正常抽取。

重修、转世或飞升继续清空弟子及个人天赋。随机序列如何重置需统一约定，并与同一存档重复加载的规则分开处理。

## 6. 界面与验证

列表在姓名附近显示天赋数量与最高品级，完整名称、品级、等级（Lv.N／3）、当前效果与当前岗位是否生效放入现有详情提示。没有天赋显示“无天赋”；不新增逐人弹窗或抽取轮盘。

已增加天赋类别、岗位专长及无天赋筛选，支持与境界、灵根组合。筛选切换清空选择，排序按身份保留选择。速度、剩余时间、岗位平均产出、口粮摘要及突破预览使用统一计算结果。升级发生后在纪事追加一条（如“｛姓名｝突破后天赋【名称】提升至 Lv.2”）。

验收重点：

- 获取次数、等级权重、去重、类别互斥、上限及空池可确定性验证。
- 同岗位混合天赋按个人加总，调岗后保留词条并停止专长加成。
- 在线和离线收徒使用同一天赋序列，个人仅成长入门后的时间；离线不自动突破。
- 突破逐人付费并使用本人概率，新获天赋只在本次成功后生效。
- 旧档与重复读档不重抽、不重复发放，独立序列在导出／导入后续接一致。
- 管理页详情与天赋、境界、灵根组合筛选见 `tools/talent-check.mjs`。
- 猎杀天赋只作用于本人出征：准头按百分点加成功率、收获乘个人倍率 y，与宗门级技艺独立叠加；持有人可由玩家手动选入名单，推荐阵容也按真实贡献排序（见 `tools/smoke/hunting.mjs`）。
- 升级触发概率、最低级优先目标、Lv.3 封顶及天级岗位词条入池可确定性验证。
- 旧档 Lv.1 不自动升级，升级后导出／导入与离线结算一致。
- [ ] 多种子培养审计比较个体成长分布、岗位分工、材料竞争和断供，不只看首个天灵根弟子。

# 建筑价格与扩张节奏：猫国对照

更新：2026-10-16。状态：讲经堂／观星台新增灵机费用已试调，其余建筑候选尚未实施，建筑效果不变。本作基于当前 v0.384 工作区；猫国读取本地 `cat-zh-master/js/buildings.js`，并交叉核对[官方建筑源码](https://github.com/nuclear-unicorn/kittensgame/blob/master/js/buildings.js)。本地副本部分条目较旧，本文比较的基础价格与涨价率已核对官方版本。建材及科研费用试调见 [费用专题第6节](RESEARCH-CRAFT-PRICE-COMPARISON.md#6-第一轮已实施试调2026-10-16)。

## 1. 结论与比较口径

本作多数中高级建筑的涨价率已经比猫国更高，问题不能概括为“建筑涨价太慢”。更值得调整的是：**每个住额的投入、扩建的材料层级、研究与扩产争用材料的程度，以及扩仓附带解除了多少其他门槛**。

两边的资源单位、生产速度、开局仓容、升级折扣和重置体系不同，不能直接把“100木”和“100灵木”当成相同劳动量。下表只用于比较结构；实际调参须使用本作的材料净流量、库存与前级仓容，验证第1／5／10／20座所需准备时间。

本作第n座基础报价为 `ceil(基础价 × priceRatio^(n-1))`，由 `src/game/systems/core.js` 的 `buildingPriceAt` 计算；首间茅屋的免木料另算。猫国实际价格还受政策、升级与降价效果影响，下表是未经折扣的元数据，不能直接当玩家界面价格。

## 2. 住房：总价涨得快，但每座带来的扩张也很大

| 档位 | 猫国基础价格／住额／涨价率 | 本作基础价格／住额／涨价率 |
| --- | --- | --- |
| 初级 | 小屋：木5；2人；2.5 | 茅屋：灵气80、灵木20（首间免木）；2人；1.55 |
| 中级 | 木屋：木200、矿物250；1人；1.15 | 木屋：灵木300、灵石20；6人；1.55 |
| 高级 | 豪宅：钛25、石板185、钢75；1人；1.15 | 精舍：玄铁混灵土8、灵木1000、木板10、阵基4；10人；1.6 |
| 更高档 | 不作一对一映射 | 洞府：玄铁混灵土20、玄金6、木板20、灵晶30、法器15；24人；1.7 |

本作第10座木屋已经要灵木15492、灵石1033，第10座洞府约要玄铁混灵土2372、玄金712、木板2372、灵晶3558、法器1779，并不便宜。继续提高1.6／1.7会迅速把后续扩建推到不可容纳的价格。

但首座洞府摊到每个住额，仅为玄铁混灵土约0.83、玄金0.25、木板约0.83、灵晶1.25、法器0.625。各住宅又分别从自己的基础价起算，玩家可以交替建设不同档位扩大人口。

前轮原版24小时审计样本的24茅屋、19木屋、11精舍、8洞府，合计恰好提供464个住额，其中洞府贡献192。此为单策略样本，不代表真人最优路径；它说明中后期住额集中来自少量高档建筑，单看茅屋涨价率会漏掉主要扩张来源。

**建议**：保留首屋优惠与前期住房承接；优先试调精舍、洞府的基础材料预算，而非继续提高涨价率或直接砍旧档住额。首轮候选为高级住宅基础费用约×1.5～×2，具体按每新增10个住额所需的劳动与加工预算定；木屋先维持，观察人口规模成本的叠加影响。不得新加尚未开放或只能由下游取得的材料。

## 3. 修行建筑：更应看材料竞争与多条加成叠加

| 建筑 | 基础费用 | 涨价率 | 当前主要效果 |
| --- | --- | ---: | --- |
| 猫国图书馆 | 木25 | 1.15 | 科学增产、科学上限（由动态效果计算） |
| 猫国学院 | 木50、矿物70、科学100 | 1.15 | 科学+20%、科学上限+500等 |
| 猫国天文台 | 铁750、科学1000、石板35、脚手架50 | 1.10 | 科研及配套效果 |
| 本作藏经阁 | 灵气200、灵木60 | 1.18 | 灵机产出+10% |
| 本作典籍库 | 灵木60、矿石80 | 1.14 | 灵机上限+80、产出+5% |
| 本作讲经堂 | 阵基4、木板25、灵机200 | 1.25 | 灵机产出+35%、上限+800 |
| 本作观星台 | 灵晶50、木板30、玄铁1000、灵机600、道札6 | 1.30 | 灵机产出+50%、灵机上限+3000、阵图上限+5 |

本作讲经堂和观星台的涨价率已经更高；猫国这两类建筑本身消耗科学，扩建与研究争用同一资源。本作第一轮试调分别加入灵机200、1000；当前知识链接入后，观星台改为灵机600＋道札6，让现付灵机与提前积累的知识共同承担费用。详见 [知识加工](KNOWLEDGE-CRAFTS.md)。

还要看组合效果：本作同时有藏经阁、典籍库、讲经堂、观星台四条可重复建设的灵机增益来源。原版样本的54／69／33／16座合计贡献+2840%灵机资源加成，即该部分倍率为×29.4（同一资源ratio相加，不是四层相乘，尚未计其他增益）。不能把这一结果全归因于典籍库1.14。

**建议先试两项**：

1. 典籍库首座价保持，涨价率试1.14→1.16，避免破坏开局及首次研究扩仓。仅这项会使第10／20／40座报价相对当前增加约17%／39%／97%，不是全程翻倍。暂不直接跳到1.18，也不与大幅削减仓容同时做。
2. 讲经堂、观星台增加适量灵机建设费，第一轮试用200、1000；当前讲经堂仍200，观星台已改为灵机600＋道札6，原建材与涨价率保留。首座可由前级来源与仓储承接，闭包通过；仍需观察实际准备时间。

前轮D2审计显示，24小时灵机产速已约943/s，下一境灵机费用仅4800，约等于5.1秒毛产出。这说明即使建筑价格合理，后期研究／破境需求如果远低于成熟产能，仍会快速连跳；不能声称只调建筑价格就能保证首飞达到某个天数。

## 4. 仓储：保护基础缓冲，复核高档综合仓的跨系统回报

猫国谷仓基础木价50、涨价1.75；仓库用梁1.5、石板2、涨价1.15；港口进一步使用石板、金属板和脚手架。重点是扩仓逐步进入加工材料，而非所有仓库一律高涨价。

本作谷仓1.18、库房1.22、材料库1.25、玄库1.30、广储库1.32、洞天1.35，整体已经逐级提高。若照搬猫国谷仓1.75，本作第20座谷仓木料报价会从约4179变为约746万，可能堵死基础供粮与扩仓，不能这样改。

更应检查高档综合仓：广储库基础费用为玄铁混灵土30、秘银20、木板20、灵石8000，同时提供多种资源各50000定额、灵机12000及4000通用仓；洞天还有更大的定额与12000通用仓。**通用仓也会按灵机默认权重1增加灵机容量**，所以它们分别提供16000／27000基础灵机容量，再叠对应仓储倍率。一座仓库可能同时跨过多种研究与建设门槛。

**建议**：首轮保留谷仓、库房和首座中后期仓储的启动能力；列清广储库／洞天按资源的实际容量，再评估基础价格约×1.5或部分改为当阶加工材料。暂不先砍已建仓容；若以后细化科研仓储与综合仓分工，应另做旧档资产及研究可达性方案，不能在调价格时顺带清空或截掉旧库存。

## 5. 工业与供能：避免用涨价率掩盖建筑职责差异

猫国工坊基础木100、矿物400、涨价1.15，每座通用制作收益+6%；本作百工坊为灵木100、矿石150、涨价1.30，同样+6%，另有木板容量并承担木作工位。本作第20座百工坊的基础价倍率约146.19，猫国约14.23；本作涨价已经更陡，且两者承担的职责并不完全相同。

本作炼丹房、炼器坊、符箓堂还同时提供专业制作增益、工位或资源增益、周转仓。扩建有多项回报，而且部分专业设施可长期用基础木石铁扩建。成熟原料产线可能轻松支付这些费用，而共享加工链因此加速。

**建议**：先保留百工坊首座与1.30涨价率；逐个检查专业设施第10／20座的完整回报与实际备料时间，再试调其基础价格或加入已可稳定取得的加工材料。加入木板／阵基／玄钢等之前必须检查该配方是否反过来依赖本设施，避免自锁。不同时提高价格、降低收益和增加维护三项，便于识别效果。

本作湮灭炉涨价1.6，明显高于猫国反应堆基础1.15；且首炉是灵能和阵印链的启动设施，本轮不建议继续抬高首炉价格。此前审计机器人没有建炉，优先修正审计策略的覆盖，而不是把其未启动判为“产线过便宜”。

## 6. 建议试调顺序与验收

1. **先验证科研扩建**：典籍库1.16＋讲经堂／观星台的适量灵机建设费，分别做单项与组合对照。
2. **再验证高档住宅**：精舍／洞府基础材料预算×1.5～×2，保留住额与现有涨价率，观察每新增10人所需的准备和供养成本。
3. **最后检查综合仓与专业工业**：按实际瓶颈选一类调整；前两项生效后旧快照已经变化，不能把所有候选一次性叠上去。

验收应使用同一版本机器人、固定种子，并区分真实随机与强制成功、首轮与重修、在线与低频上线。记录各阶段第1／5／10／20座的材料缺口、补料时间、仓容和边际收益；并检查新资源首次来源、旧档库存、少量仙缘重修及首炉／首阵印可达性。

这里给的是**结构诊断和待测价格范围**，不是已完成的数值平衡。高涨价率会惩罚堆第30座，却未必能阻止每解锁一个新档位就迅速完成一轮扩张；真正要对齐的是“新阶段第一轮建设需要多大产业投入”。

# 前中期仓储与加工节奏调整

2026-10-14，依据金丹期、72 名弟子的导出存档核对。原料填仓约 13–24 分钟，灵气约 2.4 分钟；灵石自然产出约 0.99/秒，却有 16,080 仓容，空仓填满约 4.5 小时。生产设施成品仓容大幅增加，而专业制作收益每座仅增加 5 个百分点。

## 复核方式

`npm run audit:buildings` 检查全境界来源与仓容可达性，不估算推进耗时。

可只读重算任意导出存档：

```powershell
npx vite build --ssr tools/storage-pacing-audit.mjs --outDir .smoke-storage-pacing
node .smoke-storage-pacing/storage-pacing-audit.js '存档路径.txt'
```

脚本列出仓容、自然净产出、填仓时间、超限库存、下一座库房造价、制作收益及下一境基础费用是否可容纳。

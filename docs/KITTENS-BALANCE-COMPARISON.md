# 猫国（Kittens Game）对照：数值结构与节奏差距

## 2026-10-18：重置循环复核

用户提出直接放大破境费用是否过于粗糙。本节重新核对官方 master 源码及 Wiki；下文早期本作数值仍为历史资料，不能作为当前规则。P1现有加价版保留为实验对照，尚未定为最终平衡方案。

- 汉化中的“领导力”对应 Paragon，与指定某只猫担任领袖不同。普通情况下重置所得为当前猫数减70；超过35只猫便开始获得另一项重置收益 Karma。130猫重置通常得60 Paragon。[官方重置入口](https://github.com/nuclear-unicorn/kittensgame/blob/master/game.js)。
- 早期未花费的每点 Paragon 提供1%主要产出及0.1%仓容加成；产出存在递减，普通 Paragon 的仓容加成没有同样的软上限。Paragon还能购买跨轮保留的形而上学升级，包括降低建筑涨价系数。消费会减少未花费余额的被动收益，存在留存与投资取舍。它缓解的是反复扩建的成本曲线，并非只让所有资源更快贴顶。[官方永久升级与倍率实现](https://github.com/nuclear-unicorn/kittensgame/blob/master/js/prestige.js)。
- 常见首轮重置建议是混凝土小屋后、130猫以上，往往同时准备宗教收益保留；这是有明确后续购买用途的里程碑，不是最早能重置的条件。[Wiki攻略](https://wiki.kittensgame.com/en/guides-and-advice-and-stuff/monstrous-advice)。现实约1～3周、常见约2周只是历史社区经验，受版本、在线时间和熟练度影响；不是官方固定时长，也不是按本项目150秒操作节奏做的同条件实测。[历史讨论](https://www.reddit.com/r/kittensgame/comments/eiwz68/)、[133猫首轮约3周的个人记录](https://www.reddit.com/r/kittensgame/comments/x10nfx/)。
- 高级材料与仓容共同控进度。例：混凝土小屋需125000科学、3000钛、45混凝土；科学和钛必须有足够仓容，同时要完成钛来源及混凝土加工链。科学仓容由图书馆、学院、天文台及有上限的纲要增容等扩展；高级科技也开放更有效的仓储。[官方升级费用](https://github.com/nuclear-unicorn/kittensgame/blob/master/js/workshop.js)、[科学仓容](https://wiki.kittensgame.com/en/general-information/resources/science)、[钛来源与仓储](https://wiki.kittensgame.com/en/general-information/resources/titanium)。
- 木梁、石板、钢等常规加工材料没有本作这样的逐项仓容限制，能将有限仓容的原料分批转为长期备料；不能将猫国概括为“每一种高级材料都再加一道仓容墙”。仓容、加工、贸易、效率及新设施共同形成破局路径。[官方资源定义](https://github.com/nuclear-unicorn/kittensgame/blob/master/js/resources.js)。

对本作的设计结论：首次转世3～5天目标保留；分段价格仍需校准，但不能用单笔灵机与材料费放大代替完整成长结构。后续优先复评现有永久修持是否可承接营造涨价缓解、加工效率或早期减负，并给飞升前各阶段安排真实产业升级与更有效的扩仓途径。此处是方向复评，不代表已经新增永久升级、取消加工品仓容，或恢复改价前报价。直飞仍须有独立可达路线，转世次数不作为门槛。

状态复核：2026-10-17。本文保留早期结构比较，不是现行待办；人口成本、外交、仓容、知识加工及离线机制已有后续调整，优先级与剩余工作以 [ROADMAP](ROADMAP.md) 为准。

分析日期：2026-10-15。对照基准：

- **猫国**：工作区 `cat-zh-master/`（本地副本，比官方 master 旧，含已废弃的 `brewery` 节点）。
- **本作**：当前 `main`（v0.382），源码 + `audit:pacing` 实测。

本文件是**结构对照与差距清单**，不修改任何游戏数值。所有猫国数字来自源码实际值并标注文件行号；本作数字来自源码与本次实测。

## 1. 日历时间尺度（与完整进程耗时分开）

| 项 | 猫国 | 本作 |
| --- | ---: | ---: |
| 1 tick | 0.2 s（`game.js:1716` ticksPerSecond 5） | 主循环 100 ms |
| 1 天 | 2 s（10 tick） | 3 s（`calendar.js` DAY_SECONDS） |
| 1 季 | 200 s | 270 s（90 天） |
| 1 年 | 800 s = 13.33 min | 1080 s = 18 min |
| **现实 1 秒 = 游戏天数** | **0.5 天** | **0.333 天** |
| 季节对主产的乘数 | 春 1.5 / 冬 **0.25**（`calendar.js:13,41`） | 春 +20% / 冬 −20%（`calendar.js:54-79`） |

校正（2026-10-16）：按上表猫国每现实秒0.5游戏天、本作约0.333游戏天，猫国日历推进约为本作的 **1.5倍**，原“82倍”结论错误，不用于平衡决策。日历推进速度不能推导首次重置／飞升需要多少现实时间。表中猫国冬季猫薄荷倍率0.25与本作所列常规季节减产也不是同一种资源压力，不能概括为统一的“惩罚两倍”。后续对照须按具体资源的全年流量、维持成本和产业门槛测量。

## 2. 数值结构对照

### 2.1 基础仓容：本作更宽松，但极值需求/仓容比更极端

猫国基础仓容（`buildings.js:2002-2021` `effectsBase`）：catnip 5000、wood 200、minerals 250、coal 60、iron 50、gold 10、titanium **2**。

| 指标 | 猫国 | 本作 |
| --- | --- | --- |
| 资源条数 | 58（`resources.js:21-516`） | 38（35 核心 + 3 猎杀） |
| 层级字段 | `type`：common/uncommon/rare/exotic | `storageWeight` 0.003~1 |
| 基础仓容量级 | catnip 5000 / wood 200 / iron 50 / titanium 2 | qi 500 / insight 200 / wood 200 / stone 150 / 灵宝 5 |
| 最大「单笔需求 ÷ 基础仓容」 | titanium 3500 ÷ 2 = **1750×** | 灵石 300,000 ÷ 150 = **2000×**；灵机 320,000 ÷ 200 = **1600×** |
| 仓储涨价率 | barn **1.75**、harbor/warehouse 1.15 | 谷仓 1.18、库房 1.22、材料库 1.25、玄库 1.3、广储库 1.32、洞天 1.35 |
| 人口涨价率 | hut **2.5**、logHouse/mansion 1.15 | 茅屋/木屋 1.55、精舍 1.6、洞府 1.7 |

两边同型：**仓容线性增长、造价指数增长**，因此「扩容的边际性价比必然恶化」。本作的乘区更早封顶（仙缘 ×≤1.5、比例扩仓合计 ×≤3.5），主要靠堆叠建筑。

### 2.2 人力产出：猫国「人力唯一」，本作「建筑 + 人力」双轨

| | 猫国 | 本作 |
| --- | --- | --- |
| 建筑直产 wood/minerals | **完全没有**（全库无 `woodPerTickBase`/`mineralsPerTickBase`） | 无直产，但伐木场 +5%/座、采矿场 +10%/座 |
| 岗位产出 | 樵夫 0.09 wood/s、农夫 5 catnip/s、学者 0.175 science/s、矿工 0.25 minerals/s（`village.js:14-147`，×5） | 阵徒 0.6 qi/s、樵夫 0.15 wood/s、矿工 0.15 rock/s + 0.015 ore/s、采药人 0.07 herb/s、悟道者 0.02 insight/s（`jobs.js`） |
| 口粮 | 每猫 4.25 catnip/s（`village.js:9,596`） | 每弟子 0.25 qi/s × 境界倍率（`config.js:16`） |
| 口粮 ÷ 主产岗毛产 | 4.25 ÷ 5 = **85%** | 0.25 ÷ 0.6 = **41.7%**（任何境界恒定） |
| 人口上限与重置收益 | paragon = `kittens − 70`（`game.js:4364`） | 仙缘 = √(累计灵机/2000)×…，与人口无关 |

**各自的自洽点**：猫国口粮压力大 → 人口上限就是重置收益上限 → 用「人口」当主轴。本作口粮只占 41.7% → 人口不构成压力 → 用「境界 + 仙缘」当主轴，人口是纯粹的劳动力投入。

### 2.3 幸福度 / 宜居度：猫国是「人口越多越差」，本作是「配套跟不上才差」

| | 猫国 | 本作 |
| --- | --- | --- |
| 公式 | `(kittens − 5) × 2%`，**第 6 只起每只 −2% 产出**（`village.js:680-686`） | 基础 20；每点 −1% 产出（−50% 封顶）；人口≥20 且 H < N−20 时弟子产能 ×0.5 |
| 上限 | 25% 幸福度下限 + 超编额外惩罚 | 富余最高 +50%（H ≥ N+220） |
| 有没有「人口反噬」 | 有，且从第 6 人就开始 | **没有**：人口只要住得下、粮食够，就是纯收益 |

### 2.4 研究与进度结构

| | 猫国 | 本作 |
| --- | --- | --- |
| 科技节点 | 59（`science.js:13-826`）+ 45 政策 | 研究 80 + 技艺 74（50 技艺 + 24 法宝）= 154 |
| 前置链最大深度 | **17 层** | **19 层**（immortalIndustry / immortalJade） |
| 科技费用是否涨价 | **不涨**，固定常数（`science.js` 无 priceRatio） | 不涨，一次性灵机费 |
| 费用曲线 | 逐层 ×1.5~×3，末端一次 ×25 | 灵机 25 → 320,000（min/中位/max = 25/8,000/320,000） |
| 单节点放行量 | 平均 1.7 项（科技 0.81 + 建筑 + 升级） | 「一个节点放行下一步」的强串联较多（金丹九项拆三入口） |
| 难度靠什么递增 | **资源层级**（科学→手稿→纲要→蓝图→遗物→时间水晶→虚空）+ 建筑指数价 | 灵机仓容闸门 + 建筑指数价 + 境界倍率 |

### 2.5 重置层

| | 猫国 | 本作 |
| --- | --- | --- |
| 主货币 | paragon（`kittens−70`，+1%/点产出、+0.1%/点库容，封顶 +200%） | 仙缘（软上限渐近 +200%） |
| 次级 | karma（阈值 35/60/100/150/300/750，`getUnlimitedDR` 压缩） | 道果（+5% 产出/颗，无上限；+10% 仙缘结算） |
| 重置折扣 | 27 项 perk 共 3,115 paragon；含 −priceRatio | 无等价物 |

本作的「破境概率 + 身死」是猫国**没有**的一层风险，属于本作特色；但它同时是**后期唯一能惩罚玩家的机制**。

## 4. 差距清单（按严重度）

### D1 筑基→金丹 断层（已于本次调整，见 §7）

**最初的判断是错的。** 最初归因于「金丹 350 灵机的门槛」，但反事实测试否掉了它：把金丹破境灵机 350→200 只让到达时间从 13.35 h 变成 12.67 h。

真实机制是**研究费用曲线在这一段过陡**，而灵机又是唯一缺少规模效应的资源：

| 岗位 | 每人每秒 | 能否靠扩建放大 |
| --- | ---: | --- |
| 阵徒 → 灵气 | 0.6 | 能：聚灵阵 0.3/座 |
| 樵夫 → 灵木 | 0.15 | 能：伐木场 +5%/座 |
| 矿工 → 矿石 | 0.15 | 能：采矿场 +10%/座 |
| **悟道者 → 灵机** | **0.02** | **几乎不能**：藏经阁 +10%/座、典籍库 +5%/座 |

诊断日志（每 6 分钟采样）显示 3.0~6.5 h 期间玩家一直是 22 名弟子、其中只有 2 名悟道者，灵机产出 0.15/秒，而灵机长期贴顶（1208/1208）——研究需求也正好是 1208。也就是说：**整段等待由「灵机产出 ÷ 研究费用」决定**。

cat 国没有这个问题，因为它的科技费用是固定常数且每层只 ×1.5~×3，而且每个科技平均放行 1.7 项。

### D2 口粮只占 41.7%，且没有人口反噬

猫国口粮占主产岗 85%（冬季更高），并用幸福度 `(kittens−5)×2%` 让第 6 只猫起就扣产出，因此「人口」是一个必须权衡的资源。本作口粮恒定占 41.7%（因为口粮与产出同乘境界倍率，比值不变），宜居度只在配套不足时惩罚，**人口只要住得下就是纯收益**。

实测印证：72 h 弟子 610 人且在增长，其中 128 矿工只产出 0.0015 灵石/座/秒的副产 —— 后期「灵石」这条硬通货的唯一稳定来源是极低产速的矿工副产，而因果池要 300,000 灵石。

建议方向：给人口加一个温和的全局反噬项（例如按人口数给研究/加工速度轻微减速），或让灵石产速随人口有正向联动（例如点石成灵可被悟道者/加工产能放大），避免「堆人无代价，但硬通货还是慢慢磨」。

### D3 灵石 / 灵机的需求÷基础仓容比最极端

- 灵石：基础 150 → 因果池 300,000（**2000×**）。猫国最极端的 titanium 是 2 → 3500（1750×），但猫国用太空建筑扩容，本作靠库房 ×250/座 + 材料库 ×8000/座 + 比例 +35%。
- 灵机：基础 200 → 最贵研究 320,000（**1600×**），靠观星台 3,000/座 + 比例 +140% + 通用仓。

两者都在可达范围内（定点校验通过），但**需要玩家提前大量投资仓储**，且这一段没有其他决策，属于「为仓储而仓储」。

建议方向：把因果池的灵石单价下调一档，或给库房的灵石仓容一个更高档（当前库房每座 250 灵石，占同座灵木份额的 1/4；材料库每座 8,000 灵石才是主要承载）。

### D4 仓容配比与需求脱节：灵木 4.5% 闲、香火/灵草长期贴顶

72 h 实测：灵木上限 7.95 M、占用 4.5%；而灵草长期 100% 贴顶、香火同样是瓶颈（山门 80/座、香火鼎 120/座、涨价率都是 1.30，是全局每座给出最少的仓储）。

值得说明的是，灵木充裕**不构成 D1 那种白送**：采集类研究的灵木增益同时带灵草（灵流要诀 wood/herb/ore 各 +30%、灵渠网络各 +25%），御剑术是 wood +20% / **ore** +20%（不是灵木独享），所以灵木被满仓截断只损失其中一部分收益。真正的问题是对比关系：

- 灵木每座 1000、香火每座 80~120 —— **香火每座只有灵木的 8%~12%**，却比灵木更常贴顶；
- 灵石每座 250，需求却是全游戏最高（因果池 300,000）。

建议方向：把仓储份额按实际流量重排（抬高香火与灵石的每座仓位、压低灵木），而不是继续按「灵木流得最快」的旧假设分配。

### D5 前置链已比猫国更深（19 层 vs 17 层）

本作研究 80 条 + 技艺 74 条 = 154 条，比猫国 59 科技多 2.6 倍；同时末端存在 18~19 层的长链（immortalIndustry / immortalJade / immortalDiscovery / energyDrive / energyCore）。叠加 D1 的仓容闸门，后期「可见内容多但一次只能推进一条」。

建议方向：在末端 3~4 个节点处引入分叉（像猫国 `electronics` 一次放行 5 个工坊升级 + 3 个后续科技），让后期玩家有并行投资选择。

## 5. 节奏是否合理：结论

**结构是健康的，但节奏分布不合理。**

健康的部分：
1. 双层承重（境界倍率 × 仙缘/道果）比猫国单一的 paragon 更有纵深；
2. 仓储「线性容量 × 指数造价」与猫国同型，且比例区间（1.14~1.35 仓储 / 1.55~1.70 人口）比猫国（1.15 / 1.75 / 2.5）更温和，玩家的扩容体验更平滑；
3. 工序链（原理→工艺→精研）与猫国「科技开门禁、工坊兑现」的分工一致，154 条内容量足够支撑多轮重置；
4. 破境概率 + 身死 + 退境，是猫国没有的风险层，给后期提供了决策（护道、香火、退境容忍度）。

不合理的部分：
1. **节奏重心错位**：36% 的首轮时间花在「筑基→金丹」的等待上，而真正需要决策的后期（炼虚、合体）各只要 0.7~1.7 h。猫国的曲线是「前 1/3 学基础、中 1/3 铺产业、后 1/3 换资源层级」，本作是「前期陡坡、后期台阶」。
2. **人口无代价**：猫国的人口是必须精算的资源（口粮 85%、幸福度税），本作的人口是「住得下就堆」，导致后期 128 矿工的灵石副产成为硬通货瓶颈，玩家却无法用人口解决。
3. **容量与需求错配**：灵木过剩与灵石/灵机短缺同时存在，说明仓储份额与实际需求不同步。

以上为旧版本诊断。当前优先级见 [开发路线](ROADMAP.md)；D1、D4与D6已落地，D2规模成本已实现，不再采用增加灵石供给的建议。

## 6. 本次分析的边界

1. 本作实测为**固定种子、无事件、每 5 秒决策的单样本**（`audit:pacing`），文档本身声明不能当作平均耗时或上限。玩家真实节奏（离线挂机、不主动决策）会更慢。
2. 旧版本首飞报告已由当前阶段审计取代，不可混合不同版本、策略与成功率处理的耗时；当前完整首飞仍待重测。
3. 猫国本地副本比官方 master 旧，个别解锁关系（mine/quarry）建议以官方仓库复核。
4. 未测量项：仙缘 ≥1 轮后的重置节奏、道果加成后的飞升曲线、离线挂机（不上线）的实际推进速度 —— 这三项都会显著改变上面的结论，建议下一步针对它们补测。
5. 2026-10-16（v0.383）后本文数值已过时的部分：香火每座仓位 80/120 → 240、库房灵石 250 → 500（§4 D4 已按 [ROADMAP.md](ROADMAP.md) 已完成范围落地）；新增「宗门外交」可选模块（§8.4 的富余出口缺口部分解决：3 宗固定汇率 + 机缘骰，见 [modules/diplomacy](../src/modules/diplomacy/data.js)），猫国 8 种族贸易对照依然成立但不再是「一个都没有」。

## 8. 第二轮对照（2026-10-16）：数值结构之外的系统

第一轮（§1~§7）只对照了时间、仓容、人力、研究、重置层与节奏实测。本轮补齐剩余系统：工坊升级、信仰层、贸易/外交、空间/时间、挑战、领袖/天赋、成就、离线。所有猫国数字仍取自 `cat-zh-master/` 源码。

### 8.1 推进节点总量：§2.4 的口径需要修正

§2.4 曾用「猫国 59 科技」对照「本作 154 节点」，这是**错位的**：猫国与研究同型的其实是**工坊升级**（`workshop.js`，137 条，逐条买断、永久生效、串成长链），科学只负责开门禁。修正后的总量对照：

| 节点类别 | 猫国 | 条数 | 本作 | 条数 |
| --- | --- | ---: | --- | ---: |
| 门禁研究 | 科学（`science.js`） | 59 | 研究（`upgrades.js` 78 + 猎杀 2） | 80 |
| 增益层 | **工坊升级**（`workshop.js:7-1956`） | **137** | 技艺/法宝（`techniques.js` 70 + 猎杀 4） | 74 |
| 合成配方 | 工坊合成（`workshop.js:1962-2176`） | 21 | 炼制（`crafts.js` 22 + 猎杀 1） | 23 |
| 信仰建筑/升级 | 宗教升级 10 + 金字塔 10 + 超越 10（`religion.js`） | 30 | 香火线（建筑 3 + 技艺若干） | ≈6 |
| 政策（重置货币购买） | 45 项 | 45 | 仙缘直接按比例结算，无商店 | 0 |
| 空间建筑 | 24 座（`space.js`） | 24 | 阵道/奇观并入 52 座建筑 | — |
| 时间锻造/虚空 | 7 + 6（`time.js`） | 13 | 无 | 0 |
| **合计（可比口径）** | **≈284** | | **≈183** | |

结论从「本作内容多 2.6 倍」反转为「**猫国推进节点约为本作的 1.5 倍**」。差距集中在三块：工坊升级的**每资源专精深度**、信仰层的**独立货币纵深**、空间/时间的**后期开新页**。

### 8.2 工坊升级 ↔ 技艺：结构同型，密度差一半

| | 猫国工坊升级 | 本作技艺/法宝 |
| --- | --- | --- |
| 条数 | 137 + 4 斑马升级 | 74 |
| 货币 | science / 各类资源 | 灵机 + 材料 |
| 单资源专精深度 | 木 11 条（斧 6 + 锯 5，各 +15%~+70%）、人力 8、油 3 | 靠 `craftBonusByResource` 通配，单资源专属条目少 |
| 合成放大 | `craftRatio` + 工厂分层（tier1~5 各 ×2~×10，`workshop.js:1245-1316`） | `craftBonus` + 工位容量（`industry.js` 6 工位、三模式） |

两边同型（买断式永久增益、串链推进），但猫国给每种资源做了一条「斧→锯」式的**纵向专精线**，使后期每多买一条都有可感知的单资源变化；本作的增益更偏全局比例，后期体感会被稀释。这是内容量问题而非数值问题，与 §8.1 的 1.5× 差距互为印证。

### 8.3 信仰层：猫国的第二货币纵深，本作只有浅层香火

猫国的信仰是一个**跨重置的独立货币体系**：

- 产：牧师 0.0015 faith/tick（`village.js:96`）+ 寺庙加成；
- 花：10 条宗教升级（`religion.js:533-715`，`priceRatio 2.5`，按累计信仰 150→125,000 逐层解锁）；
- 深：「超越」层把累计信仰折算成信仰倍率（`religion.js:1048` `_getTranscendTotalPrice`），10 条超越升级用**遗物**购买（`religion.js:717-911`，tier 1~25 门槛）；
- 兑现：太阳革命按当前信仰给最高 +10% 全局产出（`religion.js:959`），**跨重置保留**。

本作的香火：香使 0.02/s（`jobs.js:61-68`）、山门 80/座 + 香火鼎 120/座（`buildings.js:515,526`）、出口是破境辅助（香火祈愿 +1~3 百分点，`realms.js:128-170`）与渡劫「立愿应劫」（faith 20,000，+6% 且身死 −10 百分点，`realms.js:176`），外加零星研究/技艺费用与灵符配方（`crafts.js:189` faith 200）。

差距：本作的香火**只有「护道」一个主出口、不跨轮回**，而猫国信仰有「宗教升级→超越层级→遗物→太阳革命」四级纵深。香火与本作「破境概率 + 身死」的风险层耦合得不错（这是特色），但作为资源本身纵深约差一个数量级。

### 8.4 贸易/外交 ↔ 事件 + 猎杀：本作缺「富余资源出口」

猫国外交（`diplomacy.js:13-202`）：8 个种族各收一种资源，概率掉落稀缺品——**蓝图固定 10%**（`diplomacy.js:504-507`）、香料 35% + 1%/使馆（`496-502`）、斑马钛 15% + 0.35%/船（`509-514`）。种族按文化/船队/核裂变解锁（`267-319`）。它的核心功能是**把过剩资源换成卡脖子的稀缺资源**，是后期产能的泄洪口。

本作没有常驻贸易系统。最接近的两个：

- 商队是一次性选择事件（`events.js` caravan），不是持续机制；
- 猎杀模块（`modules/hunting/`）：只有 1 个猎场（山麓，筑基开放）、1~5 人队、120 s、消耗专属的「猎备」而非过剩资源（`data.js:15-50`），产出皮/骨是**新增材料**而非富余转化。

结合 §3.3 的实测（72 h 灵木占用 4.5%、灵草/香火贴顶），本作后期**富余与短缺并存却无转化通道**——这正是猫国贸易解决的问题。

### 8.5 后期开页：空间/时间/虚空 ↔ 境界风险

猫国后期靠**开新资源维度**续命：13 次太空任务 + 12 星球 + 24 座太空建筑（`space.js`），时间水晶/通量/虚空（`time.js` 7 条时间锻造 + 6 条虚空升级，时空球 `buildings.js:1812-1833`），每次重置引入新机制（悖论、碎裂、暗未来）。

本作后期不开页，而是把深度压在**同一页的风险管理**上：破境概率 0.20→0.10、身死 15%~20%、退境（炼虚起）、三选一辅助（`realms.js:105-178`）。两条路线的取舍是清楚的：猫国卖内容广度，本作卖决策强度。**但注意一个结构事实**：猫国的新页同时承担了「富余资源出口」（太空消耗钛/铀/反物质）与「推进节点增量」（§8.1 的 37 条），本作这两件事目前都没有承接者——这是 §9 的 D7。

### 8.6 挑战模式：猫国 9 项，本作无对应物

猫国有 9 个可重复挑战（`challenges.js:12-292`）：钢铁意志、凛冬将至、无政府、能源、无神论、千年、黑天、和平主义、后启示录，完成各给永久小加成（如凛冬 +5% 春季猫草），重置时生效并清时空球。本作的轮回/飞升是**推进**而非**挑战**，没有任何「自愿受限换加成」的玩法。这直接影响多周目重玩动机：本作第二周目与第一周目的规则完全相同，只有仙缘数值不同。

### 8.7 领袖 ↔ 天赋：同目的、不同粒度

| | 猫国领袖 | 本作战天赋 |
| --- | --- | --- |
| 粒度 | 全宗 1 只 | 每名弟子独立 |
| 变化来源 | 7 特性随机/指派（`village.js:986-1010`） | 出生 0/1/2 天赋按 70/25/5%（`talents.js:4`），破境 10% 出新、40% 升级（`talents.js:2-6`） |
| 加成 | 本职产出 ×(rank+1)/1.4（`village.js:580-586`）+ 特性系数（工程师 +5% 合成等） | 修为 +10%~+90%、破境 +2~+14 百分点，4 阶 × 8 类共 32 条 |
| 消耗 | 无（任命制） | 无（掷骰制，`talentRandom` LCG） |

本作粒度更细、上限更高，方向是对的；两者都不构成数值差距。

### 8.8 成就与离线：两项持平

- **成就**：猫国 27 成就 + 12 徽章，**纯装饰无任何加成**（全库检索无效果挂钩）；本作 25 成就，加成旋钮 `ACHIEVEMENT_REWARD = 0` 显式关闭（`achievements.js:12`，注释保留 +2%/个的设计意图）。**两边现状完全一致**，且本作留了恢复开关，这一项无差距。
- **离线**：猫国**没有离线产出**（通量只在关闭时积累、且需时间锻造，用途是碎裂/加速而非生产，`time.js:75-100`）；本作 8 h 基础上限（`config.js:14`），两项研究各 +8 h 至 24 h（`upgrades.js` longBreath/breathArt），逐秒模拟、自动炼制生效、事件不触发（`simulation.js:256`）。这是移动端时代的设计差异，不是待修差距——但它解释了为什么本作「前期断层」对真实玩家比 §3 的实测更痛：玩家关掉游戏后进度仍在走，等待段被离线摊薄，而决策段被压缩。

## 9. 第二轮差距清单（D6~D9）

按对真实体验的影响排序。与 §4 的 D1~D5 不同，这四条**都是内容/机制缺口，不是数值失衡**，无法靠调数字解决。

### D6 富余资源无出口（对应 §8.4，最高优先）

§3.3 实测已证明「灵木 4.5% 闲、灵草/香火贴顶」并存。猫国用贸易（概率换稀缺品）与太空（消耗钛/铀）泄洪，本作的猎杀模块不消化富余（消耗专属猎备）。建议方向：给猎杀或新贸易机制接入**富余资源定价**（例如用灵木/矿石折算猎备或商队货款），让「过剩」变成「购买力」。

### D7 信仰纵深不足（对应 §8.3）

香火目前只服务护道。建议方向二选一：其一，沿现有风险层加深（香火积累降低身死/退境的永久词条）；其二，学猫国做跨轮回沉淀（香火→愿力，飞升时按比例结算进仙缘），让香火成为第二条重置货币。**不建议**照搬太阳革命式的全局产出加成——本作已有境界倍率 × 仙缘 × 道果三层乘区，再加全局乘数只会稀释。

### D8 无挑战模式，多周目规则恒定（对应 §8.6）

轮回/飞升只有数值差异。猫国的挑战证明「自愿受限 + 永久小加成」是低成本高回报的重玩引擎。本作现成的可限制项很多（禁事件、禁离线、锁定境界倍率、只许人力生产），可作为轮回时的可选誓约，完成给道果或仙缘加成。

### D9 单资源专精线稀薄（对应 §8.2）

137 : 74 的差距里，最扎眼的是猫国每种资源有一条纵向专精线（木 11 条）。本作的 `craftBonusByResource` 是通配机制，但缺少「灵木从斧头一路升到灵纹锯」的推进感。此项与 D5（后期分叉）可以合并处理：在技艺树末端给 2~3 种主力资源各补一条 3~4 节的专精链。

## 10. 第二轮结论

1. **修正第一轮的一个误判**（§8.1）：猫国的推进节点约 284 条，是本作 183 条的 1.5 倍。第一轮「本作内容多 2.6 倍」的结论是把猫国的门禁层当成了全部。
2. 数值结构层面（第一轮的结论）不变：仓储、涨价率、乘区设计都健康，节奏问题已定位并修掉 D1。
3. 第二轮发现的都是**机制缺口**：富余无出口（D6）、信仰浅（D7）、无挑战（D8）、专精线稀（D9）。它们的共同点是「后期产能无处安放」——猫国用贸易 + 太空 + 信仰 + 挑战四个池子承接，本作目前一个都没有。
4. 建议的落地顺序：**D6 → D7 → D8 → D9**。D6 直接消解 §3.3 实测可见的资源错配，且是 D7（香火若做富余沉淀会用到同一通道）的前置。

本轮边界：未重跑 `audit:pacing`（D6~D9 不影响 72 h 节奏曲线）；猫国信仰跨重置细节（apocrypha 结算）以 `religion.js:1010-1050` 为准，本地副本与官方若有出入以官方为据。

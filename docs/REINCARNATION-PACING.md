# 转世与直飞：补测及修改方案

日期：2026-10-18；游戏v0.41.0。顶部记录用户确认方向、已实施机制及首转校准，后文保留历史补测与方案。用户已授权直接实施：顶部新机制已写入工作区，首转门槛5个种子为3.33～4.36天，种子2的0／1／2次转世累计首飞分别为27.26／16.39／12.40天，三条路线均真实结算，见[P1实施](P1-IMPLEMENTATION.md)；历史样本不代表新机制节奏。

## 最新方向：加工备料与仙缘成长

用户已明确：首次主动转世目标保持现实3～5天；转世的主要能力就是全局生产及仓储加成；移除加工品上限，并进一步削减境界全局产出，将成长重心转移到仙缘。飞升始终不检查转世次数。本轮不扩展仙缘购买型天赋树或永久折扣树。

### 资源范围

取消仓容的23项稳定加工品：木板、道札、道论、阵图、玄钢、阵基、混灵土、玄铁混灵土、秘银、玄金、晶银、灵液、灵晶、仙草、丹药、凝元丹、九转丹、符箓、灵符、法器、灵器、灵宝、飞升阵印。

基础原料、灵气、灵机、香火保留仓容；信符保持独立容量；兽皮／兽骨仍作为猎杀原料。灵气分子、正负灵子、灵能与仙灵力属于设施容纳的粒子／能量体系，保留容量及已有逸散规则。不能仅按“存在制作配方”分类，否则会把催生灵木、点石成灵的基础原料也误设为无限仓容。

不限仓容仍需材料、配方、研究和加工能力；不免费产出，不代表瞬发制作无限份，也不改变转世时加工品随本世清空的规则。库存本身始终是有限Decimal金额，只有派生仓容可以使用无上限哨兵。

### 必须同步处理的调整

1. **境界倍率拆分**：`REALMS.mult`还用于个体产出权重、口粮、招募、逐出费与加工节拍。不能直接整列减半，导致个体与宗门产出被重复削减。宗门全局生产单独缩放；口粮基准同步核对，避免生产降了而养人费用原样上涨。招募与逐出费展示、参照机器人口粮估算使用同一新口径。个人成长与加工节拍分别评估，不混作全局生产奖励。
2. **万民归心跟随新基准**：只强化削减后的境界额外生产奖励，避免永久修持把旧境界高倍率重新加回来。仙缘、道果、境界及修持乘区分别展示。
3. **自动加工的目标与保留**：不限仓容后不能再依赖“满仓停产”保护原料。库存目标应在首次自动炼制时可用，消费后补回，保留0代表不限的主动选择。凝灵诀与普通自动加工共用目标／保留规则；不顺便取消工位、动力、冷却与效率专精。
4. **百分比保留不能乘无限仓容**：改动前`autoCraftReserve`直接按仓容乘比例；改为无限后会得到无限保留量，零比例还可能出现`∞×0`。无上限加工品使用有限的数量保留；旧绝对目标与保留量保留，旧百分比保护需要有限转换或安全的迁移安排，不能静默放开旧档受保护库存。
5. **专仓重新定位**：改动前法藏只增加加工品仓容，取消后会完全失去作用，必须同步重做；优先承接仍有限的灵气／香火／灵子仓储，而不是再叠加工乘区。药藏剩余灵草仓容、材料库／玄库剩余原料仓容也要重评性价比。旧建筑数量保留，新效果与旧说明一起更新，不能只把旧收益删除。
6. **费用重新校准**：上一轮360000化神灵机、6000000渡劫灵机及高额阵印费，是在加工品有仓容的前提下试出的。先在新机制下测清首转瓶颈，再回调研究与破境费用，不继续按目标天数叠加涨价；尤其避免所有阶段最后只剩灵机仓容一条门槛。至少一条扩仓链应能用分批积累的加工建材继续推进，不以加工品仓容反锁仓库。
7. **工具及兼容**：可达性审计不能再要求所有可建仓库达到有限最大数量；无上限加工建材可能让扩仓本身没有有限闭包。改为核对阶段来源、单份加工投入及必要容量是否覆盖目标，不能把迭代预算截止当成不可达。界面和报告明确标注不限量；不把无上限当0，不追扣旧库存，不重算旧仙缘数量。

新一轮先验证无上限加工的在线／离线、自动目标、保留及旧档，再做首转阶段校准，阶段范围成立后再跑0／1次转世累计首飞及2次转世控制。多次转世另查增长递减，不能靠增加冷却或转世次数门槛解决。原有每日16小时可操作、8小时睡眠、150秒集中操作是测量工作假设，不是已确认的真人上线总时长。

旧候选的首次转世中位4天、直飞14.18天、一次转世累计10.44天保留为历史对照；移除加工品上限及修改乘区后必须重建基线，不能沿用旧结果宣称新机制达标。

## 口径与边界

转世在化神期开放，只结仙缘；飞升需要渡劫期，另结道果。用户目标为首次主动转世现实3～5天，之后通过转世成长缩短最终飞升的累计时间，同时保留不转世直飞路线。此前把首次飞升误称为首次转世的结论已撤回。

本轮沿用v4作息：从零永久积累开局，每150秒集中执行至多12个参照机器人步骤，每日前16小时在线、后8小时睡眠离线；自然突破、完整护道、有限D7投资、阶段产业、参照分工及ready预留，启用事件。不是每天只玩几小时，也不是对真人操作负担的验证。

v5新增两种一次化神转世策略：

- **立即转世**：首次到化神就按真实规则结算，清空本世进度后重建，不先证心。
- **先兑现香火**：到化神后，同次操作先执行一次原有限香火策略，能证心、能购买永久修持就真实扣费完成，然后转世。不等待额外资源，不自动把剩余香火或愿力兑换为永久收益。

两种策略均不重启作息、不清零累计耗时、不重置随机流。转世、飞升、身死分别记账；最后一世时间单列，不能拿它代替累计时间。观察上限168小时，预算或观察截止保留。额外重走境界会消耗随机抽样，同种子不代表两条路线被强制安排相同突破结果。

## 建议修改顺序

当前问题有两层：化神约一天就开放，早于用户希望的3～5天；随后仅再用约一天多便可直接飞升，留给仙缘加速回本的后半段太短。只提高仙缘收益仍会让直飞只有两天左右，只拉高全部费用又会拖累开局和每次重建。

### 1. 分段延长，保留前几小时的推进

优先在`src/data/realms.js`调整已有境界的产业备料需求；不设纯等待时间，不增加转世次数判断。

- 凡体至金丹先保留现有主线，避免把开局与每次重建都改成长时间等待。
- 金丹至元婴、元婴至化神承担首次转世前的主要扩产投入，围绕灵机、道札、灵液、灵晶、法器和阵基调整。目标是自然经营下首次到化神约3～5天。
- 化神之后逐段提高既有研究与产业积累的份量，重点为炼虚／合体的灵机、灵晶与法器链，以及大乘／渡劫的灵器、合金、灵宝和阵印链。主要新增时长放在这一段，让下一世的仙缘加速有足够回收空间。
- 暂不把灵气费用同步成倍放大，不提高口粮与失败死亡率；仓容需要逐笔验证能通过正常建设覆盖。已有制作可瞬发，单纯调低自动加工速度不能解决手动直飞偏快的问题。

不把“材料费乘几倍”等同于“耗时乘几倍”：扩产、扩仓、事件、护道与重修都会改变曲线。本轮不提供伪精确的最终价格。

### 2. 先测新曲线，再决定是否加仙缘

先只调整上述分段需求，保留现有仙缘公式及每点价值，重测0转世与1转世的配对累计首飞。更长的第一世和更多研究投入可能自然提高仙缘收益，但公式只统计实际入库灵机，满仓截断不计入；不能假定在线更久必然拿到更多仙缘。

若转世后的累计首飞仍无明显优势，再单独试算“仙缘结算倍率×2”，作为实验候选，不直接写入正式规则。优先保持每点仙缘价值、既有仙缘余额及软上限不变，在共享结算入口引入一个可审计系数；飞升同样使用，身死仍为正常结算的一半，避免改变三种结算的相对关系。新增字段或库存补偿不在首轮方案中。

不优先加强D7来解决转世回报：道心修持在不转世的本世也能生效，并非主动转世专享收益。

### 3. 提高决策可见性

在现有转世预览中展示“当前仙缘乘区→本次转世后乘区”和仓储变化；继续明确本世愿力、仪轨与研究清空，道心和永久修持保留。对可当场证心的未处理愿力给出可操作提示，不替玩家自动证心，也不虚构预计节省天数。

## J. 第二种驱动：阴阳分灵与湮灭 —— **已实施（方案 A）**

实施记录见 [BALANCE.md](./BALANCE.md)。剩下的两件事：

1. **"造价超过玩家实际上限"这一类，目前还只能靠推演发现**。
   已经做的：把"仓储定点"断言从破境扩展到**建筑与学术花费**。
   但实测发现它量的是**理论上限**（模型只买仓储、不花别的钱），
   比参照玩家实际堆到的高 —— 把分灵阵改回 25 万，它**不会**报红。
   要抓这一类（两次翻车：分灵阵 25 万 vs 玩家上限 22.8 万；《湮灭法》30 万感悟 vs 26.8 万），
   需要一个**推演型**检查：跑 72~96 小时，找出"已解锁、却到结束时仍买不起"的建筑与研究。
   难点是**误报**：48 小时还没盖够仓储的东西会被误判成买不起。
   两个候选做法：① 只报"已解锁 + 有前置 + 仍未建造 + 造价高于当时上限"；
   ② 给参照玩家补一条"该堆仓储"的意愿（它现在只按固定优先级买）。
2. **决定湮灭炉是否吃灵宝** —— 要吃就是接上进阶品链，改一行造价。

原设计稿（含数值草案与猫国反应堆对照）见 [RESEARCH.md](./RESEARCH.md) §13。

## I. 成就奖励重新设计（用户已点名要做）

成就现在只记录"做过什么"，`ACHIEVEMENT_REWARD = 0`，不再给全局加成。重新设计时的方向：

- **给规则**：例如"首次转世后解锁某建筑 / 某配方"、"达成某成就后开放一条玩法分支"；
- **给解锁**：纪事条目、称号、界面偏好、宗门志的额外章节；
- **给里程碑式的短时增益**：一次性的 buff（而非永久叠乘），避免"满成就 +50%"这种无脑成长线；
- 好处：成就回到"记录与引导"的本职，不再和仙缘/道果抢"全局乘区"的生态位。

恢复方式：把 `src/data/achievements.js` 里的 `ACHIEVEMENT_REWARD` 改回非零即可，
引擎与界面（成就页、加成拆解）都是条件分支，会自动跟着走。

## B. 把循环测量做成常驻工具（小）

「每次到化神期就转世」的循环测量（5 轮 45.9 小时、仙缘 125、每轮耗时 16.2 → 6.7 小时）
现在是临时脚本，值得做成 `npm run loop`，带两个参数：**转世门槛**与**轮数**。
它回答的是「刷轮次到底能提速多少」，和 `npm run balance` 是互补的。

## C. 道果的「内容层」（中）

现在道果只给数字。猫国的经验是**上层要解锁新内容**（时间水晶 → 虚空），否则玩家容易停在低层。
做法：2~3 个**需要道果**的修真 / 技艺节点（例如「道果 ≥ 1 才能参悟的《太一》」），
或一座需要道果的终局建筑。验证：断言「首枚道果之前不可参悟」+ 端到端「参悟后效果生效」。

## D. 境界三阶段（大，已规划未实施）

原方案：破境的「货币」按阶段迁移，让玩家注意力跟着走。

| 阶段 | 境界 | 阶段货币 | 闸门形态 |
| --- | --- | --- | --- |
| Ⅰ 立基 | 凡体 ~ 筑基期 | **灵石** | 一次性造价（铸币 0.1~0.7/秒、上限 870~2,870，存得住） |
| Ⅱ 炼器 | 金丹期 ~ 炼虚期 | **玄铁 + 灵草** | **持续消耗为主**（产量 28~250/秒 > 上限，攒不住）+ 中等造价 |
| Ⅲ 结丹 | 合体期 ~ 渡劫期 | **丹药 + 符箓 + 法器** | 一次性造价（成品慢、存得住） |

实测依据与逐档草案见当次讨论记录；关键约束是**阶段 Ⅱ 只能用持续消耗**（玄铁/灵草产量远超上限，
一次性造价不可能成为闸门）。实施要动 `realms.js`（10 档破境造价）+ 五座建筑的玄铁/灵草维护费。

## E. 灵木 / 灵草的第二个合成产物（中）

上一轮的教训（写在 BALANCE《灵木的精加工产物：木板》）：**一次性建材追不上指数产量** ——
12 小时做出 6,650 方木板，而加大木板需求后**推演轨迹一字不差**（木板从来不是瓶颈）。
所以新产物必须带**持续去处**（维护费，或「A → B」的持续转换）。

灵草目前仍然紧缺（长期归零），要动它就得同步看丹药线（`npm run audit -- herb 12`）。
